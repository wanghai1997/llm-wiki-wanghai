# Skill: 深度研究与缺口填补 (Deep Research)

## 触发条件

- lint-and-repair 检查到知识缺口
- 用户在查询中发现 Wiki 无法回答的问题
- `state.md` 的“知识缺口”区域有超过 7 天未处理的条目
- 用户明确说“深入研究 [主题]”、“填补 [某领域] 的空白”

## 执行流程

### 1. 缺口确认

- 从 `state.md` 或 lint 报告中提取知识缺口清单
- 与用户确认优先级：“当前有 3 个知识缺口，请选择要研究的对象：[列表]”

### 2. 外部搜索

- 使用 Kimi 模型的联网搜索能力（如 API 支持）
- 或调用 Tavily API（如已单独配置 Key，告知 Claude 在命令中使用）
- 搜索策略：
  - 组合同义词与关联概念（如“有限理性 + 行为经济学 + 最新实证”）
  - 限制来源为高置信度领域（如顶级期刊、学术数据库）
  - 至少获取 3-5 篇独立文章

### 3. 结果归档

- 将网页搜索结果转为 Markdown，保存为 `raw/inbox/search_[主题]_YYYY-MM-DD.md`
- 自动触发 ingest-inbox skill 处理该文件
- 摄入完成后，更新 `state.md` 中将该缺口标记为 `[已填补 YYYY-MM-DD]`

### 4. 迭代追问

- 如果新摄入的内容又产生了新缺口，询问用户是否继续深入（每次迭代需用户确认）
