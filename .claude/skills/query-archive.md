# Skill: 查询与归档 (Query & Archive)

## 触发条件

- 用户针对 Wiki 内容提问
- 用户说“根据 Wiki 回答...”、“总结...”、“比较...”

## 查询流程

1. 读取 `wiki/index.md` 和 `state.md` 了解全局
2. 使用 Obsidian MCP 搜索（如可用）定位最相关的 5-10 个页面
3. 读取命中的页面（优先读取 `status: foundation` 和 `consolidated` 的页面）
4. 综合回答，引用格式：`（来源：[[页面名]]）`

## 产出形式

根据问题类型，产出可采取多种格式：

- 总结型问题 → Markdown 要点列表
- 比较型问题 → Markdown 对照表格
- 关系型问题 → Mermaid 图表（在 Obsidian 中可渲染）
- 数据型问题 → 提取 YAML Front Matter 数据，必要时生成 matplotlib 图表

## 归档判断

回答完成后，评估以下条件：

- [ ] 回答是否产生了 Wiki 中没有的新综合观点？
- [ ] 回答是否澄清了原本模糊的矛盾关系？
- [ ] 回答是否建立了新的跨概念连接？

如果任一条件满足，主动建议：

> “这次讨论中产生了 [具体内容]，建议归档到 Wiki 的 [建议页面路径]。是否同意归档？”

用户同意后：

1. 创建或更新对应 Wiki 页面
2. 更新 `index.md` 和 `log.md`
3. 如有跨概念连接，确保双向 [[Wikilinks]] 已建立
