# 极致协同设计

## 命题（来自 [[黄仁勋]]）

> "加速计算不是芯片问题，也不是系统问题，其完整表述应为应用加速。"

[[NVIDIA]] 据此将自身定位为**全球第一家垂直整合、横向开放**的公司：自研架构 / 系统 / 软件栈，但允许整合进任何合作伙伴平台。

## 极致协同设计的关键体现

- **算法 × 硬件**：NVFP4 张量核心 + Dynamo 推理调度 + TensorRT-LLM，使推理性能远超摩尔定律的 1.5×（来源声称达到 35×，Semi Analysis Dylan Patel 评注"实际 50×"）。
- **系统级**：NVLink 从 8 路扩展到 NVLink 72 / 144 / 576；Kyber 机架将 144 GPU 组成单一 NVLink 域。
- **网络级**：Spectrum X 共封装光学（CPO）交换机量产；铜缆 + 光纤 + CPO 三条扩展路线并行。
- **跨厂商协同**：与 [[Groq]] 形成非对称分离推理（Prefill 在 [[Vera Rubin]]，Decode 在 Groq，借助以太网紧密耦合）。
- **跨域协同**：通过 [[Omniverse]] / NVIDIA DSX 让机架级机械、热学、电气、网络在虚拟世界协同设计；声称将能源利用效率提升约 2×。

## 实证主张

- 同一座 1 GW 数据中心，2 年内 Token 生成速率从 2,200 万/秒 → 7 亿/秒，**350×**（同期摩尔定律仅 1.5×）。
- Fireworks 在 NVIDIA 升级软件后平均 Token 速度从 ~700/秒 → ~5,000/秒（**~7×**）。
- 1 GW 工厂中，Grace Blackwell 较 Hopper 在最高价值层提升 **35× 吞吐量**，多产生 ~5× 收入（按四档功率均分估算）。

## 反面论点与数据空白

- **数据非中立来源**：所有性能数字均出自 NVIDIA 自身或 Semi Analysis（与 NVIDIA 关系紧密）。需以 MLPerf、SPEC、第三方云成本对比作交叉验证。
- **协同设计 = 锁定客户**：极致协同设计的另一面是**强供应商锁定**，长期 TCO 是否真低存疑。
- **"35× / 350× 提升"对比基线**：与 H200 / Hopper 比较时是否使用同等精度、相同模型、相同上下文长度未明确披露。
- **跨厂商协同的工程稳定性**：[[Groq]] 与 [[Vera Rubin]] 通过以太网耦合，对网络延迟、抖动的容忍度未知；非对称推理在生产环境的故障域如何切分未公开。
- **Omniverse "能源效率 2×"**为保守估计但缺方法学。
- **CPO 量产细节**：声称首款量产，但未披露良率、价格、生命周期。
