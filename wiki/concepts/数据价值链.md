# 数据价值链

**数据价值链**（Data Value Chain）是描述数据从产生到最终创造价值的全过程的分析框架。作为数字经济的核心基础设施概念，连接了数据要素化、数据定价、数据交易等政策前沿问题。

## 核心环节

```
数据产生 → 数据采集 → 数据存储/管理 → 数据分析/加工 → 数据产品/应用 → 价值实现
```

| 环节 | 核心活动 | 价值增量 |
|------|---------|---------|
| 产生 | 设备/传感器/用户行为产生原始数据 | 无——原始数据如原油，未经提炼无直接价值 |
| 采集 | 抓取、日志、API、IoT 汇聚 | 低——数据从分散到集中 |
| 存储/管理 | 清洗、标注、分类、数据库化 | 中——可用性创建 |
| 分析/加工 | 统计建模、ML 训练、可视化 | 高——模式识别、预测能力 |
| 产品/应用 | 嵌入决策/产品/服务 | 最高——数据转化为行动 |

## 中国政策背景

2020 年，中国将**数据**列为第五大生产要素（土地、劳动力、资本、技术、数据），数据要素市场建设成为数字经济核心政策议程。但数据的价值定价、交易机制、产权界定仍处于极早期阶段。

## 反面论点与数据空白

- **数据价值链的线性模型可能过时**：数据价值的产生往往是循环/网络化的（数据→模型→更多数据→更好模型），线性链条不能准确描述价值创造过程
- **隐私与价值的冲突**：最"有价值"的数据（个人行为、健康、金融）恰好也是隐私保护要求最高的数据——数据价值的释放与隐私保护存在根本性张力
