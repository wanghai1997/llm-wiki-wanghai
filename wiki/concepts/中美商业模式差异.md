# 中美商业模式差异

[[琦谈天下]] 将商业模式分析从微观企业扩展至宏观经济体比较，核心洞见：**中美产业分布在微笑曲线的不同位置，决定了净现金回报的能力差异。**

## 微笑曲线分布

```
   附加值
     ↑
     │  ￣￣￣￣￣￣￣
     │  │ 美国     │           │ 美国 │
     │  │ (品牌)   │           │(设计)│
     │  │          │           │      │
     │  │    ┌─────┼───────────┼────┐ │
     │  │    │     │  中国     │    │ │
     │  └────┘     │ (制造)    │    └─┘
     │             │           │
     └─────────────┼───────────┼─────────→ 产业链
                  上游        下游
```

- **美国**：集中于微笑曲线两端——互联网平台操作系统（微软/苹果/谷歌）、品牌（耐克/麦当劳/迪士尼）、医药研发（礼来/诺和诺德）
- **中国**：集中于微笑曲线中段——制造业，资产更重、净现金积累更少、利润率更低

## A股 vs 美股：结构差异

| 指标 | A股（全部） | 美股（全部） | 年份 |
|------|-----------|------------|------|
| 融资-分红/回购 | −1.31 万亿元净流出 | +10.83 万亿美元净回报 | 2013-2022 |
| 资本支出/折旧摊销 | 206% | 122% | 2015-2022 均值 |
| 营收年增速 | 10.5% | 9.0% | 2015-2022 均值 |
| 制造业增加值/GDP | 27.7% | 11.0% | 2022 |

差异根源：A股制造业占比远高于美股。制造业每一份边际收入都需要采购固定比例的原材料、投入新增资本支出→盈利能力和自由现金流弱于平台/品牌/医药研发→分红和回购能力弱。

正面信号：2021 和 2022 年 A股已连续两年实现净现金回报（分别为 2,208 亿和 5,596 亿元）。

## 两个宏观现象的商业化解

琦谈的框架解释了之前两篇文章中提出的表观悖论：

- **中国快递价格低但物流费用/GDP 高于美国**：中国制造业增加值绝对量和占比远超美国，有形商品制造和销售自然需要比服务业更多的物流
- **美国 GDP 第一但用电量仅为中国一半**：美国经济以信息服务业为主，中国以制造业为主——单位 GDP 的电力消耗天然不同

## 产业竞争前景

琦谈的定性判断：

- **美国优势**：互联网内容（搜索/社交）和操作系统方面的平台优势在相当长时间内难以被打破。TikTok 是唯一的例外（算法驱动内容的突破）
- **中国优势**：制造业综合优势可望维持甚至扩大——完善的供应链、海量 STEM 毕业生（年 470 万 vs 美国 57 万）、持续的工艺改进迭代
- **各自守势**：美国制造业回流因缺乏劳动力/供应链的比较优势，长期难持续（巴斯夏的"看得见的后果 vs 推测到的后果"）；中国突破高端材料/精密零部件/品牌产品的概率更高
- **受挤压者**：日、韩、德等制造业占 GDP 比例较高的国家可能受到中国制造业升级的更大压力

## 反面论点与数据空白

- **2023 年后数据**：AI 投资周期可能导致美国科技公司资本支出飙升，改变净现金回报格局
- **STEM 数量的质量折扣**：470 万数量优势的质量调整——论文→产业创新→商业成功的转化效率在中国可能更低
- **台海不确定性**：琦谈自己也指出台海局势的不确定性是企业投资的非经济外生负面因素——这一因素的权重可能在框架中被低估
