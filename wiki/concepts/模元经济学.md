# 模元经济学

**模元经济学**是 [[李刚]] 与 [[常斌]]（2026）提出的概念——将 Token（词元）作为大模型时代的基本分析单元，研究其交易定价、成本收益和流通消费机制的经济学框架。是 [[AI政治经济学分析框架]] 研究议程的起手式。

## 为何需要"模元"而非"词元"

原文指出：随着多模态模型、世界模型的发展，Token 正在将结构化数据和文本、图片、视频等非结构化数据统一——因此 **"模元"（模型之元）比"词元"更准确**。Token 在经济特性上虽然仍有较大的异质性，但与 Byte 相比差异性已大为收敛，可以作为稳定的研究对象进行分析。

## 三大研究课题

| 课题 | 核心问题 |
|------|---------|
| Token 交易定价 | 不同模态 Token 的相对价格如何形成？是否收敛至统一的 Token 定价公式？ |
| Token 成本收益 | 推理 Token 的边际成本曲线形状？规模经济是否存在上限？ |
| Token 流通与消费 | Token 在 AI 产业链中的"货币"属性——流向、沉淀、乘数效应？ |

## 与 Token 工厂经济学的区别

[[Token工厂经济学]] 聚焦于 **算力供给侧的产业组织**（GPU → 推理基础设施 → Token 输出），而模元经济学聚焦于 **Token 本身作为经济分析单元的微观经济学**（Token 的定价、成本、流通）。两者互补。

## 反面论点与数据空白

1. **"模元"术语未被学术界采纳**：这只是两位作者的建议，主流学术界仍使用"Token"或"token"
2. **Token 的异质性可能被低估**：不同模态（文本/图像/视频/代码）的 Token 在经济价值上的差异可能远大于"模元"概念所暗示的统一性
3. **Token 经济学的实际经验数据几乎为零**：目前没有公开的 Token 定价市场（Token 通常在封闭的 API 定价体系内），"模元经济学"目前是纯概念框架
4. 大模型自身的 Token 定价策略（如 GPT-4o vs Sonnet vs DeepSeek）已经是实际的"Token 市场"——但缺乏学术性的定价模型
