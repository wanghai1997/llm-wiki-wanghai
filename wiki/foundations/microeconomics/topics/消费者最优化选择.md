## 2. 三条贯穿全 Batch 的红线

### 2.1 "约束 + 偏好 + 优化器"三件套
任何消费者 / 工人 / 储蓄者问题都化简为：
- **约束** ：[[预算约束]] 的某个变体；
- **偏好** ：[[偏好五公理]] + 一种 [[偏好类型]]；
- **优化器** ：[[效用最大化问题]] / [[支出最小化问题]] + [[拉格朗日法]] / 切线条件。

教材的核心教学技巧：把"劳动 / 储蓄 / 借贷 / 消费"问题**全部**塞进同一个三件套——见 [[禀赋预算]]、[[跨期预算约束]]、[[劳动-闲暇预算]]。

### 2.2 SE-IE 分解作为比较静态的统一引擎
- 外生预算（Ch 7）：标准 [[替代效应]]；
- 禀赋预算（Ch 8）：加上"禀赋价值变化"项（[[禀赋经济中的SE-IE]]）→ 劳动后弯 / Laffer / 资本供给非单调 / 借贷需求规整都是它的应用；
- 形式化（Ch 10）：[[Slutsky方程]] 给出代数一致性。

### 2.3 对偶系统作为 Ch 10 的封顶
[[效用最大化问题]] ↔ [[支出最小化问题]]，[[间接效用函数]] ↔ [[支出函数]]，[[Marshallian需求曲线]] ↔ [[补偿需求曲线]]，由四件机器（[[Slutsky方程]] / [[Shephard引理]] / [[Roy恒等式]] / [[包络定理]]）锁死。详见 [[消费者对偶性]]。

## 3. 三大教学偏置（[BIAS]）

### 3.1 偏好示例的 Cobb-Douglas 偏置
教材在 Ch 6–9 反复用 **Cobb-Douglas** 作为闭式示例，但在 Ch 10 又强调"消费者剩余仅在准线性下精确"——CD 是 [[同位偏好|同位]],**不是**[[准线性偏好|准线性]]。读者易因反复并置而误以为 "CD ≈ 准线性"。详见 [[消费者剩余]]、[[Marshallian需求与Hicksian需求关系]]。

### 3.2 政策叙事的小政府偏向
- [[经济学六大教训|教训 6]] "政府干预未必更好"在 Ch 1-18 反复出现；
- [[无谓损失DWL]] / [[Laffer曲线]] / [[总额税与扭曲税]] 论述时口吻偏 supply-side；
- Pigou 矫正性税要到 **Ch 21** 才出现 → 读者若止步前 18 章会形成"政府总在添乱"的失衡印象。详见 [[Microeconomics-Nechyba-2e]] / [[无谓损失DWL]]。

### 3.3 美式制度示例
- [[IRA与跨期税收]] / 慈善捐赠抵扣 / Bush-Obama 减税：均为美式制度示例,**已加 `regional-bias` 标签**；
- 中欧（强制企业年金 / 公共养老 / 增值税体系）下结论不直接迁移。
