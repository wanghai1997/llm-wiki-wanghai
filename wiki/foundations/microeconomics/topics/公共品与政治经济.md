# 公共品与政治经济（主题）

> Nechyba 微观经济学 Ch 27-28 综合导览页。分析对象从"市场"扩展到"政府"和"集体决策"——第一福利定理的第三类失效模式（政府失灵）。

## 1. 全章拓扑

```
市场失灵（Ch 21-22）
   ↓
公共品（Ch 27）
   ├─ 非竞争性 + 非排他性
   ├─ 搭便车问题
   ├─ Samuelson条件
   ├─ 政府供给
   ├─ 市场建立（Coase局限）
   └─ 偏好显示机制
         ↓
政府也会失灵（Ch 28）
   ├─ 寻租
   ├─ 议程操纵
   ├─ Arrow不可能定理
   └─ 社会选择理论
```

## 2. 三条贯穿红线

### 红线 1：非排他性 → 市场缺失

公共品的非排他性导致无法收费 → 私人供给无利可图 → 市场缺失 → 政府介入。但政府介入又面临自身的信息和激励问题。

### 红线 2：集体决策 → 偏好聚合困难

Arrow 不可能定理证明：不存在完美的民主决策机制。任何投票制度都必须在效率、公平、自由之间权衡。

### 红线 3：政府作为"必要的恶"

- 市场失灵时需要政府
- 但政府也可能失灵（寻租、俘获、信息不对称）
- 政策设计是"两害相权取其轻"

## 3. 教学偏置 [BIAS]

- **政府仁慈假设**：Ch 27 在分析公共品供给时，假设政府能够无成本地观测社会偏好并执行最优供给。但 Ch 28 才引入政府失灵。若两章之间缺乏衔接，读者可能形成"政府供给 = 最优解"的印象。
- **Arrow 定理的悲观主义**：Ch 28 的 Arrow 定理常被解读为"民主制度不可能合理聚合偏好"，但教材可能未充分讨论后续突破（Sen 的自由悖论、VCG 机制在特定条件下的可行性）。
- **公共品供给的实证忽略**：教材对公共品最优供给量的讨论通常是理论性的，缺乏实证校准（如国防的最优支出、环保的最优投资）。

## 4. 数据空白

- 公共品最优供给量的实证估计（需估计所有个体的偏好）
- 政府失灵的程度（寻租成本占 GDP 的比例）
- 不同投票制度的福利比较
- 数字公共品（开源软件、开放数据）的供给机制效率
