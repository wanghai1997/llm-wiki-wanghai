## 红线

### 纯交换经济

**Edgeworth 盒**:两人两商品交换经济的几何。初始禀赋 $\omega$ → 无差异曲线 → [[互惠交易集MB]] → [[契约曲线]](Pareto 高效点)。

**核**:不能被任何联盟阻断的配置。两人经济中核 = $MB \cap CC$。多人经济中核更小。核收敛定理(Debreu-Scarf 1963):经济复制时核 → Walras 均衡集合。

### Walras 一般均衡

**存在性**:Arrow-Debreu 1954 用不动点定理证明(凸偏好 + 局部非饱和)。

**唯一性 + 稳定性**:并非保证。SMD 定理(Sonnenschein-Mantel-Debreu 1972-74)证明总超额需求函数可任意;Scarf 1960 给出 tâtonnement 不收敛的反例。

**第一福利定理**:Walras 均衡 ⊂ Pareto 集。完全竞争 + 无外部性 + 无公共品 → 市场配置 Pareto 高效。

**第二福利定理**:Pareto 集中任意点 = 某 lump-sum 重分配后的 Walras 均衡。分配与高效的分离。

### 风险扩展

Arrow-Debreu 1953-54:状态相依商品 → 所有确定性 GE 工具直接迁移。完备市场下福利定理成立;不完备市场下失效(Greenwald-Stiglitz 1986)。

## [BIAS]

- **鲁滨逊"无社会"抽象**:Robinson Crusoe 经济把"社会"还原为"孤立个体",抹除社会互动 / 规范 / 信任维度。Bowles-Gintis 2011 / Henrich et al. 2010 证明偏好高度依赖文化。
- **第一福利定理无前提乐观**:教材默认"完全竞争 = 最优基准",忽略 SMD 反例 + 稳定性失败 + 不完备市场。
- **第二福利定理的理想主义**:Lump-sum 重分配在现实中近乎不可能(Mirrlees 1971 / Diamond-Saez 2011)。

## 数据空白

- **SMD 反例**:Sonnenschein-Mantel-Debreu (1972-74) 证明一般均衡的唯一性 / 稳定性 / 比较静态"几乎不能保证"。教材完全跳过。
- **tâtonnement 不收敛**:Scarf 1960 / Hildenbrand-Kirman 1988 展示价格调整机制在现实中可能绕圈而非收敛。
- **CGE 模型**:Caliendo-Parro 2015 / Hertel-Tsigas 1997 的政策评估 CGE 模型校准依赖大量假设,实证稳健性争议大。
- **实验经济学**:Smith 1962 / Roth 1995 实验显示真实议价收敛于核的某子集,而非整个核。
- **金融脆弱性**:2008 危机展示一般均衡模型对系统性风险 / 信贷崩溃处理不足。
