# 厂商最优化选择

> **主题导览页**：本页综合 [[Microeconomics-Nechyba-2e|Nechyba 教材]] Ch 11–13（生产函数 / 成本最小化 / 利润最大化）的全部结构，是 Batch 2 的"地图"。**不**重复证明,只勾连概念间的逻辑通路、对偶结构与教学偏置。是 [[消费者最优化选择]] 的镜像。

## 2. 三条贯穿全 Batch 的红线

### 2.1 "技术 + 价格 + 优化器"三件套

任何厂商问题都化简为：
- **技术** ：[[生产函数]]（[[等产量线]]、[[规模报酬]]）；
- **价格** ：要素 $(w, r)$ + 产品 $p$（外生 / 价格接受）；
- **优化器** ：[[成本最小化问题|CMP]] 或 [[利润最大化问题|PMP]] + [[拉格朗日法]] / 切线条件。

教材 Ch 11 给出技术,Ch 12 直接 PMP,Ch 13 走"CMP → max{px-C(x)}"两步路径。两条路径在 [[厂商对偶性]] 下等价。

### 2.2 [[两步利润最大化]] 作为求解策略

教材的核心教学技巧：**先**用 CMP 把投入选择压缩成一维成本函数 $C(w, r, x)$；**再**用 $\max_x \{px - C(x)\}$ 求最优产出。这把高维 PMP 化简为：
- Step 1（CMP）：$L^c(w, r, x) = \partial C/\partial w$（Shephard）
- Step 2（产出选择）：$p = MC(x^*)$（输出供给曲线 = MC 曲线）

> 为什么两步法重要？因为 Step 1 与"产品价格 $p$ 无关"——MC 曲线只随 $(w, r)$ 移动,不随 $p$ 移动。这是 [[输出供给曲线]] 的"几何几乎不变"的根源。

### 2.3 [[厂商对偶性]] 作为 Ch 12-13 的封顶

[[利润最大化问题|PMP]] ↔ [[成本最小化问题|CMP]]，[[利润函数]] ↔ [[成本函数]]，[[无条件投入需求]] ↔ [[条件投入需求]]，由四件机器（Shephard / Hotelling / "厂商 Slutsky"分解 / [[包络定理]]）锁死。详见 [[厂商对偶性]]。

## 3. 与消费者侧的镜像

| 消费者侧 ([[消费者最优化选择]]) | 厂商侧（本主题）|
|---|---|
| [[预算约束]] | 等价位置由 $p, w, r$ 给出（无显式约束）|
| [[偏好五公理]] / [[无差异曲线]] | [[生产函数]] / [[等产量线]] |
| [[边际替代率MRS]] = $p_1/p_2$ | [[边际技术替代率MRTS]] = $w/r$ |
| [[效用最大化问题|UMP]] / [[支出最小化问题|EMP]] | [[利润最大化问题|PMP]] / [[成本最小化问题|CMP]] |
| 序数效用（变换不变）| 基数利润（货币度量）|
| [[间接效用函数]] $V(p, m)$ | [[利润函数]] $\pi^*(p, w, r)$（凸于 $(p, w, r)$）|
| [[支出函数]] $E(p, U)$ | [[成本函数]] $C(w, r, x)$（凹于 $(w, r)$）|
| [[Marshallian需求曲线]] $x^M(p, m)$ | [[无条件投入需求]] $L^*(p, w, r)$ |
| [[补偿需求曲线]] $x^h(p, U)$ | [[条件投入需求]] $L^c(w, r, x)$ |
| [[Roy恒等式]] | [[Hotelling引理]] |
| [[Shephard引理]]（消费侧）| [[Shephard引理]]（生产侧，原始版）|
| [[Slutsky方程]] | "厂商 Slutsky"分解 |
| [[消费者剩余]] $CS$ | [[生产者剩余]] $PS$ |
| [[消费者对偶性]] | [[厂商对偶性]] |

> 关键差异：消费侧对偶**反演型**（V↔E 互为反函数），生产侧对偶**组合型**（$\pi^* = \max_x\{px - C\}$）。原因：利润有货币度量、效用是序数。详见 [[消费者对偶性]] §"生产侧镜像"。

## 4. 三大教学偏置（[BIAS]）

### 4.1 完全竞争 / 价格接受假设无处不在

Ch 11-13 全部默认 $p, w, r$ 外生，对应**完全竞争**。但：
- **垄断**（$p$ 内生）→ Ch 23 才出现，PMP FOC $p \cdot MP_L = w$ 退化为 $MR \cdot MP_L = w$；
- **垄断买方**（$w$ 内生）→ Ch 25，要素市场价格变成厂商决策变量；
- **寡头**（策略博弈）→ Ch 24-25，"供给曲线"概念失效（用反应函数替代）。

读者若止步前 13 章会形成"市场总是完全竞争"的失衡印象。详见 [[价值边际产品VMP]] §[BIAS]、[[利润最大化问题]] 的反面论点。

### 4.2 CRS-IRS 张力的隐含矛盾

教材 Ch 11 给出 [[规模报酬|CRS / IRS / DRS]] 三档,但：
- **CRS** 下 $\pi^* = 0$（任何规模都最优）→ 厂商规模不定;
- **IRS** 下 $\pi$ 无界 → PMP 不存在内点解，与完全竞争不相容;
- **DRS** 下 PMP 有解但教材在 Ch 13 又用 [[平均成本曲线包络|U 型 LAC]]——U 型隐含 IRS（左半段）+ DRS（右半段）共存。

> Ch 11-13 的"完全竞争 + 内点 PMP"故事**实际只对 DRS 全局** / "U 型 LAC + 自由进入"成立。软件、平台、AI（IRS 显著）的当代行业被排除在框架外——本 Wiki 在 [[规模报酬]]、[[关闭条件]] 已加 [BIAS] 标注。详见 [[CRS-IRS权衡]]（计划页）。

### 4.3 静态 + 风险中性 + 单产品

教材 Ch 11-13 假设：
- **静态**：无资本折旧、人员调整成本（Hamermesh 1989 动态 LDP 超出范围）;
- **风险中性**：$\pi$ 是确定值，无价格不确定;
- **单产品**：$x$ 标量,多产出下 $\nabla_p \pi^* = x^*$ 给出向量供给（Ch 12 不展开）。

→ 真实厂商决策（如 Tesla 同时生产电池+车+软件）需要 Ch 17 风险 + Ch 22-25 寡头 + 多产品扩展。
