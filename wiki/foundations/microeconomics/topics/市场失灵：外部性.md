# 市场失灵：外部性（主题）

> Nechyba 微观经济学 Ch 21 综合导览页
> 第一福利定理的失效模式之一：外部性

## 1. 全章拓扑

```
外部性定义（私人成本/收益 ≠ 社会成本/收益）
    ↓
分类：生产外部性 / 消费外部性 / 正外部性 / 负外部性
    ↓
市场失灵机制：MSC ≠ MPC → Q_market ≠ Q_social-optimal
    ↓
两种解决方案：
    ├─ 政府路径：Pigou 税（对 MEC 征税）
    └─ 市场路径：Coase 定理（产权 + 市场交易）
        ↓
Coase 定理的前提：产权明确 + 交易成本为零
        ↓
交易成本分析：为什么市场往往无法自行解决外部性
        ↓
现实案例：污染权交易、碳市场、土地税
```

## 2. 三条贯穿红线

### 红线 1：缺失市场 = 外部性本质

外部性不是"市场失灵"，而是**某些市场根本不存在**（见 [[市场缺失]]）。污染权没有市场价格 → 工厂"免费"排放。解决方案要么是**创建市场**（Coase 路径：产权界定 + 交易），要么是**模拟市场**（Pigou 路径：政府定价）。

### 红线 2：效率 vs 分配的两难

- Pigou 税和 Coase 定理都追求**效率**（社会最优产量）。
- 但**分配后果**截然不同：
  - Pigou 税：税收归政府 → 可用于再分配。
  - Coase 定理：产权租金归产权所有者 → 初始产权分配决定赢家输家。
- **环境正义**：负外部性的受害者通常是低收入社区 → 政策设计需同时考虑效率和公平。

### 红线 3：信息要求决定政策选择

| 外部性特征 | 推荐政策 | 理由 |
|---|---|---|
| MEC 可精确估计、污染者可识别 | Pigou 税 | 信息成本较低 |
| 少数相关方、产权可界定 | Coase 式谈判 | 交易成本可控 |
| MEC 不确定、污染源众多 | 可交易许可证 | 分散信息聚合 |
| 完全不可测量 | 技术标准/禁令 | 市场工具失效 |

## 3. 教学偏置 [BIAS]

### [BIAS] Coase 定理的"零交易成本"默认

教材通常先展示 Coase 定理的效率结论，再"补充"交易成本。但对**交易成本为何如此普遍**分析不足：
- 大气污染涉及数百万受害者 → 谈判不可能。
- 产权界定是政治过程（谁获得初始产权？）。
- 即使产权明确，**谈判力量不对等**也会导致结果偏向强势方。

**后果**：读者易形成"私有化即可解决外部性"的过度乐观印象。

### [BIAS] Pigou 税的完美信息假设

教材在介绍 Pigou 税时，假设政府**精确知道 MEC**。但现实中：
- 边际外部成本涉及流行病学、环境科学等跨学科估计。
- Stern 2007 估计社会碳成本（SCC）为 $85/吨 CO₂，但后续估计差异极大（$12-$200+）。
- 政治经济学：外部性受益者（污染者）有动力游说反对征税 → 实际税率通常低于社会最优。

### [BIAS] 忽略政府失灵

Ch 21 在引入政府干预（Pigou 税）时，未充分讨论**政府失灵**（regulatory capture、信息不对称下的政策设计、官僚激励）。这与 Batch 3 [[第一福利定理]] [BIAS] 的"无前提乐观"形成对照——市场会失灵，政府也会失灵。

## 4. 数据空白

- **碳税的环境效益**：第一重红利（减排）可测量，但与经济增长、技术变革的交互效应难以分离因果。
- **碳边境调节机制（CBAM）**：EU 2023 年启动，但全球碳价差异巨大（EU ~$80/吨 vs 中国 ~$10/吨）→ 贸易泄漏和报复风险未充分评估。
- **AI 算力外部性**：大模型训练的能耗外部性缺乏系统经济学分析（单次 GPT-4 级训练约耗电 50-100 GWh，相当于数千家庭年用电）。
- 环境库兹涅茨曲线（EKC）的实证争议：人均收入与污染的关系呈倒 U 型？跨国家面板数据结果不一致。
