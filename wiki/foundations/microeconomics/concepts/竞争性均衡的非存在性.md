# 竞争性均衡的非存在性

> Nonexistence of Competitive Equilibrium

在标准的一般均衡理论中，[[第一福利定理]]证明了完全竞争均衡的存在性和效率。但 Rothschild-Stiglitz（1976）的里程碑式发现表明：**在信息不对称下，竞争性均衡可能根本不存在**。

## Rothschild-Stiglitz 的核心结果

### 模型设定

- 保险市场：两类投保人（低风险 L 和高风险 H）。
- 保险公司竞争性地提供合同菜单。
- 零利润条件：每份合同的保费 = 期望赔付。

### 均衡不存在的逻辑

**步骤 1**：假设存在一个分离均衡（高风险选 $(p_H, b_H)$，低风险选 $(p_L, b_L)$）。

**步骤 2**：某保险公司偏离，提供一项新合同 $(p', b')$：
- 对两类人都有吸引力（比原均衡合同更好）。
- 在平均风险 $\bar{\pi}$ 下零利润。

**步骤 3**：新合同吸引两类人 → 原均衡合同无人选择 → 原均衡被打破。

**步骤 4**：但新合同本身也不是均衡——因为另一家公司可以提供只吸引低风险者的合同 → 交叉补贴不可持续。

**结论**：在竞争性（价格接受）行为假设下，**没有任何合同菜单能抵抗偏离** → 均衡不存在。

### 关键参数：低风险者比例

均衡是否存在取决于低风险者在市场中的比例 $q$：

- $q$ **足够低**（高风险者占多数）：分离均衡存在（低风险者的信息租金不足以吸引偏离）。
- $q$ **足够高**（低风险者占多数）：任何候选均衡都可被偏离 → **均衡不存在**。

## 解决方案：修改博弈结构

### Wilson 均衡（Wilson 1977）

允许保险公司**撤回**亏损合同：
- 若某合同吸引混合类型池 → 实际赔付高于保费 → 亏损 → 保险公司撤回该合同。
- 预期到撤回，偏离者不提供此类合同 → 均衡恢复。

### Riley 均衡（Riley 1979）

允许保险公司**预期对手的反应**：
- 偏离者考虑：若我提供新合同 → 对手也提供类似合同 → 我无利润。
- 预期到竞争 → 不偏离 → 均衡恢复。

### 强制参保（Government Mandate）

政府要求所有人参保 → 消除退出选项 → 逆向选择池被强制混合 → 市场稳定。

### 垄断/寡头市场结构

放弃完全竞争假设：
- 垄断保险公司 → 可强制提供单一合同 → 混同均衡。
- 寡头竞争 → 合谋或限制合同数量 → 均衡可能恢复。

## 理论意义

### 对完全竞争范式的挑战

Rothschild-Stiglitz 结果的深远影响：
- [[第一福利定理]]的"完全竞争 → 效率"结论依赖于**完美信息**。
- 信息不对称下，即使**价格接受**行为也可能导致市场崩溃。
- 这是比外部性更深层的市场失灵——不是"市场结果偏离最优"，而是"市场结果根本不存在"。

### 与 [[市场缺失]] 的联系

信息不对称 → 逆向选择 → 均衡不存在 → 市场完全缺失。这与 Coase 的"市场缺失 = 外部性"形成互补：
- Coase：某些权利未交易化 → 外部性。
- Rothschild-Stiglitz：某些信息无法交易 → 市场崩溃。

## 反面论点与数据空白

- **竞争性行为假设**：均衡不存在的结论依赖于保险公司是价格接受者。现实中的保险市场通常是**寡头**或**受监管垄断** → 市场结构本身可能解决了非存在性问题。
- **强制参保的现实效果**：全民医保（如英国 NHS、加拿大 Medicare）确实消除了逆向选择，但引入了政府失灵（等待时间、资源错配）。
- 均衡不存在的**实证检验困难**：无法直接观测"均衡不存在"，只能观察到市场波动、合同频繁变更、保险公司退出等间接证据。
- **动态视角**：重复互动中的声誉和学习可能恢复均衡（即使静态模型中不存在）。
