# 补偿需求曲线

## 一句话定义

> [[支出最小化问题|EMP]] 的解函数 $x_i^h(p, U)$ ——保持**效用 $U$ 不变**，价格变动下的需求轨迹。也称 **Hicksian 需求** / **compensated demand**——名字来自 [[John Hicks]]。

## 与 [[Marshallian需求曲线]] 的关系

- **重合于一点**：在原始 $(p, m)$ 下，$x^h(p, V(p, m)) = x(p, m)$。
- **斜率不同**：Hicks 仅含纯 [[替代效应|SE]]，无 IE → 斜率绝对值**通常更小**。
- **整段重合 ⟺ 准线性**：见 [[准线性偏好]] / [[消费者剩余]] / [[Marshallian需求与Hicksian需求关系]]。

## 关键性质

| 性质 | 说明 |
|---|---|
| 自身价格效应非正 | $\partial x^h_i/\partial p_i \le 0$ ——**永远**下倾 |
| 0 阶齐次 | $x^h(\lambda p, U) = x^h(p, U)$（仅相对价格重要） |
| 与 $E$ 的关系 | $x^h_i = \partial E/\partial p_i$ ——[[Shephard引理]] |
| 满足 [[Slutsky方程]] | $\partial x/\partial p = \partial x^h/\partial p - x \cdot \partial x/\partial m$ |

## 几何

| 操作 | Marshall | Hicks |
|---|---|---|
| $p_1$ 变动时 | 沿原预算线滑到新切点 → 含 SE + IE | 沿原 IC 滑到新斜率切点 → **仅 SE** |
| 福利度量 | $\Delta CS$（有偏） | $\Delta CV$ / $\Delta EV$（精确） |

## 在 [[Microeconomics-Nechyba-2e|Nechyba 教材]] 中的位置

教材 Ch 7 引入 Hicks 路径作为 SE-IE 分解的几何框架，Ch 10 把它正式提升为对偶系统的"支出侧"——
- $x^h$ 由 [[Shephard引理]] 从 [[支出函数]] $E$ 直接生成；
- $x^h$ 用作 [[补偿变差CV]] / [[等价变差EV]] 的精确福利度量基底；
- $x$ 与 $x^h$ 通过 [[Slutsky方程]] 连接。

## 反面论点与数据空白

- **[BIAS] Hicksian 需求实证不可观测**：现实只能观测到 Marshallian 需求(实际选择)；Hicksian 需求需通过 $E$ 反推——教材 Ch 1–10 不涉及估计方法。
- **数据空白**：当代 Demand System 文献（AIDS, QUAIDS）如何同时估计 Marshall 与 Hicks 系统未在教材中提及。
