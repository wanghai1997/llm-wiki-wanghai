# 生产者剩余

> 厂商从市场参与中获得的"超额收益"——价格与边际成本之间的面积。是消费者侧 [[消费者剩余]] 的镜像，也是 [[利润函数]] 在政策福利分析中的几何具象化。

## 定义

设市场价格 $p^*$，厂商按 [[输出供给曲线]] 生产 $x^*(p^*) \geq 0$：

$$
PS = \int_0^{x^*} (p^* - MC(x)) \, dx = p^* x^* - \int_0^{x^*} MC(x) \, dx
$$

几何：在价格水平线下、$MC$（= 供给曲线）以上的面积。

```
  p
   │            S = MC
   │            /
   │ p* ───────●
   │   ╔═══╗  /  ←  PS = 阴影面积
   │   ║   ║ /
   │   ║   ╲/
   │   ║   /\
   │   ╚══●__╲___ x
   │      x*
```

## 与可变成本的关系

由 $\int_0^{x^*} MC(x) \, dx = VC(x^*)$（可变成本）：

$$
\boxed{
PS = p^* x^* - VC(x^*) = \text{营收} - \text{可变成本}
}
$$

读法："厂商总营收减去可变成本，剩下的就是 PS。" 这**包含**对固定成本的"贡献"——厂商可用 PS 偿付 $r\bar K$。

## PS vs 利润

| 度量 | 公式 | 短期 vs 长期 |
|---|---|---|
| **生产者剩余 PS** | $p^* x^* - VC(x^*)$ | 不含固定成本 → SR 与 LR 同 |
| **短期利润 $\pi^{\text{SR}}$** | $p^* x^* - VC(x^*) - r\bar K$ | $= PS - r\bar K$ |
| **长期利润 $\pi^{\text{LR}}$** | $p^* x^* - LC(x^*)$ | $= PS$（长期 $r\bar K$ 也可避免，并入 LC）|

> **关键**：短期 PS = $\pi^{SR} + r\bar K$；长期 PS = $\pi^{LR}$（自由进入下零利润 → 长期 PS = 0）。

## 与 [[利润函数]] 的等价（变量替换）

由 [[Hotelling引理]]：$\partial \pi^* / \partial p = x^*(p)$。从某基准价格 $p_0$ 到 $p^*$：

$$
\pi^*(p^*) - \pi^*(p_0) = \int_{p_0}^{p^*} x^*(p) \, dp
$$

这是"价格变化时的利润增量" = "供给曲线左侧到价格线的面积"。当 $p_0 = p_{\text{shutdown}}$ 时，$\pi^*(p_0) = -r\bar K$（关闭时），$\pi^*(p^*) - (-r\bar K) = PS$，故：

$$
\boxed{
PS = \int_{p_{\text{shutdown}}}^{p^*} x^*(p) \, dp = \int_{p_{\text{shutdown}}}^{p^*} S(p) \, dp
$$

——PS 也可解为"供给曲线左侧的面积"。两种几何定义等价（[[输出供给曲线]] 是 $MC$ 反演）。

## 与消费者剩余的镜像

| 消费者侧 [[消费者剩余]] | 厂商侧生产者剩余 |
|---|---|
| $CS = \int_0^{x^*} (p_{\max}(x) - p^*) \, dx$ | $PS = \int_0^{x^*} (p^* - MC(x)) \, dx$ |
| 需求曲线下、价格上的面积 | 价格下、供给曲线上的面积 |
| 与 [[补偿变化CV]] / [[等价变化EV]] 联系 | 与 $\Delta \pi^*$ 联系 |
| 用马歇尔需求 vs 补偿需求时存在偏差 | 短期 vs 长期 PS 差异为 $r\bar K$ |

> CS + PS = **总社会剩余（Total Surplus, TS）**。完全竞争 + 无外部性下 TS 最大化 → 帕累托效率（Batch 3 [[竞争性市场均衡]]）。

## 与 Batch 3 市场均衡的连接

Ch 14-15 把 PS 纳入 [[社会剩余]] 的聚合分析:
- **短期 PS**:市场供给曲线上方、价格线下方面积。SR 中 PS 可正可负(当 $p > SAVC_{\min}$ 但 $p < SAC_{\min}$ 时 PS > 0 但利润 < 0)。
- **长期 PS**:在 constant-cost 行业,LR 零利润使 PS = 0;在 increasing-cost 行业,PS = Ricardian 租(地租 / 稀缺要素回报)。
- **国际贸易**:出口国生产者因 $p^w > p_a$ 获得 PS 增益;进口国生产者因 $p^w < p_a$ 遭受 PS 损失。

详见 [[社会剩余]] / [[第一福利定理-部分均衡]] / [[国际贸易福利]]。

## 政策福利分析

**应用 1：税收的福利成本**

征收每单位税 $\tau$ → 消费者面对价格 $p^* + \tau$，厂商面对净价 $p^*$，市场出清在 $x'$（$x' < x^*$）：

```
  p
   │
   │ ╔══CS'══╗   ← 新 CS
   │ ║       ║
   │p+τ──────●
   │   ╲     ╱
   │ TR ╲   ╱  ← 税收收入
   │     ╲ ╱
   │ p* ──●
   │   ╔══╗ ╲     DWL = 三角形
   │   ║PS'║  ╲
   │   ╚══╝   ╲___ x
   │           x' x*
```

DWL（无谓损失）= 旧 TS − 新 (CS' + PS' + TR)。详见 Batch 3。

**应用 2：价格管制的福利损失**

价格上限 $\bar p < p^*$ → 供给减至 $x'$ → PS 损失 + CS 增加（部分），但**总 TS 损失**。

## 长期 PS = 0（自由进入定理）

在长期均衡下，自由进入使 $p^* = LAC_{\min}$，此时：

$$
PS^{LR} = p^* \cdot x^*_{MES} - LC(x^*_{MES}) = LAC_{\min} \cdot x^*_{MES} - LAC_{\min} \cdot x^*_{MES} = 0
$$

——长期下零利润。但**短期 PS** 仍可正（行业短期租金）。详见 [[平均成本曲线包络]]、[[关闭条件]]。

## 反面论点与数据空白

- **PS 仅在完全竞争下严格成立**：垄断 / 寡头下 $p \neq MC$，$PS$ 几何边界改变（用反应函数代替供给曲线）。
- **多市场互动**：单市场 PS 加总 ≠ 多市场总 PS（同一厂商在多市场可能存在交叉补贴）。
- **动态 PS**：流量 PS 累计为厂商净现值，但用静态 PS 误导（Vives 1999 关于动态福利分析的纠正）。
- **租金 vs 利润 vs PS 概念混淆**：经济租金（无机会成本的报酬）、会计利润（含正常报酬）、PS（短期定义）三者不等。Nechyba 不细辨。
- **数据空白**：行业 PS 估计依赖供给曲线识别（IV 或自然实验），跨行业实证差异巨大。
