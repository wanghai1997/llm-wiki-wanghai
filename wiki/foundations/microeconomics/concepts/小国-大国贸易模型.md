# 小国-大国贸易模型

> 国际贸易分析中的关键二分:**小国**面对完全弹性的世界供给曲线($p^w$ 给定);**大国**面对正斜率世界供给曲线(本国进口数量影响 $p^w$)。两者关税福利后果**根本不同**——小国关税严格降低福利,大国关税可能改善福利。

## 形式区分

设本国是某商品的进口国。世界出口供给曲线 $X^{S,w}(p)$:

- **小国**:$\eta^{S,w} \to \infty$,即 $p^w$ 在本国进口量变化时不变。本国是世界市场的"价格接受者"。
- **大国**:$\eta^{S,w}$ 有限,即 $p^w$ 随本国进口量变化。本国对世界价格有"市场势力"。

## 小国关税分析

设小国规定进口关税 $t$:
- 国内价格 $p^c = p^w + t$。
- 进口量 $M' < M$(下降)。
- 福利变化:CS↓ + PS↑ + R(关税收入)= -DWL$_{prod}$ - DWL$_{cons}$,**严格 < 0**。

详见 [[贸易税与配额]] 和 [[国际贸易福利]]。

## 大国关税分析:贸易条件改善

设大国规定关税 $t$:
- 本国进口减少 → 世界进口需求左移 → 出口国被迫降价 $p^w \to p^{w'} < p^w$。
- 国内价格 $p^c = p^{w'} + t$,但 $p^{w'} + t$ 可能 < $p^w + t$ 的小国预测。
- **贸易条件改善**:本国进口品变便宜。
- 福利变化:CS↓ + PS↑ + R↑(关税收入 + 贸易条件红利)。
- **可能净 > 0**:在某些 $t$ 下福利上升。

## 最优关税公式

Bickerdike 1906 / Johnson 1953-54 最优关税:

$$t^* = \frac{1}{\eta^{S,w}}$$

其中 $\eta^{S,w}$ = 出口国对本国价格的供给弹性。

直觉:
- $\eta^{S,w} \to \infty$(小国):$t^* \to 0$ → 自由贸易最优。
- $\eta^{S,w} \to 0$(本国是该商品的唯一买家):$t^* \to \infty$ → 极端关税最优(类似买方垄断)。

## "大国"的判断标准

大国不必是地理大,而是**该商品市场上占需求 / 供给比例显著**:
- **美国**对石油:大国(占世界进口 ≈ 25%)。
- **美国**对咖啡:小国(占世界进口 ≈ 15-20%,临界)。
- **中国**对铁矿石:大国(占世界进口 ≈ 70%)。
- **新加坡**对几乎所有商品:小国。

## 大国关税的两类成本

即使大国福利上升,需考虑:
1. **报复**:其他大国设置反制关税 → 双方福利下降(囚徒困境)。Johnson 1953 *"Optimum Tariffs and Retaliation"* 分析报复均衡。
2. **多边协议放弃**:WTO / GATT 规则禁止单边大国关税,违反者面临制裁。
3. **政治成本**:全球供应链断裂、地缘政治冲突。

## 大国 vs 小国的实证案例

| 案例 | 国家 | 商品 | 大国 / 小国 | 实证后果 |
|---|---|---|---|---|
| Smoot-Hawley 1930 | 美国 | 多商品 | 大国 | 报复触发大萧条贸易萎缩 |
| OPEC 1973-79 | OPEC | 石油 | 大国(出口侧) | 出口税成功改善贸易条件 + 引发滞胀 |
| 中国稀土 2010-15 | 中国 | 稀土 | 大国 | 出口配额引发美日韩反弹 + WTO 败诉 |
| 美国大豆 2018 | 美国 | 大豆 | 中等 | 中国关税迫使美国大豆转向其他市场 |

## 与一般均衡分析的关系

部分均衡小国 / 大国分析忽略:
- 多商品反馈(进口某商品的关税影响该商品要素价格 → 影响其他行业)。
- 资本流动性(国际资本反应于贸易条件变化)。
- 汇率调整(贸易条件变化引发汇率重估)。

完整大国关税分析需要 General Equilibrium 模型(Caliendo-Parro 2015 多国 CGE)。教材限于部分均衡,但**先告知**这一限制是诚实做法,Nechyba 14B / 15B 在脚注中略有提及。

## 反面论点与数据空白

- **小国 / 大国二分的人为性**:现实中"中等大小国"普遍存在(韩国 / 泰国 / 越南 / 巴西),其在不同商品上同时是大国与小国——教材二分简化遗失大量经验情景。
- **报复均衡的现实多样化**:Johnson 1953 报复模型预测对称报复,但 Bagwell-Staiger 2002 *The Economics of the World Trading System* 提出 WTO 是"逃出报复均衡"的多边制度协调,这在 Nechyba 部分均衡分析中无对应。
- **网络效应**:数字商品(Token / 软件 / 平台)的市场结构使"大国 / 小国"概念失效——平台所在国可能在世界市场拥有近垄断地位(美国对云计算、中国对短视频)。
- **WTO 改革与多边协调**:WTO Doha 回合(2001-)未能达成,意味着小国 / 大国的关税博弈在 21 世纪进入新平衡——教材完全不展开。
- **数据空白**:Broda-Limão-Weinstein 2008 *American Economic Review* "Optimal Tariffs and Market Power" 实证发现美国 / 日本 / 中国对某些商品的最优关税显著大于 0,与"小国默认 + 自由贸易最优"叙事冲突。教材不引述。
