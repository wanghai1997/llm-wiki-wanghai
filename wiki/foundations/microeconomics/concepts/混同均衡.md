# 混同均衡

> Pooling Equilibrium

混同均衡是指不同类型的信息优势方选择**相同的行动/合同** → 信息劣势方**无法从行为中推断**其类型 → 信息不对称持续的均衡状态。

## 核心特征

### 信号传递中的混同均衡

- 高能力工人和低能力工人都选择同一教育水平 $e_P$。
- 雇主观察 $e_P$ → 无法区分 → 支付**平均工资** $w_P = q w_H + (1-q) w_L$。
- **信息不揭示**。

### 信息筛选中的混同均衡

- 高风险和低风险投保人都选择同一合同 $(p_P, b_P)$。
- 保险公司无法区分 → 保费基于平均风险 $\bar{\pi}$。
- **信息不揭示**。

## 混同均衡的存在条件

混同均衡要成为**完美贝叶斯均衡**（PBE），必须满足：

1. **参与约束**：每类代理人都愿意参与（而非退出）。
2. **无偏离激励**：没有任何一方能从偏离混同行为中获益。
   - 在信号传递中：若某类代理人单独选择不同的 $e$ → 雇主的信念更新对偏离者不利（如"选择 $e \neq e_P$ 的是低能力者"）。

### 信念设定的关键

混同均衡高度依赖**非均衡路径上的信念**（off-path beliefs）：
- 若雇主相信"任何偏离 $e_P$ 的都是低能力者" → 无人偏离 → 混同均衡成立。
- 但此信念可能不合理——高能力者若偏离到足够高的 $e$ 可能更有利。

**直观标准**（Cho-Kreps 1987）通常排除此类不合理的混同均衡：若某偏离对低类型总是不利、但对高类型可能有利，则雇主应相信偏离者是高类型 → 低类型不会偏离 → 高类型偏离 → 混同破裂。

## 分离均衡 vs 混同均衡的效率比较

| 维度 | 分离均衡 | 混同均衡 |
|---|---|---|
| 信息揭示 | 完全 | 无 |
| 高类型效用 | 较低（承担信号成本） | 较高（平均工资 > 低类型工资，且无信号成本） |
| 低类型效用 | 最低 | 较高（平均工资 > 低类型工资） |
| 总效率 | 通常较低（信号成本） | 可能更高（无信号成本） |
| 信息劣势方 | 完美推断 | 无推断 |

**悖论**：分离均衡揭示信息但浪费资源（信号成本）；混同均衡不揭示信息但可能更有效率。社会福利最大化未必偏好分离。

## 现实中的混同现象

| 领域 | 混同表现 | 后果 |
|---|---|---|
| **保险** | 强制全民医保 → 所有人同一合同 | 消除逆向选择，但健康者为患病者补贴 |
| **教育** | 义务教育年限标准化 | 无法通过基础教育年限区分能力 |
| **劳动力** | 最低工资/标准化职称 | 压缩工资差异，高能力者信号不足 |
| **信贷** | 标准化房贷利率（无风险定价） | 安全借款人为高风险借款人补贴 |

## 反面论点与数据空白

- 混同均衡在理论上**经常被均衡精炼排除**（如直观标准），但现实中混同现象普遍存在。这说明：
  1. 现实中的信念更新不像理论那样"理性"；
  2. 制度约束（如法律、社会规范）维持了混同；
  3. 信号成本可能低于模型假设（如获取基础教育的成本在义务教育下极低）。
- **部分混同**（partial pooling）更现实：某些类型混同、某些类型分离（如三个类型中两个混同、一个分离）。
- 混同均衡的**福利分析**：若信号是纯浪费（如 Spence 教育信号），则混同可能更优；若信号有人力资本功能，则分离更优。实证上难以区分。
