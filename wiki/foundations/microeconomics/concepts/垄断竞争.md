# 垄断竞争（Monopolistic Competition）

## 定义

垄断竞争是指**大量厂商生产差异化产品、自由进入退出**的市场结构。由Chamberlin 1933和Robinson 1933独立提出，后经Dixit-Stiglitz 1977形式化。

核心特征：
1. **大量厂商**：每个厂商的市场份额很小
2. **产品差异化**：每个厂商的产品有独特性
3. **自由进入退出**：长期中利润趋于零
4. **价格制定权**：向下倾斜的需求曲线（$P > MC$）

## Dixit-Stiglitz模型

### 设定

- CES偏好（常替代弹性）：
  $$U = \left(\sum_{i=1}^{n} q_i^{\rho}\right)^{1/\rho}, \quad 0 < \rho < 1$$

- 替代弹性：$\sigma = \frac{1}{1-\rho} > 1$
- 厂商 $i$ 面临的需求：$q_i = Q \left(\frac{P_i}{P}\right)^{-\sigma}$
  其中 $P = \left(\sum_{j=1}^{n} P_j^{1-\sigma}\right)^{1/(1-\sigma)}$ 为价格指数

### 短期均衡

- 每个厂商有定价权：$MR = MC$
- $MR = P_i(1 - 1/\sigma) = MC$
- 定价加成：$\frac{P_i - MC}{P_i} = \frac{1}{\sigma}$

### 长期均衡

自由进入使利润趋于零：
- 零利润条件：$P_i = AC(q_i^*)$
- 最优条件：$MR = MC$

均衡结果：
- 每个厂商在 $P = AC$ 且 $P > MC$ 处生产
- 存在**超额产能**（output低于最小有效规模）

## 福利分析：太多还是太少品种？

| 研究者 | 结论 | 原因 |
|---|---|---|
| **Spence 1976** | 太多品种 | 厂商不考虑消费者剩余的外部性 |
| **Dixit-Stiglitz 1977** | 社会最优（CES特殊性质）| 需求的外部性恰好抵消 |
| **Mankiw-Whinston 1986** | 太多品种 | 商业窃取效应（business stealing）|

**商业窃取效应**：新进入者抢夺现有厂商的需求，但不考虑对现有厂商利润的损失。导致进入过度。

## 反面论点与数据空白

- **[BIAS] CES假设的特殊性**：Dixit-Stiglitz模型依赖CES偏好，这假设所有品种对称、替代弹性恒定。现实中品种差异化程度各异，替代弹性随市场结构变化。
- **厂商规模的异质性**：模型假设所有厂商相同，但现实中厂商规模分布高度 skewed（Zipf定律）。Melitz 2003将生产率异质性引入垄断竞争，证明只有高生产率厂商出口。
- **营销与固定成本**：模型中的固定成本是生产性的，但现实中大量固定成本用于广告和品牌建设（[[广告经济学]]）。
- **数据空白**：垄断竞争的实证集中于贸易（Melitz 2003；Bernard-Jensen 1999）和零售（不同规模商店的分布）。结构估计需要估计需求弹性（Nevo 2001）和成本函数。
