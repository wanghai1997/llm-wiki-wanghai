# 社会剩余

> 部分均衡福利度量。$W = CS + PS + 政府收入 - 外部性$。完全竞争 LR 均衡使 $W$ 最大化(详见 [[第一福利定理-部分均衡]]),任何扭曲(税、价格管制、贸易壁垒)产生 [[市场扭曲下的福利损失公式|死重损失]]。

## 定义

$$W = CS + PS + R - E$$

- **CS(消费者剩余)**:$\int_0^{X^*} P^D(x) \, dx - p^* X^*$ = 需求曲线下方、价格线上方的面积。代表**所有购买者愿付价格高于实付价格的总金额**。
- **PS(生产者剩余)**:$p^* X^* - \int_0^{X^*} P^S(x) \, dx$ = 价格线下方、供给曲线上方的面积。SR 中代表"超过可变成本"的部分(包括固定成本回收 + 利润);LR 中由于 [[长期零利润条件]] 通常 = 0(constant-cost 行业)。
- **R(政府收入)**:税收 - 补贴。
- **E(外部性)**:负外部性使社会成本 > 私人成本(MEC > 0,详见 [[Pigou税]] [Batch 4]);正外部性反之。

## 等价表述

$$W = \int_0^{X^*} [P^D(x) - P^S(x)] \, dx \quad (\text{无外部性、无政府介入时})$$

即"所有交易的边际净社会价值"之和。

完全竞争均衡 $X^{LR}$ 使该积分最大化(在 $P^D = P^S$ 处取最大值)。

## 几何直觉

- $X < X^{LR}$:右侧仍有 $P^D > P^S$ 的空间——增产增加 $W$。
- $X > X^{LR}$:增产 $P^D < P^S$,减少 $W$。
- $X = X^{LR}$:边际单位 $P^D = P^S$,$W$ 取最大值。

## 各类扭曲下的 DWL 公式

| 扭曲类型 | DWL 几何 | 大小 |
|---|---|---|
| 数量管制($\bar X < X^{LR}$) | $X^{LR}$ 与 $\bar X$ 之间的"未实现交易三角形" | $\frac{1}{2}(P^D - P^S)\Delta X$ |
| 价格上限 / 下限 | 短缺或过剩侧的三角形 | $\frac{1}{2} \Delta p \Delta X$ |
| 单位税 $t$ | $X^{LR}$ 与 $X^{tax}$ 之间的三角形 | $\frac{1}{2} t \Delta X$,Harberger formula |
| 关税 / 配额 | 进口减少导致的三角形 | $\frac{1}{2} \Delta p_w \Delta M$ |
| 价格 / 配置错误 | 任意偏离 $X^{LR}$ | $\frac{1}{2} \Delta P \Delta X$ |

> **统一公式**:DWL 总是 **$\frac{1}{2}$ × 价差 × 数量差**(Harberger 三角形)。详见 [[市场扭曲下的福利损失公式]]。

## CS / PS / W 的可比性争议

- **CS 是 EV / CV / Marshallian 的混淆**:严格福利分析需要补偿变化(CV)或等价变化(EV),而 CS = 需求曲线积分使用 Marshallian 需求,只有在 Quasilinear 偏好下(无收入效应)才与 CV / EV 一致。Willig 1976 证明对小价格变动两者差异 < 5%,但对大变动可能严重偏差。详见 [[补偿变化]] / [[等价变化]] [Batch 4 Ch 19]。

> **教材简化**:Nechyba 14B / 15B 默认 quasilinear 设定,使 $CS = CV = EV$,完全回避了上述微妙问题。

## 加总性问题

$W = CS + PS$ 的写法**默认每元等价对待**——富人的 1 元 CS 与穷人的 1 元 CS 在 $W$ 中权重相同。这等价于"分配中立"立场。

> **反面立场**:Atkinson 1970 提出"social welfare function with inequality aversion"——富人的边际美元应在福利函数中权重更低。教材完全采用功利主义加总,忽视分配公平的可能调整。

## 与税收 / 补贴的关系

- **从价税 $t$**:消费者支付 $p^c = p + t$,生产者收 $p^s = p$。CS↓、PS↓、R↑(总税收 = $tX^{tax}$)、DWL = $\frac{1}{2} t \Delta X$。
- **税收归宿**:消费者承担多少 / 厂商承担多少由两侧弹性比例决定:$\frac{\Delta p^c}{\Delta p^s} = \frac{\eta^S}{\eta^D}$(详见 [[税收归宿]])。

## 反面论点与数据空白

- **CS / PS 的隐含偏好假设**:加总 CS / PS 等价于功利主义福利函数 + 美元等价权重。Atkinson 1970 / Sen 1979 提出加权或不加总的福利函数,但教材完全采用 Marshall-Hicks 的功利主义传统。
- **PS = 0 vs PS > 0 的混淆**:教材有时将 PS 与"租"混用,有时与"利润"混用——LR 零利润条件下 PS 在 constant-cost 行业为 0,但 increasing-cost 行业有正 PS(Ricardian 租)。
- **行为经济学的批评**:Tversky-Kahneman 1991 endowment effect 实证发现 WTP < WTA 比例可达 2-3 倍,意味着 CS 与 PS 的对称性分析(Marshallian / Hicksian)在心理上不成立。
- **跨期 / 风险下的剩余**:Ch 17 风险与状态依赖商品下,CS / PS 概念需要重新定义为期望剩余,但教材延续静态确定性分析。
- **数据空白**:行业 DWL 估计的可信度——Harberger 1954 估计美国制造业垄断 DWL ≈ 0.1% GDP,Cowling-Mueller 1978 估计 ≈ 4% GDP,差异巨大,反映了估计方法的不稳健性。教材不引述。
