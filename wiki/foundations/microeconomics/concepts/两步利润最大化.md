# 两步利润最大化

> Nechyba Ch 11A.5 / 12A.4 / 13B.2 反复使用的方法论：**先成本最小化（CMP）→ 再利润最大化（PMP）**。这是 [[厂商对偶性]] 在求解层面的体现。

## 两步分解

**单步形式**：

$$
\max_{L, K} \;\; \pi(L, K) = p f(L,K) - wL - rK
$$

**两步形式**：

**Step 1**（成本最小化）：固定输出水平 $\bar x$，求最低成本投入组合：

$$
C(w, r, \bar x) = \min_{L, K} \; wL + rK \quad \text{s.t.} \quad f(L, K) = \bar x
$$

解为 [[条件投入需求]] $L^c(w, r, \bar x)$、$K^c(w, r, \bar x)$；值函数为 [[成本函数]]。

**Step 2**（输出选择）：在已知成本曲线的前提下选最优输出：

$$
\max_{x \geq 0} \;\; \pi(x) = p x - C(w, r, x)
$$

FOC：$p = \frac{\partial C}{\partial x} = MC(x)$，即"价格 = 边际成本"。

> **核心结论**：两步最优 = 单步最优。Step 1 决定"如何高效生产"，Step 2 决定"生产多少"。

## 为什么这样分解？

1. **Step 1 与价格 $p$ 无关**：技术约束（生产函数）和投入价格（$w, r$）共同决定成本。这意味着**成本曲线**是厂商面对**任何输出价格** $p$ 的"内在性质"。
2. **Step 2 把所有的市场需求 / 价格信息**塞进 $p$；成本曲线 + 价格即可定供给。
3. **方法论价值**：把高维联合优化（在 $L, K$ 上同时找最大值）拆成两个低维子问题（先在 $L, K$ 上做约束最优 → 再在标量 $x$ 上做无约束最优）——这是 [[包络定理]] 的经典应用场景。

## 与消费者侧 EMP/UMP 的对应

| 步骤 | 消费者侧 | 生产侧 |
|---|---|---|
| Step 1 | [[支出最小化问题]]（EMP）：固定 $\bar u$ 求最低开支 → [[补偿需求曲线]]、[[支出函数]] | [[成本最小化问题]]（CMP）：固定 $\bar x$ 求最低成本 → [[条件投入需求]]、[[成本函数]] |
| Step 2 | 用 $E(p, \bar u) = I$ 反解 $\bar u^*(p, I)$，得 [[间接效用函数]] | 用 $\max_x \{p x - C(w,r,x)\}$ 求 $x^*(p,w,r)$，得 [[利润函数]] |

> 二者**步骤序与机制完全镜像**——这是 [[消费者对偶性]] 与 [[厂商对偶性]] 在"求解机器"层面的同构性证明。

## 几何解读

在 $(x, \$)$ 平面上画成本曲线 $C(x)$：

- $C(x)$ 是 [[成本函数]] 关于 $x$ 的**值函数**；
- $MC(x) = dC/dx$ 是其切线斜率；
- 利润最大化 = 选择 $x^*$ 使 $p$ 与 $MC$ 相切。

```
     $
     │      / TR = px (斜率 p)
     │     /        ●  最大利润处
     │    /     C(x)  ↑(p = MC)
     │   /────────  
     │  /     /
     │ /     /
     │/     /
     0─────────── x
```

## 应用：Hotelling 引理通过两步法直推

由 Step 2 包络定理：$\partial \pi^* / \partial p = x^*$（不通过 $L^*, K^*$ 间接求导），即 [[Hotelling引理]] 的"输出供给"部分。再用 Step 1 包络定理（[[Shephard引理]]）：$\partial C / \partial w = L^c$，又得到"投入需求"部分。两步分解是**两件机器一次组装**的施工图。

## 反面论点与数据空白

- **要求生产集凸 + 价格外生**：与单步 PMP 共享前提；垄断 / 寡占下 Step 2 需替换为 $MR = MC$。
- **不可分性破坏两步法**：当生产存在最低批次或整数性约束时，Step 1 的最优可能不连续，Step 2 的求导不再适用。
- **多产出情形**：Nechyba 未涉及；多产出下 Step 1 / Step 2 都要相应推广为向量优化问题。
- **数据空白**：成本曲线的"光滑可微"假设依赖工程估计；Christensen-Greene 1976 给出 U 形 LRAC 的实证，但 Nechyba 不引。
