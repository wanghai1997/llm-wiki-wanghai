# 消费者对偶性

## 一句话定义

> [[效用最大化问题|UMP]] 与 [[支出最小化问题|EMP]] 在**解集层面完全镜像**——同一最优束 $x^*$，可由 $(p, m)$ 通过 UMP 或由 $(p, U^* = V(p, m))$ 通过 EMP 给出。两个问题及其价值函数（$V$ / $E$）通过四件"对偶机器"形式连接：

| 机器 | 把什么转化为什么 |
|---|---|
| [[Slutsky方程]] | $\partial x/\partial p$ → $\partial x^h/\partial p$（Marshall ↔ Hicks 价格效应） |
| [[Shephard引理]] | $E(p, U)$ → $x^h$ ($\partial E/\partial p_i = x^h_i$) |
| [[Roy恒等式]] | $V(p, m)$ → $x$ ($x_i = -V_{p_i}/V_m$) |
| [[包络定理]] | 提供前三件机器的**统一证明**（FOC 在最优处的一阶导规则） |

## 价值函数对偶

$$E(p, V(p, m)) = m, \qquad V(p, E(p, U)) = U$$

→ $V$ 与 $E$ **互为反函数**（在 $U$ / $m$ 维度上）。

需求函数对偶：

$$x_i^h(p, V(p, m)) = x_i(p, m), \qquad x_i(p, E(p, U)) = x_i^h(p, U)$$

→ Marshallian 与 Hicksian 需求**互推**。

## 几何

| | 起点 | 切点条件 | 解函数 |
|---|---|---|---|
| UMP | 沿预算线扫 IC | 预算线 / IC 相切 | $x(p, m)$, $V(p, m)$ |
| EMP | 沿 IC 扫预算线 | IC / 预算线相切 | $x^h(p, U)$, $E(p, U)$ |

两者切点条件**同一**：MRS = $p_1/p_2$ ——这是为什么解集镜像。

## 实证 vs 理论的角色分配

| 问题 | 工具 |
|---|---|
| 估计实际消费需求 | Marshallian 需求 $x(p, m)$（**可观测**） |
| 度量真实福利变化 | Hicksian 需求 $x^h(p, U)$（**理论一致**） |
| 在二者之间转换 | [[Slutsky方程]] / [[Roy恒等式]] / [[Shephard引理]] |

## 生产侧镜像：[[厂商对偶性]]

厂商侧 [[成本最小化问题|CMP]] ↔ [[利润最大化问题|PMP]] 也对偶,但**结构非完全同构**：

### 对照

| 消费侧对偶 | 生产侧对偶（[[厂商对偶性]]）|
|---|---|
| UMP（max 效用 s.t. 预算）| CMP（min 成本 s.t. 产出）|
| EMP（min 支出 s.t. 效用）| PMP（max 利润，无外约束）|
| 两题**互为反向**优化（max-min 翻转）| 两题**通过 $\max_x\{px-C\}$ 串联**|
| $V$ 与 $E$ 互为反函数（在 $U$ / $m$ 维度）| $\pi^*(p, w, r) = \max_x\{px - C(w, r, x)\}$（**组合**而非反演）|
| 4 件机器：Slutsky / Shephard / Roy / 包络 | 4 件机器：Shephard（生产）/ Hotelling / "厂商 Slutsky" / 包络 |
| 序数效用 → Roy 须除以 $V_m$ | 基数利润 → Hotelling 直接读偏导 |

### 关键结构差异

> 消费侧对偶是**反演型**（V ↔ E 互为反函数），生产侧对偶是**组合型**（$\pi^* = \max_x\{px - C\}$ 把 CMP 的解嵌入 PMP）。

这一差异源于：
1. **目标基数 vs 序数**：利润有货币度量、可与价格直接相加（$px - wL - rK$），效用是序数（"$+$ 价格"无意义，需除以 $V_m$）。
2. **约束的角色**：UMP 预算约束有边界（$p \cdot x = m$），PMP 无显式约束（利润已含价格惩罚）；故"反演"在生产侧不是机器,而是"两步分解"。

### 实证-理论分配的镜像

| 问题 | 消费侧工具 | 生产侧工具 |
|---|---|---|
| 估计实际行为 | Marshallian $x(p, m)$ | [[无条件投入需求]] $L^*(p, w, r)$ |
| 度量真实福利变化 | Hicksian $x^h(p, U)$ | [[条件投入需求]] $L^c(w, r, \bar x)$ |
| 换算桥梁 | Slutsky | "厂商 Slutsky" |

详见 [[厂商对偶性]] §"对照表"。

## 与 Batch 3 一般均衡的连接

Ch 16 的 [[一般均衡-Walras版]] 把个体 UMP / EMP 聚合为市场均衡:
- **UMP 的加总**:每个消费者按 $p$ 求解 UMP → 个体 Marshallian 需求 $x^i(p, m^i)$ → 水平加总 = [[市场需求曲线]]。
- **EMP 的福利应用**:社会计划者用 EMP 框架评估政策福利变化(CV / EV),但 GE 分析需要把所有消费者的 EMP 同时纳入 Edgeworth 盒的契约曲线。
- **对偶机器在 GE 中的角色**:Roy 恒等式 / Shephard 引理 / Slutsky 方程是推导 GE 比较静态(价格变化如何影响需求 → 市场出清如何调整)的基础工具。

> **关键张力**:UMP / EMP 假设个体是价格接受者;GE 中价格由总供需决定。核收敛定理([[核收敛定理]])证明大经济中这一假设的合作博弈论辩护成立。

## 反面论点与数据空白

- **[BIAS] "解集镜像"假设凸偏好 + 内点解**：[[非凸偏好与多解]] 或 [[角点解]] 下对偶机器可能失效——教材在 Ch 10 不展开。
- **[BIAS] 教材偏向"对偶系统优雅"**：但 MWG 等高级教材会指出对偶在公共品 / 不完全市场下需要修改——教材 Ch 10 不引入这些边界。
- **数据空白**：对偶机器的实证应用（用 $E$ 估计 CV/EV，用 $V$ 估计 IRR 等）在 Ch 1–10 不出现。
