# 借贷需求曲线

## 一句话定义

> 借贷者在不同利率 $r$ 下选择的最优借入量 $b^*(r) = c_1^* - m_1$（当 $> 0$ 表示借入；$< 0$ 表示储蓄）形成的曲线。是 [[资本供给曲线]] 的镜像。

## 推导路径（Ch 9）

| 步骤 | 工具 |
|---|---|
| 1 | [[跨期预算约束]]：$c_1 + c_2/(1+r) \le m_1 + m_2/(1+r)$ |
| 2 | 求 $c_1^*(r)$ |
| 3 | $b^*(r) = c_1^*(r) - m_1$ |
| 4 | 在 $(b, r)$ 平面绘曲线 |

## 形态

| $r \uparrow$ 时净借贷者 | 影响 |
|---|---|
| SE | 借贷变贵 → 减少今日消费 → 减少借入 |
| IE_W | 财富贴现值变化（净借贷者贴现价值上升 → 财富下降）→ 倾向减少今日消费 → 减少借入 |
| **总效应** | SE + IE 同向 → 借贷需求曲线**通常下倾** |

> 注：这与 [[资本供给曲线]] 的"非单调"形成对比——
> - 净储蓄者：SE 与 IE 反向（"禀赋价值变化"主导反向 IE）→ 可能后弯；
> - 净借贷者：SE 与 IE 同向 → 曲线规整下倾。

## 与 [[资本供给曲线]] 的对偶

- 个体既是借贷者又是储蓄者的可能性 → 同一禀赋点 $(m_1, m_2)$ 下，最优 $c_1^*$ 与 $m_1$ 比较决定身份；
- 利率变化时身份可能切换；
- 总市场利率由汇总供给（储蓄）= 汇总需求（借贷）决定（一般均衡视角，伏笔到 Ch 16）。

## 政策应用

- **房贷利率政策** ：央行调控基准利率 → 借贷需求曲线沿轴移动 → 影响家庭杠杆与房地产。
- **学生贷款补贴** ：相当于把净 $r$ 拉低 → 沿曲线移动到更高借贷量。
- **信贷紧缩** ：曲线左移（数量配给）→ 借贷量低于"利率均衡"水平。

## 反面论点与数据空白

- **[BIAS] 单一利率假设**：借贷与储蓄实际利差显著——教材在 Ch 9 不展开。
- **[BIAS] 理性预期假设**：现实借贷者对未来收入 $m_2$ 的期望可能系统性偏离实际（特别是年轻人/学贷），教材不涉及。
- **数据空白**：当代信贷约束 / 流动性约束文献（Hall-Mishkin, Zeldes 1989）在 Ch 1–10 不出现。
