# 生产外部性

> Production Externality

生产外部性是指厂商的生产决策对**非交易第三方**产生的、未通过市场价格反映的成本或收益。

## 经典案例：污染工厂与养鱼场

### 负外部性（Negative Production Externality）

上游钢铁厂排放废水 → 下游养鱼场产量下降。

- **私人边际成本**（PMC）：钢铁厂的直接生产成本。
- **社会边际成本**（MSC）：PMC + 养鱼场损失。
- 市场均衡：$P = PMC$ → 产量 $Q_{\text{市场}}$ 过高。
- 社会最优：$P = MSC$ → 产量 $Q_{\text{社会最优}} < Q_{\text{市场}}$。
- **福利损失**：$Q_{\text{社会最优}}$ 到 $Q_{\text{市场}}$ 之间，MSC > 消费者支付意愿 → 每多生产一单位，社会净损失。

### 正外部性（Positive Production Externality）

养蜂场为附近果园授粉 → 果园产量提高但无需付费。

- **私人边际收益**（PMB）：养蜂场的蜂蜜收入。
- **社会边际收益**（SMB）：PMB + 果园增产价值。
- 市场均衡：$PMB = MC$ → 养蜂量 $Q_{\text{市场}}$ 过低。
- 社会最优：$SMB = MC$ → 养蜂量 $Q_{\text{社会最优}} > Q_{\text{市场}}$。

- $Q_{\text{market}}$：$P = PMC$ 的交点（市场均衡）。
- $Q^*$：$P = MSC$ 的交点（社会最优）。
- $Q_{\text{market}} > Q^*$ → 过度生产。
- DWL = MSC 与需求曲线之间、从 $Q^*$ 到 $Q_{\text{market}}$ 的三角形面积。

## 其他案例

| 行业 | 外部性 | 受影响方 |
|---|---|---|
| 燃煤发电 | 空气污染、碳排放 | 公众健康、全球气候 |
| 畜牧业 | 甲烷排放、水体污染 | 周边居民、下游用户 |
| 采矿 | 土地退化、尾矿污染 | 当地社区、未来世代 |
| 数据中心 | 高能耗、水耗、热污染 | 电网、水资源、局部气候 |
| 软件/平台 | 正：网络效应、数据溢出 | 用户、开发者 |

## 反面论点与数据空白

- 教材通常用**单一污染者 + 单一受害者**的简化模型。现实中的污染通常是**多污染源 + 多受害者**（如城市空气污染涉及数百万车辆和工厂）→ Coase 定理的谈判解决不可行。
- **边际外部成本（MEC）的测量极其困难**：需要因果识别污染与损害的关系（如 PM2.5 与肺癌的剂量-反应关系），涉及流行病学、环境科学、统计学等多学科。
- **技术变革改变外部性**：同一行业的 MEC 随清洁技术而下降（如可再生能源降低电力行业的碳外部性）。
- 数据中心的能耗外部性：全球数据中心耗电约 1-2%（IEA 2022），但增长极快；AI 训练（如大模型）的单次能耗极高 → 外部性随 AI 扩张而急剧增加。缺乏对 AI 行业外部性的系统经济学分析。
