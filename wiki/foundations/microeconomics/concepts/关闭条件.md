# 关闭条件

> 厂商何时**短期停产** vs **长期退出**？由价格与平均成本的比较决定，是 [[输出供给曲线]] 在低价格段的几何边界。

## 核心命题

| 时段 | 关闭条件 | 经济解释 |
|---|---|---|
| **短期 SR** | $p < AVC_{\min}$ | 价格连可变成本都覆盖不了 → 停产（仍承担 $r\bar K$）|
| **长期 LR** | $p < LAC_{\min}$ | 长期价格低于最小有效平均成本 → 退出市场（甩卖资本）|

读法："短期看 AVC，长期看 LAC——固定成本在短期是**沉没**的，在长期是**可避免**的。"

## 短期关闭决策

短期 PMP（详见 [[短期利润最大化]]）：

$$
\max_L \pi^{\text{SR}} = p f(L; \bar K) - wL - r\bar K
$$

如果生产，$\pi^{\text{SR}}(x^*) = (p - SAVC(x^*)) \cdot x^* - r\bar K$。

如果不生产（$L = 0$），$\pi^{\text{SR}}(0) = -r\bar K$。

**生产 vs 关闭比较**：

$$
(p - SAVC(x^*)) \cdot x^* - r\bar K \;\;\geq\;\; -r\bar K
$$

简化（$r\bar K$ 在两侧抵消，因 SR 不可避免）：

$$
\boxed{
p \cdot x^* \geq SAVC(x^*) \cdot x^* \;\;\Longleftrightarrow\;\; p \geq SAVC(x^*)
}
$$

由 PMP FOC $p = SMC$，关闭点是 $SMC = SAVC$ 处，即 $SAVC$ 的最小点：

$$
\boxed{p_{\text{shutdown SR}} = SAVC_{\min}}
$$

## 长期退出决策

长期无固定成本（$K$ 可调到 0）：

$$
\pi^{\text{LR}}(x^*) = (p - LAC(x^*)) \cdot x^*
$$

$\pi^{\text{LR}} \geq 0$ 等价于 $p \geq LAC(x^*)$。由 PMP FOC $p = LMC$，最低生产价格 = $LMC$ 与 $LAC$ 的交点 = $LAC_{\min}$：

$$
\boxed{p_{\text{exit LR}} = LAC_{\min}}
$$

## 几何（短期供给曲线）

```
  p
   │       SMC
   │      /
   │     / SAC
   │    / /
   │   / / SAVC
   │  / //
   │ ●关闭点: SMC = SAVC_min
   │/ /
   │ /  
   │/  
   │_______________ x

  供给曲线 = SMC 在 SAVC 之上的部分
```

短期供给曲线 $S^{SR}(p)$：

$$
S^{SR}(p) = \begin{cases} 0 & p < SAVC_{\min} \\ x \text{ s.t. } SMC(x) = p & p \geq SAVC_{\min} \end{cases}
$$

> 在关闭价格 $p = SAVC_{\min}$，供给从 0 跳到正值（不连续点）。

## 长期供给曲线

$$
S^{LR}(p) = \begin{cases} 0 & p < LAC_{\min} \\ x \text{ s.t. } LMC(x) = p & p \geq LAC_{\min} \end{cases}
$$

长期下市场供给曲线还需考虑**厂商进入**：当 $p > LAC_{\min}$ 时新厂商进入直至零利润，故行业**长期供给曲线**通常水平于 $p = LAC_{\min}$（自由进入假设下）。

## 决策树

```
     是否 p ≥ SAVC_min?
       /        \
      否          是
      ↓          ↓
   SR 关闭    SR 生产 x* (SMC = p)
   x = 0       │
      │       是否 p ≥ LAC_min?
      │       /         \
      │      否           是
      │      ↓            ↓
      │   长期退出       长期保留
      │  (亏损但 SR 不止血更糟)  (盈利或零利润)
      │
   长期退出
```

## 关键直觉：固定成本在 SR 不影响决策

> "已花的钱不再是成本"——经济学的关键直觉。

短期固定成本 $r \bar K$ 是**沉没成本（sunk）**：无论生产与否都已支付。因此，关闭决策**不应**依赖 $r \bar K$，仅依赖**可变**部分（AVC）。

**反例直觉**：刚买了昂贵机器但市场暴跌，$p < SAC$。许多人想"必须用机器赚回投资"——错。理性决策仅看 $p$ vs $SAVC$：若 $p > SAVC$，**继续生产**减少损失（每单位赚 $p - SAVC > 0$ 摊薄沉没成本）；若 $p < SAVC$，停产（继续生产是雪上加霜）。

## [BIAS] 概念漂移：固定 / 沉没 / 可避免

教材中常出现术语漂移：

| 术语 | Nechyba 用法 | 严格定义 |
|---|---|---|
| 固定成本 fixed cost | $r \bar K$（与 $x$ 无关）| 短期不变 |
| 沉没成本 sunk cost | 模糊，常等同 fixed | 已支付不可挽回 |
| 可避免成本 avoidable cost | 不强调 | 长期可消除 |

> 严格地说，关闭决策应区分"沉没（已花，与未来决策无关）"vs"准固定（短期不变但长期可避免）"。Nechyba Ch 13.B 处理可读但术语松散。本 Wiki 在 [[短期成本与长期成本]] §"固定成本 vs 沉没成本" 严格表格化。

## 与 Batch 3 自由进入退出的连接

Ch 14 的 [[自由进入退出]] 是关闭条件的长期动态版:

| 维度 | SR 关闭(Ch 13) | LR 退出(Ch 14) |
|---|---|---|
| 触发条件 | $p < SAVC_{\min}$ | $p < LAC_{\min}$ |
| 资本可否回收 | 否(固定成本沉没) | 是(资本可调整) |
| 决策准则 | 不亏可变成本 | 不亏总成本(含资本机会成本) |
| 对称性 | 关闭后可重启 | 退出后需重建 |

- LR 退出门槛 $\min LAC$ > SR 关闭门槛 $\min AVC$ → LR 退出更"激进"。
- 但沉没成本破坏对称性:Dixit 1989 *sunk cost hysteresis* 使经济利润在某区间既不进也不出。
- [[长期零利润条件]]:LR 均衡 $p^{LR} = \min LAC$,$\pi = 0$。
- **僵尸企业**(Caballero-Hoshi-Kashyap 2008):银行延贷使应退出企业不退,关闭条件失效。

## 应用

1. **油气行业关闭**：油价跌破 $SAVC_{\min}$ ≈ $30/桶（仅勘探与抽取）时，短期停产；跌破 $LAC_{\min}$ ≈ $50/桶（含资本回收）时，永久封井。
2. **航空业 COVID 关停**：2020 年 $p$ 远低于 $SAC$ 但高于 $SAVC$ → 部分航司继续运营（少损失）；少数破产退出（$p$ 持续低于 $LAC$）。
3. **僵尸企业（Caballero-Hoshi-Kashyap 2008）**：信贷补贴使得本应退出的厂商保留，扭曲资源配置——这是关闭条件失效的政策反例。
4. **科技公司"亏损扩张"反例**：Uber、Snap 长期 $p < LAC$ 但持续运营——预期未来 IRS / 网络效应使 $LAC$ 下降。本 Wiki 在 [[规模报酬]] [BIAS] 已铺垫——这是 IRS 故事的金融化叙事，超完全竞争模型范围。

## 反面论点与数据空白

- **不可逆退出 / 重启成本**：现实中"退出"再"进入"有重大转换成本（如品牌重建），关闭决策应是动态选项问题（real option theory），Dixit-Pindyck 1994 框架超 Nechyba 范围。
- **金融约束**：流动性短缺可能使厂商即使 $p > SAVC$ 也被迫关闭（无法支付工资），关闭条件需加金融约束（Bond-Meghir 1994）。
- **多产品厂商**：单产品下关闭就是"零产出"；多产品下可能停某产品而保留其他——决策维度爆炸。
- **数据空白**：行业关闭 / 退出率的实证（Dunne-Roberts-Samuelson 1988 关于行业进出动态）未被 Nechyba 引用。
