# 逆向选择

> Adverse Selection

逆向选择是指由于**事前信息不对称**（hidden information），高质量品退出市场、低质量品充斥市场，导致市场平均质量下降的动态过程。它是 [[信息不对称]] 的核心表现形式之一。

## 经典模型：Akerlof 的柠檬市场（1970）

### 设定

- 二手车市场：卖方知道车的真实质量（好车 worth $2000$ 或 柠檬 worth $1000$），买方不知道。
- 买方只愿支付**期望价值**：$E[V] = p \times 2000 + (1-p) \times 1000$。
- 好车车主的保留价格 = $1500$；柠檬车主的保留价格 = $500$。

### 动态

1. 初始市场：好车占 50% → 买方出价 $E[V] = 1500$。
2. 好车车主不愿以 $1500$ 出售（保留价 $1500$ = 出价，无剩余）→ 部分好车退出。
3. 市场中好车比例下降 → $E[V]$ 下降 → 更多好车退出。
4. 恶性循环：最终好车全部退出 → 市场只剩柠檬 → 买方出价 $1000$ → 柠檬车主出售（$1000 > 500$）。
5. **极端结果**：若好车比例初始过低，市场**完全崩溃**（买方出价低于柠檬车主的保留价）。

### 核心不等式

逆向选择发生的条件：

$$E[V|\text{市场}] < \text{高质量卖方的保留价格}$$

即：买方的期望支付不足以补偿高质量卖方的机会成本。

## 其他案例

| 市场 | 信息结构 | 逆向选择表现 |
|---|---|---|
| **健康保险** | 投保人知自身健康，保险公司不知 | 健康者退出 → 参保池风险上升 → 保费上涨 → 更多健康者退出 |
| **劳动力市场** | 工人知自身能力，雇主不知 | 高能力者不愿接受平均工资 → 低能力者充斥 → 平均工资进一步下降 |
| **信贷市场** | 借款人知项目风险，银行不知 | 安全项目借款人退出 → 银行提高利率 → 更多安全项目退出（Stiglitz-Weiss 1981） |
| **金融市场** | 发行方知资产质量，投资者不知 | 好公司不愿以平均价发行 → 市场充斥坏公司 → IPO 折价 |

## 数学化：保险市场的二元类型模型

- 两类投保人：低风险（概率 $\pi_L$）和高风险（概率 $\pi_H$），$\pi_L < \pi_H$。
- 保险公司提供统一合同 $(p, b)$（保费 $p$，赔付 $b$）。
- 竞争性均衡要求零利润：$p = \bar{\pi} b$，$\bar{\pi}$ = 参保池平均风险。
- 若低风险者退出 → $\bar{\pi}$ 上升 → $p$ 上升 → 更多低风险者退出。
- Rothschild-Stiglitz（1976）证明：竞争性均衡可能**不存在**（见 [[竞争性均衡的非存在性]]）。

## 反面论点与数据空白

- Akerlof 模型预测市场**完全崩溃**，但现实中：
  - **质保**（warranty）：好车卖家更愿意提供长期质保（因为故障概率低）→ 质保成为分离信号。
  - **品牌声誉**：重复交易中的声誉机制降低信息不对称。
  - **第三方认证**：Carfax、质检报告等外部验证。
  - **政府强制**：柠檬法（Lemon Laws）要求披露车辆事故史。
- Genesove（1993）对二手车市场的实证发现：质量差异确实存在，但市场**并未崩溃**——多种缓解机制同时运作。
- **连续类型空间**：Akerlof 模型是二元类型（好/坏）的极端简化。连续类型下，结论更复杂——通常是**部分崩溃**而非全部崩溃（Riley 2001）。
- 数据平台的**信息优势悖论**：平台声称通过数据降低信息不对称（如 Uber 的司机评分），但平台本身的信息不透明（算法黑箱）创造了新的信息不对称。
