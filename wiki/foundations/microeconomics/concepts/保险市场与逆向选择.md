# 保险市场与逆向选择

> Insurance Markets and Adverse Selection

保险市场是[[逆向选择]]理论最经典的应用场景。投保人与保险公司之间的信息不对称（投保人知自身风险，保险公司不知）导致市场效率损失甚至崩溃。

## 基础模型

### 设定

- 两类投保人：
  - 低风险（L）：事故概率 $\pi_L$，比例 $q$
  - 高风险（H）：事故概率 $\pi_H$，比例 $1-q$
  - $\pi_L < \pi_H$
- 初始财富 $W$；事故损失 $L$。
- 保险合同：$(p, b)$，保费 $p$，赔付 $b$（事故发生时）。
- 投保人效用：$u(W - p)$（无事故）或 $u(W - p - L + b)$（有事故）。
- 保险公司利润：$p - \pi b$（期望利润）。

### 信息对称基准

若保险公司知道投保人类型：
- 对 L 提供**精算公平合同**：$p_L = \pi_L b_L$ → L 选择**完全保险** $b_L = L$。
- 对 H 提供**精算公平合同**：$p_H = \pi_H b_H$ → H 选择**完全保险** $b_H = L$。
- 两类人均达到最优风险分担。

### 信息不对称下的分离均衡

保险公司提供合同菜单 $(p_L, b_L)$ 和 $(p_H, b_H)$，满足：

1. **零利润条件**：
   - 高风险合同：$p_H = \pi_H b_H$（完全保险，$b_H = L$）
   - 低风险合同：$p_L = \pi_L b_L$（部分保险，$b_L < L$）

2. **激励相容约束**：
   - H 不冒充 L：$u(W - p_H) \geq (1-\pi_H)u(W - p_L) + \pi_H u(W - p_L - L + b_L)$
   - L 不冒充 H：自动满足（L 在 $(p_L, b_L)$ 下更好）

**关键结果**：低风险者获得**部分保险**（作为"自选择"的代价），高风险者获得**完全保险**。

### 混同均衡

若保险公司提供单一合同 $(p_P, b_P)$：
- $p_P = \bar{\pi} b_P$，$\bar{\pi} = q\pi_L + (1-q)\pi_H$
- 两类人均选择同一合同 → 信息不揭示。
- 但通常被**直观标准**排除（若有分离合同更优）。

## 现实中的缓解机制

### 强制参保

- **汽车保险**：多数国家强制所有车主参保 → 消除逆向选择。
- **全民医保**：英国、加拿大、德国等 → 强制混合风险池。
- **奥巴马医改（ACA）**：个人强制参保令 + 雇主强制提供 → 扩大风险池。

### 风险分类（Risk Classification）

保险公司根据**可观测特征**进行初步分类：
- 年龄、性别、职业、居住地。
- 健康状况问卷（有限但有用）。
- 行为数据（驾驶记录、理赔历史）。

### 部分保险设计

通过**免赔额**（deductible）和**共付比例**（coinsurance）实现自我选择：
- 低风险者接受高免赔额（愿自担风险）→ 低保费。
- 高风险者接受低免赔额（不愿自担风险）→ 高保费。

## 实证证据

### 经典研究

- **Chiappori-Salanie（2000）**：法国汽车保险市场——在控制可观测风险因素后，未发现显著的逆向选择证据。可能的解释：风险分类已足够精细。
- **Sydnor（2010）**：房屋保险市场——发现"过度保险"现象（低风险者购买过多保险），与标准逆向选择模型预测相反。可能原因：行为偏差（概率误判）。
- **Finkelstein-Poterba（2004）**：英国年金市场——发现显著的逆向选择（长寿者更倾向购买年金）。

### 悖论：逆向选择未必存在

实证研究发现，许多保险市场**未表现出**强烈的逆向选择。原因可能包括：
1. 风险分类技术足够精细（大数据、基因检测争议）。
2. 消费者缺乏信息（并非总是信息优势方）。
3. 行为偏差（过度保险或保险不足）。
4. 监管限制（如禁止基因歧视）。

## 反面论点与数据空白

- 标准模型假设投保人**完全理性**且**精确知自身风险**。现实中：
  - 多数人**高估**小概率风险（购买过度保险）。
  - 部分人**低估**风险（保险不足）。
  - 行为因素（如默认选项、框架效应）对保险选择的影响可能超过逆向选择。
- **基因检测的双刃剑**：基因技术使风险预测更精确 → 理论上降低信息不对称。但若允许保险公司使用基因信息 → 高风险者无法获得保险 → "基因歧视"伦理问题。
- 大模型/AI 在保险定价中的应用：算法可能发现传统统计方法遗漏的风险模式 → 更精细的风险分类 → 逆向选择减少，但"算法歧视"和"不可解释性"成为新问题。
