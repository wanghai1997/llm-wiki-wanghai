# 成本最小化问题（CMP）

> [[两步利润最大化]] 的 **Step 1**——固定输出找最低成本投入组合。是消费者侧 [[支出最小化问题]] 的完全镜像。

## 问题陈述

给定输出水平 $\bar x$、要素价格 $(w, r)$、生产函数 $f(L, K)$：

$$
\boxed{
\min_{L, K \geq 0} \;\; wL + rK \quad \text{s.t.} \quad f(L, K) = \bar x
}
$$

解：[[条件投入需求]] $L^c(w, r, \bar x)$、$K^c(w, r, \bar x)$。
值函数：[[成本函数]] $C(w, r, \bar x) = wL^c + rK^c$。

## 拉格朗日

$$
\mathcal{L}(L, K, \mu) = wL + rK + \mu \cdot (\bar x - f(L, K))
$$

FOC：

$$
\frac{\partial \mathcal{L}}{\partial L}: w = \mu \cdot MP_L \\
\frac{\partial \mathcal{L}}{\partial K}: r = \mu \cdot MP_K
$$

二者相除：

$$
\boxed{\frac{w}{r} = \frac{MP_L}{MP_K} = MRTS_{LK}}
$$

即"等成本线斜率 = [[等产量线]] 斜率"——内点最优 = [[边际技术替代率MRTS|MRTS]] 等于要素价格比。$\mu^*$ 是边际成本（产出增加 1 单位的额外成本）。

## 几何

```
    K
    │
    │\\\\        最低 \等成本线
    │  \\\\\          ●(L^c, K^c) 切点
    │     \\\\\\______
    │           ___f(L,K)=x̄ 等产量线
    │          /
    │_________/__________ L
```

在 $\{f(L,K) = \bar x\}$ 等产量线上找**最低**等成本线 $wL + rK = \bar C$ 的切点。

## 与 EMP 的镜像

| EMP（消费者）| CMP（厂商）|
|---|---|
| $\min p \cdot x$ s.t. $u(x) \geq \bar u$ | $\min w \cdot L + r \cdot K$ s.t. $f(L,K) \geq \bar x$ |
| $MRS = p_1/p_2$ | $MRTS = w/r$ |
| $\bar u$ 是"目标效用"，序数 | $\bar x$ 是"目标产出"，基数 |
| 解：[[补偿需求曲线]] $h(p, \bar u)$ | 解：[[条件投入需求]] $L^c, K^c$ |
| 值函数：[[支出函数]] $E(p, \bar u)$ | 值函数：[[成本函数]] $C(w, r, \bar x)$ |

> 二者**结构同构**——这是 [[厂商对偶性]] 在求解层面的根。

## 关键性质

由对偶理论可证：

1. **$C(w, r, \bar x)$ 在 $(w, r)$ 上凹**（对偶函数普性，与 [[支出函数]] 一致）。
2. **$C(w, r, \bar x)$ 在 $\bar x$ 上单调递增**（更多产出需要更多投入）。
3. **[[Shephard引理]]（生产侧）**：$\partial C / \partial w = L^c$、$\partial C / \partial r = K^c$。

## 与 PMP 的关系

[[利润最大化问题|PMP]] 与 CMP 等价（[[厂商对偶性]]）：

$$
\pi^*(p, w, r) = \max_{x \geq 0} \{p x - C(w, r, x)\}
$$

——CMP 给出的 $C(\cdot)$ 完全决定 PMP 的解。FOC：$p = \partial C / \partial x = MC$。

## 反面论点与数据空白

- **要求生产集凸**：非凸生产集下 CMP 可能多解；FOC 仅必要、非充分。
- **要素价格外生假设**：在垄断买方（monopsony）下 $w$ 内生于厂商雇佣量，CMP 退化。
- **要素不可分**：现实中工厂雇佣以"班次 / 工种"为单位，$L$ 是离散变量；CMP 的连续解仅近似。
- **数据空白**：跨行业 CMP 解的实证（Christensen-Greene-Jorgenson 1970s 之后的"成本函数估计"文献综述）未被 Nechyba 引用。
