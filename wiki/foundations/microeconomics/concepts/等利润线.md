# 等利润线

> Nechyba Ch 11A.2 "Tastes for Profits"——把厂商的"利润目标"几何化：在 $(L, x)$ 平面上，**等利润线**就是厂商的"无差异曲线"。

## 定义

**等利润线**是 $(L, x)$ 平面上**给定利润水平** $\bar\pi$ 的所有 $(L, x)$ 组合的轨迹：

$$
\bar\pi = px - wL \;\Longleftrightarrow\; x = \frac{w}{p} L + \frac{\bar\pi}{p}
$$

- **斜率** = $w/p$（产品价格 / 工资比的倒数 → 工资 / 产品价格之比）
- **截距** = $\bar\pi / p$（利润水平的"产品当量"）
- **越靠上越好**：等利润线截距越大、利润越高

## 几何与经济直觉

- 把劳动 $L$ 视为投入"商品"，产出 $x$ 视为产出"商品"——等利润线是厂商在该坐标系下的**线性偏好**（无 [[边际替代率MRS|MRS]] 递减）。
- 厂商不像消费者那样有凸偏好；厂商的目标是**线性的**：每多 1 单位 $L$ 必须带来至少 $w/p$ 单位 $x$ 才"不亏"。
- **利润最大化** = 选择 $(L, x)$ 使其落在最高的等利润线上，**且** $(L, x)$ 在 [[生产函数]] $x \leq f(L)$ 的可行集内。

## 在 PMP 中的角色

PMP 几何：

```
    x
    │      / 等利润线 π = π* (最高)
    │     /
    │    /●  (L*, x*)  ← 最优生产点
    │   /  \
    │  /    \   生产函数 f(L)
    │ /      \
    │/________\____ L
```

最优条件：等利润线**与生产函数相切**——

$$
\text{切点斜率} = MP_L = \frac{w}{p} \;\Longleftrightarrow\; p \cdot MP_L = w
$$

即 [[价值边际产品VMP]] = 工资。

## 与消费者侧的镜像

| 消费者侧 | 生产侧 |
|---|---|
| [[预算约束]] $p_1 x_1 + p_2 x_2 = I$（约束）| 等利润线 $\bar\pi = px - wL$（**目标**，而非约束）|
| [[无差异曲线]]（**目标**） | [[生产函数]] $x \leq f(L)$（**约束**） |
| 切线条件：$MRS = p_1/p_2$ | 切线条件：$MP_L = w/p$ |

> **角色互换**：消费者把约束（线性）和目标（凸 IC）配对；厂商把目标（线性等利润线）和约束（凹生产函数）配对。这种**对称性翻转**是教材"两步利润最大化"思路的核心动机。

## 多投入推广

Ch 12 把等利润线推广为 [[等利润平面]]——$(L, K, x)$ 三维空间中的平面 $\bar\pi = px - wL - rK$。几何变 3 维，但相切条件保持：$MP_L = w/p$、$MP_K = r/p$。

## 反面论点与数据空白

- **"利润最大化"行为假设的局限**：Baumol 1959 / Marris 1964 提出"销售最大化"或"增长最大化"作为厂商目标；委托-代理问题（Jensen-Meckling 1976）使"利润"难以观测。Nechyba 推迟到 Ch 22。
- **风险中性假设**：等利润线把利润视为确定数；现实中厂商对**预期利润**做选择，且要权衡风险。Ch 17（Batch 4）才引入风险偏好。
- **会计利润 vs 经济利润**：等利润线中的 $\pi$ 是**经济利润**（已扣机会成本），与会计报表的"经营利润"不同——这一术语漂移在 13A 才被显式区分。
