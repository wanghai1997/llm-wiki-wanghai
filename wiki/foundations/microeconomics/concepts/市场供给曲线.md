# 市场供给曲线

> 把市场上**所有厂商**的 [[输出供给曲线]] **水平加总**得到的曲线。是 Ch 14 市场均衡分析的供给侧输入。

## 形式定义

设市场有 $J$ 家厂商,第 $j$ 家厂商的输出供给为 $x^j(p, w, r)$。市场供给为:

$$
\boxed{
X^S(p; w, r) = \sum_{j=1}^J x^j(p, w, r)
}
$$

直观:在固定价格 $p$ 下,把每家厂商愿意供给的数量相加。

## 短期 vs 长期

| 维度 | 短期(SR) | 长期(LR) |
|---|---|---|
| 厂商数 $J$ | **固定** | **内生**(自由进入退出) |
| 个体供给 | $x^{j,SR}(p; \bar K_j)$,资本 $K_j$ 固定 | $x^{j,LR}(p)$,所有要素可调 |
| 加总形式 | 简单水平加 | 自由进入使 $J \to J^*$ 直到零利润 |

详见 [[短期均衡]] / [[长期均衡]] / [[长期供给曲线]]。

## 几何加总:水平加总

与 [[市场需求曲线]] 镜像。固定 $p$,沿 $x$ 轴把所有个体供给曲线横向叠加:每家厂商在 $p$ 下供给 $x^j(p)$,市场总量为 $\sum_j x^j(p)$。

## 关闭决策与市场供给的下端

每家厂商个体的 [[关闭条件]] 给出"$p$ 低于关闭价格 $p^{shutdown}$ 时不生产"。市场供给曲线在低 $p$ 段会有**断点**:
- 若 $p > p^{shutdown}$:所有厂商正常供给,$X^S = \sum_j x^j(p)$。
- 若 $p < p^{shutdown}$ 中某些厂商:这些厂商关闭,不在 $X^S$ 中。

异质厂商(不同 $p^{shutdown}$)使市场供给曲线在低价段呈台阶状或不连续。

## 长期自由进入的影响

长期内潜在厂商可自由进入。若 $p > \min LAC$(超额利润存在)→ 新厂商进入 → $X^S$ 右移 → $p$ 下降。均衡条件 $p = \min LAC$ 使每家在位厂商**经济利润为零**(详见 [[长期零利润条件]] / [[自由进入退出]])。

LR 行业供给曲线的形状取决于行业类型(constant-cost / increasing-cost / decreasing-cost),详见 [[长期供给曲线]] / [[完全竞争行业类型]]。

## 性质

- **正斜率**(在内点处):个体 $x^j(p)$ 通常在 $p > \min AVC$ 时正斜率(Hotelling 引理 + $\pi^*$ 凸于 $p$ 的镜像);加总保留正斜率。
- **关于 $w, r$ 的负响应**:要素价格上升 → 个体供给左移 → 市场供给左移。
- **同次 0 度**(在 $(p, w, r)$ 中):同时缩放所有名义价格,实物供给不变。

## 与 Ch 12 的衔接

Batch 2 [[输出供给曲线]] / [[利润最大化问题]] 给出**个体厂商**供给曲线;本页是其市场水平加总。Ch 14 的均衡分析在 $(p, X)$ 平面把市场供给与 [[市场需求曲线]] 求交点。

## 反面论点与数据空白

- **加总忽略容量约束**:个体厂商有产能上限,在 $p$ 高时供给变陡;市场加总后,异质产能使加总曲线在容量逼近时弯曲。教材未展开异质厂商的供给加总。
- **隐性合谋破坏价格接受**:即使形式上是完全竞争行业,少量大厂商可能默契提价(寡头边缘行为),使市场供给曲线"实际斜率"低于完全竞争预测。Goulder-Williams 2012 综述行业供给弹性,实证 $[\sim 0.1, \sim 5]$,与教材完全竞争默认值差距大。
- **进入退出的滞后**:LR 自由进入假设瞬时调整,现实中受到行业特定资本(船坞、晶圆厂)、监管牌照、品牌建设的滞后限制——使"LR 调整到零利润"的速度为数年至数十年。半导体行业(NVIDIA / TSMC 等)是显著例子,详见 [[NVIDIA]] 跨域链接。
- **数字平台的零边际成本**:软件 / 数字内容 / Token 等行业边际成本 ≈ 0,$\min LAC \to 0$,LR 完全竞争均衡退化为垄断或寡头(IRS [BIAS],详见 [[规模报酬]])。教材完全竞争模型不直接适用。
- **数据空白**:行业供给弹性的实证综述(Goulder-Williams 2012)、关闭率实证(Dunne-Roberts-Samuelson 1988)未在教材引述。
