# 外部性

> Externality

外部性是指经济主体的行为对**非交易第三方**产生的、未通过市场价格机制反映的成本或收益。它是[[第一福利定理]]失效的核心原因之一。

## 定义与分类

### 基本定义

当一方的生产或消费决策直接影响另一方的福利，且这种影响**未通过市场交易价格补偿**时，就存在外部性。

$$
\text{社会成本} = \text{私人成本} + \text{外部成本}
$$

$$
\text{社会收益} = \text{私人收益} + \text{外部收益}
$$

### 四象限分类

| | **生产侧** | **消费侧** |
|---|---|---|
| **正外部性** | 养蜂场对果园的授粉 | 疫苗接种降低他人感染风险 |
| **负外部性** | 工厂污染影响周边居民 | 吸烟者的二手烟 |

### 网络外部性（Network Externality）

一种特殊的正外部性：商品价值随使用者数量增加而增加。
- **直接网络外部性**：电话、社交网络（用的人越多，每个用户的价值越大）。
- **间接网络外部性**：操作系统 → 应用软件生态（用户越多 → 开发者越多 → 软件越多 → 用户越多）。

网络外部性是平台经济和软件行业的核心特征，使[[规模报酬]]的分析更加复杂。

## 外部性与市场失灵

### 为什么市场失灵？

个体在做决策时只考虑**私人成本/收益**，忽略**社会成本/收益**：
- 负外部性 → 私人成本 < 社会成本 → 过度生产/消费（$Q_{\text{市场}} > Q_{\text{社会最优}}$）。
- 正外部性 → 私人收益 < 社会收益 → 生产/消费不足（$Q_{\text{市场}} < Q_{\text{社会最优}}$）。

### 与"市场缺失"的关系

外部性的本质是**某些权利/服务没有市场**（见 [[市场缺失]]）：
- 污染权没有市场价格 → 工厂"免费"排放。
- 疫苗接种的群体免疫效益无法向受益者收费 → 接种者无法获得全部社会回报。

## 解决方案概述

| 方案 | 核心机制 | 适用条件 |
|---|---|---|
| [[Pigou税]] | 对边际外部成本征税 | 外部成本可观测/估计 |
| [[Coase定理]] | 明确产权 + 市场交易 | 交易成本低、产权可界定 |
| 管制（Command-and-Control） | 直接限制排放量 | 信息成本高、污染者众多 |
| 可交易许可证（Cap-and-Trade） | 设定总量 + 市场交易配额 | 排放可测量、市场流动性好 |

## 反面论点与数据空白

- "外部性"概念边界模糊：几乎所有经济活动都有某种溢出效应。若将"外部性"泛化，则市场处处失灵 → 概念失去分析力（Coase 1960 的批评）。
- 外部性的**测量困难**：边际外部成本（MEC）通常无法直接观测，需要复杂的流行病学/环境科学模型（如空气污染的健康成本）。
- **分配维度被忽略**：Pigou 税和 Coase 定理都追求效率，但初始产权分配和税负分配影响公平。低收入社区通常承受更多负外部性（环境正义问题）。
- 网络外部性的实证：Metcalfe 定律（$V \propto n^2$）被广泛引用但缺乏严格实证支持；实际网络价值增长可能更慢（$V \propto n \log n$ 或 $V \propto n^{1.5}$）。

## Batch 5 连接：公共品作为外部性特例

公共品可视为**极端的正外部性**：

- 国防：一旦提供，所有国民同时受益（非竞争性）
- 知识：一旦公开，所有人可使用（非排他性）
- 清洁空气：改善使所有人受益

公共品的分析框架（Ch 27）是外部性理论的直接延伸：
- 外部性 = 某些市场缺失
- 公共品 = 非排他性导致的市场完全缺失
- 解决方案：政府供给、Lindahl 均衡、Clarke-Groves 机制

详见 [[公共品]]、[[搭便车问题]]、[[公共品供给机制]]（Ch 27）。
