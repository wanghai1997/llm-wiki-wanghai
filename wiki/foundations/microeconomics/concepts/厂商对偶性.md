# 厂商对偶性

> 厂商侧的"四联结构"——[[利润最大化问题|PMP]] 与 [[成本最小化问题|CMP]] 在解和值函数层面相互可推导。是消费者侧 [[消费者对偶性]] 的完全镜像。

## 核心命题

**PMP ⟺ CMP**：厂商利润最大化的解 $(L^*, K^*, x^*)$ 必同时是"在 $\bar x = x^*$ 下的成本最小化"解；反之，对每个 $\bar x$ 的 CMP 解 $(L^c, K^c)$ 通过选择最优 $\bar x$（由 $p = MC$）即得 PMP。

形式化：

$$
\boxed{
\pi^*(p, w, r) = \max_{x \geq 0} \{p x - C(w, r, x)\}
}
$$

——PMP 通过 $C$ 中介可分解为"先 CMP 再选 $x$"两步（详见 [[两步利润最大化]]）。

## 四联结构图

```
            ┌────────────┐
            │  生产函数 f  │
            └─────┬──────┘
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
    ┌───────┐           ┌───────┐
    │  CMP  │           │  PMP  │
    └───┬───┘           └───┬───┘
        │                   │
        ▼                   ▼
  ┌──────────┐      ┌──────────────┐
  │  Lᶜ, Kᶜ  │      │  L*, K*, x*  │
  │条件投入需求  │      │ 无条件投入需求 │
  │           │      │  + 输出供给   │
  └──────────┘      └──────────────┘
        │                   │
        ▼                   ▼
   ┌────────┐         ┌────────┐
   │ C(w,r,x̄)│         │π*(p,w,r)│
   │ 成本函数 │         │ 利润函数 │
   └────────┘         └────────┘
        │                   │
   Shephard            Hotelling
   ∂C/∂w = Lᶜ         ∂π*/∂p = x*
                      ∂π*/∂w = -L*
```

## 关键恒等式

| 恒等式 | 含义 |
|---|---|
| $L^* = L^c(w, r, x^*(p, w, r))$ | PMP 解 = CMP 解在最优产出处取值 |
| $\pi^* = p x^* - C(w, r, x^*)$ | 利润函数 = 净收入（值函数恒等式）|
| $p = \partial C / \partial x \big|_{x = x^*}$ | PMP 的 Step 2 FOC：$p = MC$ |
| $\partial \pi^* / \partial w = -L^*$ | [[Hotelling引理]]，要素价格分量 |
| $\partial C / \partial w = L^c$ | [[Shephard引理]]（生产侧）|

## 与消费者对偶性的镜像

| 消费者侧 [[消费者对偶性]] | 厂商侧厂商对偶性 |
|---|---|
| UMP ↔ EMP | PMP ↔ CMP |
| 解：$x^M(p, I)$ ↔ $h(p, \bar u)$ | 解：$L^*(p, w, r)$ ↔ $L^c(w, r, \bar x)$ |
| 值函数：$V(p, I)$ ↔ $E(p, \bar u)$ | 值函数：$\pi^*(p, w, r)$ ↔ $C(w, r, \bar x)$ |
| 反演：$V(p, E(p, \bar u)) = \bar u$ | 组合：$\pi^* = \max_x \{px - C\}$ |
| Roy ↔ Shephard 用作 SE/IE 分解 | Hotelling ↔ Shephard 用作"投入间替代 + 规模" 分解 |
| Slutsky 方程：$\partial x^M / \partial p = \partial h / \partial p - x^M \cdot \partial x^M / \partial I$ | 厂商 Slutsky-like：$\partial L^* / \partial w = \partial L^c / \partial w + \partial L^c / \partial x \cdot \partial x^* / \partial w$ |

> **结构性差异**：消费者侧 EMP 与 UMP 通过"反演" $V \leftrightarrow E$ 互通；厂商侧 PMP 与 CMP 通过"组合" $\pi^* = \max\{px - C\}$ 互通——这反映 PMP 无外生收入约束，故关系比消费者侧简单一层。

## Hotelling 引理 vs Shephard 引理

两个引理在厂商侧**共存**：

- **Shephard 引理**：$\partial C / \partial w = L^c$（CMP 值函数对要素价格的偏导 = 条件需求）
- **Hotelling 引理**：$\partial \pi^* / \partial p = x^*$、$\partial \pi^* / \partial w = -L^*$（PMP 值函数对所有价格的偏导 = 供给 / 负投入需求）

二者通过 $\pi^* = \max\{px - C\}$ 与 [[包络定理]] 联系：

$$
\frac{\partial \pi^*}{\partial w} = - \frac{\partial C}{\partial w} \bigg|_{x = x^*} = -L^c(w, r, x^*) = -L^*
$$

详见 [[两步利润最大化]] 的"Hotelling 推导"段。

## 在政策分析中的运用

**举例**：碳税 $\tau$ 加在能源要素 $E$（视为第三投入），$w_E \to w_E + \tau$。预测厂商响应：

1. **短期（CMP，$\bar x$ 不变）**：用 $\partial L^c_E / \partial w_E$（Shephard）— 严格下降，能源消耗减少。
2. **长期（PMP，$x^*$ 内生调整）**：用 $\partial L^*_E / \partial w_E$（Hotelling）— 比 SR 减少更猛（增加规模效应）。

[[输出供给曲线|供给曲线]] 整体左移：$\Delta x^* = \partial x^* / \partial w_E \cdot \tau < 0$。

## 反面论点与数据空白

- **凸生产集**：非凸生产集（IRS、不可分性）下对偶性退化——CMP 多解、PMP 无解或局部解。详见 [[规模报酬]] [BIAS] 段。
- **价格外生**：双侧（$p$ 来自需求方、$w, r$ 来自要素市场）的价格内生化（垄断、垄断买方、寡头）破坏对偶性——需用博弈论代替 PMP 的"决策论"框架（Ch 23-25）。
- **静态假设**：动态下 $\pi^*$ 是 Bellman 值，[[Hotelling引理]] 替换为相应的动态包络。
- **多产出**：单产出 $x \in \mathbb{R}$ 时对偶清晰；多产出 $x \in \mathbb{R}^m$ 下，$\pi^* = \max\{p \cdot x - C(w, x)\}$，需 $C$ 凸 & 单调，但**联合生产**实证常见 $C$ 不可分（"production possibilities frontier"），对偶推广到 Färe 1988 的距离函数 / Hyperbolic measure。Nechyba 限单产出。
- **数据空白**：跨行业对偶估计（Christensen-Jorgenson Translog 文献）需要假定特定函数族；估计结果对函数选择敏感（Berndt-Khaled 1979）。
