# 正常商品与劣等商品

## 定义

| 类型 | 定义（收入弹性） | $\partial x/\partial m$ |
|---|---|---|
| **正常商品**（normal good） | 收入上升 → 需求上升 | $> 0$ |
| **劣等商品**（inferior good） | 收入上升 → 需求**下降** | $< 0$ |

> 注：商品的"正常 / 劣等"性质不是物理属性，而是**偏好属性**——同一商品对不同人或不同收入水平可能切换。

## 经典示例

| 商品 | 在何收入区间 |
|---|---|
| 公共交通 | 低收入正常 / 高收入劣等（替换为私家车） |
| 方便面 | 低收入正常 / 高收入劣等（替换为外卖/餐厅） |
| 经济舱机票 | 低中收入正常 / 高收入劣等（替换为商务舱） |

## 与 [[替代效应|SE-IE 分解]] 的关系

$$\frac{\partial x}{\partial p} = \underbrace{\frac{\partial x^h}{\partial p}}_{\text{SE} \le 0} - \underbrace{x \cdot \frac{\partial x}{\partial m}}_{\text{IE}}$$

- 正常商品：$\partial x/\partial m > 0$，IE 与 SE **同向**（价格升 → 财富缩水 → 需求再降） → 需求曲线**下倾**且陡峭。
- 劣等商品：$\partial x/\partial m < 0$，IE **反向**（价格升 → 财富缩水 → 该商品需求**上升**），但通常 SE 主导 → 需求仍下倾,**但比正常商品平坦**。
- [[Giffen商品]]：极强劣等性 + 商品占预算极大 → IE 反向力 > SE → 需求曲线**上倾**（教材反例）。

## Engel 曲线的对应

需求随收入变化的轨迹称 **Engel 曲线**（占位）：
- 正常商品 → Engel 曲线**正斜率**；
- 劣等商品 → Engel 曲线**负斜率**；
- 收入弹性 = 1（[[同位偏好]]） → Engel 曲线为**直线** through origin。

## 反面论点与数据空白

- **[BIAS] 教材对劣等商品的处理偏理论**：现实中"商品类型随收入变化"是常见现象，但教材一般在固定收入区间内讨论。
- **数据空白**：劣等商品的实证识别需要面板数据 + 价格变化的外生冲击；教材 Ch 1–10 仅给定性陈述。
