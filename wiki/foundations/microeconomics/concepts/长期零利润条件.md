# 长期零利润条件

> 完全竞争 LR 均衡的特征条件:每家在位厂商的经济利润 $\pi^j = 0$,等价于价格 $p^{LR} = \min LAC^j$。

## 形式陈述

LR 均衡下:

$$
\boxed{
p^{LR} = \min LAC^j \quad \forall \, \text{在位厂商} \, j \quad \Longleftrightarrow \quad \pi^j(p^{LR}) = 0
}
$$

如果厂商间技术相同,所有厂商共享同一 $\min LAC$。如果技术异质(部分厂商更高效),只有"边际厂商"(刚好不能赚到正经济利润的厂商)的 $p^{LR} = \min LAC^{marginal}$;更高效厂商赚 Ricardian 租(详见 §"异质厂商"段)。

## 三种推导路径

### 路径 1:经济直觉

- $p > \min LAC$ → 经济利润正 → 新厂商进入 → $p$ 下降。
- $p < \min LAC$ → 经济利润负 → 在位厂商退出 → $p$ 上升。
- 唯一稳态 $p = \min LAC$。

### 路径 2:厂商个体优化

利润最大化要求 $p = LMC$;LR 均衡再要求 $\pi = 0$。两条件联立 $\Rightarrow LMC = LAC$ 在某 $x^* > 0$。LMC 与 LAC 的交点恰是 LAC 最低点(微积分:$\frac{d(LAC)}{dx} = 0$ ⇔ $LMC = LAC$)。

### 路径 3:几何

LR 均衡价格水平线必须**与 LAC 曲线相切**于 LAC 最低点;若高于该点,曲线下方有正利润空间;若低于,所有产量都亏损。切点条件 = 零利润 + 个体优化的合一。

## 异质厂商:Ricardian 租

若厂商技术异质(部分厂商在土地、人才、专利上有禀赋优势),LR 均衡下:
- **最差(边际)厂商**:$p^{LR} = \min LAC^{worst}$,$\pi^{worst} = 0$。
- **更高效厂商**:$\min LAC^{better} < p^{LR}$,赚正利润 $\pi^{better} > 0$。

但这不是"经济利润"——而是**Ricardian 租**:对**有限禀赋**(优质土地、稀缺人才、专利)的报酬。在 Ricardo 1817 的视角下,这类租金会被禀赋市场定价(土地租金 / 工资 / 专利费)反映回成本中,使经济利润仍为零。

> **教材简化**:Nechyba 14A.5 默认所有厂商技术相同,直接得到所有厂商 $\pi = 0$。异质厂商情况留待 Batch 5 Ch 23(垄断竞争)或更高级教材。

## 与第一福利定理的连接

零利润 + 价格接受 + 边际成本定价 + 完全竞争 → LR 均衡 Pareto 高效。

具体:
- 价格 = 边际成本($p = LMC$)→ 边际生产价值 = 边际机会成本 → 资源配置高效。
- 零利润 → 厂商进入退出无激励 → 行业规模 = 社会需求规模 → 总量高效。

详见 [[第一福利定理-部分均衡]]。

## 与 SR 的对比

SR 均衡下,$\pi^j$ 可任意符号:
- $\pi^j > 0$ 的 SR 均衡是 LR 进入诱因;
- $\pi^j < 0$ 但 $p > \min AVC^{SR}$ 的 SR 均衡:厂商**继续生产**(已沉没的资本无法回收,关闭也是 $\pi = -FC < 0$,继续生产至少弥补部分 $FC$),但**LR 退出**;
- $\pi^j < 0$ 且 $p < \min AVC^{SR}$:SR 关闭 + LR 退出。

详见 [[关闭条件]] / [[自由进入退出]]。

## 反面论点与数据空白

- **"经济利润为零"的实证不可观测**:经济利润需要测量股东资本的"机会成本",而机会成本本身依赖资产定价模型(CAPM、APT 等),识别困难。Fama-French 等实证发现行业平均超额收益普遍偏离零(动量 / 价值因子等)→ "LR 经济利润 = 0"在数据上是模糊的。
- **零利润 vs 高 ROE 的混淆**:许多盈利稳定的公司(可口可乐、苹果、台积电)长期保持 20%+ ROE,这与"经济利润 = 0"不矛盾——只要这些 ROE 反映了无形资产(品牌、专利、护城河)的合理回报。但教科书的"零利润"叙事容易让学生误以为这些公司"应该被竞争掉"。
- **僵尸企业(Caballero-Hoshi-Kashyap 2008)**:违反"$\pi < 0$ → 退出"的 LR 退出机制——僵尸企业在 $\pi < 0$ 状态下被银行延贷续命,LR 均衡的零利润条件失效。日本 1990s、中国 2010s 钢铁 / 煤炭 / 太阳能板行业是显著案例,教材完全不提。
- **数字平台的"超额利润持久"**:网络效应 + 边际成本 0 → IRS → 在位平台(Google / Meta / 字节)的经济利润长期 > 0,自由进入退出失效。
- **数据空白**:Dunne-Roberts-Samuelson 1988 行业进入退出率综述、Hopenhayn 1992 厂商动态学未在教材引述。
