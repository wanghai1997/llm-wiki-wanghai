# 替代弹性

## 一句话定义

> $\sigma$（elasticity of substitution）= MRS 变化 1% 时，最优消费比 $x_2/x_1$ 的变化百分比：
>
> $$\sigma = \frac{d \ln(x_2/x_1)}{d \ln MRS}$$
>
> 衡量"在效用不变的前提下，消费者用 $x_1$ 替代 $x_2$ 的容易程度"。

## 关键节点（[[偏好类型]] 全谱）

| $\sigma$ | 偏好家族 | 直觉 |
|---|---|---|
| $0$ | 完全互补（Leontief） | 比例固定，无替代 |
| $(0, 1)$ | 弱替代（如食品） | 价格变化时少量调整比例 |
| $1$ | Cobb-Douglas | 收支占比对价格不变 |
| $(1, \infty)$ | 强替代（如品牌竞品） | 价格小变化引起比例大调整 |
| $\infty$ | 完全替代 | 仅买更便宜那个 |

## 与 CES 函数族的对应

CES：$u = (\alpha x_1^{\rho} + (1-\alpha) x_2^{\rho})^{1/\rho}$ → $\sigma = 1 / (1 - \rho)$

| $\rho$ | $\sigma$ | 极限 |
|---|---|---|
| $\rho \to -\infty$ | $\to 0$ | 完全互补 |
| $\rho \to 0$ | $\to 1$ | Cobb-Douglas |
| $\rho \to 1$ | $\to \infty$ | 完全替代 |

## 在 [[Microeconomics-Nechyba-2e|Nechyba 教材]] 中的位置

教材 Ch 5 引入 $\sigma$ 作为偏好"形状的单一摘要数字"，是 Ch 7–10 比较静态与福利分析中**所有**定量预测的核心参数。Ch 10 Table 10.1 / 10.2 把 [[无谓损失DWL]] 写成 $\sigma$ 的函数——$\sigma$ 越小（替代越难），同税率下 DWL 越小（消费者更难躲）。

## 生产侧镜像：要素替代弹性

Batch 2 厂商侧的**要素替代弹性**衡量"在产出 $\bar x$ 不变下，要素价格比变化 1% 时最优投入比的变化百分比"：

$$
\sigma_{KL} = \frac{d \ln(K/L)}{d \ln(MRTS)} = \frac{d \ln(K/L)}{d \ln(w/r)}
$$

由 [[边际技术替代率MRTS|MRTS]] = $w/r$（CMP 的 FOC，详见 [[成本最小化问题]]）。

### 镜像对照

| 消费侧 $\sigma$ | 生产侧 $\sigma_{KL}$ |
|---|---|
| 沿 [[无差异曲线]]（效用不变）| 沿 [[等产量曲线]]（产出不变） |
| MRS = $p_1/p_2$ | MRTS = $w/r$ |
| $u = (\alpha x_1^\rho + (1-\alpha) x_2^\rho)^{1/\rho}$ | $f = (\alpha L^\rho + (1-\alpha) K^\rho)^{1/\rho}$ |
| 0 = Leontief 互补 | 0 = Leontief 固定比例（如"一机一人"）|
| 1 = Cobb-Douglas | 1 = Cobb-Douglas 生产函数 |
| ∞ = 完全替代 | ∞ = 线性生产函数（要素完全可换）|

### 数据范围（行业经验）

| 行业 | $\sigma_{KL}$ 估计 | 来源（行业惯例）|
|---|---|---|
| 农业 | $\sim 0.5$（土地与劳动难替代）| Hayami-Ruttan 1985 |
| 制造业 | $\sim 0.5$–$1$ | Berndt-Christensen 1973 |
| 服务业 | 接近 1（CD 可近似）| Jorgenson 系列 |
| AI / 算力 | $\to \infty$（GPU 与 CPU 间）| 反例:[[CRS-IRS权衡]] 启示 |

### 政策应用

- **资本所得税**：$\sigma_{KL}$ 大 → 厂商把资本换成劳动，税基快速侵蚀；$\sigma_{KL}$ 小 → 资本"被锁住"，税收实际由资本所有者承担。
- **最低工资**：$\sigma_{KL}$ 大 → 厂商用资本（自动化）替代劳动 → 失业上升；$\sigma_{KL}$ 小 → 雇佣量影响有限，价格转嫁给消费者。

> 这是教材"消费者-厂商对称"美学的体现：同一参数 $\sigma$ 在两侧分别决定**消费者对价格变化的回避能力**与**厂商对要素价格变化的替代能力**——而政策福利分析（[[无谓损失DWL|DWL]] / 税负归宿）由两侧 $\sigma$ 同时决定。

详见 [[条件投入需求]]、[[成本函数]]、[[CRS-IRS权衡]]。

## 反面论点与数据空白

- **[BIAS] $\sigma$ 假设全局常数**：CES 的强大正源于此假设，但现实中 $\sigma$ 可能随消费量水平变化——教材在 Ch 5 不讨论非常数版本（如 generalized CES、translog）。
- **数据空白**：教材引述"住房 $\sigma \approx 1$"等参数但**未给一手实证文献**，对 Table 10.1/10.2 的可靠性是关键短板。
