# 预算约束

## 一句话定义

> 在给定收入 $m$ 与价格 $(p_1, p_2)$ 下，消费者**可负担的消费束集合**：$\{(x_1, x_2) \mid p_1 x_1 + p_2 x_2 \le m\}$。其边界即**预算线** $p_1 x_1 + p_2 x_2 = m$。

## 关键性质

1. **斜率** $= -p_1/p_2$ ——单位 $x_2$ 换 $x_1$ 的市场比价。其绝对值是 $x_1$ 的 [[机会成本]]。
2. **截距**：横轴截距 $m/p_1$、纵轴截距 $m/p_2$ ——即"全花在某一种商品上"时能买的数量。
3. **价格变化** → 预算线**绕另一截距旋转**。
4. **收入变化** → 预算线**平行外移/内缩**。

## 在 [[Microeconomics-Nechyba-2e|Nechyba 教材]] 中的位置

教材 Ch 2 把预算约束作为消费者最优化的**约束侧**（偏好侧见 [[偏好五公理]]），并在 Ch 3 推广为四种变体：

| 变体 | 含义 | 页 |
|---|---|---|
| 外生收入预算 | $m$ 给定 | [[预算约束]]（本页） |
| [[禀赋预算]] | 收入由禀赋点 $(e_1, e_2)$ 与价格内生决定 | [[禀赋预算]] |
| [[跨期预算约束]] | $c_1 + c_2/(1+r) \le m_1 + m_2/(1+r)$ | [[跨期预算约束]] |
| [[劳动-闲暇预算]] | $c = w(L̄ - \ell) + \pi$ | [[劳动-闲暇预算]] |

## 与最优化条件的关系

预算线斜率 $-p_1/p_2$ 是 [[内点最优条件]] 的右半边——MRS = -p₁/p₂——即偏好侧斜率（[[边际替代率MRS]]）等于约束侧斜率。这一切线条件是 Ch 6 求解 [[效用最大化问题]] 的核心几何。

## 反面论点与数据空白

- **[BIAS] 教材几乎只画两商品平面**：高维预算（多商品）的几何在 Ch 2–3 不出现，留给微积分版用 $\sum p_i x_i \le m$ 一笔带过——可能让"图形派"读者低估真实预算空间的复杂性。
- **数据空白**：教材未讨论"软预算约束"（科尔奈, 1986）——当个体可期望事后救助时,预算约束本身可能被部分内生化。
