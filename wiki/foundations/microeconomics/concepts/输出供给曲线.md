# 输出供给曲线

> [[利润最大化问题|PMP]] 的解（产出侧）——给定产品价格 $p$ 与要素价格 $(w, r)$ 时的最优产量。是消费者侧 [[Marshallian需求曲线|马歇尔需求曲线]] 的"对侧"——消费者沿需求曲线买，厂商沿供给曲线卖。

## 定义

$$
x^*(p, w, r) \;=\; f(L^*(p, w, r), K^*(p, w, r))
$$

或由 [[Hotelling引理]]：

$$
\boxed{x^*(p, w, r) = \frac{\partial \pi^*(p, w, r)}{\partial p}}
$$

## 由两步利润最大化的角度

[[两步利润最大化]] Step 2：

$$
\max_x \{p x - C(w, r, x)\} \;\;\Longrightarrow\;\; \boxed{p = MC(x^*) = \frac{\partial C}{\partial x}}
$$

读法："厂商在 $p = MC$ 处选择产量。" 故供给曲线 = MC 曲线（在 AVC 之上的部分）。

## 几何

```
 p
  │
  │           MC
  │          /
  │         /  ATC
  │        /  /
  │       / /
  │      // ← p₀: x* by p = MC(x*)
  │ p₀──/────
  │   ╱│
  │  ╱ │
  │_╱__│___ x
       x*
```

供给曲线 = $MC(x)$ 在 $p \geq AVC_{\min}$ 区段（详见 [[关闭条件]]）。

## 关键性质

| 性质 | 说明 |
|---|---|
| **单调上升于 $p$** | $\partial x^* / \partial p = \partial^2 \pi^* / \partial p^2 \geq 0$（$\pi^*$ 凸性的直接推论）|
| **零阶齐次于 $(p, w, r)$** | $x^*(\lambda p, \lambda w, \lambda r) = x^*(p, w, r)$ |
| **对要素价格交叉效应** | $\partial x^* / \partial w = -\partial L^* / \partial p$（Hotelling 对称性）|
| **不可能向下倾斜** | 厂商侧无 Giffen——$\pi^*$ 凸性严格保证 |

## 与马歇尔需求的镜像（两侧而非对偶）

| 消费者 [[Marshallian需求曲线|马歇尔需求曲线]] | 厂商输出供给曲线 |
|---|---|
| $x^M_i(p, I)$，$\partial x^M / \partial p$ 可正可负（Giffen）| $x^*(p, w, r)$，$\partial x^* / \partial p \geq 0$ 严格 |
| 由 [[Roy恒等式]] | 由 [[Hotelling引理]] |
| 价格 $p$ = 厂商角度的"输出价格" $p$ | 价格 $p$ = 消费者角度的"购买价" |
| 横轴 $x$ 是消费数量 | 横轴 $x$ 是生产数量 |

> 在均衡分析中，消费者总需求曲线 $D(p) = \sum x^M_i(p, \cdot)$ 与厂商总供给曲线 $S(p) = \sum x^*_j(p, \cdot)$ 在 $p^*$ 处相交（详见 Batch 3 [[竞争性市场均衡]]）。

## 短期 vs 长期供给

| 时段 | $K$ 的处理 | 供给曲线 |
|---|---|---|
| **短期** | $K = \bar K$ 固定 | $p = SMC(x; \bar K)$，含开 / 关 决策（[[关闭条件]]）|
| **长期** | $K$ 可调整 | $p = LMC(x)$，长期 [[平均成本曲线包络|LRAC 包络]] |

短期 $S$ 比长期 $S$ 更陡（资本不可调，仅劳动调整慢）。详见 [[短期成本与长期成本]]、[[平均成本曲线包络]]。

## 厂商进入与退出

长期均衡下零利润：

$$
p = LRAC_{\min} \;\;\Longrightarrow\;\; x^* = x_{\text{efficient}}, \;\; \pi^* = 0
$$

价格高于此引发厂商进入；低于此引发退出。详见 [[关闭条件]] 与 Batch 3 的 [[竞争性市场均衡]]。

## 应用：政策分析

1. **税收 $\tau$ 加在产品**：厂商面对净价 $p - \tau$，供给曲线 $x^*(p - \tau, w, r)$ 整体右移（生产者承担部分税负，剩余部分由消费者承担——具体分担由弹性决定）。
2. **补贴 $s$ 加在产品**：对称——$x^*(p + s, w, r)$ 左移（增加产出）。
3. **要素税** $w \to w + \tau_w$：$x^*(p, w + \tau_w, r)$ 右移（产出下降）。

> 数据：美国油气行业碳税 + 上游要素税 $\to x^*$ 实证下降幅度可在 Goulder-Williams 2012 综述。

## 反面论点与数据空白

- **完全竞争 / 价格接受假设**：垄断 / 寡头下 $p$ 内生，"供给曲线"概念退化（Ch 23-25 用反应函数 / 博弈策略代替）。
- **调整成本**：动态下 $x^*$ 含资本折旧、人员调整摩擦——SR 与 LR 之间是连续过渡，非离散切换。
- **多产出**：单产出下 $x^*$ 是标量；多产出下 $x^* \in \mathbb{R}^m$，$\nabla_p \pi^* = x^*$ 给出向量供给。
- **数据空白**：行业供给弹性估计差异巨大（农产品 $\sim 1$，矿产 $\sim 0.1$，软件 $\sim \infty$）；Nechyba 不引实证综述。
