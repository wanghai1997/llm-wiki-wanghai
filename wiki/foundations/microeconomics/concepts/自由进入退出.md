# 自由进入退出

> 完全竞争 LR 均衡的核心机制。新厂商可以**无门槛**进入有利可图的行业,在位厂商可以**无成本**退出亏损行业,直到经济利润归零。

## 定义

"自由"包含两层意思:
1. **无门槛进入**:任意潜在厂商可以使用相同技术、雇用相同要素、面对相同要素价格,以**任意规模**进入行业。
2. **无成本退出**:在位厂商可以将所有要素回收(资本回到资本市场,劳动回到劳动市场),无沉没成本。

这两条假设共同保证 LR 经济利润 → 0。

## 触发机制

- **进入触发**:$\pi^j > 0$(经济利润正)→ 潜在厂商看到机会 → 进入 → $X^S$ 右移 → $p$ 下降 → 直到 $\pi^j = 0$。
- **退出触发**:$\pi^j < 0$(经济利润负)→ 在位厂商发现机会成本未被补偿 → 退出 → $X^S$ 左移 → $p$ 上升 → 直到 $\pi^j = 0$。

进入 / 退出在 LR 持续到 $p = \min LAC$ 即 [[长期零利润条件]] 满足。

## "零利润"的精确含义

> **常见误解**:零利润 ≠ 零回报。

- **会计利润 = 收入 - 显性成本**:LR 均衡下通常为正(资本所有者得到正会计回报)。
- **经济利润 = 收入 - 全部机会成本**:包含股东资本的正常回报、企业家时间的机会成本、品牌价值的折旧等。LR 均衡使**经济利润为零**——资本和企业家得到机会成本回报,无超额。

教材在 12A.4 / 14A.5 强调这一区分,但仍是常见考试陷阱。

## 与 [[关闭条件]] 的区分

| 维度 | 关闭(SR) | 退出(LR) |
|---|---|---|
| 时间 | 短期 | 长期 |
| 资本可否回收 | 否($\bar K$ 固定) | 是 |
| 触发条件 | $p < \min AVC^{SR}$ | $p < \min LAC^{LR}$(经济利润持续负) |
| 是否可逆 | 是(SR 关闭后,$p$ 回升即可重启) | 是,但需重建固定要素 |
| 决策准则 | 不亏可变成本 | 不亏总成本(含资本机会成本) |

LR 退出门槛 $\min LAC$ 高于 SR 关闭门槛 $\min AVC$(因 LAC 包括资本成本),所以 LR 退出比 SR 关闭更"激进"。详见 [[关闭条件]]。

## 进入退出的对称性

教材在 14A.5.2 明确:LR 进入决策(看 $p > \min LAC$)与 LR 退出决策(看 $p < \min LAC$)以**$\min LAC$ 为对称轴**——意味着 LR 调整在两侧速度相同。

> **现实违反**:沉没成本破坏对称性。Dixit 1989 *sunk cost hysteresis*:进入决策需考虑沉没投入(机器、培训、品牌),退出决策只考虑剩余可避免成本 → 进入门槛 > 退出门槛 → 经济利润可在某区间内既未触发进入也未触发退出。

## 与"完全竞争"的逻辑关系

完全竞争 = 价格接受 + 同质商品 + 完美信息 + **自由进入退出**。

四条件**任一**违反,完全竞争模型失效:
- 进入有壁垒(专利、规模经济、品牌)→ 垄断 / 寡头(Ch 23-25)。
- 退出有沉没成本 → 现有厂商可在不同价区间内"耗着"。
- 信息不完美 → 检索成本 + 价格分散(Stigler 1961, Diamond 1971)。

## 反面论点与数据空白

- **进入壁垒的普遍性**:现实中"无门槛进入"几乎从不存在——专利(制药)、网络效应(社交平台)、固定资本巨额(半导体)、监管牌照(银行 / 出租车 / 电信)、品牌效应(可口可乐),都形成进入壁垒。Bain 1956 *Barriers to New Competition* 是这一文献的奠基作,Nechyba 不展开。
- **退出沉没成本的不对称**:平均回收率(asset specificity)使退出"摩擦"普遍存在——制造业资本回收率约 60-70%,服务业更低。这一不对称是垄断 / 寡头长期持续的物理基础。
- **僵尸企业(Caballero-Hoshi-Kashyap 2008)**:银行体系延贷使应退出企业不退,日本 1990s / 中国 2010s / 欧洲南部 2010s 大量出现。本 Wiki 在 [[长期均衡]] [BIAS] 段详述,教材完全不提。
- **平台行业的"零边际成本 + 网络效应"**:Token / 数字内容 / 软件 / 社交平台的技术结构使自由进入失效——先入者形成正反馈优势(IRS),后入者无法击穿。Nechyba 完全竞争模型不直接适用。详见 [[NVIDIA]] / [[Token工厂经济学]] 跨域 see-also。
- **数据空白**:行业进入率 / 退出率(Dunne-Roberts-Samuelson 1988 综述美国制造业)与教材完全竞争预测的偏差未引述。
