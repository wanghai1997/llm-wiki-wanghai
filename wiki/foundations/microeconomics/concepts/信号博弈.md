# 信号博弈（Signaling Games）

## 定义

信号博弈是一类特殊的**不完全信息动态博弈**：

- **发送者**（Sender，信息优势方）首先行动，选择一个可观察的"信号" $m$
- **接收者**（Receiver，信息劣势方）观察到信号后，选择"行动" $a$
- 双方的收益依赖于发送者的**私有类型** $\theta$、信号 $m$ 和行动 $a$

经典结构：
```
自然
/    \
θ_H    θ_L
 |      |
发送者选择 m
 |      |
接收者观察 m，选择 a
 |      |
(收益: u_S(θ, m, a), u_R(θ, m, a))
```

## 均衡概念：完美贝叶斯均衡（PBE）

信号博弈的解概念是**完美贝叶斯均衡**（Perfect Bayesian Equilibrium），要求：

1. **发送者策略最优**：给定接收者的反应策略，每种类型选择最优信号
2. **接收者策略最优**：给定信念，每个信号后选择最优行动
3. **信念一致性**：接收者的信念与发送者策略一致（通过贝叶斯更新）

## 均衡类型

### 分离均衡（Separating Equilibrium）

不同类型的发送者选择**不同的信号**：

- 高类型选择 $m_H$，低类型选择 $m_L$
- 接收者可**完美推断**发送者类型
- 需要满足：**激励相容约束**——每种类型的发送者不想伪装成另一类型

### 混同均衡（Pooling Equilibrium）

所有类型的发送者选择**相同的信号**：

- 高类型和低类型都选择相同的 $m^*$
- 接收者**无法推断**类型，只能基于先验信念行动
- 需要满足：偏离 $m^*$ 被视为来自特定类型（通常是最低类型）

### 半分离均衡（Semi-separating Equilibrium）

某些类型随机化信号，其他类型选择纯策略：

- 例如：高类型总是选择 $m_H$，低类型以概率 $p$ 选择 $m_H$、以 $1-p$ 选择 $m_L$
- 接收者观察到 $m_H$ 后，通过贝叶斯更新推断后验概率

## 经典示例

### Spence 教育信号模型

- 发送者：求职者（知道自己的真实能力 $\theta \in \{H, L\}$）
- 信号：教育水平 $e$（教育本身不提高生产率，但成本不同）
- 接收者：雇主（观察 $e$，决定工资 $w$）

分离均衡条件：
$$c_H(e^*) \leq w_H - w_L \leq c_L(e^*)$$

即：高能力者的信号成本低于收益差，低能力者的信号成本高于收益差。

### 劳动力市场筛选

与 [[信息筛选]] 的对照：
- **信号博弈**：信息优势方（求职者）先行动，发送信号
- **筛选模型**：信息劣势方（雇主）先行动，设计合同菜单

## 直观标准（Intuitive Criterion）

Cho-Kreps 1987 提出"直观标准"来精炼 PBE：

- 若某个偏离信号 $m'$ 对某种类型 $\theta$ 有利（无论接收者如何反应），但对另一种类型 $\theta'$ 永远不利
- 则接收者应推断：$m'$ 来自 $\theta$，而非 $\theta'$

这一精炼可排除"不合理"的混同均衡。

## 反面论点与数据空白

- **[BIAS] 信号成本的外生性**：Spence 模型假设信号成本是外生的（高能力者天生获取成本低），但现实中教育可能同时具有人力资本投资和信号功能。区分两者 empirically 极其困难（Hungerford-Solon 1987；Card 1999）。
- **社会浪费性**：在分离均衡中，教育投资纯属"浪费"——只为发送信号，不创造社会价值。若社会能找到成本更低的筛选机制（如能力测试），则可消除这种浪费。
- **信号过载**：现实中信号可能过多，接收者难以处理（如求职者过度包装简历）。信息过载可能降低信号的区分效力。
- **数据空白**：信号博弈的实证集中于教育经济学（Card 1999；Oreopoulos 2006）和金融市场（信用评级、审计意见）。结构式估计（如识别信号成本和能力分布）需要强假设。
