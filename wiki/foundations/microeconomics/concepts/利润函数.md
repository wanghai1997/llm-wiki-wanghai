# 利润函数

> [[利润最大化问题|PMP]] 的**值函数**——给定产品价格 $p$ 与要素价格 $(w, r)$ 时，厂商可达成的最大利润。是消费者侧 [[间接效用函数]] 的镜像，但**单位是货币**（基数）而非效用（序数）。

## 定义

$$
\pi^*(p, w, r) \;=\; \max_{L, K \geq 0} \{p f(L, K) - wL - rK\} \;=\; p x^* - w L^* - r K^*
$$

其中 $(L^*, K^*, x^*)$ 是 PMP 的解。

## 关键性质（由对偶理论）

| 性质 | 说明 |
|---|---|
| **凸于 $(p, w, r)$** | 多个线性函数（每个固定 $(L, K, x)$ 给一线性 $\pi$）的上包络必凸——这与 $C$ 的凹性是对偶面 |
| **非递减于 $p$** | $\partial \pi^* / \partial p = x^* \geq 0$（[[Hotelling引理]]）|
| **非递增于 $w, r$** | $\partial \pi^* / \partial w = -L^* \leq 0$、$\partial \pi^* / \partial r = -K^* \leq 0$ |
| **零阶齐次于 $(p, w, r)$** | $\pi^*(\lambda p, \lambda w, \lambda r) = \lambda \pi^*(p, w, r)$（一阶齐次，正比例）|
| **[[Hotelling引理]]** | 一阶偏导直接给出 $x^*$（输出供给）和 $-L^*, -K^*$（投入需求的负值）|
| **连续 / 几乎处可微** | 由凸性保证（凸函数几乎处可微，不可微点为次梯度集合）|

## 与间接效用函数的镜像

| 消费者侧 [[间接效用函数]] | 厂商侧利润函数 |
|---|---|
| $V(p, I) = \max u(x)$ s.t. $p \cdot x \leq I$ | $\pi^*(p, w, r) = \max p f(L, K) - wL - rK$ |
| **凸（拟凸）于 $p$** | **凸于 $(p, w, r)$** |
| $\partial V / \partial p_i = -\lambda \cdot x_i^M$（[[Roy恒等式]]）| $\partial \pi^* / \partial p = x^*$（[[Hotelling引理]]）|
| 单位：序数效用（变换不变）| 单位：货币利润（基数）|
| 输入：$(p, I)$（价格 + 收入）| 输入：$(p, w, r)$（产品价 + 要素价）|

> **基数 vs 序数差异的具体后果**：$V$ 的凸 / 拟凸性在效用单调变换下不保留（结构性）；$\pi^*$ 的凸性在货币重定价（汇率换算）下严格保留。Nechyba 强调"利润可加性"是 PMP 与 UMP 在基数 vs 序数维度的本质分野。

## 凸性的几何

$\pi^*(p, w, r)$ 在 $p$ 轴上凸：

```
π*(p)
  │      ╱
  │    ╱
  │  ╱
  │╱_____ p
  │ p₀  p₁
```

含义：$p$ 上涨时，$\pi^*$ 至少线性增加（保持原有 $x^*$ 即可），但厂商**调整 $L^*, K^*, x^*$ 后**实际涨幅更大——故凸（[[包络定理]] 的标准应用）。

## 与成本函数的关系

由 [[两步利润最大化]]：

$$
\pi^*(p, w, r) = \max_x \{p x - C(w, r, x)\}
$$

FOC：$p = MC(x^*) = \partial C / \partial x$。再代入即得 $\pi^*$。

由此：
$$
\frac{\partial \pi^*}{\partial p} = x^*, \quad \frac{\partial \pi^*}{\partial w} = -\frac{\partial C}{\partial w} = -L^c(w, r, x^*) = -L^*
$$

——这是 [[Hotelling引理]] 通过 $C$ 中介的形式（详见该页"两步证明法"）。

## 在 [[厂商对偶性]] 中的位置

$\pi^*$ 是厂商侧"四联结构"的顶点：

$$
f(L, K) \;\xrightarrow{\text{CMP}}\; C(w, r, \bar x) \;\xrightarrow{\text{Step 2}}\; \pi^*(p, w, r) \;\xrightarrow{\text{Hotelling}}\; (x^*, L^*, K^*)
$$

镜像消费者侧：

$$
u(x) \;\xrightarrow{\text{EMP}}\; E(p, \bar u) \;\xrightarrow{\text{反演}}\; V(p, I) \;\xrightarrow{\text{Roy}}\; x^M(p, I)
$$

差异：消费者由 $V \leftrightarrow E$ 反演（恒等式 $V(p, E(p, \bar u)) = \bar u$）；厂商由 $\pi^* = \max\{px - C\}$ **直接组合**——后者更简单，因 PMP 无外生收入约束。

## 应用

1. **Hotelling 福利分析**：$\Delta \pi^* = \int x^* \, dp$（生产者剩余增量），用于政策评估。
2. **要素需求弹性预测**：$\partial^2 \pi^* / \partial w^2 = -\partial L^* / \partial w \geq 0$ 由凸性给出 $L^*$ 单调下降于 $w$。
3. **行业利润测量**：实证文献用 $\pi^* / \text{revenue}$ 测加成率（Markup），De Loecker-Eeckhout 2017 的"Markup 大幅上升"论文是此类工具的应用。

## 反面论点与数据空白

- **凸性依赖凸生产集**：IRS 行业（软件、平台）下 $\pi^*$ 无界——参见 [[规模报酬]] [BIAS]。
- **价格接受假设**：垄断 / 寡头下 $p$ 由厂商 / 寡头博弈内生，$\pi^*$ 退化为博弈值（Ch 23-25）。
- **多产出泛化**：单产出 PMP 下 $x^*$ 是标量；多产出（联合生产）下 $\pi^*$ 输入还含 $p \in \mathbb{R}^m$，[[Hotelling引理]] 给出向量 $\nabla_p \pi^* = x^*$。Nechyba 限单产出。
- **风险中性 / 静态**：动态、不确定下 $\pi^*$ 替换为期望折现利润，Bellman 方程；本 Wiki 留待 Batch 4。
- **数据空白**：行业 $\pi^*$ 估计存在"利润 vs 经济租金 vs 准租金"的概念混淆（Mundlak 1996），Nechyba 未细辨。
