# 信号传递

> Signaling

信号传递是指**信息优势方**（如高能力工人）通过发送**成本高昂且难以模仿的信号**来主动揭示自身类型，从而解决 [[逆向选择]] 问题。

## Spence 教育信号模型（1973）

### 设定

- 两类工人：高能力（H）和低能力（L）。
- 能力无法直接观测，但工人可选择教育年限 $e$。
- 教育成本：$C_H(e) < C_L(e)$（高能力者学习更轻松）。
- 雇主观察 $e$ → 推断能力 → 支付工资 $w(e)$。

### 分离均衡（Separating Equilibrium）

高能力者选择足够高的教育水平 $e^*$，使得低能力者模仿不划算：

$$w_H - C_L(e^*) < w_L$$

即：低能力者若假装高能力，教育成本超过工资增益。

- 高能力者选择 $e = e^*$ → 被识别为高能力 → 获得 $w_H$。
- 低能力者选择 $e = 0$ → 被识别为低能力 → 获得 $w_L$。
- **信息完全揭示**：教育成为可信的信号。

### 混同均衡（Pooling Equilibrium）

两类工人都选择同一教育水平 → 雇主无法区分 → 支付平均工资：

$$w_P = q w_H + (1-q) w_L$$

- 信息不揭示，但教育成本可能较低。
- 具体见 [[混同均衡]]。

## 信号的有效条件

信号要成为**可信的分离机制**，必须满足：

1. **成本差异**：不同类型发送信号的成本**显著不同**（$C_H(e) \ll C_L(e)$）。
   - 反例：若两类人的教育成本相同，则教育无法成为信号。
2. **成本足够高**：信号成本必须高到足以阻止低类型模仿。
   - 反例：若 $e^*$ 太低，低类型也会选择 $e^*$ → 混同。
3. **可观测性**：信号必须能被信息劣势方观察到。

## 信号的社会成本：纯浪费 vs 人力资本

Spence 模型的关键争议：**教育是否提高生产率？**

| 观点 | 机制 | 效率含义 |
|---|---|---|
| **纯信号**（Spence） | 教育不提高生产率，仅传递信息 | **纯社会浪费**：资源投入信号，总产出不变 |
| **人力资本**（Becker） | 教育提高实际技能和生产力 | 社会投资：产出增加 |
| **混合**（主流观点） | 教育同时具有两种功能 | 部分浪费 + 部分投资 |

实证分解极为困难（Hungerford-Solon 1987），因为：
- 无法随机分配教育水平（伦理问题）。
- 能力混淆：高能力者既容易获得教育，也高产出。

## [BIAS] 教学偏置：信号的社会浪费性未充分讨论

教材在介绍 Spence 模型时，通常：
1. 展示分离均衡如何揭示信息。
2. 但对**信号的社会成本**分析不足——若教育是纯信号，则整个教育系统的大部分投入是浪费。

**后果**：读者可能形成"信号传递 = 好的解决方案"的印象，而忽略了信号竞赛的负面效应：
- 学历通胀：工作需要硕士 → 人人读硕士 → 硕士不再传递信息 → 需要博士。
- 不平等加剧：低收入家庭无法承担高昂信号成本。

## 反面论点与数据空白

- 现实中信号通常是**多维的**：学历 + 工作经验 + 推荐信 + 面试表现 + 作品集。单一维度模型过于简化。
- **动态信号**：信号不是一次性事件（如获取文凭），而是持续过程（如工作表现）。重复互动中的声誉可能比一次性信号更有效。
- 数字平台的**算法信号**：LinkedIn 的技能认证、GitHub 的贡献记录等新型信号——成本结构与传统信号不同（几乎零边际成本）。
- 信号模型的**福利分析缺失**：标准的 Spence 模型不计算总福利（因为效用是序数的），无法回答"信号传递使社会变得更好还是更坏"。
