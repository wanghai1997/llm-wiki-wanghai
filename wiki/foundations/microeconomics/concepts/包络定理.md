# 包络定理

## 一句话命题

> 对于参数化最优化问题 $V(\theta) = \max_x f(x, \theta) \text{ s.t. } g(x, \theta) = 0$ 的**最优值函数** $V$，其对参数 $\theta$ 的偏导**等于拉格朗日量在最优处对 $\theta$ 的偏导**——
>
> $$\frac{\partial V(\theta)}{\partial \theta} = \frac{\partial \mathcal L(x^*(\theta), \lambda^*(\theta), \theta)}{\partial \theta}$$
>
> 即"决策变量 $x^*(\theta)$ 随 $\theta$ 变化的部分**自动相互抵消**"——只剩下 $\theta$ **直接进入**目标 / 约束的贡献。

## 直觉

在最优处，$x$ 已对 $\theta$ 调到边际值不变；$\theta$ 微小变化时,$x^*$ 也变化,但因一阶条件成立,$x^*$ 的变化对目标函数的边际贡献为 0 → **只**需考虑 $\theta$ 直接进入 $\mathcal L$ 的偏导。

## 在 [[消费者对偶性]] 四件机器中的位置

包络定理是其他三件机器（[[Slutsky方程]] / [[Shephard引理]] / [[Roy恒等式]]）的**统一证明工具**。

| 机器 | 包络定理的应用 |
|---|---|
| **Roy 恒等式** | $\partial V/\partial p_i = \partial \mathcal L^*/\partial p_i = -\lambda x_i^*$（UMP，$p_i$ 仅在预算约束中出现） |
| **Shephard 引理** | $\partial E/\partial p_i = \partial \mathcal L^*/\partial p_i = x_i^h$（EMP，$p_i$ 仅在目标中出现） |
| **Slutsky 方程** | 由对偶恒等 $x = x^h(p, V(p, m))$ + 链式法则 + 上述两条得出 |

## UMP 的包络

$\mathcal L = u(x) - \lambda(p \cdot x - m)$

- $\partial V/\partial p_i = \partial \mathcal L^*/\partial p_i = -\lambda x_i^*$（用于 [[Roy恒等式]]）
- $\partial V/\partial m = \partial \mathcal L^*/\partial m = \lambda$（"收入的边际效用"）

## EMP 的包络

$\mathcal L = p \cdot x - \mu(u(x) - U)$

- $\partial E/\partial p_i = \partial \mathcal L^*/\partial p_i = x_i^h$（用于 [[Shephard引理]]）
- $\partial E/\partial U = \partial \mathcal L^*/\partial U = \mu$（"效用的边际成本"）

## 历史

包络定理在 1930 年代由 Hotelling、Samuelson 等系统化引入经济学；其纯数学版本最早见于 Lagrange 力学。Samuelson 1947 *Foundations of Economic Analysis* 把它升格为**比较静态分析的核心工具**。

## 生产侧镜像：CMP 与 PMP 的包络

包络定理在厂商侧产生**两件**对偶机器（详见 [[厂商对偶性]]）：

### CMP 的包络（生产侧 Shephard）

$\mathcal L = wL + rK - \mu(f(L, K) - \bar x)$

- $\partial C/\partial w = \partial \mathcal L^*/\partial w = L^c$（用于 [[Shephard引理]] 生产侧）
- $\partial C/\partial r = \partial \mathcal L^*/\partial r = K^c$
- $\partial C/\partial \bar x = \partial \mathcal L^*/\partial \bar x = \mu = MC$（"产出的边际成本" = 拉格朗日乘子）

### PMP 的包络（[[Hotelling引理]]）

$\pi = pf(L, K) - wL - rK$（**无约束**最大化，故 $\mathcal L = \pi$）

- $\partial \pi^*/\partial p = \partial \pi/\partial p \big|_{*} = f(L^*, K^*) = x^*$
- $\partial \pi^*/\partial w = \partial \pi/\partial w \big|_{*} = -L^*$
- $\partial \pi^*/\partial r = \partial \pi/\partial r \big|_{*} = -K^*$

→ **三件机器变成 8 件**（消费侧 4 + 生产侧 4），但底层都是同一个包络定理。

### 八件对偶机器全表

| 侧 | 问题 | 价值函数 | 引理 | 公式 |
|---|---|---|---|---|
| **消费侧** | UMP | $V(p, m)$ | [[Roy恒等式]] | $x_i = -V_{p_i}/V_m$ |
| | EMP | $E(p, U)$ | [[Shephard引理]] | $\partial E/\partial p_i = x_i^h$ |
| | UMP↔EMP | | [[Slutsky方程]] | 价格效应分解 |
| | 共通 | | [[包络定理]] | 统一证明 |
| **生产侧** | CMP | $C(w, r, \bar x)$ | Shephard（生产）| $\partial C/\partial w = L^c$ |
| | PMP | $\pi^*(p, w, r)$ | [[Hotelling引理]] | $\partial \pi^*/\partial p = x^*$ |
| | CMP↔PMP | | "厂商 Slutsky"分解 | $\partial L^*/\partial w = \partial L^c/\partial w + (\partial L^c/\partial x)(\partial x^*/\partial w)$ |
| | 共通 | | [[包络定理]] | 同一工具 |

> **关键统一观察**：包络定理是**所有比较静态恒等式**的母规则。每条特定引理（Roy / Shephard / Hotelling）只是同一规则在不同优化问题上的"表达式"——记住"包络"，记不住具体公式也能即时推导。

## 与 Batch 3 一般均衡的连接

Ch 16 的 [[第一福利定理]] 和 [[第二福利定理]] 的证明核心依赖包络定理:
- **第一福利定理**:Walras 均衡下消费者 UMP 的包络给出 $MRS^i = p_1/p_2$;厂商 PMP 的包络给出 $MRTS^j = w/r$。价格统一使 $MRS^A = MRS^B = MRTS$ → Pareto 高效。
- **第二福利定理**:从 Pareto 点出发,用 Hahn-Banach 分离定理找支撑超平面(价格),再通过 lump-sum 重分配使预算线经过该点。包络定理保证价格下个体最优 = 社会最优。
- **核收敛定理**:复制经济中,每个消费者的包络条件在大数极限下收敛于价格接受行为。

> 包络定理是 GE 福利分析的**统一数学工具**——从个体优化到社会最优,从静态均衡到比较静态,包络提供"一阶条件 suffice"的简洁性。
