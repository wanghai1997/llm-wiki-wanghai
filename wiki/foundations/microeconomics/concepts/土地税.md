# 土地税

> Taxing Land

土地税是经济学中**最接近"无效率损失的税收"**的税种——因其税基（土地供给）完全无弹性。

## Henry George 定理

Henry George（1839–1897）在 *Progress and Poverty*（1879）中提出：**对土地价值征税不会造成效率损失（DWL = 0）**，因为土地供给是固定的，征税不会改变土地利用决策。

### 图形直觉

- 土地供给曲线是**完全无弹性**的垂直线（$E_s = 0$）。
- 对土地征税 → 土地所有者承担**全部**税负 → 土地使用者支付的价格不变 → 使用量不变 → **无 DWL**。
- 这是 [[税收归宿]] 中"弹性小的一方承担更多"的极端情形：弹性为零 → 承担 100%。

### 与一般均衡视角

在 [[一般均衡]] 框架下，土地税的特殊性在于：
- 土地是**生产要素**而非商品 → 土地税影响厂商成本 → 影响产品市场价格。
- 但土地总量固定 → 即使价格变化，土地总供给不变 → 效率结论在 GE 中依然成立（Harberger 1962 的一般均衡税收归宿分析确认了这一点）。

## 现实中的复杂性

### 土地价值评估困难

- "土地" vs "土地改良"（建筑、基础设施）难以分离。
- 土地价值税（LVT, Land Value Tax）要求精确评估**纯土地价值**（扣除改良后的价值），操作成本极高。

### 规划法规的影响

- Henry George 定理假设土地利用不受规划法规约束。
- 现实中， zoning 法规决定土地"最高最佳使用" → 土地税可能改变开发时序（即使不改变最终开发强度）。

### 国际实践

- **新加坡**、**香港**：政府拥有土地 → 通过土地出让金/年租实质征收土地税。
- **澳大利亚部分地区**（如新南威尔士州）：实施 LVT，但税基包括土地和建筑 → 不完全符合 Henry George 理想。
- **美国宾州 Harrisburg**：1980s 将房产税从建筑转向土地 → 空置土地减少、市中心复兴（但因果识别困难）。

## 反面论点与数据空白

- Henry George 定理假设土地供给**在任何价格下**都固定。但城市土地的"有效供给"受规划法规影响——土地税可能促使地方政府调整规划以获取更多税收。
- 土地税的**分配后果**：地主（通常是财富集中度最高的群体）承担全部税负 → 土地税是高度累进的。但地主可能通过提高其他要素回报（如降低工资）来部分转嫁。
- 现代经济中，"纯土地"与"资本改良"的界限日益模糊（如数据中心、光伏电站的资本投入与土地价值高度捆绑）。
- 缺乏对 LVT 大规模实施的严格因果评估（Harrisburg 案例样本小、控制变量困难）。
