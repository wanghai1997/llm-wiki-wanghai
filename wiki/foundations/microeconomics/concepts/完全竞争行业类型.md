# 完全竞争行业类型

> Constant-cost / Increasing-cost / Decreasing-cost 三种行业,根据"行业扩张是否改变要素价格 / 单位成本"分类。决定 [[长期供给曲线]] 形状。

## 三类对比

| 类型 | 扩张对要素价格 | 扩张对 $\min LAC$ | LR 供给曲线 | 教材主例 |
|---|---|---|---|---|
| **Constant-cost** | 不变 | 不变 | 水平 | 14A 默认例(小型零售) |
| **Increasing-cost** | 推高 | 上移 | 正斜率 | 14A.5.4 农业、采掘业 |
| **Decreasing-cost** | 降低 / 外部规模经济 | 下移 | **负斜率** | 14A.5.4(罕见,教材点到为止) |

## Constant-cost 的成立条件

行业要素需求**远小于**全经济要素总供给——行业扩张不影响要素价格。
- 行业占总用工不到 1%-2% → 扩张不显著推高 $w$。
- 行业占总用资本 / 总用某中间品比例小 → $r$、原材料价格不变。
- 适用于:本地服务业、小型零售、餐饮、理发等。

> Nechyba 14A 默认 constant-cost 作为基础情形,使 LR 供给曲线**水平**——价格 = $\min LAC$,行业可在该价格下任意扩张。

## Increasing-cost 的来源

- **要素稀缺**:行业用的某要素全经济供给有限——农业用耕地(土地是固定的)、采掘业用矿藏(储量有限)、特定技能劳动力。
- **行业占要素需求比例高**:汽车业占钢需求大份额 → 汽车扩张推高钢价 → 汽车成本曲线上移。
- **环境约束**:产生大量污染的行业,扩张迫使政府提高排放成本(Pigou 税或限额)→ 间接成本上升。

LR 供给曲线斜率取决于要素供给曲线的弹性 + 行业要素强度。

## Decreasing-cost 的来源(外部规模经济)

- **共享基础设施**:产业聚集 → 物流、维修、信息中心成本分摊。例:深圳硬件制造、东莞玩具业。
- **专业化供应商**:行业大到足以养活专业化中间品供应商 → 中间品质量上升 + 价格下降。例:硅谷 EDA 工具厂商生态。
- **知识溢出**:研发成果外溢使所有在位厂商受益。Marshall 1890 *Principles* 称之为"industrial atmosphere"。
- **学习曲线 / Arrow 1962 'Learning by Doing'**:累积产量越大,单位成本越低。半导体 Moore 定律是极端例子。

> **重要区分**:外部规模经济(industry-level)≠ 内部规模经济(firm-level IRS)。
> - 外部:整个行业曲线下移,但**单家厂商**仍是 CRS 或 DRS(LAC 在某 $x^*$ 取最低)。完全竞争**仍可持续**。
> - 内部:**单家厂商**LAC 单调下降(IRS)→ 大厂商总比小厂商成本低 → 自然垄断 → 完全竞争**失效**。详见 [[规模报酬]] [BIAS]。

## 教学整洁与现实复杂性

教材按"行业是哪一种?"提问,默认行业类型外生且静态。现实中:
- **生命周期视角**:行业初期可能 decreasing-cost(快速学习 + 网络效应);中期 constant-cost(标准化生产);晚期 increasing-cost(资源约束 + 环境约束)。Klepper 1996 行业演化文献给出系统证据。
- **混合特征**:数字平台同时具有外部规模经济(网络效应)+ 内部规模经济(零边际成本)→ 不属于完全竞争模型的任何一类,需用垄断竞争 / 双边市场模型。

## 与跨域 see-also 的连接

- **[[NVIDIA]]**:半导体制造业历史上是 increasing-cost(晶圆厂资本密集)+ decreasing-cost(Moore 定律学习曲线)的混合。NVIDIA 自身则是垄断厂商(受专利 + CUDA 生态保护),完全偏离完全竞争。
- **[[Token工厂经济学]]**:Token 推理市场具有 decreasing-cost 特征(规模化算力 + 学习曲线),但也接近 IRS 极端 → 不完全适用 Ch 14 完全竞争模型。

## 反面论点与数据空白

- **三类划分的边界模糊**:Nechyba 给出三种类型,但未给可操作的判别准则——某行业属于哪类需要事后实证。
- **静态分类 vs 动态演化**:Klepper 1996 / Audretsch 1995 行业演化文献证明行业类型随生命周期变化,Nechyba 静态分析忽略这一维度。
- **稳定性问题**:Decreasing-cost 行业的 LR 供给负斜率破坏均衡稳定性——需求 / 供给冲击放大而非收敛。Marshall 1890 已意识到,教材简略带过。
- **数据空白**:行业 LR 弹性实证(Goulder-Williams 2012 综述行业级估计 $[\sim 0.1, \sim 5]$)、学习曲线斜率(航空 80% 学习率、半导体 70% 等)未在教材引述。
- **与气候变化的张力**:21 世纪 increasing-cost 来源(碳排放约束、水资源约束)在教材完全竞争模型中无对应处理。
