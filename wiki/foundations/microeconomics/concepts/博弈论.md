# 博弈论（Game Theory）

## 定义

博弈论是研究**策略互动**（strategic interaction）的数学框架——即当多个决策主体的收益不仅取决于自身选择，还取决于他人选择时，如何分析理性决策。

博弈论的四要素：
1. **参与者**（Players）：$N = \{1, 2, ..., n\}$
2. **策略集**（Strategy Sets）：$S_i$ 为参与者 $i$ 的所有可行策略
3. **支付函数**（Payoff Functions）：$u_i(s_1, s_2, ..., s_n)$ 为策略组合下的收益
4. **信息结构**（Information）：完全信息 vs 不完全信息；完美信息 vs 不完美信息

## 博弈的表示形式

### 标准式（Normal Form）

用**支付矩阵**表示同时行动博弈：

|  | 参与者 2: L | 参与者 2: R |
|---|---|---|
| **参与者 1: U** | (3, 3) | (0, 5) |
| **参与者 1: D** | (5, 0) | (1, 1) |

- 每个单元格为 $(u_1, u_2)$
- 上述矩阵即经典的[[囚徒困境]]

### 扩展式（Extensive Form）

用**决策树**表示序贯行动博弈：

```
        参与者 1
       /       \
      A         B
     /           \
  参与者 2      参与者 2
  /    \        /    \
C      D      E      F
|      |      |      |
(3,1) (0,0)  (2,2)  (1,3)
```

扩展式明确表达：
- 行动顺序
- 信息集（参与者知道什么、不知道什么）
- 历史路径

## 博弈的分类

|  | 完全信息 | 不完全信息 |
|---|---|---|
| **静态**（同时行动）| [[纳什均衡]] | [[贝叶斯纳什均衡]] |
| **动态**（序贯行动）| [[子博弈精炼均衡]] | 完美贝叶斯均衡 |

## 核心解概念

博弈论提供了一系列"解概念"（solution concepts）来预测博弈结果：

| 解概念 | 适用场景 | 核心思想 |
|---|---|---|
| [[占优策略均衡]] | 存在占优策略 | 无论对手怎么做，某策略始终最优 |
| [[纳什均衡]] | 一般博弈 | 给定对手策略，无人想单方面偏离 |
| [[子博弈精炼均衡]] | 动态博弈 | 排除不可置信威胁 |
| [[贝叶斯纳什均衡]] | 不完全信息静态博弈 | 给定信念和对手策略，无人想偏离 |
| 完美贝叶斯均衡 | 不完全信息动态博弈 | 信念与策略一致，子博弈精炼 + 贝叶斯更新 |

## 反面论点与数据空白

- **[BIAS] 共同知识假设**：博弈论的核心假设是"理性是共同知识"——每个人知道每个人知道每个人……都是理性的。这一假设在现实中几乎不可能满足。实验经济学显示，人类行为系统性地偏离博弈论预测：在[[囚徒困境]]中 40-50% 参与者选择合作（Fehr-Gächter 2000）；在最后通牒博弈中，提议者给出显著高于零的分配（Güth et al. 1982）。Camerer 2003 的《行为博弈论》系统总结了这些偏离。
- **[BIAS] 支付矩阵的完备性假设**：博弈论要求支付矩阵已知且固定，但现实中参与者 often 不知对手的偏好结构，且偏好可能随情境变化。演化博弈论（Maynard Smith 1982）放松了完全理性假设，但仍难以直接应用于复杂经济环境。
- **计算复杂性**：寻找纳什均衡是 PPAD-complete 问题（Daskalakis-Goldberg-Papadimitriou 2006），对于大规模博弈（如电力市场、频谱拍卖），均衡计算在实践上可能不可行。近似均衡和机器学习求解（如 Policy Space Response Oracles, Lanctot et al. 2017）是活跃前沿。
- **数据空白**：博弈论的实验检验在实验室环境中进行（Goeree-Holt 2001），但场域数据（field data）的检验受限于博弈结构的不可观测性。结构式估计（Bajari-Hortacsu 2005 拍卖；Wolak 1994 电力市场）是主要实证方法，但识别假设争议持续。
