# 确定性等价

> 与风险赌局 $\tilde x$ 提供相同期望效用的**确定收入** $CE$。风险厌恶者 $CE \lt \mathbb{E}[\tilde x]$;风险中性者 $CE = \mathbb{E}[\tilde x]$。教材用其量化风险厌恶程度。

## 形式定义

$$u(CE) = \mathbb{E}[u(\tilde x)] = \sum_s \rho_s \cdot u(x^s)$$

- $CE$ = 确定性等价(certainty equivalent)。
- 解出:$CE = u^{-1}(\mathbb{E}[u(\tilde x)])$。

## 几何直觉

在期望收入 $\mathbb{E}[\tilde x]$ 处:
- 凹 $u$ 的函数值 $u(\mathbb{E}[\tilde x])$ > $\mathbb{E}[u(\tilde x)]$ = $u(CE)$。
- $u$ 单调递增 → $CE \lt \mathbb{E}[\tilde x]$。
- 差额 = 风险溢价。

## 风险态度与 CE 的关系

| 态度 | $u$ 形状 | CE vs $\mathbb{E}[\tilde x]$ |
|---|---|---|
| 风险厌恶 | 凹($u'' \lt 0$) | $CE \lt \mathbb{E}[\tilde x]$ |
| 风险中性 | 线性($u'' = 0$) | $CE = \mathbb{E}[\tilde x]$ |
| 风险偏好 | 凸($u'' \gt 0$) | $CE \gt \mathbb{E}[\tilde x]$ |

## 与风险溢价的关系

$$RP = \mathbb{E}[\tilde x] - CE$$

$RP$ = 主体为消除风险而愿意放弃的期望收入。

详见 [[风险溢价]]。

## 应用:保险定价

设某人面临损失 $L$(概率 $\rho$)或无损(概率 $1-\rho$)。精算公平保险 = 保费 = $\rho L$。
- 风险厌恶者:购买全额保险,确定性等价 = 财富 - $\rho L$(无风险状态)。
- 精算不公平保险(保费 = $\rho L + \text{loading}$):只购买部分保险,确定性等价介于完全风险和完全保险之间。

详见 [[精算公平保险]] / [[完全保险]]。

## 应用:资产定价

CAPM / CCAPM 中,资产价格 = 未来现金流期望的确定性等价折现:
$$P = \frac{CE(\tilde C)}{1+r_f}$$

其中 $CE(\tilde C) \lt \mathbb{E}[\tilde C]$ 反映风险调整。详见 CCAPM [Batch 5]。

## 反面论点与数据空白

- **CE 的可观测性问题**:CE 依赖 $u$ 的形式,而 $u$ 不可直接观测。实验经济学科研中 CE 通过选择任务反推,但不同实验框架给出不同 CE 估计。
- **损失厌恶下的 CE**:Kahneman-Tversky 1979 prospect theory 中,CE 不仅由 $\mathbb{E}[\tilde x]$ 决定,还由参照点(reference point)决定。同样的 $x$ 在不同参照点下 CE 不同。
- **状态依赖性**:同一赌局在不同状态(健康 / 病)下 CE 不同,但教材假设状态独立。
- **数据空白**:Holt-Laury 2002 / Andersen et al. 2008 用不同方法估计 CE 的实验,教材不引述。
