# Hotelling模型（Hotelling Model）

## 定义

Hotelling模型是产品差异化的经典位置模型（Hotelling 1929）。消费者均匀分布在一条"线性城市"上，厂商选择位置（产品特征），消费者选择距离最近的厂商购买。

## 基本设定

- 消费者均匀分布在 $[0, 1]$ 区间上，密度为 1
- 两个厂商同时选择位置 $x_1, x_2 \in [0, 1]$
- 消费者从位置 $y$ 购买产品，运输成本为 $t|y - x_i|$（$t$ 为单位距离运输成本）
- 产品同质，生产成本为 0

## 价格竞争阶段

在厂商位置确定后，进行价格竞争：

- 位于 $y$ 的消费者对厂商 1 和 2 无差异时：
  $$p_1 + t(y - x_1) = p_2 + t(x_2 - y)$$

- 边际消费者位置：
  $$y = \frac{x_1 + x_2}{2} + \frac{p_2 - p_1}{2t(x_2 - x_1)}$$

## 均衡

### 价格均衡（给定位置）

对位置 $x_1, x_2$（假设 $x_1 < x_2$），价格反应函数：

$$p_1 = \frac{p_2 + t(x_2 - x_1)}{2}, \quad p_2 = \frac{p_1 + t(x_2 - x_1)}{2}$$

均衡价格：
$$p_1^* = p_2^* = t(x_2 - x_1)$$

价格随产品差异化程度（距离）增加而增加。

### 位置均衡

Hotelling的原始结论（最小差异化原理）：
- 厂商倾向于向中心集聚（$x_1 = x_2 = 1/2$）
- 争夺最大市场份额

**d'Aspremont-Gabszewicz-Thisse 1979 的修正**：
- 若运输成本为**线性**（$t|y - x_i|$），中心集聚不是均衡——因为价格竞争导致利润函数不连续
- 若运输成本为**二次**（$t(y - x_i)^2$），中心集聚是均衡

## 二次成本Hotelling模型

设运输成本为 $t(y - x_i)^2$：

- 边际消费者：$y = \frac{x_1 + x_2}{2} + \frac{p_2 - p_1}{2t(x_2 - x_1)}$
- 均衡价格：$p_1^* = p_2^* = t(x_2 - x_1)$
- 利润：$\pi_i = \frac{p_i^*}{2} = \frac{t(x_2 - x_1)}{2}$

位置均衡：厂商向中心移动（$x_1 = 1/2 - \epsilon$，$x_2 = 1/2 + \epsilon$），但避免完全重合（因为差异化带来利润）。

## 最大差异化原理

若引入**位置选择先于价格竞争**的两阶段博弈：

- 第一阶段：选择位置
- 第二阶段：进行价格竞争

均衡结果：**最大差异化**（$x_1 = 0$，$x_2 = 1$）。

直觉：厂商通过差异化 soften 价格竞争，差异化带来的利润增加超过市场份额损失。

## 反面论点与数据空白

- **圆形城市模型（Salop 1979）**：Salop将线性城市改为圆形城市，可内生厂商数量。模型预测自由进入均衡下，厂商数量过多（相对于社会最优）。
- **多维度差异化**：现实中的差异化通常是多维的（位置、质量、品牌、服务），单维模型过于简化。
- **消费者异质性**：模型假设消费者均匀分布，但现实中消费者偏好可能聚集（如高端社区 vs 低端社区）。
- **数据空白**：Hotelling模型的实证集中于零售业选址（快餐店、加油站、银行分支），使用地理数据估计位置竞争。但产品质量差异化的结构估计更困难。
