# 间接效用函数

## 一句话定义

> $V(p, m) = u(x^*(p, m))$ ——把 [[效用最大化问题|UMP]] 的解 $x^*(p, m)$ 代入效用函数得到的**最优效用值**作为 $(p, m)$ 的函数。

## 关键性质

| 性质 | 说明 |
|---|---|
| **关于 $p$ 不增** | 价格上升 → 消费集变小 → 效用变小 |
| **关于 $m$ 不减** | 收入增加 → 消费集变大 → 效用变大 |
| **0 阶齐次** | $V(\lambda p, \lambda m) = V(p, m)$ |
| **关于 $p$ 拟凸** | 几何上为"凸下集" → 反映替代品的可获得性 |
| **连续** | 由 [[偏好五公理|连续性]] 公理保证 |

## 与 [[Roy恒等式]] 的连接

由 Roy 恒等式：

$$x_i(p, m) = -\frac{\partial V/\partial p_i}{\partial V/\partial m}$$

→ 知 $V$ → 用偏导可直接读出 Marshallian 需求。

这是为什么 $V$ 在实证中是**有用的**对象——许多需求模型（如 logit、nested logit）直接对 $V$ 建参数化。

## 与 [[支出函数]] $E$ 的对偶

$$E(p, V(p, m)) = m, \qquad V(p, E(p, U)) = U$$

→ $V$ 与 $E$ **互为反函数**（在效用 / 收入维度）。这是 [[消费者对偶性]] 的核心恒等。

## 与 $\lambda$（收入边际效用）

由 UMP 的 [[拉格朗日法|拉格朗日]] 求解：$\lambda^* = \partial V/\partial m$ ——**多 1 元收入能带来多少效用增量**。这是"货币的边际效用"——常数当且仅当 [[准线性偏好]]（$x_2$ 上线性）。

## 在 [[Microeconomics-Nechyba-2e|Nechyba 教材]] 中的位置

教材 Ch 6B 引入间接效用作为 UMP 的"价值函数"，Ch 10B 把它升格为对偶系统的"需求侧入口"——通过 [[Roy恒等式]] 把任意间接效用反推为 Marshallian 需求。

## 在福利度量中的角色

- $\Delta V$ 不能直接累加 → "效用变化"无单位、不可加；
- 需用 [[等价变差EV]] / [[补偿变差CV]] 把 $\Delta V$ 转换为**货币度量**——见 Ch 10 的福利测度章节（推迟 Batch 4 / MWG）。

## 反面论点与数据空白

- **[BIAS] 教材在 Ch 6-9 用 CD / CES 给出闭式 $V$**：现实偏好下 $V$ 通常无闭式——教材 Ch 1–10 不涉及数值估计。
- **数据空白**：间接效用在离散选择模型（McFadden, 1974）中的关键作用,教材未提及。
