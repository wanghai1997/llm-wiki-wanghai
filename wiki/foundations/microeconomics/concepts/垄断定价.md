# 垄断定价（Monopoly Pricing）

## 定义

垄断（monopoly）是指市场中**只有一个卖方**，且该卖方面临**向下倾斜的市场需求曲线**——即垄断者认识到自身产量决策会影响市场价格，而非像完全竞争者那样视价格为给定。

与完全竞争的关键区别：
- 完全竞争：$P = MR = MC$（价格接受）
- 垄断：$P > MR = MC$（价格制定）

## 模型推导

### 利润最大化条件

垄断者选择产量 $Q$ 以最大化利润：

$$\max_Q \quad \pi(Q) = P(Q) \cdot Q - C(Q)$$

一阶条件：

$$\frac{d\pi}{dQ} = P(Q) + Q \cdot \frac{dP}{dQ} - MC(Q) = 0$$

即：

$$MR = MC$$

其中边际收益 $MR = P + Q \cdot \frac{dP}{dQ} = P\left(1 - \frac{1}{|\varepsilon|}\right)$，$\varepsilon$ 为需求价格弹性。

### 勒纳指数（Lerner Index）

由 $MR = MC$ 和 $MR = P(1 - 1/|\varepsilon|)$ 可得：

$$\frac{P - MC}{P} = \frac{1}{|\varepsilon|}$$

这被称为**勒纳指数**（Lerner 1934），衡量垄断势力的程度：
- $|\varepsilon| \to \infty$（完全弹性）→ 勒纳指数 = 0 → 完全竞争
- $|\varepsilon| = 2$ → 勒纳指数 = 0.5 → $P = 2MC$

## 反面论点与数据空白

- **[BIAS] 单一产品垄断的简化**：教材通常分析单一产品垄断者，但现实中的垄断者（如 Microsoft、Google）通常是多产品厂商，面临的需求系统更复杂（交叉价格弹性、捆绑销售）。此外，平台垄断（双边市场）涉及两个用户群体，传统垄断模型无法直接套用（Rochet-Tirole 2003）。
- **跨期定价问题**：Coase 1972 指出，耐用品垄断者面临"时间不一致"问题——今天以高价销售后，明天有动机降价吸引剩余消费者；预期到这一点，消费者会推迟购买，迫使垄断者价格路径趋于竞争水平。这与静态垄断模型矛盾。
- **相关市场界定难题**：反垄断执法中，判断"是否存在垄断"需要界定相关市场（relevant market）。美国 v. Microsoft 1998 的争议焦点之一是"浏览器市场"是否构成独立市场。这一界定带有主观性，不同界定可得出完全不同的结论。
- **数据空白**：勒纳指数的实证估计需要同时观测价格、边际成本和需求弹性。由于边际成本通常不可直接观测，实证研究多采用会计数据近似（ROIC 减去资本成本）或结构式 IO 方法（Bresnahan 1989）。不同方法得出的市场势力估计差异显著。
