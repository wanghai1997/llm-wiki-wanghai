# 拉格朗日法

## 一句话定义

> 求解**带约束最优化问题**的标准代数工具。把约束引入目标函数，构造**拉格朗日量** $\mathcal L$，对决策变量与拉格朗日乘子取偏导 = 0 得**一阶条件**。

## [[效用最大化问题|UMP]] 的拉格朗日

$$\mathcal L(x_1, x_2, \lambda) = u(x_1, x_2) - \lambda(p_1 x_1 + p_2 x_2 - m)$$

**一阶条件**：
- $\partial \mathcal L / \partial x_1 = 0$ → $u_1 = \lambda p_1$
- $\partial \mathcal L / \partial x_2 = 0$ → $u_2 = \lambda p_2$
- $\partial \mathcal L / \partial \lambda = 0$ → $p_1 x_1 + p_2 x_2 = m$

前两条相除 → $u_1/u_2 = p_1/p_2$ → [[边际替代率MRS]] = 价格比 → [[内点最优条件]]。

## 拉格朗日乘子 $\lambda$ 的经济解释

$\lambda^* = \partial V / \partial m$ ——**收入的边际效用**：再多 1 元收入能多带来 $\lambda^*$ 的效用。这是 Ch 6B 的核心解读，也是 [[包络定理]] 在消费者最优化上的最直接应用。

## [[支出最小化问题|EMP]] 的拉格朗日

$$\mathcal L(x_1, x_2, \mu) = p_1 x_1 + p_2 x_2 - \mu(u(x_1, x_2) - \bar U)$$

FOC 给出 $p_i = \mu u_i$ → $u_1/u_2 = p_1/p_2$ ——**与 UMP 同构**。乘子 $\mu^* = \partial E/\partial U$ ——**效用的边际成本**。

## 不等式约束（KKT 推广）

$x_i \ge 0$ 引入互补松弛条件：$\partial \mathcal L / \partial x_i \le 0$ 且 $x_i \cdot \partial \mathcal L / \partial x_i = 0$。
这处理 [[角点解]] 与 [[折点预算]] 的最优化。
