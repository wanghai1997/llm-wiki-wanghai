# 成本函数

> [[成本最小化问题|CMP]] 的**值函数**——给定要素价格与目标产出时的最低生产成本；与消费者侧 [[支出函数]] 完全镜像。

## 定义

$$
C(w, r, \bar x) \;=\; \min_{L, K \geq 0} \{ wL + rK : f(L, K) = \bar x \} \;=\; w L^c(w, r, \bar x) + r K^c(w, r, \bar x)
$$

## 关键性质（由对偶理论）

| 性质 | 说明 |
|---|---|
| **零阶齐次于 $(w, r)$** | $C(\lambda w, \lambda r, \bar x) = \lambda C(w, r, \bar x)$（一阶齐次，正比例缩放）|
| **凹于 $(w, r)$** | 由"min over $L, K$"的对偶函数性质——多个线性函数的下包络必凹 |
| **单调递增于 $\bar x$** | 更多产出至少需更多成本 |
| **[[Shephard引理]]：$\frac{\partial C}{\partial w} = L^c$** | 一阶偏导 = [[条件投入需求]] |
| **[[包络定理]] 应用** | 通过 $\partial \mathcal{L}/\partial w$ 直接求得，不需对 $L^c, K^c$ 反向求导 |

## 几何与组合

$$
C(w, r, \bar x) = \text{长期总成本（LTC）}
$$

把 $C$ 关于 $\bar x$ 的几何：

- 边际成本 $MC(\bar x) = \partial C / \partial \bar x$
- 平均成本 $AC(\bar x) = C(\bar x) / \bar x$
- LTC 凸或凹取决于 [[规模报酬]]：CRS → LTC 线性；DRS → LTC 凸；IRS → LTC 凹

详见 [[平均成本曲线包络]]。

## 与支出函数的镜像

| 消费者侧 [[支出函数]] | 生产侧成本函数 |
|---|---|
| $E(p, \bar u) = \min p \cdot x$ s.t. $u(x) \geq \bar u$ | $C(w, r, \bar x) = \min w L + r K$ s.t. $f(L,K) \geq \bar x$ |
| 凹于 $p$ | 凹于 $(w, r)$ |
| $\partial E / \partial p_i = h_i$（[[补偿需求曲线]]）| $\partial C / \partial w = L^c$（[[条件投入需求]]）|
| 同一 [[Shephard引理]] | 同一 [[Shephard引理]] |

> Shephard 1953 同时给出消费侧 $E$ 与生产侧 $C$ 的引理——本 Wiki 在 [[Shephard引理]] 页通过 §"生产侧扩展" 一并讨论。

## 在 [[厂商对偶性]] 中的位置

$C(w, r, \bar x)$ 是 [[两步利润最大化]] 的 **Step 1 输出**；Step 2 用 $C$ 求 PMP：

$$
\pi^*(p, w, r) = \max_{x} \{p x - C(w, r, x)\}
$$

FOC：$p = MC(x^*) = \partial C / \partial x$。

## 应用

1. **行业进入与退出**：长期均衡下零利润 → $p = AC_{\min}$（详见 [[关闭条件]] 与 Batch 3 的 [[竞争性市场均衡]]）。
2. **要素价格冲击**：$\partial C / \partial w = L^c$ 直接告诉我们工资上涨对成本的边际影响 = 当前劳动用量。
3. **政策评估**：碳税 / 排污税推高某要素价格 $w_e$，由 $L_e^c(w_e)$ 直接预测要素再配置。

## 反面论点与数据空白

- **凸生产集前提**：非凸下 $C$ 可能不可微（多解处尖角）；Shephard 引理在尖角处需用次梯度。
- **要素价格外生**：垄断买方下 $w$ 内生，$C$ 退化。
- **静态假设**：实际成本含调整成本（资本折旧、人员培训），动态版 $C$（Hamermesh 1989）超出 Nechyba 范围。
- **数据空白**：跨国 / 跨行业 $C$ 函数的参数化估计依赖特定函数族（Translog、Generalized Leontief），结果对函数选择敏感（Berndt-Khaled 1979）。
