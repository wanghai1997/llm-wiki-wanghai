# 第一福利定理-部分均衡

> 完全竞争 LR 均衡使**社会剩余最大化**——在没有外部性、信息不对称、公共品、市场势力的前提下,自由市场配置 Pareto 高效。Adam Smith 1776 "看不见的手" 的现代部分均衡形式化版本。[BIAS:小政府偏向]

## 形式陈述(部分均衡版)

在某商品市场,假设:
1. **完全竞争**:消费者与厂商都是价格接受者。
2. **无外部性**:生产 / 消费的边际效益与边际成本完全在私人主体内部。
3. **完美信息**:价格反映所有相关信息。
4. **自由进入退出**:LR 均衡 [[长期零利润条件]] 成立。
5. **无公共品 / 共有资源**:商品产权清晰。

则 LR 均衡 $(p^{LR}, X^{LR})$ 使**社会剩余** $W = CS + PS$ 最大化(详见 [[社会剩余]])。

## 直觉推导

完全竞争均衡同时满足:
- **消费者**:$p^{LR} = MU / \lambda$(边际效用 = 价格,在收入约束下)→ 消费的边际价值 = 价格。
- **厂商**:$p^{LR} = LMC$(边际成本 = 价格)→ 生产的边际成本 = 价格。

合一:**边际效益 = 边际成本**。任何偏离都使总剩余下降:
- $X < X^{LR}$:边际效益 > 边际成本 → 增产可创造正剩余。
- $X > X^{LR}$:边际效益 < 边际成本 → 减产可创造正剩余。

## 几何

价格 $= p^{LR}$ 的水平线把图分两部分:
- **CS** = 需求曲线下方、价格线上方的面积。
- **PS** = 价格线下方、供给曲线上方的面积(LR 中 = 0,因零利润条件)。
- **DWL** = 0(均衡未被扭曲)。

任何价格 / 数量管制使均衡偏离 $X^{LR}$ → 出现死重损失三角形(详见 [[市场扭曲下的福利损失公式]])。

## 与"看不见的手"的关系

Smith 1776 *Wealth of Nations*:每个人追求自利的同时,被"看不见的手"引导促进社会福利。

> Nechyba 在 Ch 15 强调这是**部分均衡版**——只考虑单一市场。一般均衡版(所有市场同时出清)需要 Ch 16 Edgeworth 盒 + Walras 框架(详见 [[第一福利定理]] / [[一般均衡-Walras版]])。

## [BIAS:小政府偏向]

> **教材立场**:Nechyba 默认从"完全竞争 + 自由市场"出发,把所有干预视为对该基准的偏离,并用 DWL 三角形量化偏离成本。

> **反面立场**:Stiglitz 1986、Greenwald-Stiglitz 1986 *"Externalities in Economies with Imperfect Information and Incomplete Markets"* 证明:**信息不对称 + 市场不完全**普遍存在(几乎所有真实市场均如此),所以"完全竞争是基准"在论证起点上就是反事实的——市场失灵是规则,不是例外。

> **历史宏观证据**:1929 大萧条、2008 金融危机、2020 公共卫生危机都展示了"自由市场 + 看不见的手"在面对系统性冲击时的脆弱性。第一福利定理的"无precondition-optimism"假设忽视宏观稳定 / 金融危机 / 系统性风险的可能。

## 反面论点与数据空白

- **五假设的现实违反程度**:经验上无任何真实市场同时满足所有五条假设——结果第一福利定理的"基准"地位与其说是描述,不如说是反事实。
- **"潜在 Pareto 改进"无意义**:Hicks-Kaldor 补偿原理使 DWL 在不发生实际补偿时仍被视为政策反对理由,但补偿在政治上几乎从不发生(Hochman-Rodgers 1969 critique;Sen 1979 social-choice critique)。
- **路径依赖与历史不公**:第一福利定理只保证 Pareto 高效,不保证分配公平——给定不同初始禀赋分配,第一定理给出无穷多个不同的均衡(Pareto 无可比性)。Sen 1970 / Atkinson 1970 强调这一点。
- **环境外部性的系统性低估**:Stern 2007 *Stern Review on the Economics of Climate Change* 估计气候外部性占 GDP 的 5-20%,远超 Nechyba 在 Ch 15 给出的"小三角形 DWL"形象。
- **Lipsey-Lancaster 1956 第二最优定理**:当一条假设违反时,**保持其他假设**未必使福利提高——可能需要主动违反多个假设以恢复整体高效。教材忽略这一关键反面定理。

## Batch 5 连接：市场势力导致失效

以上分析假定"价格接受"。Batch 5（Ch 23-26）系统放弃该假设：

| 市场结构 | 均衡条件 | 福利损失 |
|---|---|---|
| **完全竞争** | $P = MC$ | 无 |
| **垄断** | $MR = MC < P$ | Harberger 三角 + X-非效率 |
| **Cournot寡头** | $MR = MC$，$P > MC$ | 中等 |
| **Bertrand寡头**（同质）| $P = MC$ | 无（Bertrand悖论）|
| **Bertrand寡头**（差异化）| $P > MC$ | 取决于替代弹性 |

关键洞见：市场势力的福利损失不仅来自 $P > MC$ 的 allocative inefficiency，还来自：
- **X-非效率**（Leibenstein 1966）：垄断者内部成本膨胀
- **寻租成本**（Tullock 1967）：为获取/维持垄断地位耗费的资源
- **创新抑制**（Arrow 1962）：垄断者缺乏创新动机

详见 [[不完全竞争与博弈论]]（主题页）、[[垄断无谓损失]]。
