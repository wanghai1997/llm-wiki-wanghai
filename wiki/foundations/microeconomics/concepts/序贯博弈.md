# 序贯博弈（Sequential Games）

## 定义

序贯博弈（Sequential Games）是指参与者**按特定顺序行动**的博弈——后行动者能观察到先行动者的选择。这与同时行动的"静态博弈"形成对照。

序贯博弈用**扩展式**（Extensive Form）表示：
- 决策节点（每个节点对应一个参与者）
- 行动分支（从节点延伸出的可选行动）
- 信息集（参与者知道自己在哪个节点，但可能不知道对手的历史行动）
- 终端节点（博弈结束，给出支付）

## 逆向归纳法（Backward Induction）

求解序贯博弈的核心方法：

1. 从博弈的**最后一个决策节点**开始
2. 对该节点的决策者，选择最优行动
3. 将该最优行动"嵌入"前一个节点，简化博弈
4. 重复直至初始节点

### 示例：进入博弈

```
      潜在进入者
      /       \
  进入         不进入
   /             \
 在位者         (0, 10)
  /    \
 接纳    斗争
  |      |
(5, 5)  (-1, 1)
```

逆向归纳：
- 最后节点（在位者）：接纳 $(5) \gt$ 斗争 $(1)$ → 在位者选择**接纳**
- 回溯到进入者：进入后预期在位者接纳，进入收益 $(5) \gt$ 不进入 $(0)$ → 进入者选择**进入**

均衡路径：进入者进入 → 在位者接纳 → 收益 $(5, 5)$

## 先动优势 vs 后动优势

| 优势类型 | 直觉 | 例子 |
|---|---|---|
| **先动优势** | 率先行动者可"锁定"市场、设定标准 | [[Stackelberg竞争]]（领导者产量更大、利润更高） |
| **后动优势** | 观察到对手行动后可针对性反应 | 价格匹配（后降价者可精准打击） |

先动优势的来源：
- **承诺价值**：先动者的行动成为沉没成本，不可撤销（Spence 1977 过剩产能投资）
- **抢占资源**：抢占专利、土地、市场份额
- **网络效应**：先积累用户，后享受正反馈

## 信息集与完美信息

- **完美信息博弈**：每个决策节点属于一个单独的信息集——后行动者**完全知道**此前的全部历史
- **不完美信息博弈**：某些决策节点属于同一个信息集——参与者**不知道**自己处于哪个具体节点

[[Stackelberg竞争]] 是完美信息博弈；同时行动的 Cournot 博弈可视为不完美信息博弈（每个厂商在做决策时不知对方产量）。

## 承诺价值

先动优势的本质是**可信承诺**（Credible Commitment）：

- 若先动者的行动**不可逆**（sunk cost），则后动者必须接受该行动作为既定事实
- 若先动者的行动**可逆**，则后动者预期先动者可能改变行动 → 承诺不可信 → 先动优势消失

### 例子：产能投资

- 在位者投资大量沉没产能 → 进入者预期价格战后在位者仍可盈利 → 进入被阻止
- 若产能可灵活调整（非沉没）→ 在位者投资不可信 → 进入者不受威慑

## 反面论点与数据空白

- **连锁店悖论**（Chain Store Paradox）：Selten 1978 指出，在位者在多个市场面临进入者时，早期"斗争"以建立声誉的策略在逆向归纳下不可信——最后一个市场无未来声誉可维护，因此在位者必然接纳；回溯至倒数第二个市场，同样逻辑适用。最终，在位者在所有市场都接纳，进入者自由进入。这与现实中观察到的"为声誉而战"行为矛盾。
- **有限理性**：逆向归纳要求参与者进行多步推理。实验显示，人类参与者的推理深度有限（通常 1-3 步；Nagel 1995）。
- **共同知识假设**：逆向归纳要求"理性是共同知识"——每个参与者知道每个参与者知道……理性。若参与者怀疑对手的理性，逆向归纳的推导可能提前终止。
- **数据空白**：序贯博弈的实验检验主要通过实验室实验（如"信任博弈""最后通牒博弈"），但场域数据稀缺。产业组织中的动态博弈估计（Ericson-Pakes 1995 框架）需要大量数据和高计算成本。
