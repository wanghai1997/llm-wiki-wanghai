# 长期均衡

> 在**自由进入退出**条件下,市场需求 = 市场供给且**所有在位厂商经济利润为零**($\pi^j = 0$)的稳态。

## 定义

LR 均衡是一组 $(p^{LR}, X^{LR}, J^{LR})$ 满足:

1. **市场出清**:$X^D(p^{LR}) = X^{S,LR}(p^{LR}; J^{LR})$
2. **零利润条件**:在位厂商 $\pi^j(p^{LR}) = 0$,即 $p^{LR} = \min LAC$ → [[长期零利润条件]]
3. **个体最优**:$p^{LR} = LMC^j$ → 每家厂商在长期边际成本曲线上选最优数量

> **三条件等价表述**:LR 均衡 = 价格 $p^{LR} = \min LAC$,在位厂商数 $J^{LR}$ 满足总产出等于市场需求 $X^D(p^{LR})$。

## 与 SR 的差异

| 维度 | SR | LR |
|---|---|---|
| 厂商数 $J$ | 固定 | 内生(自由进入退出) |
| 资本 $K_j$ | 固定 | 可调 |
| 经济利润 | 可正可负 | $= 0$(否则触发进入 / 退出) |
| 价格 $p$ | 任意供需相等 | $p^{LR} = \min LAC$(取决于行业类型) |
| 调整速度 | 瞬时(教材假设) | 数年至数十年(现实) |

## 自由进入退出机制

- 若 SR 均衡 $p^{SR} > \min LAC$ → 在位厂商赚超额利润 → 新厂商进入 → $X^S$ 右移 → $p$ 下降 → 直到 $p = \min LAC$。
- 若 SR 均衡 $p^{SR} < \min LAC$ → 在位厂商亏损 → 部分厂商退出 → $X^S$ 左移 → $p$ 上升 → 直到 $p = \min LAC$。

详见 [[自由进入退出]]。

## 行业类型与 LR 供给曲线

LR 行业供给曲线 $X^{S,LR}(p)$ 的形状取决于"扩张行业是否改变要素价格":

| 行业类型 | 要素价格 | LR 供给斜率 |
|---|---|---|
| Constant-cost | 不变 | **水平**($p^{LR} = \min LAC$ 不变) |
| Increasing-cost | 行业扩张推高 | **正斜率**($p^{LR}$ 随 $X$ 升) |
| Decreasing-cost | 行业扩张降低(外部规模经济) | **负斜率**($p^{LR}$ 随 $X$ 降) |

详见 [[完全竞争行业类型]] / [[长期供给曲线]]。

## 比较静态

LR 中,需求侧冲击对**价格**的影响比 SR 弱:
- Constant-cost 行业:需求上升 → 新厂商进入 → $p$ 不变,$X$ 上升。
- Increasing-cost 行业:需求上升 → 进入 + 要素价格上升 → $p$ 部分上升,$X$ 上升。

供给侧冲击(技术进步、要素价格永久变化)在 LR 完全反映:
- 新技术使 $\min LAC$ 下降 → LR 价格下降 → 长期消费者剩余增加。

## 福利意义:第一福利定理(部分均衡版)

LR 均衡的零利润条件 + 价格接受 + 完全竞争 → 该均衡 Pareto 高效(详见 [[第一福利定理-部分均衡]] / [[社会剩余]])。

> 注意:**零利润 ≠ 零会计利润**。经济利润 = 收入 - 全部机会成本(包括股东资本的正常回报);LR 均衡下经济利润为零意味着资本得到机会成本回报,但**会计利润**仍为正。

## 反面论点与数据空白

- **"长期"是否真实存在**:教材的 LR 假设瞬时进入退出 + 资本完全可调;现实中行业特定资本(船坞、晶圆厂)、监管牌照、品牌建设使 LR 时长达数年至数十年。某些行业(核电、航空母舰)LR 时长可比观察年限更长 → "LR 均衡"成为不可观测的反事实状态。
- **僵尸企业(Caballero-Hoshi-Kashyap 2008)**:日本 1990s 大量"应退出但未退出"的僵尸企业由银行延贷支持,违反 LR 均衡的零利润退出条件。中国 2010s 的过剩产能行业(钢铁、煤炭、太阳能板)出现类似现象。
- **沉没成本破坏对称性**:进入决策考虑全部成本(含沉没投资),退出决策只考虑可避免成本 → 进入门槛高于退出门槛 → "迟滞区间"内既不进也不出(Dixit 1989 sunk cost hysteresis)。教材忽略沉没成本的不对称影响。
- **数字平台的零 LAC**:软件 / 数据 / Token 等边际成本 ≈ 0,$\min LAC \to 0$,LR 均衡退化为"赢家通吃"垄断而非完全竞争(IRS [BIAS],参见 [[规模报酬]] / [[NVIDIA]] 跨域链接)。
- **数据空白**:行业进入退出率(Dunne-Roberts-Samuelson 1988)、调整时长实证未在教材引述。
