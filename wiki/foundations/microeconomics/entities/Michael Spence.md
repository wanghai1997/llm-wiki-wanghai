# Michael Spence

- **生卒**：1943–
- **国籍**：美国
- **主要领域**：信息不对称、劳动力市场、经济增长
- **学术归属**：斯坦福大学商学院、哈佛大学
- **荣誉**：2001 年诺贝尔经济学奖（与 George Akerlof、Joseph Stiglitz 共享）

## 核心贡献

### 信号传递模型（Signaling, 1973）

在 *Market Signaling*（1973）中，Spence 提出：**信息优势方**（如高能力工人）可以通过发送**成本高昂的信号**（如教育文凭）来主动揭示自身类型，从而解决逆向选择问题。

核心机制：
- 高能力者的信号成本 **低于** 低能力者（因为高能力者学习更轻松）。
- 存在临界信号水平：高于此水平 → 被市场识别为高能力，获得高工资；低于此水平 → 被识别为低能力。
- **分离均衡**（Separating Equilibrium）：两类人选择不同信号水平 → 信息完全揭示。
- **混同均衡**（Pooling Equilibrium）：两类人选择相同信号 → 信息不揭示。

### 信号的社会成本

Spence 模型的关键洞见：若教育**不提高实际生产率**（纯信号功能），则社会在信号上投入的资源是**纯浪费**——每个人为证明自己而接受更多教育，但总产量未增加。这引发了"教育到底是人力资本投资还是信号"的长期实证争论。

## 反面论点与数据空白

- 纯信号模型中，教育是**纯社会浪费**；但实证上教育同时提高生产率（人力资本功能）和传递信息（信号功能）。Hungerford-Solon 1987 试图分解两者，但识别困难。
- 信号可能**加剧不平等**：低收入家庭无法承担高昂的信号成本（如大学学费）→ 被锁定在低能力标签下。
- 现实中的信号通常是**多维的**（学历 + 工作经验 + 推荐信 + 面试表现），而非单维的。
