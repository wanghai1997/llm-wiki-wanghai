# 孙国峰

> **一句话画像**：孙国峰，[[中国人民银行]] 货币政策司司长（2017-2021，本文署名时职务），中国央行内部"信用货币论"代表人物之一；2021 年 1 月在人民银行官网发表《[[现代货币政策框架|健全现代货币政策框架]]》，系统阐述中国货币政策的目标—工具—传导三组件框架。

## 文中体现的理论立场

### 1. 信用货币论 / 内生货币观（中国央行版本）

- 关键陈述：**"在现代信用货币体系下，银行通过贷款等资产扩张方式创造存款，是货币创造的直接主体"**。
- 含义：央行不再直接"发行"流通中的货币，而是通过引导银行**主动**的货币创造行为来管理货币总量。
- 与 Mankiw 9e Ch 4 [[部分准备金银行]] / [[货币乘数]] 教科书叙事的对照：Mankiw 框架将基础货币 → 货币乘数 → 广义货币视为外生因果链；孙国峰版本将其颠倒为银行**主动放贷创造存款，央行被动应对准备金需求**——本质上接受了 BoE 2014《Money Creation in the Modern Economy》（McLeay-Radia-Thomas）的内生货币立场。
- 详见 [[央行三大约束-流动性资本利率]]。

### 2. 中介目标"基本匹配"原则

- 主张 [[M2与社会融资规模]] 增速与名义 GDP 增速"基本匹配"作为中介目标。
- 这是数量目标（M2 / 社融）与利率规则（LPR / MLF）的混合体，与美联储联邦基金利率单一目标制不同。
- 三条操作要点：基本匹配 ≠ 完全相等（保留逆周期空间）、综合考虑潜在产出（[BIAS] 加总生产函数依赖）、中长期概念而非短期。

### 3. 跨周期政策设计

- 区别于 Mankiw 教材"逆周期 / 稳定化政策"叙事，孙国峰强调 [[跨周期政策设计]] —— 跨越经济周期平滑政策力度，避免短期对冲带来的政策反复。
- 可能受 BIS Borio (2014) 金融周期理论与中国 2015-2016 股市与汇市波动的政策教训影响。

### 4. 三大约束方法论

- 区别于 Mankiw 框架的"准备金 + OMO + 贴现率"传统三工具，孙国峰提出央行通过 **流动性 / 资本 / 利率** 三大约束影响银行货币创造行为：
  - 流动性约束 → [[OMO公开市场操作-中国]] / [[MLF中期借贷便利]] / [[SLF常备借贷便利]] / 准备金率调整
  - 资本约束 → [[永续债银行资本工具]] + [[CBS央行票据互换]]
  - 利率约束 → [[LPR贷款市场报价利率]] / "MLF→LPR→贷款利率"传导

## 反面论点与数据空白

- **理论自洽性张力**：孙国峰一方面承认"贷款创造存款"（内生论），另一方面保留"基础货币—准备金—货币乘数"工具组合（外生论），存在内在张力。Borio (BIS 2017) 已批评央行政策语言与现代银行学不一致——中国版本尤其矛盾。[CONTRADICTION]
- **政策预测后视**：本文（2021-01）预见"防止信用收缩"风险，但**未预见** 2021-2022 房地产去杠杆危机与 2023-2024 通缩压力。"基本匹配"原则在 2022-2024 出现"M2 增速持续高于名义 GDP"的剪刀差现象，需要后续摄入 2024 年潘功胜《建设现代中央银行制度》(陆家嘴论坛) 等更新文本进行对照。[BIAS] [数据空白]
- **理论原创性争议**：本文提出的"现代货币政策框架"在多大程度上原创、多大程度上是 BoE 2014 + BIS Borio + IMF 主流框架的中国化阐释，需要孙国峰系列学术论文（2018+）对比研究。[数据空白]
- **政治经济角色**：作为央行高官的署名文本，本文不仅是学术陈述，也是政策宣告。其实际指导意义需要与同期央行《货币政策执行报告》对照解读，本 Wiki 暂无后续批次摄入。[数据空白]
- **原作者后续动向**：2021 年后孙国峰的职务变动与思想演变（如对 2024 货币政策框架二次改革的回应）暂无信息。[数据空白]
