# 宏观审慎评估MPA

> **一句话定义**：**Macro-Prudential Assessment, MPA**，[[中国人民银行]] 2016 年正式实施的银行评估体系，将资本与杠杆、资产负债、流动性、定价行为、资产质量、跨境业务、信贷政策执行等多维度纳入综合评估，配合 [[微观审慎监管]] 形成"双支柱"调控框架。在 [[孙国峰]] 文中作为 [[宏观审慎政策]] 的中国实施载体。

## 概念出处

- 制度沿革：2011 差别准备金动态调整 → 2016 升级为 MPA → 2017+ 纳入表外理财 / 同业存单。
- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 关键陈述："**完善'货币政策+宏观审慎政策'双支柱调控框架，发挥宏观审慎政策的结构性、定向性优势**"——MPA 是宏观审慎政策的核心工具。

## 评估七大维度（按 PBoC 官方框架）

| 维度 | 主要指标 | 政策意图 |
|---|---|---|
| 1. 资本和杠杆 | 资本充足率、杠杆率 | 保证银行承担风险的能力 |
| 2. 资产负债 | 广义信贷增速 / 委托贷款增速 | 控制信贷过度扩张 |
| 3. 流动性 | 流动性覆盖率（LCR）/ 净稳定资金比例（NSFR）| 控制流动性风险 |
| 4. 定价行为 | 利率定价行为 | 防止恶性竞争 |
| 5. 资产质量 | 不良贷款率 / 拨备覆盖率 | 保证资产质量 |
| 6. 跨境业务 | 跨境融资合规 | 防止跨境套利 |
| 7. 信贷政策执行 | 三农 / 小微 / 普惠等 | 落实政策导向 |

评估周期：季度 / 年度。
评估结果：A / B / C 三档，对应不同准备金利率与政策工具准入。

## 关键创新

### 广义信贷概念

- 不仅纳入表内贷款，还包括债券投资、股权投资、买入返售、表外理财等。
- 防止银行通过"非贷款"业务规避信贷增速考核。

### 与 Basel III 衔接

- 资本充足率 / 杠杆率 / 流动性指标对接 Basel III。
- 但增加了 PBoC 特有的逆周期资本缓冲 + 信贷政策执行维度。

### 逆周期调节

- 通过信贷投向 / 速度的考核与激励，引导银行在经济过热时放慢扩张、在低迷时加快投放。
- 配合 [[结构性货币政策工具]] 形成"激励 + 约束"组合。

## 与微观审慎的关系

按孙国峰文："**形成宏观审慎与微观审慎相结合、相互补充的金融监管体系**"：

- 微观审慎（银保监会 / 证监会主导）：单家机构合规与风险。
- 宏观审慎（PBoC 主导）：系统性风险 + 跨周期 / 跨市场风险联动。
- MPA 桥接两者：单家银行评估指标但聚合后形成系统性视角。

## 国际比较

| 国家 | 宏观审慎工具 | 主要监管 |
|---|---|---|
| 中国 | MPA + 金融机构系统重要性评估 + 房地产宏观审慎 | PBoC + 金融委 |
| 美国 | CCAR 压力测试 + Dodd-Frank 系统重要性 | Fed + FSOC |
| 欧洲 | SSM 单一监管机制 + ECB 系统性风险委员会 | ECB + ESRB |
| 英国 | FPC 金融政策委员会 | BoE |
| 巴塞尔 | Basel III 框架 + 全球系统重要性银行（G-SIB）| BIS |

## 反面论点与数据空白

- **MPA 的可观察性争议**：MPA 评估结果不公开（A / B / C 档为机构内部信息），实证研究依赖间接指标。学术界对 MPA 实际约束力的实证研究有限。[数据空白]
- **广义信贷边界争议**：广义信贷的边界随金融创新不断变化（同业存单 / 资管产品 / ABS 等），定义滞后于市场创新。规避方式可能持续涌现。[CONTRADICTION] [BIAS]
- **激励一致性**：MPA 鼓励银行投放重点领域（小微 / 三农），但同时考核资产质量；当重点领域天然违约率较高时，激励冲突。[CONTRADICTION]
- **"双支柱"理论争议**：货币政策（总量）+ 宏观审慎（结构）的"双支柱"理论由 PBoC 强力倡导，但国际上仍有争议。BIS 主张更彻底分工（货币政策只管价格稳定 + 宏观审慎管金融稳定）；中国版本的"协同"是否更有效，证据未定。[CONTRADICTION]
- **MMT 视角**：MPA 是央行控制银行信贷扩张的微观操作；MMT 视角下信贷扩张应由财政与监管协同管理，而非货币政策从属。MPA 的合法性边界在 MMT 框架下值得讨论。[CONTRADICTION]
- **2024 改革延续**：2024 后金融监管改革（金融监管总局成立、PBoC 职能调整）改变 MPA 制度环境；本文之后的发展需要后续摄入。[数据空白]
- **MPA 与"信贷指导"的边界**：MPA 在多大程度上是"评估"，多大程度上是"指导"？指标设计具有事实上的强制性（不达标影响业务准入）→ 是否回到了"信贷规模管理"的路径？[CONTRADICTION]
