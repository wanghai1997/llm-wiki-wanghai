# SLF常备借贷便利

> **一句话定义**：**Standing Lending Facility, SLF**，[[中国人民银行]] 2013 年创设的常备性流动性供应工具，由银行**主动申请**获得央行流动性支持。在 [[央行政策利率体系-中国]] 利率走廊中作为**走廊上限**，是中国版"贴现窗口"。

## 概念出处

- 工具创设：2013 年。
- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）多处提及，作为完成"利率约束"的工具组件之一。
- 关键陈述："**先后下调常备借贷便利（SLF）利率、再贷款再贴现利率，推动整体市场利率和贷款利率下行**。"

## 操作机制

### 期限

- 隔夜、7 天、1 个月（最常见）。

### 申请方式

- **银行主动申请**：银行根据自身流动性需要主动申请，区别于 OMO（央行被动招标）。
- **抵押物**：高等级债券（国债 / 政金债 / AAA 信用债）+ 优质信贷资产。

### 利率定价

- SLF 利率高于市场利率（含"惩罚利率"性质），构成利率走廊上限。
- 调整频率：低（数年一次大幅调整 + 微调）。

## 在利率走廊中的位置

```
利率走廊：
  上限 ----- SLF 利率 ← 银行不会以高于 SLF 的成本融资
   |
  中枢 ----- 7 天逆回购利率（OMO 短端政策利率）
   |
  下限 ----- 超额准备金利率
```

## 与美联储贴现窗口的对照

| 维度 | 美联储贴现窗口 | 中国 SLF |
|---|---|---|
| 创设时间 | 1913 联储成立时 | 2013 年 |
| 申请方式 | 银行主动申请 | 银行主动申请 |
| 利率定位 | 走廊上限（"惩罚利率"） | 走廊上限 |
| 期限 | 隔夜 + 短期 | 隔夜 + 7 天 + 1 个月 |
| 抵押物 | 银行优质资产 | 高等级债券 + 优质信贷资产 |
| 历史使用频率 | 低（"stigma"声誉风险） | 中（特定时点活跃） |
| 透明度 | 较高（每周公布合计数据） | 较低（月度合计） |

## 历史使用情况（推断）

- 季末 / 年末流动性紧张时使用频率上升。
- 2013 6 月"钱荒"期间设立后立即派上用场。
- 2020 抗疫期间作为补充工具。
- 长期来看使用规模显著低于 MLF / OMO，体现走廊上限的"备用"性质。

## 反面论点与数据空白

- **"stigma"风险**：与美联储贴现窗口类似，银行可能因申请 SLF 暗示自身流动性紧张而避免使用。中国"stigma"程度需实证。[数据空白]
- **抵押物范围争议**：SLF 接受的抵押物种类影响银行资产配置激励。本文未讨论。[BIAS]
- **走廊上限实际有效性**：当 SLF 利率与市场利率（如 R007）差距过大时，市场利率可能"突破"上限。中国 2013、2017、2020 等年份均出现过 R007 短时高于 SLF 利率的情形。[CONTRADICTION] [数据空白]
- **数据透明度**：SLF 月度操作数据公布粒度有限，无法详细分析使用结构。[数据空白]
- **MMT 视角**：SLF 体现央行作为"最后贷款人"的本质；本质上是央行对银行体系的无限承诺，与基础货币创造无差异。[CONTRADICTION]
- **走廊机制完整性**：理论上利率走廊需要明确的下限工具（如 IORB 中国版本），中国对走廊下限的明示性低于 ECB / Fed。[数据空白]
