# OMO公开市场操作-中国

> **一句话定义**：**Open Market Operations (China)**，[[中国人民银行]] 通过在公开市场进行**回购 / 逆回购 / 央行票据发行**等交易调节短期流动性的工具。在 [[孙国峰]] 文确立的体系中，**OMO 利率（主要是 7 天逆回购利率）作为短期政策利率**，构成 [[央行政策利率体系-中国]] 的短端锚。

## 概念出处与体系定位

- 工具沿革：1998 年起常态化。
- 体系定位：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）—"以公开市场操作利率为短期政策利率"。
- 与中期政策利率（[[MLF中期借贷便利]]）共同构成 [[央行政策利率体系-中国]] 的双轨结构。

## 操作机制

### 主要工具

1. **逆回购**（最常用）：央行向一级交易商按约定利率买入证券，到期再卖回，本质是央行对市场的短期资金投放。
   - **7 天逆回购利率**：日常操作主要利率，作为短端政策利率锚。
   - 14 天 / 28 天逆回购：临时性操作。
2. **正回购**：央行向一级交易商卖出证券约定回购，本质是回收流动性。
3. **央行票据发行**：央行向银行体系发行短期债券，回收流动性（2010s 后使用减少）。
4. **国库现金管理**（与财政部协同）：将国库现金存入商业银行，调节流动性。

### 频率

- 日度操作：每个工作日发布操作公告。
- 滚动续作：到期续作或差额操作，平滑流动性。

### 一级交易商

- 约 50 家金融机构（国有大行 + 股份制 + 部分外资行 + 政策性银行）。

## 与美国 OMO 的关键差异

| 维度 | 美联储 OMO | 中国 OMO |
|---|---|---|
| 主要工具 | 国债现券买卖（永久性 OMO）+ 回购 / 逆回购 | 主要是回购 / 逆回购，国债现券买卖较少 |
| 政策利率锚 | 联邦基金利率（市场利率） | 7 天逆回购利率（工具利率） |
| 操作频率 | 日度 + 大额一次性（QE 时） | 日度 + 滚动续作 |
| 对手方 | 一级交易商（投行 + 商业银行） | 一级交易商（主要商业银行） |
| 抵押物 | 国债 + MBS（QE 时） | 国债 + 政金债 + 高等级信用债 |
| 操作目标 | 联邦基金利率走廊中枢 | 7 天逆回购利率本身 |

孙国峰文区分两类做法：美联储是"将市场利率作为操作目标"（第一类），中国是"将货币政策工具利率作为央行政策利率，将操作目标、政策利率、工具利率合而为一"（第二类）。中国的 OMO 7 天利率即工具利率，直接作为操作目标。

## 在利率走廊中的位置

```
利率走廊（中国版）：
  上限 ----- SLF 利率（[[SLF常备借贷便利]]）
   |
   |
  中枢 ----- 7 天逆回购利率（OMO 短端政策利率） ← 央行通过 OMO 操作维持市场利率（DR007 等）围绕此中枢运行
   |
   |
  下限 ----- 超额准备金利率（接近 0，常被 DR007 击穿）
```

## DR007 作为市场基准

- DR007（存款类机构 7 天质押式回购加权利率）：中国货币市场 7 天回购利率的市场基准。
- 央行通过 OMO 7 天逆回购操作引导 DR007 围绕政策利率中枢波动。
- 是中国货币市场利率的主要观察指标。

## 反面论点与数据空白

- **"工具利率即政策利率"的理论局限**：将工具利率（OMO 7 天逆回购）直接作为政策目标，简化了利率传导链条，但也使央行操作受限于工具的物理特征。Woodford (2003) "interest rate as monetary policy" 学术框架下，市场利率目标更具弹性。[CONTRADICTION]
- **2024 单轨化**：潘功胜行长 2024 陆家嘴论坛已强化 7 天逆回购利率作为单一短期政策利率的地位，淡化 MLF 政策属性。本文双轨结构正在转向单轨结构。[数据空白]
- **"操作目标 = 政策利率"的实证证据**：DR007 是否真正紧贴 OMO 7 天逆回购利率？2019-2024 实证显示偏离度可达 30-100bp（特别是季末 / 年末 / 春节前后）。本文未充分讨论偏离原因。[BIAS] [数据空白]
- **抵押品偏好的市场后果**：OMO 接受抵押品的种类影响市场对应资产的吸引力。本文未讨论抵押品政策的市场扭曲后果。[BIAS]
- **MMT 视角**：央行通过 OMO 调节流动性是技术细节；主权货币国家央行对短端利率拥有完全控制权，OMO"操作"是仪式化形式。[CONTRADICTION]
- **影子银行对 OMO 影响的弱化**：影子银行（信托 / 货币基金 / 理财）规模庞大时，OMO 通过银行体系的传导效率下降。资管新规后是否改善需实证。[数据空白]
