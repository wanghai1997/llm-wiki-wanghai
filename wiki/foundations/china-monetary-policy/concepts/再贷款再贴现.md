# 再贷款再贴现

> **一句话定义**：[[中国人民银行]] 直接对商业银行 / 政策性银行 / 农村金融机构发放定向资金支持的工具，配合定向**再贴现**（央行对银行已贴现票据再次贴现），构成中国 [[结构性货币政策工具]] 体系的核心组件。在 [[孙国峰]] 文中是"**精准滴灌**"实体经济的关键政策抓手。

## 概念出处

- 工具沿革：再贷款是 PBoC 早期主要工具（1980-90s 政策性贷款）；再贴现 1986 年起常态化。
- 体系定位：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）作为结构性货币政策工具的代表。
- 关键陈述："**创新和运用定向降准、定向中期借贷便利（TMLF）、再贷款、再贴现等结构性货币政策工具，精准加大对民营、小微企业等重点领域和薄弱环节的支持力度**。"

## 工具谱系

### 再贷款类型（按用途）

| 类型 | 对象 | 用途 |
|---|---|---|
| 流动性再贷款 | 商业银行 | 流动性紧张时的应急支持 |
| 信贷政策支持再贷款 | 政策性银行 / 商业银行 | 三农 / 小微 / 扶贫 / 棚改 / 抗疫等 |
| 金融稳定再贷款 | 商业银行 | 处置金融机构风险 |
| 专项再贷款 | 商业银行 | 特定政策目标（如 2020 抗疫保供） |

### 再贴现

- 央行对商业银行已贴现的商业承兑汇票 / 银行承兑汇票进行**再次贴现**。
- 央行根据贴现的票据对应行业 / 企业 / 用途进行政策性引导。

### 关键衍生工具

- **PSL（抵押补充贷款）**：2014 创设，主要支持政策性银行（国开行 / 农发行 / 进出口行）的棚改 / 重大基建。本文未直接提及但属再贷款体系。
- **TMLF（定向中期借贷便利）**：2018 创设，期限较长 + 利率较 MLF 低。

## 2020 抗疫专项再贷款体系（按文中明示）

| 工具 | 规模 | 用途 |
|---|---|---|
| 抗疫保供再贷款 | 3000 亿 | 应对疫情医疗物资 / 民生保供 |
| 复工复产再贷款 | 5000 亿 | 复工复产企业流动性支持 |
| 普惠性再贷款再贴现 | 1 万亿 | 普惠小微企业 / 三农 |

加上"两项直达工具"——**普惠小微企业贷款延期支持工具** + **普惠小微企业信用贷款支持计划**——构成 2020 应对疫情的结构性政策组合。

## 操作机制

### 利率定价

- 再贷款利率较 MLF 利率低 50-200bp（视类型）。
- 再贴现利率类似定位。
- 利率优惠是对银行投放对应贷款的激励兼容设计。

### 期限

- 再贷款：3 个月、6 个月、1 年（按用途）。
- 滚动续作可能（部分长期定向工具）。

### 央行的"激励兼容"机制

按孙国峰文："**设计激励相容机制引导银行货币创造行为**"——通过提供低成本资金，引导银行向特定领域投放贷款。

## 反面论点与数据空白

- **"精准滴灌"的实证争议**：黄益平等指出再贷款 / 再贴现的"精准滴灌"易被银行"包装"使用——通过财务安排将资金转化为一般用途。普惠小微贷款增速完成度可能依赖统计调整 + 政策性贷款挤出市场化贷款。"精准"程度待实证检验。[CONTRADICTION] [数据空白]
- **直达工具效果评估**：2020 两项直达工具的违约率、信用贷款支持计划的精准度、延期工具的偿还表现，本文未披露。[数据空白]
- **结构性 vs 总量的边界模糊**：当 [[结构性货币政策工具]] 规模庞大（万亿级），其总量效应已不可忽视；与 MLF / OMO 总量工具的边界模糊。本文未充分讨论。[CONTRADICTION]
- **道德风险**：再贷款 / 再贴现降低银行融资成本，可能弱化银行风险评估激励。Stiglitz-Weiss 1981 信息不对称下信贷配给框架预测此类政策的效率损失。[BIAS]
- **行业分布偏倚**：再贷款重点支持小微 / 民营 / 三农 / 扶贫 / 抗疫 / 绿色——这些行业的政治属性强；客观上排除了一些可能高效的非重点行业。[BIAS]
- **MMT 视角支持**：MMT 主张央行直接对实体经济注资是合理的；中国结构性工具"直达实体"的设计在某种程度上接近 MMT 推荐的"直接货币融资"，但在概念上仍区分于"财政赤字货币化"。[CONTRADICTION]
- **国际对比**：ECB TLTRO / BoE FLS 是发达经济体类似工具，但规模占比 / 行业分布与中国差异巨大。完整对比需要 IMF / BIS 跨国数据库。[数据空白]
- **2024 政策延续性**：2024 后再贷款 / 再贴现工具继续创新（科技再贷款 / 设备更新再贷款 / 房贷支持工具等），需要后续摄入。[数据空白]
