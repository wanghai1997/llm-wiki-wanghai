# M2与社会融资规模

> **一句话定义**：[[中国人民银行]] 货币政策中介目标的双指标组合。**M2**（广义货币供应量）+ **社会融资规模**（[[社会融资规模]] 缩写 TSF / Total Social Financing）。在 [[孙国峰]] 2021 年文中确立的"基本匹配"原则下，两者增速应与**名义经济增速**基本匹配。

## 概念出处与制度演变

- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 制度演变史：
  - 高速增长阶段（~2018 前）：以 M2 + 社融**数字目标**（参考上年实际值测算）。
  - 转向高质量发展阶段：潜在增速下降 → 数字目标可能导致信贷与经济偏离 → 调整为"基本匹配"。
  - 2019 中央经济工作会议：货币信贷、社会融资规模增长同经济发展相适应。
  - 2020 应对疫情：M2 + 社融增速目标"明显高于上年"。
  - 2020 中央经济工作会议：保持 M2 + 社融增速 ≈ 名义经济增速基本匹配（**正式制度定型**）。
- 2018-2019 实测：M2 + 社融平均增速与名义经济增速大致相当。

## "基本匹配"操作三要点（按孙国峰文）

1. **基本匹配 ≠ 完全相等**：M2 / 社融增速可略高或略低于名义经济增速，体现逆周期调节。
2. **综合考虑三类参考值**：名义经济增速 + 潜在产出 + 经济增速目标。
   - 高质量发展阶段：实际名义增速 ≈ 反映潜在产出的名义增速。
   - 受到严重冲击时：偏离潜在增速 → 政策参照后者，支持回归潜在。
3. **中长期概念，按年度匹配**：不是每季度 / 每月都要匹配，以保证政策连续性、稳定性、可持续性（[[跨周期政策设计]] 的具象化）。

## "基本匹配"的三重价值（按孙国峰文）

1. **跨周期政策支撑**：稳住货币总量；M2 / 社融向反映潜在产出的名义增速靠拢。
2. **科学合理的"锚"**：提高逆周期调节能力。
3. **稳增长—防风险长期均衡**：M2 / 社融与债务增速基本一致 → 稳定 [[宏观杠杆率]] 内嵌于中介目标。

## 与教材标准中介目标的对照

| 维度 | Mankiw 9e（反映 1990+ 主流） | 孙国峰中国版 |
|---|---|---|
| 中介目标主流形态 | 通胀目标制（隐含）/ [[Taylor规则]] 利率反应函数 | M2 + 社融数量目标 + "基本匹配"弹性 |
| 历史演变 | 1979-82 Volcker M2 实验 → 1983 后转向利率 | 1980s+ 数字目标 → 2020s "基本匹配" |
| 数量目标地位 | 边缘化（$V$ 不稳定使简单 [[货币数量论]] 失效） | 中心地位（双指标组合 + 弹性） |
| 利率目标地位 | 中心（联邦基金利率）+ 通胀预期管理 | 配合性（[[LPR贷款市场报价利率]] 改革后地位上升） |

## 社会融资规模 vs M2

[[社会融资规模]] 是 [[中国人民银行]] 2011 年创设的中国独有指标：

- M2：负债侧 —— 流通货币 + 存款（金融机构对实体的负债）。
- 社融：资产侧 —— 银行表内贷款 + 表外融资（信托 / 委托 / 未贴现票据）+ 直接融资（债券 / 股票）+ 政府债券 + 其他。
- 双指标设计：单纯 M2 不能反映非银行融资渠道；社融弥补"影子银行 + 直接融资"维度，是中国金融体系特殊性的指标化回应。

## 反面论点与数据空白

- **2022-2024 实证违反**：2022-2024 年 M2 与社融增速持续高于名义 GDP 增速 3-5pp，但通胀低迷甚至通缩 —— 挑战"基本匹配"原则的实证基础。可能反映：(a) 货币需求结构性变化（理财化 / 老龄化储蓄）、(b) 房地产去杠杆使社融存量结构调整、(c) "基本匹配"事实上演变为"宽松托底"的政治正当化语言。[CONTRADICTION]
- **潜在产出 estimation 依赖**：本目标依赖可估计的"反映潜在产出的名义经济增速"。但 [[Cambridge Capital Controversy]] 已证伪加总生产函数；中国 2018+ 潜在增速估计分歧巨大（社科院、林毅夫、蔡昉、朱嘉明各自估计 5%-7% 不等）。锚点本身脆弱。[CONTRADICTION]
- **数量论的弱化变体**：以 M2 + 社融为中介目标实质上保留了 [[货币数量论]] 思想，但放松其严格性（容许逆周期偏离）。1980s 全球放弃 M 系列目标的核心原因是 $V$ 不稳定 —— 中国是否在重蹈覆辙，需观察 2024+ 实证。[数据空白]
- **2024 框架二次改革修正**：潘功胜行长 2024 陆家嘴论坛已提出"淡化 M2 数量目标、转向短端政策利率为核心"，"基本匹配"作为唯一中介目标的地位可能被修正。[数据空白]
- **MMT 反驳**：MMT 视角下 M2 / 社融是经济活动的内生结果，央行无法主动"匹配"——只能被动响应银行放贷需求。"匹配"语言是央行决策权的修辞。[CONTRADICTION]
- **统计口径调整**：M2 与社融的统计口径在历史上经过多次调整（如 2018 货币基金纳入 M2、社融纳入地方政府专项债等），跨期可比性需要慎重。[BIAS]
