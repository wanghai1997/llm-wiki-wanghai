# 现代中央银行制度

> **一句话定义**：党的十九届五中全会（2020-10）提出的中央银行制度建设目标。按 [[孙国峰]] 文界定，由四个组件构成：**[[现代货币政策框架]]、金融基础设施服务体系、系统性金融风险防控体系、国际金融协调合作治理机制**。是中国央行体制现代化的顶层设计。

## 概念出处

- 政治源头：党的十九届五中全会（2020-10）"建设现代中央银行制度"部署。
- 学术阐释：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 关键陈述："**现代中央银行制度是现代货币政策框架、金融基础设施服务体系、系统性金融风险防控体系和国际金融协调合作治理机制的总和**，现代货币政策框架是现代中央银行制度的重要组成部分。"

## 四组件结构

### 组件一：现代货币政策框架（核心）

详见 [[现代货币政策框架]]。

- 优化的货币政策目标（最终 / 中介 / 操作三层级）。
- 创新的货币政策工具（围绕 [[央行三大约束-流动性资本利率]]）。
- 畅通的货币政策传导机制（[[利率市场化改革-中国]] + [[人民币汇率市场化]]）。

### 组件二：金融基础设施服务体系

孙国峰文中未详细展开。隐含范围：
- 支付清算系统（CNAPS / 网联 / 银联 / SWIFT 中国分支）。
- 数字人民币基础设施（DC/EP，2020+ 试点）。
- 征信系统（人民银行征信中心 + 百行征信）。
- 金融统计与数据报送基础设施。
- 反洗钱（AML）/ 反恐怖融资（CFT）基础设施。

### 组件三：系统性金融风险防控体系

孙国峰文中未详细展开。隐含范围：
- [[宏观审慎评估MPA]]。
- 系统重要性金融机构（D-SIB）监管。
- 金融稳定保障基金（2022 创设，本文未涵盖）。
- 跨境资本流动宏观审慎管理。
- 金融控股公司监管。
- 与银保监 / 证监会的"一委一行两会"协同（2018+ 框架）。

### 组件四：国际金融协调合作治理机制

文中部分展开：
- "加强国际宏观经济政策协调"——党的十九届五中全会提出。
- 利用外部正面溢出 + 防范外部负面溢出 + 用好自身溢出效应。
- 提高参与国际金融治理能力（IMF / G20 / BIS / FSB / SCO 等多边机制）。
- "央行 + 财政"双驱协调。

## 与"现代货币政策框架"的层级关系

```
现代中央银行制度
├── 现代货币政策框架 ★（孙国峰文核心）
├── 金融基础设施服务体系
├── 系统性金融风险防控体系
└── 国际金融协调合作治理机制
```

孙国峰文集中阐释组件一（货币政策框架），其他三组件作为系统性背景被简略提及。

## 与教材"中央银行"概念的对照

按 [[Macroeconomics-Mankiw-9e]] Ch 4 默认的"中央银行"功能：

| Mankiw 教材功能 | 中国"现代央行制度"对应组件 |
|---|---|
| 货币供给控制 | 组件一：现代货币政策框架 |
| 银行的银行 / 最后贷款人 | 组件二：金融基础设施 + 组件三：系统性风险防控 |
| 政府的银行 / 国库代理 | 组件二：金融基础设施 |
| 金融监管（部分） | 组件三：系统性金融风险防控（中国 PBoC 仅承担系统性风险防控；银 / 保 / 证机构监管在三会）|
| 国际储备管理 | 组件四：国际金融协调（外管局，PBoC 下属）|

差异：
- 中国 PBoC 不直接承担机构监管（在银保监 / 证监会），与美联储 + OCC + FDIC 多机构监管类似但分工不同。
- 中国 PBoC 直接管理外汇储备（外管局），美联储不持有外汇储备。

## 反面论点与数据空白

- **"现代"语义争议**：本文使用"现代"一词，但其制度内涵在多大程度上比 1990s 通胀目标制 + 1990s 央行独立性范式更"现代"，理论上未充分论证。可能更接近 BIS 2010s "central bank operating models" + 危机后宏观审慎整合的中国化阐释。[数据空白]
- **央行独立性维度**：本制度框架未明确把"央行独立性"列为组件——这与 Rogoff 1985 / Alesina-Summers 1993 / Cukierman 1992 央行独立性范式形成显著差异。中国央行作为国务院组成部门的体制定位，决定了"现代"的内涵不同于西方主流。[CONTRADICTION] [regional-bias]
- **组件二、三、四的论述薄弱**：本文集中于组件一，对其他三组件论述简略。需要后续摄入易纲、潘功胜公开演讲或人民银行白皮书补足。[数据空白]
- **2024 二次改革**：潘功胜行长 2024 陆家嘴论坛《建设现代中央银行制度》对四组件结构有更详尽阐释，本文若干立场已被修订。需后续摄入。[数据空白]
- **金融控股公司监管**：本制度对金控公司、互联网平台金融业务（蚂蚁集团 2020-11 暂停 IPO 等）的监管涵盖，需要 2021+ 后续政策文本完善。[数据空白]
- **与"金融供给侧改革"的关系**：现代央行制度作为顶层设计，与"金融供给侧结构性改革"（2018+）的关系未明确。两者在 2020+ 应有融合，需后续追踪。[数据空白]
