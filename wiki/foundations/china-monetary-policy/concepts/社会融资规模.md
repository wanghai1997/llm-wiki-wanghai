# 社会融资规模

> **一句话定义**：**Total Social Financing, TSF**，[[中国人民银行]] 2011 年创设的中国独有指标，衡量实体经济从金融体系（含银行表内表外 + 直接融资 + 政府债券）获得的资金总额。与 M2 共同构成 [[中国货币政策框架]] 的双中介目标。详见 [[M2与社会融资规模]]。

## 概念出处

- 创设机构：[[中国人民银行]]，2011 年（统计口径）。
- 引用来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）多处提及，作为 M2 的伴生指标。

## 统计口径（截至 2020 文献时）

社融统计涵盖以下融资渠道：

1. **银行表内**：人民币贷款 + 外币贷款。
2. **银行表外**：委托贷款 + 信托贷款 + 未贴现银行承兑汇票。
3. **直接融资**：企业债券 + 股票（境内非金融企业 IPO + 增发）。
4. **政府债券**：地方政府专项债（2018+ 纳入）+ 国债（部分年份）。
5. **其他**：保险公司赔偿 + 投资性房地产 + 小额贷款 + 贷款核销 + ABS（资产证券化，部分纳入）等。

## 与 M2 的关系

- M2 是**负债侧**指标（金融机构对实体的负债）。
- 社融是**资产侧**指标（金融机构对实体的债权 + 实体直接融资）。
- 在严格"贷款创造存款"假设下，理论上银行表内贷款部分应等于 M2 增量；但实践中两者口径差异（外币、表外、直接融资、政府债券）使两者**形成互补而非替代**。
- 双指标必要性：单纯 M2 漏掉非银行融资（影子银行、债券市场、股票市场），单纯社融漏掉境外资金 + 现金。

## 中国独有性

- 多数发达经济体不公布"社融"对应指标，因为：
  - 美 / 欧 / 日影子银行规模相对小（GDP 占比）；银行表外业务在 2008 后受 Basel III 严控。
  - 直接融资比例高（美国债券市场 + 股票市场远超银行信贷），不需要单独编制综合指标。
- 中国背景：金融体系以银行为主 + 影子银行（信托 / 理财）规模庞大 + 直接融资比例上升 → 需要综合指标弥补 M2 单一性。

## 历史发展节点

| 年份 | 事件 |
|---|---|
| 2011 | PBoC 首次发布社融数据（覆盖 2002+ 历史） |
| 2014 | 影子银行去杠杆，信托贷款 + 委托贷款增速回落 |
| 2017 | 资管新规（征求意见稿） + "降通道" |
| 2018 | 地方政府专项债纳入社融统计；同业理财去化 |
| 2020 | 国债部分纳入考量；社融增速反弹应对疫情 |

## 反面论点与数据空白

- **统计口径变动影响跨期可比性**：地方政府专项债 2018 纳入、ABS 部分纳入等使社融存量数据有"统计调整"成分。跨期分析需慎重。[BIAS]
- **影子银行的"重新表内化"**：2017+ 资管新规后大量影子银行业务（信托贷款 / 委托贷款）规模收缩 + 部分回表，社融总量"看起来"增速正常但结构剧变。
- **房地产融资的不透明**：2021-2022 房企出险后，社融数据未能及时反映房地产部门信用风险积累。社融作为"前瞻性指标"的能力受质疑。[数据空白]
- **直接融资比例**：中国直接融资比例（股票 + 债券）2020 约 30-35%，远低于美国（70%+）。社融指标的"中国特色"反映了金融结构的差异——若直接融资比例提升，社融与 M2 的差异可能进一步扩大。
- **MMT 视角**：社融指标隐含"金融体系融资 = 经济活动驱动"假设；MMT 主张主权货币国家的经济活动由财政支出驱动 → 社融是经济活动的结果而非原因。[CONTRADICTION]
- **数据透明度**：社融分类项目的同比与环比在 PBoC 月度发布中较详尽，但分行业（房地产 / 制造业 / 基建）社融分解未公开。结构分析依赖间接推算。[数据空白]
