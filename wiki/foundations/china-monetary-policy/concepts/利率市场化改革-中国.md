# 利率市场化改革-中国

> **一句话定义**：[[中国人民银行]] 自 1990s 以来推进的利率管制松绑改革，2019-08 [[LPR贷款市场报价利率]] 改革是 [[孙国峰]] 文中标志性节点 ——"以深化利率市场化改革为抓手疏通货币政策传导机制，**打破利率的'地板'**"。改革后形成"MLF→LPR→贷款利率"市场化传导路径。

## 概念出处与改革主线

- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 主线：找准市场化利率传导的关键"堵点"，"打破利率的地板"（贷款利率隐性下限）。

## 核心改革节点（按文中提及）

| 时间 | 事件 |
|---|---|
| 2019-08 | LPR 形成机制改革（核心节点） |
| 2020-起 | 金融机构新发放贷款主要参考 LPR 定价 |
| 2020-03 ~ 08 | 存量浮动利率贷款定价基准转换（按市场化、法治化原则顺利完成） |
| 2020 | 银行将 LPR 嵌入内部资金转移定价（FTP）体系 |
| 2020 | 加强存款利率自律，压降不规范存款创新产品 |

## 改革架构

### 一、贷款侧市场化（已基本完成）

**"MLF→LPR→贷款利率"传导路径**：
1. MLF 利率作为中期政策利率（[[MLF中期借贷便利]]）。
2. 18 家报价行在 MLF 基础上"按市场化方式加点"形成 [[LPR贷款市场报价利率]]。
3. 银行运用 LPR 定价影响实际执行的贷款利率。
4. LPR 嵌入银行 FTP 体系——切实打破贷款利率隐性下限。
5. 引导金融资源更多配置至小微、民营企业。

### 二、存款侧（渐进、保留管制痕迹）

- **存款基准利率作为"压舱石"**：央行明确保留这一管制工具，作为整个利率体系的稳定器。
- **存款利率自律机制**：通过市场利率定价自律机制约束存款利率上限。
- **压降不规范存款创新产品**：靠档计息 / 智能存款 / 结构性存款等被规范。
- **方向**：本文成文时（2021-01）存款基准未直接调整；后续 2022-2024 存款利率市场化加速（详见后续摄入）。

### 三、配套机制

- **完善以 OMO 为短期、MLF 为中期的 [[央行政策利率体系-中国]]**。
- **健全利率走廊机制**：SLF 走廊上限 + 超额准备金利率走廊下限。
- **推动货币市场基准利率改革**：DR007 / Shibor 等市场基准建设。
- **引导市场利率围绕央行政策利率中枢运行**。

## "打破利率地板"的实质

- **隐性下限**：改革前贷款基准利率 + 行业自律协会的隐性下限（如基准利率 0.9 倍）。
- **隐性下限的存在原因**：(a) 银行间默契、(b) 监管对低利率竞争的担忧、(c) 内部 FTP 与外部定价不一致。
- **改革核心**：通过 LPR 替代贷款基准利率 + 嵌入 FTP，使银行内部成本核算与外部定价对齐——从而**真正**让市场化利率向下渗透。

## 与教材标准利率市场化叙事的对照

按 [[Macroeconomics-Mankiw-9e]] 隐含的"市场化利率制度"标准：

| 维度 | Mankiw 默认（美国 1980+） | 中国渐进改革 |
|---|---|---|
| 利率管制起点 | 1933 Glass-Steagall Q 条款 → 1980 取消 | 1990s 起，渐进至 2015 存款利率上限取消 |
| 贷款利率市场化 | 1980+ 一步到位 | 2013 取消贷款利率下限 → 2019 LPR 改革 |
| 存款利率市场化 | 1980+ 一步到位 | 2015 名义取消上限 → 至今"自律 + 压舱石"模式 |
| 央行操作目标 | 联邦基金利率（市场利率） | OMO + MLF（工具利率，孙国峰文第二类做法） |
| 存款保险 | 1933 FDIC 配套保护 | 2015 起保护配套（同步进行） |

## 反面论点与数据空白

- **"打破隐性下限"实证强度待验**：殷剑峰 (2020) / 张明 (2021) 等指出 LPR 改革后银行间贷款利率分化加大；FTP 改革滞后于 LPR；存款基准"压舱石"挤压净息差。改革成效需以银行业实际定价微观数据验证。[数据空白]
- **存款基准"压舱石"与 LPR 市场化的内在张力**：理论上不可能同时存在完全市场化贷款利率与管制存款利率，长期会挤压银行净息差或推动银行规避。2022-2024 净息差持续下行已说明矛盾。[CONTRADICTION]
- **存款利率市场化的滞后**：2021 文本时存款利率市场化明显滞后于贷款侧；2022 后加速但本文未涵盖。需要后续摄入。[数据空白]
- **利率走廊上下限不透明**：SLF 利率虽公开但调整频率低；下限的确定规则不透明。与 ECB / Fed 利率走廊的明示性差距大。[数据空白]
- **金融抑制 vs 金融自由化辩论**：McKinnon-Shaw 1973 金融抑制理论支持完全市场化；但 Stiglitz 1989 + Stiglitz-Weiss 1981 指出信息不对称下完全市场化可能导致信贷配给恶化。中国渐进改革更接近 Stiglitz 立场。[BIAS]
- **跨境传导的限制**：人民币利率市场化在国内推进，但跨境利率传导仍受资本管制约束（[[不可能三角]] 中的张力）。
- **MMT 视角**：MMT 主张利率主要由央行决定（即使市场化下，央行仍可通过资产负债表政策完全控制曲线）；"利率市场化"本质是央行把控制权从行政指令转向市场操作的修辞。[CONTRADICTION]
