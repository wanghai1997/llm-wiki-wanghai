# 央行政策利率体系-中国

> **一句话定义**：[[中国人民银行]] 的**双轨政策利率体系**：以 [[OMO公开市场操作-中国]] 利率（7 天逆回购为主）作为**短期政策利率**，以 [[MLF中期借贷便利]] 利率作为**中期政策利率**。区别于美联储联邦基金利率单一目标。

## 概念出处

- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 关键陈述：**"完善以公开市场操作利率为短期政策利率和以中期借贷便利（MLF）利率为中期政策利率的央行政策利率体系，有效实现操作目标。"**

## 国际两类做法对照

按孙国峰文，央行实现货币政策操作目标有两类做法：

| 做法 | 描述 | 代表 |
|---|---|---|
| 第一类 | 将**市场利率**作为操作目标，通过流动性调节引导市场利率在操作目标附近运行 | 1990s 联邦基金利率目标制 |
| 第二类 | 将**货币政策工具利率**作为央行政策利率，并以此为操作目标，将操作目标、政策利率、工具利率合而为一 | 2008 后 IORB / ECB MRO / 中国 OMO+MLF 双轨 |

孙国峰文判断：**2008 国际金融危机后，第二类做法因提高货币政策有效性和传导效率优势显现，逐渐成为主流。**

## 中国双轨结构

### 短期政策利率：OMO（公开市场操作利率）

- 主要工具：7 天逆回购利率（DR007 调控的主要锚）。
- 用途：日常流动性管理 + 短端利率走廊中枢。
- 期限定位：1 周内。

### 中期政策利率：MLF（中期借贷便利利率）

- 期限：1 年（典型）。
- 用途：通过 [[LPR贷款市场报价利率]] 加点机制传导至贷款利率。
- 在贷款定价中地位最重要：**"MLF→LPR→贷款利率"的市场化利率调控传导路径**。

### 两轨之间的关系

- OMO 7 天 + MLF 1 年 + 国债收益率曲线 → 整体期限结构。
- 两者通常同向调整，但幅度可不同（如 2018Q4+ 累计下行 35bp）。
- 利率走廊机制：SLF（[[SLF常备借贷便利]]）作为走廊上限，超额准备金利率（IOER 中国版）作为下限。

## "MLF→LPR→贷款利率"传导路径详解

按孙国峰文：

1. **第一段：MLF → LPR**
   - 18 家报价行在 MLF 利率基础上"按市场化方式加点"形成 LPR。
   - 加点反映：(a) 银行资金成本（含存款）、(b) 风险溢价、(c) 期限溢价、(d) 市场供求。
2. **第二段：LPR → 贷款定价**
   - 银行运用 LPR 定价影响实际执行的贷款利率。
   - 2020 起，金融机构新发放贷款已主要参考 LPR 定价。
   - 2020-03~08 完成存量浮动利率贷款定价基准转换。
3. **第三段：FTP 嵌入**
   - 银行将 LPR 嵌入内部资金转移定价（FTP）体系。
   - "切实打破贷款利率隐性下限"——避免银行内部以高 FTP 抵消 LPR 下行。
4. **辅助锚定：存款基准利率**
   - 作为"我国整个利率体系的压舱石"。
   - 加强存款利率自律，压降不规范存款创新产品。

## 与 Mankiw 教材"传统三工具"的对照

按 [[美联储工具]] 教材叙事：

| Mankiw 工具 | 中国对应 |
|---|---|
| OMO | 中国 OMO（差异：中国 OMO 主要是回购 / 逆回购，不是直接买卖国债现券；针对短期政策利率 7 天而非联邦基金利率） |
| 贴现率 | 中国 SLF（[[SLF常备借贷便利]]）作为利率走廊上限 |
| 法定准备金率 | 仍是中国央行常用工具（2018-2020 共 10 次降准），未像美联储 2020-03 设为 0% |
| 现代工具：IORB | 中国超额准备金利率（角色类似但运作机制不同） |
| 现代工具：ON-RRP | 中国正回购（货币市场基金未单设利率走廊下限） |
| 现代工具：QE | 中国未实施大规模 QE；MLF / PSL（抵押补充贷款）部分扮演类似角色 |
| 现代工具：前瞻指引 | 中国央行对前瞻指引使用较少，主要通过央行行长讲话与货币政策执行报告 |

## 反面论点与数据空白

- **双轨利率的内在张力**：OMO 7 天 + MLF 1 年存在期限错配，且两者的政策含义可能不同（OMO 反映短期流动性管理，MLF 反映中期信用引导）。在 OMO / MLF 不同向时市场预期可能混乱。[CONTRADICTION]
- **2024 单轨化趋势**：潘功胜行长 2024 陆家嘴论坛提出"以 7 天逆回购利率为单一短期政策利率，淡化 MLF 利率"，本文双轨结构在 2024 后实质修订。[数据空白：后续摄入]
- **Taylor 规则估计**：Sun-Mehrotra (BIS 2017) / 丁志杰 (2019) 用 1995-2017 数据估计中国 PBoC 反应函数，发现对通胀反应系数 < 1，违反 Taylor 原则。可能存在金融稳定 / 汇率稳定动机覆盖。需 2018-2024 当代数据更新。[数据空白]
- **存款基准"压舱石"的张力**：本文一方面强调 LPR 市场化、"打破隐性下限"；另一方面强调存款基准利率作为"压舱石"。理论上不可能同时存在完全市场化贷款利率与管制存款利率（银行净息差受挤压）。殷剑峰 (2020) 等已批评。[CONTRADICTION]
- **利率走廊机制**：本文宣示但未明确公布走廊上下限。SLF 利率虽公开但调整频率低；下限的确定（超额准备金利率）规则不透明。[数据空白]
- **MMT 视角**：MMT 主张央行可以无限弹性设定利率，工具差异是技术细节而非实质约束。中国双轨 vs 美联储单轨的分歧只是技术选择，不改变货币政策本质。[CONTRADICTION]
