# 结构性货币政策工具

> **一句话定义**：[[中国人民银行]] 创设的具有**定向性、激励兼容、利率优惠**特征的货币政策工具集合，区别于 MLF / OMO 等总量工具。在 [[孙国峰]] 文中作为"**精准滴灌**"实体经济、支持高质量发展的关键政策抓手。

## 概念出处

- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 关键陈述："**注重引入激励相容机制，健全结构性货币政策工具体系，根据经济发展不同时期的需要动态调整支持重点，促进提升经济发展的可持续性和韧性**。"

## 工具谱系

按文中明示与隐含，结构性货币政策工具体系至少包括：

### 流动性 + 利率激励类

1. **定向降准**：对达到特定信贷投向标准的银行降低法定准备金率。
2. **定向中期借贷便利（TMLF）**：2018 创设，期限较长 + 利率较 MLF 低。
3. **再贷款**：详见 [[再贷款再贴现]]。
4. **再贴现**：详见 [[再贷款再贴现]]。
5. **抗疫保供再贷款**（3000 亿，2020 创设）。
6. **复工复产再贷款**（5000 亿，2020 创设）。
7. **普惠性再贷款再贴现**（1 万亿，2020）。

### 直达工具类（2020 创新）

8. **普惠小微企业贷款延期支持工具**：央行对地方法人银行办理普惠小微贷款延期还本付息的，按一定比例给予激励。
9. **普惠小微企业信用贷款支持计划**：央行对地方法人银行 2020 年新发放的普惠小微信用贷款，按 40% 提供资金支持。

### 资本工具类

10. **永续债 + CBS**：详见 [[永续债银行资本工具]] / [[CBS央行票据互换]]。

## 设计原则

### 激励兼容（Incentive Compatibility）

按孙国峰文："**设计激励相容机制引导银行货币创造行为**"——通过提供低成本资金 / 利率优惠，引导银行**主动**向政策目标领域投放贷款。

### 精准滴灌（Targeted Allocation）

针对：
- **重点领域**：小微企业 / 民营企业 / 三农 / 制造业 / 科技创新 / 绿色发展。
- **薄弱环节**：扶贫 / 抗疫 / 普惠金融。

### 阶段性 + 退出机制

按孙国峰文："**结构性工具的存续期要与其服务的阶段性目标相适应，稳妥调整和接续特殊时期出台的应急政策**"——结构性工具不是永久性，应配合政策目标演变退出。

### 与总量工具的协调

按孙国峰文："**把握好结构性工具与总量工具的协调配合**"——结构性 + 总量并行，避免冲突或重复。

## 与教材标准货币政策工具的对照

按 [[美联储工具]] 教材叙事：

| 维度 | Mankiw 标准（美联储 1990-2008）| 中国结构性工具体系 |
|---|---|---|
| 政策中性 | 工具中性，不分行业 | 明确定向、行业差异 |
| 与产业政策关系 | 严格分离 | 紧密协同 |
| 激励兼容 | 主要是利率传导（间接） | 直接利率优惠 + 配额 |
| 工具数量 | 主要三传统 + 几个现代工具（约 5-7 种） | 大量动态调整（10+ 工具） |
| 退出机制 | 较慢（依赖会议决策） | 文中强调"阶段性 + 退出" |

## 改革效果（按文中数据）

- 2018+ 10 次降准释放约 8 万亿长期流动性。
- 2018Q4+ MLF / OMO 利率累计下行 35bp。
- 2020 抗疫体系 3000+5000+10000 亿三档再贷款 + 两项直达工具。
- 2020 全年向实体经济让利 1.5 万亿元。
- 2020-11 企业贷款利率 4.62%（2015 来最低）。

## 反面论点与数据空白

- **"精准滴灌"实证争议**：黄益平等指出结构性工具的"精准滴灌"易被银行"包装"使用——通过财务安排将资金转化为一般用途。普惠小微贷款增速完成度可能依赖统计调整。[CONTRADICTION] [数据空白]
- **结构性与总量边界模糊**：万亿级结构性工具的总量效应已不可忽视；与 MLF / OMO 总量工具边界模糊。当结构性 / 总量都积极时，宏观影响可能放大；都收紧时则双重收缩。本文未充分讨论。[CONTRADICTION]
- **退出机制实证**：2020 抗疫工具中 2 项直达工具到 2021 末平稳退出，但部分工具被 2022+ 新工具接替（科技 / 绿色 / 制造业 / 设备更新等）→ 退出与接续的实际节奏值得追踪。[数据空白]
- **道德风险**：结构性工具降低银行融资成本，可能弱化银行风险评估激励；Stiglitz-Weiss 1981 信息不对称框架预测信贷配给恶化。[BIAS]
- **政治经济属性**：结构性工具的"重点领域"选择具有政治属性（小微 / 民营 / 三农 / 抗疫 / 绿色）；这些行业未必是高效率行业，可能排除真正具有比较优势的领域。[BIAS]
- **MMT 视角**：MMT 支持央行直接对实体经济注资；中国结构性工具"直达实体"的设计在某种程度上接近 MMT 推荐，但本文坚持区分于"财政赤字货币化"。理论自洽性需要更严格论证。[CONTRADICTION]
- **国际比较**：ECB TLTRO / BoE FLS / Fed PPPLF 等是发达经济体类似工具，但规模占比 / 行业覆盖与中国差异显著。Stein-Stein 2019 / IMF 2021 等已开始系统对比，结论尚未定论。[数据空白]
- **结构性工具的有效性边界**：结构性工具改变银行**激励**，但银行**能力**（资本 + 风险偏好 + 信息）仍是约束；2022-2024 经济疲弱期结构性工具效用边际下降的现象需追踪。[数据空白]
