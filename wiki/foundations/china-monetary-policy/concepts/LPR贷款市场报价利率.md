# LPR贷款市场报价利率

> **一句话定义**：**Loan Prime Rate, LPR**，由 18 家报价行在 [[MLF中期借贷便利]] 利率基础上"按市场化方式加点"形成的贷款市场报价利率。2019-08 改革后成为中国贷款定价的市场化基准，构成"**MLF→LPR→贷款利率**"传导路径的中间环节。

## 概念出处

- 来源：[[孙国峰]] 《健全现代货币政策框架》（2021-01-13）。
- 制度节点：2019-08 LPR 形成机制改革。
- 关键陈述：**"贷款市场报价利率（LPR）在 MLF 利率基础上按照市场化方式加点形成，再通过银行运用 LPR 定价影响实际执行的贷款利率，共同形成市场化的利率形成和传导机制。"**

## 形成机制

### 报价行结构

- 18 家报价行：包括 6 大国有商业银行 + 12 家股份制商业银行 / 城商行 / 农商行 / 外资行（动态调整）。
- 每月 20 日（节假日顺延）报价。

### 加点逻辑

加点反映：
- 银行资金成本（含存款成本 / 同业成本）。
- 风险溢价（系统性 / 客户类型 / 行业）。
- 期限溢价（1Y / 5Y）。
- 市场供求。

### 期限分类

- 1 年 LPR：短期与中期贷款定价基准。
- 5 年 LPR：长期贷款（特别是个人住房贷款）定价基准。

## 核心传导链条："MLF→LPR→贷款利率"

按孙国峰文：

1. **MLF→LPR**：[[MLF中期借贷便利]] 利率作为政策利率锚；报价行在此基础上按市场化方式加点。
2. **LPR→贷款定价**：银行运用 LPR 定价影响实际执行的贷款利率。
3. **2020 主要参考 LPR 定价**：金融机构新发放贷款主要参考 LPR 定价。
4. **2020-03~08 存量转换**：按市场化、法治化原则顺利完成存量浮动利率贷款定价基准转换（从贷款基准利率转为 LPR）。

## 嵌入 FTP 体系

按孙国峰文："**促进银行将 LPR 嵌入内部转移定价（FTP）体系**，切实打破贷款利率隐性下限，引导金融资源更多配置至小微、民营企业。"

- FTP（Funds Transfer Pricing）：银行内部资金成本转移定价机制。
- 嵌入意义：使银行内部资金成本核算与外部市场定价对齐 → 切实打破贷款利率隐性下限。
- 配套：以市场化改革办法促进降低贷款实际利率。

## 改革效果（按文中数据）

- 2018 Q4 以来，MLF / OMO 利率累计下行 0.35 个百分点 → 推动整体市场利率与贷款利率下行。
- 2020-11 企业贷款利率 4.62%，较 2019-12 下降 0.50 个百分点 —— **2015 年有统计以来的最低水平**。
- 2020 全年金融机构向实体经济让利 1.5 万亿元。

## 与教材标准利率叙事的对照

| 维度 | Mankiw / 美国主流 | 中国 LPR 体系 |
|---|---|---|
| 贷款定价基准 | 各银行自主定价（在联邦基金利率 + 期限溢价基础上）| LPR 集中报价 + 银行加点 |
| 短期政策利率与贷款的传导 | 联邦基金利率 → 短期国债 → 长期国债 → 银行成本 → 贷款 | MLF → LPR → 贷款（更直接） |
| 市场基准建设 | LIBOR（已退出）/ SOFR / Treasury Curve | LPR / DR007 / Shibor |
| 贷款利率刚性突破 | 1980 金融自由化（Q 条款取消） | 2019 LPR 改革 + FTP 嵌入 |

## 反面论点与数据空白

- **传导效率争议**：殷剑峰 (2020) / 张明 (2021) 等指出 LPR 改革后银行间贷款利率分化加大；FTP 改革滞后于 LPR；存款基准"压舱石"挤压净息差。"打破隐性下限"实证强度待验。[数据空白]
- **加点机制透明度不足**：18 家报价行的加点方法论未完全公开；监管对"过低加点"的合规性约束如何落实未明。[数据空白]
- **贷款实际利率 vs LPR 偏离度**：本文数据"企业贷款利率 4.62%"vs 当时 1Y LPR 3.85%，偏离 77bp；偏离结构（行业 / 期限 / 客户分级）需要银行业微观数据。[数据空白]
- **5Y LPR 与房贷市场**：5Y LPR 主要影响房贷；2021-2024 房贷利率市场化 + LPR 加点下浮触底事件（部分城市），与本文成文时假设的"市场化稳定下行"路径不同。[CONTRADICTION] [数据空白]
- **报价行激励**：报价行加点行为受银行自身资金成本与监管引导双重影响；可能存在"统一报价"行政默契。需 2019+ 历次报价数据微观分析。[数据空白]
- **2024 改革修正**：潘功胜行长 2024 陆家嘴论坛提出"以 7 天逆回购利率为单一短期政策利率"，MLF 与 LPR 关系可能转变。[数据空白]
