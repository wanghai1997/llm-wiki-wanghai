# 中国货币政策框架

> **本主题导览页**总览 [[孙国峰]] 在 [[中国人民银行]] 货币政策司司长任上发表的《健全现代货币政策框架》（2021-01-13）所呈现的中国货币政策制度体系。本页与 [[宏观经济学foundations总览]] / [[宏观经济学共识与分歧]] 并列，构成本 Wiki 宏观 foundations 的"美—中"双柱结构中的**中国柱**。

## 框架三组件（按孙国峰文）

### （一）目标体系

- 最终目标：币值稳定（对内物价 + 对外汇率）+ 就业（次级权重）
- 中介目标：[[M2与社会融资规模]]"基本匹配"
- 操作目标：[[央行政策利率体系-中国]]

### （二）工具创新

围绕 [[央行三大约束-流动性资本利率]] 设计长效机制：

- **流动性约束**：[[OMO公开市场操作-中国]] / [[MLF中期借贷便利]] / [[SLF常备借贷便利]] / 准备金率调整。2018-2020 共 10 次降准释放约 8 万亿。
- **资本约束**：[[永续债银行资本工具]] + [[CBS央行票据互换]]。截至 2020 末银行累计发行超 1.2 万亿永续债。
- **利率约束**：[[LPR贷款市场报价利率]] 改革 + 引导整体市场利率与贷款利率下行。2018Q4 后 MLF / OMO 利率累计下行 35bp。

并辅以 [[结构性货币政策工具]]（[[再贷款再贴现]] 体系）实现"精准滴灌"。

### （三）传导畅通

- [[利率市场化改革-中国]]："MLF→LPR→贷款利率"市场化传导路径，"打破贷款利率隐性下限"。
- [[人民币汇率市场化]]："破 7"事件（2019-08）后人民币汇率弹性增强。
- 两项改革共同减少了"利率地板"和"汇率天花板"的传导阻滞。

## 五项重大举措（"十四五"部署）

按孙国峰文第三部分：

1. **完善货币供应调控机制**：以币值稳定为首要目标 + 重视就业；保持 M2 / 社融 ≈ 名义 GDP；避免"大水漫灌"也防止信用收缩。
2. **构建金融有效支持实体经济的体制机制**：完善 [[结构性货币政策工具]] 体系，加大对科技创新 / 小微 / 绿色发展的支持；处理好结构性工具与总量工具协调。
3. **健全市场化利率形成和传导机制**：完善 [[央行政策利率体系-中国]] + 利率走廊；深化 [[LPR贷款市场报价利率]] 改革；存款利率市场化推进。
4. **深化人民币汇率市场化改革**：参考一篮子货币的有管理浮动；增强汇率弹性；引导企业"财务中性"理念。
5. **完善宏观经济治理**：央行与财政"两个钱袋子"分立（防 [[财政赤字货币化]]）；货币政策与财政 / 就业 / 产业 / 投资 / 消费 / 环保 / 区域政策协同；加强国际货币政策协调。

## 健全本框架的三项重要意义（按孙国峰文第一部分）

1. **推动高质量发展的内在需要**：转向创新驱动 + 高质量供给；货币政策"既不大水漫灌也不信用收缩"；激励相容机制引导银行货币创造。
2. **国家治理体系和治理能力现代化**：[[现代中央银行制度]] 是国家治理的重要组件；货币政策框架是其核心。
3. **加强国际宏观经济政策协调**：2008 后发达经济体非常规货币政策溢出加大；中国作为大国经济也有溢出效应；需把握战略主动。

## 反面论点与数据空白

### 理论自洽性

- **内生 vs 外生货币论的张力**：孙国峰承认银行主动创造货币（内生），但工具体系仍包含准备金率调整（外生）。Borio (BIS 2017) 普遍批评的"央行政策语言与现代银行学不一致"中国版本尤其明显。[CONTRADICTION]
- **数量目标与利率规则混合**：M2 / 社融"基本匹配" + LPR 市场化 + MLF 利率引导，三者在理论上不完全兼容。Sims (2003) "fiscal-monetary regime" 框架下，这种混合需要更明确的优先级。[CONTRADICTION]

### 历史预测后视（成文后实证）

- **2022-2024 M2 / 社融 vs 名义 GDP 剪刀差**：2022-2024 间 M2 增速持续高于名义 GDP（剪刀差 3-5pp），但通胀低迷甚至通缩——挑战"基本匹配"原则的实证基础。[BIAS] [数据空白]
- **房地产去杠杆危机**：2021-2022 恒大事件 + 三道红线 + 2023 出险房企潮——本文未预见的"信用收缩"风险已发生。
- **2024 框架二次改革**：潘功胜行长 2024 陆家嘴论坛提出"淡化 M2 数量目标、转向短端政策利率"，已偏离本文若干立场。[数据空白：后续摄入]

### 政策有效性

- **LPR 传导效率争议**：殷剑峰 (2020) / 张明 (2021) 等指出 LPR 改革后银行间贷款利率分化加大；FTP 改革滞后于 LPR；存款基准"压舱石"挤压净息差。"打破隐性下限"的实证强度待验。
- **结构性工具精准性**：黄益平等指出再贷款 / 再贴现的"精准滴灌"易被银行"包装"使用，普惠小微贷款增速完成度可能依赖统计调整。[数据空白]
- **永续债集中度**：1.2 万亿永续债主要集中在大型国有银行，中小银行资本约束依然紧张。[数据空白：发行结构]

### 政治经济维度

- **央行独立性 vs 党的领导**：本文明确强调"以习近平新时代中国特色社会主义思想为指导"，反映 PBoC 作为国务院组成部门的体制定位。Rogoff 1985 / Alesina-Summers 1993 央行独立性范式下中国央行独立性指数较低，但这是体制选择而非简单优劣判断。
- **MMT 视角的"两个钱袋子"分立批评**：Wray 2012 / Kelton 2020 认为主权货币国家"两个钱袋子"分立是制度化幻觉。中国 PSL（抵押补充贷款）+ 抗疫特别国债 + 2024-25 万亿超长期特别国债已部分模糊央地财政货币边界。[CONTRADICTION] [数据空白：MMT 中国研究]
- **Cambridge Capital Controversy**：本文"反映潜在产出的名义经济增速"假设可估计的潜在产出，依赖加总生产函数；Sraffa-Robinson 已证伪其严格意义；中国 2018+ 潜在增速估计分歧巨大（社科院 5%-7%）。详见 [[Cambridge Capital Controversy]]。
