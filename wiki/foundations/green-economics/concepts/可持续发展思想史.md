# 可持续发展思想史

> History of Sustainable Development

从 Brundtland (1987) 到 SDGs (2015)，可持续发展概念的演进与测度挑战。Nordhaus 定位此概念为环境意识第四波的核心。

## 关键节点

| 年份 | 事件 | 贡献 |
|---|---|---|
| 1972 | UN Stockholm 环境会议 | 首次全球环境对话；"贫困是最大的污染"（Indira Gandhi） |
| 1987 | Brundtland 报告 *Our Common Future* | 可持续发展的权威定义："满足当代需要而不损害后代满足其需要的能力" |
| 1992 | Rio 地球峰会 | Agenda 21 + UNFCCC + CBD + UNCCD 三公约 |
| 1997 | Kyoto 议定书 | 首次约束性减排目标（但仅限发达国家，美国未批准） |
| 2000 | MDGs（千年发展目标） | 发展目标与环境目标的初步整合 |
| 2012 | Rio+20 | 绿色经济纳入主流；SDGs 启动制定 |
| 2015 | SDGs + 巴黎协定 | 17 个 SDGs + 约束性国家自主贡献 (NDCs) |

## Nordhaus 的批判性评估

- Brundtland 定义的问题：太模糊——"需要"是什么？"能力"如何测量？没有操作性的代际公平标准。
- SDGs 的问题：17 个目标 × 169 个子目标 = 无优先级。Nordhaus 主张碳减排应是最高优先级（因为不可逆 + 全球尺度），但 SDGs 把它放在 #13 且与其他目标平等。
- 绿色社会的四柱框架意在提供 SDGs 缺乏的**优先级结构**。

## 反面论点与数据空白

- **可持续发展的"去政治化"批评**：Swyngedouw 等认为可持续发展话语将环境问题从"资本主义增长模式的政治冲突"转向"技术管理问题"，消解了政治行动的空间。
- **南北知识不对称**：SDGs 框架由 OECD/UN 体系制定，对全球南方国家的发展阶段差异考虑不足。"共同但有区别的责任"（CBDR）在 SDGs 中被弱化。
- **中国可持续发展历程**：从"科学发展观"(2003)→"生态文明"(2012)→"双碳"(2020)，中国的可持续发展叙事有独立谱系，与 Brundtland→SDGs 的西方谱系不完全重合。
