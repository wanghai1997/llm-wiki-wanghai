# 创新双重市场失灵

> Double Market Failure of Green Innovation

绿色技术同时受到两类市场失灵影响：发明者无法获得知识全部价值（**R&D 外部性**），用户无需承担环境损害（**环境外部性**）。两个失灵叠加，绿色技术的私人投资远低于社会最优。

## Nordhaus 的核心论证

> 与一般技术不同，清洁技术面临两个相互独立的负向激励：发明者捕获不到全部社会回报（向上偏低），用户低估环境损害（向下偏高）。两个偏差同时存在，问题加倍严重。

→ 这是 [[ch18-绿色创新的双重外部性]] 的命名由来。

## 双重失灵的结构

```
失灵 1（投入端）：R&D 知识外溢
  发明者私人回报 < 社会回报
  → 私人 R&D 投入不足

失灵 2（产出端）：环境外部性未内部化
  用户支付的产品价格 < 完整社会成本
  → 清洁产品需求不足

叠加效应：
  低 R&D 投入 × 低市场需求 = 严重不足
```

## 与一般 R&D 失灵的对比

| 项目 | 一般 R&D 失灵 | 绿色 R&D 失灵 |
|---|---|---|
| 失灵机制 | 知识溢出 | 知识溢出 + 环境外部性 |
| 政策响应 | R&D 补贴 / 专利 | R&D 补贴 + 碳价 / 法规 |
| 单工具有效性 | 部分有效 | 严重不足 |

→ 一般技术只需修复"投入端"，绿色技术必须同时修复"投入端"和"产出端"。

## 单一政策工具的次优性

Nordhaus 的关键论证：

### 仅用 R&D 补贴

- 风电、电池等技术被开发出来
- 但化石燃料更便宜（无碳价）→ 市场不采纳
- 结果：技术存在但搁置

### 仅用碳税

- 化石能源昂贵了
- 但低碳替代品不存在或不成熟（无 R&D 激励）
- 结果：经济阵痛但减排有限

### 必须组合（参见 [[绿色创新政策组合]]）

- R&D 工具修复投入端
- 碳定价修复产出端
- 两者协同 → 完整的价值链

## 学习曲线效应：第三层失灵？

太阳能/风电的"学习曲线"叠加额外动力学：
- 累积生产 → 边际成本下降
- 但学习溢出至全行业（无法独占）

→ 这相当于"R&D 外部性"的延续到生产阶段。Nordhaus 在章末论证：政府补贴早期需求（如德国 EEG 上网电价）实际上修复了这个第三层失灵。

## 对 [[Pigou税]] 单一框架的修正

经典 Pigou 框架：一种外部性 → 一个税。

绿色创新双重失灵迫使经济学家重新思考：
- 经典框架的"一对一"工具配对失败
- 必须接受"多工具组合"
- 这是从 Tinbergen 的"工具数 = 目标数"原则的延伸

## 反面论点与数据空白

- **失灵规模估算的不确定性**：R&D 外部性（30-50%）和环境外部性（碳社会成本）都有大误差棒，叠加后误差更大
- **政策互动的复杂性**：R&D 补贴 + 碳税并非简单相加——可能产生互动效应（如挤出效应）
- **"挑赢家"风险**：政府补贴特定技术的失败案例（[[Solyndra案例]]）警示精确干预的难度
- **国际溢出**：单国 R&D 补贴的收益部分流向国外——增加搭便车困境
- **失败的失灵**：部分技术（如核能）面临的不是市场失灵而是政治失灵——本章未涵盖
