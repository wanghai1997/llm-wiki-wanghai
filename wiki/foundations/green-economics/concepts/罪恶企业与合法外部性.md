# 罪恶企业与合法外部性

> Sin Stocks and Legal Externalities

某些企业（烟草、枪支、化石燃料、酒类）虽然合法但产生重大负外部性。是否应将其排除在投资和供应链之外？Nordhaus 在 Ch 20 探讨这一边界争议。

## 概念定位

### 罪恶股票（Sin Stocks）的传统范畴

- **烟草**：尼古丁致死率
- **酒类**：长期健康损害
- **赌博**：成瘾问题
- **军火**：直接杀伤
- **化石燃料**（新加入）：气候变化

### 合法外部性

这些行业的产品**合法销售**，但产品消费产生外溢成本：
- 二手烟
- 酒精相关交通事故
- 赌博相关家庭破裂
- 武器扩散
- 气候变化

→ 内部化机制不完整。

## 经济学逻辑

### 标准外部性框架

```
私人成本：消费者支付的价格
社会成本：私人成本 + 外部性
最优产量：MC = MR + 外部性

外部性大小：
  烟草：1 包烟约 $35 社会成本（医疗+生产力）
  酒类：1 杯酒约 $0.5-2 社会成本
  化石燃料：1 吨 CO2 约 $50（[[Nordhaus代际贴现率]]）
```

### Pigou 解决方案

[[庇古税]] 应内部化外部性：
- 烟草税（美国 ~$5/包）
- 酒类税
- 碳税

→ 但实际税率远低于完全内部化水平。

## "罪恶"的边界

### Nordhaus 的多重视角

> 区分"做错事"（违法欺诈如大众）和"合法但有害"（如烟草）很重要。前者必须谴责，后者更难。

#### 边界 1：合法 vs 非法

- 大众作弊（[[大众汽车排放门]]）→ 非法
- 卖烟 → 合法但有害
- → 法律给出最低底线

#### 边界 2：直接 vs 间接危害

- 武器：直接致死
- 烟草：消费者自身致病
- 化石燃料：分散、长期、间接
- → 因果链长度影响道德评估

#### 边界 3：选择 vs 强加

- 烟草：消费者主动选择（但成瘾）
- 二手烟：他人被动暴露
- 气候变化：所有人被动暴露
- → 同意问题不同

## 投资者的选择

### 排除策略

最常见 ESG 整合方法之一：
- 完全排除"罪恶股票"
- 例：天主教大学 / 伦理基金
- → 简单直接，但收益受限

### 整合策略

- 保留持仓，提供股东压力
- 支持改革议案
- → 复杂但理论上更有效

### Nordhaus 的部分支持

> 投资者拒绝"罪恶股票"是合法的伦理选择，但不应误以为这能根本解决问题。

→ 排除策略 + 政策行动 = 完整方案。

## 实证：罪恶股票表现

### 长期回报

- 罪恶股票（烟草、酒、武器）历史上表现优于市场
- "罪恶溢价"约 ~2-3%（部分研究）
- 因 ESG 投资者排除导致的价格折扣

### 含义

- 排除策略可能损害收益（[[绿色基金的成本与回报]]）
- 但价值观一致性的非财务回报
- → 投资者权衡

## 化石燃料的特殊地位

### 与传统罪恶股票的差异

- 烟草：对消费者本人有害
- 化石燃料：对所有人和未来世代有害
- → 道德上的差异

### 撤资运动（[[撤资divestment运动]]）

- 化石自由（Fossil Free）从大学开始
- 哈佛、耶鲁等教务基金被压力
- 主权基金、保险公司参与

### 反对意见

- 撤资可能效果有限（其他买家）
- 持有施压可能更有效（如[[耶鲁伦理投资政策]]）
- 也可能损害收益

## 法律与道德的紧张

### 法律允许 vs 道德反对

烟草：
- **法律**：合法销售
- **道德**：致死率高
- **政策**：高税 + 警告标签
- **企业责任**：信息披露 + 不向未成年人推销

→ 这是 [[Hobby-Lobby案与企业法律边界]] 的延伸：法律边界 vs 道德立场。

### 民主社会的处理

- 投票决定法律边界
- 个人可以选择不投资
- 企业可以选择不生产
- → 多元主义路径

## Nordhaus 的细致立场

### 不主张全面禁止

> 完全禁止"罪恶产品"可能产生黑市，效果适得其反。Pigou 税 + 信息披露 + 个人责任的组合通常更有效。

→ 经济学家的渐进主义。

### 但承认价值判断的合法性

> 投资者、企业、消费者基于个人价值观做选择是正当的。但这是个人事务，不应强加给他人。

→ 哲学上倾向 [[Robert-Nozick|Nozick]] 的自由主义。

### 边界仍模糊

- 武器 = 罪恶？军方采购怎么办？
- 化石燃料 = 罪恶？发展中国家怎么办？
- 肉类（[[素食与气候]]）= 罪恶？文化传统怎么办？

→ 道德判断必有灰色地带。

## 典型边界案例

### 案例 1：科赫兄弟

Nordhaus 自己提到的例子：
- 大量慈善捐赠（艺术、医疗）
- 同时游说反对环境监管
- → 净效应？

### 案例 2：高盛与气候

- 帮助气候相关业务
- 同时为化石燃料融资
- → 双面性如何评估？

### 案例 3：苹果与中国劳工

- ESG 高分（环境）
- 供应链劳工争议（社会）
- → 多维度评估难

## 政策选项

### 1. 完整外部性定价

- 完整碳价
- 烟酒税到完整社会成本
- → 让市场决定，不需"罪恶"标签

### 2. 信息披露义务

- 强制披露社会与环境影响
- 让消费者/投资者知情选择

### 3. 监管底线

- 禁止特别有害的（如石棉、童工产品）
- 但给道德灰色地带空间

### 4. 个人选择保障

- 保护消费者拒绝权
- 投资者选择权
- → 不强加价值观

## 反面论点与数据空白

- **滑坡论证**：界定"罪恶"主观，可能延伸到任何人不喜欢的产品
- **效果有限**：撤资历史显示效果不一致——南非种族隔离时期成功，化石燃料目前不明
- **隐性成本**："罪恶溢价"意味着排除性投资历史回报较低
- **新兴市场难题**：发展中国家化石燃料是必需品，西方道德立场不公平
- **代际伦理**：未来世代是否享有"清洁地球"权利？哲学争议
- **测量困难**：合法企业的"外部性大小"评估高度依赖假设
