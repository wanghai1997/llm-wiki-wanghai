# 传染病预算的政治经济学

> Political Economy of Pandemic Budgets

为什么美国流感预防预算只有 4000 万美元（vs 国防 7400 亿美元）？Nordhaus 将其归因于"饿死野兽"派对预防性公共支出的长期削减——一种典型的政府失灵。

## 美国 2021 年预算结构

| 项目 | 资金（百万美元）| 比例 |
|---|---|---|
| 国防部 | 740,500 | 约 99.4% |
| 联邦研发部 | 142,200 | - |
| 卫生研究 | 36,965 | - |
| CDC 总预算 | 12,612 | - |
| 流感计划 | **40** | **0.005% 国防** |

每个美国人在流感预防上的人均支出：约 0.12 美元/年。
每个美国人在宠物食品上的人均支出：约 100 美元/年。

比例：宠物食品 / 流感预防 = **800-1000 倍**。

## 政治经济学根源

### 1. "饿死野兽"运动

20 世纪 80 年代以来美国保守派的政策：
- 通过减税降低政府收入
- 强迫政府削减"非必要"开支
- "野兽" = 国防外的所有政府开支
- 流行病预防作为非可见、非紧迫的预防性支出——首当其冲

### 2. 短视的预算政治

预防性投入（如疾病防控）的特点：
- **成本明确**（每年支出预算）
- **收益不确定**（防止灾难的概率）
- 政治家偏向"看得见的工程"（如桥梁）而非"看不见的避免"（如未发生的疫情）

这正是 [[尾部事件]] 投资不足的政治经济学根源。

### 3. 利益集团缺失

军工复合体：高度组织、集中游说 → 国防预算稳定增长
公共卫生：分散、缺乏强大集体行动 → 预算长期偏低

参见 [[Mancur-Olson]] 的集体行动逻辑——少数集中利益胜过多数分散利益。

### 4. Schumpeter 的"赋税国家危机"

Nordhaus 引用 Schumpeter 1918 *The Crisis of the Tax State*：
- 国家的赋税能力决定其应对危机能力
- 减税运动 → 应急储备耗竭 → 危机响应能力下降
- 这是一种"自我实现的预言"

## 国际比较

新冠期间各国应急能力的预算根源：
- **韩国/台湾**：SARS 经验后投资公共卫生 → 储备 + 检测能力
- **德国**：日常医疗系统冗余 → 自然适应大流行
- **美国**：长期预算削减 + 联邦碎片化 → 应对失败
- **中国**：强大动员能力但相对低预防投入 → 后期补偿性大投入

## 后疫情改革的难题

理论上，新冠应促使所有国家加大公共卫生预算。但实际：
- 预算增长在最初一两年（紧急拨款）
- 一旦危机过去，"为下次疫情准备"很快被其他议程挤压
- 5-10 年后可能恢复到接近疫情前水平
- 这是预防性投资的"周期性失忆"

## 反面论点与数据空白

- **预算不是唯一因素**：日本/韩国与美国的预算差异不大，但应对效果完全不同——制度、文化、经验同等重要
- **绝对值 vs 比例**：美国流感预算 4000 万美元绝对值不算极低（多数小国低于此），关键是与其经济规模和能力不匹配
- **军费的国家安全论证**：Nordhaus 框架将国防与公共卫生对立——但有论者主张军事威胁也是国家安全的真实部分，不能简单削减
