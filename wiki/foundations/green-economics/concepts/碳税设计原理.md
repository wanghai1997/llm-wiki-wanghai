# 碳税设计原理

> Principles of Carbon Tax Design

把 [[庇古税]] 应用到 CO2 排放，需要设计 4 个维度：税率、税基、收入使用、配套政策。Nordhaus 在 Ch 17（[[ch17-绿色税收]]）系统讨论。

## 设计四要素

### 1. 税率水平

#### 理论目标
$$
t^* = \text{社会碳成本（SCC）}
$$

→ Nordhaus DICE 估算 SCC ≈ $50/tCO2（2020 美元，3% 贴现率）
→ Stern 2007 估算 SCC ≈ $200+/tCO2（用 1.4% 贴现率）

→ 差异源自 [[Nordhaus代际贴现率]] 选择。

#### 现实税率
- 北欧：$50-130
- 加拿大：$30→$170（递增）
- 欧盟 ETS：$50-100（市场决定）
- IMF 建议：$75（2030）

→ 大多数实际税率**低于** Nordhaus 估算的 SCC。

### 2. 税基（Tax Base）

**最优税基**：所有 CO2-当量温室气体（含 CH4、N2O 等）

**实际税基的范围**：
| 范围 | 覆盖 |
|---|---|
| 上游（化石燃料生产/进口）| 简单，覆盖广 |
| 中游（燃料销售）| 多数国家选择 |
| 下游（最终消费者）| 信号最直接但复杂 |

→ Nordhaus 推荐**上游征税**（行政简单 + 不易逃避）。

### 3. 收入使用

详见 [[碳税收入的使用]]。三种主流方案：

| 方案 | 优点 | 缺点 |
|---|---|---|
| 减税循环 | 双重红利 | 政治阻力 |
| 现金返还 | 缓解累退性 | 不增财政 |
| 投资清洁能源 | 协同减排 | 易被滥用 |

### 4. 配套政策

碳税需要配套：
- **碳边境调节**（防止 [[碳泄漏]]）
- **R&D 补贴**（应对 [[创新双重市场失灵]]）
- **转型援助**（高碳行业工人）

## 价格 vs 数量

详见 [[碳税vs排放交易]]。Nordhaus 立场：
- **价格优先**：因边际损害函数相对平坦
- 数量手段（限额）适用于 [[临界点与不可逆性|临界点]] 邻近时

## 设计陷阱

### 陷阱 1：豁免太多

→ 北欧早期豁免化石燃料密集型出口企业（保护竞争力）
→ 结果：减排不充分

### 陷阱 2：税率不递增

→ 静态税率不传递长期信号
→ 加拿大模式：$30→$170 递增提供清晰预期

### 陷阱 3：与其他工具冲突

→ 碳税 + 燃油效率标准（CAFE）= 双重监管
→ 应**整合**而非叠加

### 陷阱 4：政治反复

→ 法国 2018 黄背心 → 暂停燃油税
→ 反复降低长期信号可信度（[[环境政策的稳定性]]）

## 设计的"金发女孩"区间

应用 [[金发女孩原则]]：

```
税率
  │
  │   太高 → 经济损害 + 政治反弹
  │
  │   ── 最优区间 ──
  │
  │   太低 → 减排不足
  │
  └─────────── 时间
```

→ Nordhaus：当前应在 $50-100/tCO2 起步，逐年递增。

## 反面论点与数据空白

- **SCC 估算的不确定性**：Nordhaus 自己承认 SCC 有 ±50% 误差区间
- **行为经济学问题**：消费者反应可能弱于价格信号（[[行为异常-环境]]）
- **公平性**：累退性需要专门设计（[[碳税的累退性]]）
- **国际协调**：单国设计的碳税面临 [[碳泄漏]]
- **替代品的局限**：电动车依赖电网清洁化——若电网未变绿，碳税效果打折
