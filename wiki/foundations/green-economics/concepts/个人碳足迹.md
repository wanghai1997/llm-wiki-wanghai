# 个人碳足迹

> Personal Carbon Footprint

测算个人或家庭年度温室气体排放量。Nordhaus 在 Ch 19 用此为框架讨论个人减排的**潜力与天花板**。

## 定义

个人碳足迹 = 个人活动直接 + 间接产生的温室气体排放（CO2 等价）。

**直接排放**：
- 燃烧（汽油、天然气、燃油）

**间接排放**：
- 用电（依赖电网构成）
- 商品消费（生命周期排放）
- 服务（旅行、医疗、金融）

## 美国家庭典型结构

Nordhaus 引用美国数据（年人均约 16 吨 CO2-eq）：

| 类别 | 占比 | 主要来源 |
|---|---|---|
| 交通 | ~30% | 汽车 + 飞机 |
| 住房 | ~25% | 电力 + 暖气 |
| 食物 | ~15% | 肉类、奶制品 |
| 商品 | ~20% | 电子、服装、家居 |
| 服务 | ~10% | 医疗、教育、金融 |

## 测算方法

### 自上而下（Macro）

- 国家排放总量 ÷ 人口 = 人均碳足迹
- 美国 ~16 吨/年；中国 ~7 吨/年；印度 ~2 吨/年
- 简单但忽视个体差异

### 自下而上（Micro）

- 逐项乘以排放因子
- 在线计算器：EPA、Carbon Footprint Ltd
- → 精度依赖输入完整性

### 生命周期评估（LCA）

- 完整的[[生命周期分析LCA]]
- 包括：原料、生产、运输、使用、处置
- → 学术标准但成本高

## Nordhaus 的"个人减排天花板"

> 即使最积极的个人努力，也只能减少个人碳足迹的 25-30%。其余必须靠系统性政策。这并不意味着个人努力无用——而是意味着我们需要清醒认识其边界。

### 估算框架

激进绿色化能减多少？

| 措施 | 减排量（吨/年） |
|---|---|
| 改电动车（电网平均） | ~3 |
| 房屋节能改造 | ~2 |
| 完全素食 | ~1 |
| 减少飞行（每年 1 次国际） | ~1-3 |
| 减少消费（极简主义） | ~1 |
| **合计** | **~8-10** |

→ 从 16 吨降至 6-8 吨，减少 ~50%——但 Nordhaus 估算考虑实际可行性后只有 25-30%。

## 国际比较

| 国家 | 人均 CO2-eq（吨/年） | 主要驱动 |
|---|---|---|
| 美国 | ~16 | 交通 + 住房 |
| 加拿大 | ~15 | 暖气 + 油气 |
| 澳大利亚 | ~16 | 煤电 + 出行 |
| 德国 | ~9 | 工业仍重 |
| 法国 | ~5 | 核电主导 |
| 日本 | ~9 | 电力依赖煤 |
| 中国 | ~7 | 工业排放 |
| 印度 | ~2 | 整体低消费 |
| 撒哈拉以南非洲 | ~1 | 极低消费 |

→ 国家差异远大于个人差异。

## "公平份额"概念

要将全球升温限制在 1.5°C：
- 全球人均年排放预算 ~2 吨 CO2-eq
- 约为美国当前水平的 1/8、印度的 1.0
- → 美国家庭即使努力也很难达到此线

→ 这激发了 [[气候正义]] 的争论：富裕国家是否应承担更大份额？

## 测量的边界问题

### 边界 1：进口商品的排放

- 美国进口中国制造产品
- 排放发生在中国，消费在美国
- 计算方法：生产端 vs 消费端

→ 影响双倍：美国"出口排放"到中国，但中国数据看起来更高。

### 边界 2：政府服务

- 个人间接享受军费、基础设施等
- 排放是否摊到个人？
- → 多数计算器忽略，可能低估 ~1-2 吨

### 边界 3：投资碳足迹

- 401(k) / IRA 投资组合的间接排放
- ESG 基金（[[ESG基金的实践]]）开始计算"投资组合碳"
- → 多数个人计算未考虑

## Nordhaus 的清醒立场

### 1. 个人努力有意义但有限

> 节能让你做正确的事，但不要欺骗自己——气候解决方案在政策，不在个体。

### 2. 个人选择 vs 系统变革

- 个人减排 25-30% × 全人口 = 全球减排 25-30%（理想化）
- 但实际**协调失败**严重
- 系统变革（电网、工业、交通）必不可少

### 3. 道德溢出可能放大

- 个人选择可能改变社会规范（[[行为经济学与绿色选择]]）
- 进而推动政治变革
- → 这是个人努力的"非直接价值"

## 反面论点与数据空白

- **测算的不确定性**：在线计算器估算误差可达 ±30%
- **激进者的反例**：极少数家庭能达到人均 2 吨——证明天花板不绝对
- **道德负担转移**：把责任推给个人可能掩盖系统/产业责任
- **罪恶感经济学**：测算个人碳足迹可能引发无效罪恶感而非建设性行动
- **国家差异覆盖个体差异**：在美国做好不如出生在法国——但这忽视个体能动性
