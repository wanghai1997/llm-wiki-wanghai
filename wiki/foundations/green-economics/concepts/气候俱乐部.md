# 气候俱乐部

> Climate Club

Nordhaus 2015 AER 论文提出的核心政策提案：以国际目标碳价为中心、通过贸易惩罚克服搭便车的国际气候治理机制。Ch 23 的核心创新。

---

## 核心设计

### 三要素

```
气候俱乐部 = 参与国 + 统一碳价 + 对非参与者的惩罚
```

1. **国际目标碳价**（非数量上限）
   - 各参与国实施不低于俱乐部碳价的国内碳税
   - 避免国别排放上限的政治博弈
   - Weitzman 理论支持：不确定性高时价格更优

2. **俱乐部结构**
   - 从小群体开始（如 G7 + 关键排放国）
   - 逐步扩展
   - 参与国获得互惠利益（自由贸易 + 气候合作）

3. **惩罚非参与者**
   - [[碳边境调节机制]]：对非签署国进口征收统一关税
   - 税率 = 产品隐含碳 × 俱乐部碳价
   - 目的：防止碳泄漏 + 创造参与激励

---

## 理论来源

### 俱乐部理论（Mancur Olson）

- 小型群体更容易克服搭便车
- 排他性利益激励参与
- 气候俱乐部 = 将全球公共品转化为"俱乐部品"

### Weitzman 价格理论

- 不确定性高时，统一碳价优于分散配额
- 参与国保留政策灵活性（税率 vs 配额）

---

## 运作机制

### 参与激励

```
参与收益 = 避免边境税 + 俱乐部内自由贸易 + 气候合作收益
参与成本 = 实施碳价 → 国内减排成本
```

当边境税 > 减排成本时，参与是理性选择。

### 惩罚的可信性

关键问题：俱乐部能否可信地威胁惩罚？
- 需要统一执行
- 可能面临 WTO 挑战
- 大国（如美国、中国）的参与至关重要

---

## Nordhaus 的模拟结果

使用 DICE 模型的俱乐部扩展：
- 基准（无俱乐部）：2100 年升温 4.1°C
- 小规模俱乐部（~20% 全球排放）：有限改善
- 大规模俱乐部（~80% 全球排放）：接近 2°C 目标

→ **覆盖面是关键**。

---

## 实施挑战

### 1. WTO 兼容性

- 边境税可能违反非歧视原则
- 但 GATT 第 20 条（环境例外）可能适用
- 法律上可行但政治上争议

### 2. 碳含量测算

- 产品隐含碳的测算复杂
- 需要全生命周期数据
- 发展中国家可能缺乏能力

### 3. 大国参与

- 中国、美国、印度不加入 → 俱乐部无效
- 如何吸引初始参与者？

### 4. 收入使用

- 边境税收入的归属与使用
- 再分配给发展中国家？用于国内？

## 与现有机制比较

| 机制 | 约束力 | 惩罚 | 覆盖 | 评价 |
|---|---|---|---|---|
| 京都 | 有（但弱） | 无 | 低 | 失败 |
| 巴黎 | 无 | 无 | 高 | 自愿不足 |
| 气候俱乐部 | 有（惩罚） | 有（关税） | 取决于参与 | 理论完善，无先例 |

## 反面论点与数据空白

- **无实施先例**：2021 年本书写作时仍无实际案例——纯理论提案
- **WTO 冲突**：边境调节的贸易法兼容性未充分讨论
- **测算成本**：产品隐含碳的追踪成本高昂
- **发展中国家顾虑**：是否成为贸易保护主义的工具？
- **政治可行性**：各国是否愿意让渡部分贸易主权？
- **俱乐部规模动态**：小规模起步 → 大规模的理论路径未经验证
- **与其他政策的关系**：俱乐部与巴黎协定如何共存？
- **碳泄漏量化**：惩罚机制能否有效防止泄漏？
