# 撤资 divestment 运动

> Divestment Movement

通过出售化石燃料公司股权和债券来表达气候立场的全球运动。从 2011 年美国校园起步，发展为涵盖大学、教会、城市、保险公司、主权基金的跨界行动。Nordhaus 在 Ch 21 持谨慎评估。

## 历史脉络

### 阶段 1：起源（2011-2013）

- **350.org**（Bill McKibben 创立）：环保 NGO 推动
- **化石自由 U（Fossil Free U）**：美国大学校园倡议
- **Swarthmore 学院**（2011）：首批响应
- **Hampshire College**（2011）：第一所撤资

→ 最初聚焦"碳追踪计划"列出的 200 家最大化石公司。

### 阶段 2：扩散（2014-2017）

- **斯坦福大学**（2014）：撤出煤炭
- **洛克菲勒兄弟基金**（2014）：象征性意义重大（创始资金来自标准石油）
- **挪威主权基金**（2015）：撤出煤炭
- **巴黎、纽约市**等城市加入

### 阶段 3：主流化（2018-2021）

- **冰岛主权基金**（2017）
- **耶鲁、哈佛**（2020-2021）：从抗拒到部分撤资
- **教皇方济各**呼吁
- **联合国 PRI** 整合

### 阶段 4：复杂化（2022-）

- **能源危机**（俄乌战争 2022）→ 部分基金重回化石燃料
- **共和党反 ESG**：美国部分州反对
- **运动分化**：完全撤资 vs 整合参与

## 撤资的逻辑

### 经济逻辑

```
化石燃料公司价值：
  当前现金流（确定）
  + 未来产能价值（不确定）

气候政策风险：
  → 资产搁浅（stranded assets）
  → 未来产能可能为零
  → 当前估值高估
```

→ 撤资可能是**理性投资决策**，不仅是道德立场。

### 道德逻辑

- 化石燃料造成不可逆损害
- 既得利益游说阻碍政策
- 资本市场是社会工具
- → 不应资助加剧危机的活动

### 政治逻辑

- 信号效应：影响公众舆论
- 推动监管：施压立法
- 改变企业行为：化石公司面临融资压力

## 撤资 vs 持有施压：辩论

### 撤资派论据

1. **道德清白**：不参与就不复杂
2. **市场信号**：股票卖出 → 价格下跌
3. **声誉损失**：化石公司被边缘化
4. **避免搁浅资产**：金融保护
5. **历史先例**：南非反隔离的成功

### 持有施压派论据（[[耶鲁伦理投资政策]]）

1. **保留股东权利**：投票推动改变
2. **股票转手**：撤资将股票卖给"无所谓"的投资者
3. **规模问题**：撤资量占总市值小，影响力有限
4. **碳价中心**：政策才是根本解决
5. **化石公司转型**：BP、Shell 等正在转型，不应放弃支持

### Nordhaus 的中庸立场

> 撤资是合法选择，但其效果常被夸大。真正的减排来自碳价 + 政策——撤资是辅助而非替代。

→ 类似耶鲁 [[John-Simon]] 报告的立场。

## 撤资规模

### 全球撤资承诺数据

- 2014 ：~$50 billion
- 2018 ：~$8 trillion（增长 160 倍）
- 2025 估计：~$40 trillion

→ 但"承诺撤资"≠"已撤资"。多数承诺仍包含化石燃料持仓。

### 主要撤资者类型

| 类型 | 资产规模 | 主要例子 |
|---|---|---|
| 大学教务基金 | $700B+ | 哈佛、耶鲁、剑桥 |
| 教会与基金会 | $300B+ | 教皇基金、洛克菲勒兄弟 |
| 城市/州 | $1T+ | 纽约市、加州 |
| 主权基金 | $4T+ | 挪威、冰岛 |
| 保险与养老 | $20T+ | 法国 AXA、CalPERS |
| 公司养老金 | 部分 | 联邦快递、惠普 |

## 实证：撤资的效果

### 影响化石公司股价？

- 短期：宣布撤资引发短暂下跌（~1-2%）
- 长期：与基本面脱钩（油价、需求等）
- → 撤资的市场效应有限

### 影响化石公司行为？

- BP、Shell 转型（部分受撤资压力）
- 但仍持续高碳投资
- → 转型方向有但速度不足

### 影响公众认知？

- 撤资运动提升气候话题可见度
- 给政治议程定调
- → 间接、长期、难量化

### 影响政策？

- 巴黎协定（2015）部分受撤资运动推动
- 各国碳中和承诺
- → 但因果链长

## 案例分析

### 案例 1：哈佛大学

- 长期抵制撤资
- 学生抗议持续 10+ 年
- 2021 9 月宣布"撤资", 但实际是"不再新投资"
- → 部分胜利

### 案例 2：挪威主权基金（GPFG）

- 全球最大主权基金（~$1.6T）
- 2015 撤出煤炭
- 2019 撤出"上游石油"（油气勘探）
- 但保留下游
- → 渐进路径

### 案例 3：苏格兰大学联合体

- 30+ 大学 2018 联合撤资
- → 集体行动效率高

### 案例 4：Climate Action 100+

- 资管机构联合体（700+ 成员，$68T 资产）
- 不撤资但联合施压
- 持有施压派的代表
- → "engagement"路径

## Nordhaus 的具体评估

### 同意撤资的部分

- 个人/机构基于价值观选择是合法的
- 撤资作为政治行动有意义
- 减少特定公司融资可能逼其转型

### 但有保留

> 全面撤资可能将化石公司的股票转给不关心气候的投资者——并未减少全球资本。真正的减排来自**降低需求**（碳价）而不是**资本断流**（撤资）。

→ 经济学家的供需视角。

### 与无悔原则的对话

- 排除少数公司影响小（[[绿色基金的成本与回报]]）
- 但全面撤出整个行业代价大
- 投资者应权衡价值观与多元化

## 政策含义

### 1. 撤资 vs 碳价

- 碳价是根本工具
- 撤资是辅助
- 不应替代

### 2. 透明披露

- 资产搁浅风险量化
- 推动定价正确化
- → TCFD 框架

### 3. 转型金融

- 比"撤资"更具建设性
- 投资清洁能源同时
- 支持化石公司有序转型

### 4. 国际协调

- 国家间撤资政策协调
- 避免"资本流向最低标准"
- → 全球协调难

## 中国语境

### 中国"撤资"现象有限

- 主要是国资委推动的"双碳"
- 而非自下而上的运动
- 银行业绿色信贷指引推动
- → 政府主导 vs 公民运动

### 但有相关动作

- 投资者关注的"褐色资产"风险
- 央行气候压力测试
- 银保监 ESG 整合

## 反面论点与数据空白

- **撤资有效性争议**：实证研究混合，部分显示影响有限
- **道德转嫁**：撤资将股票卖给他人——总减排为零
- **化石公司转型角色**：完全撤资可能阻碍化石公司向清洁能源转型
- **新兴市场困境**：发展中国家撤资可能损害发展机会
- **能源安全副作用**：俄乌冲突显示过度撤资可能加剧能源短缺
- **规模相对效应**：撤资 $1T 看似多，但全球资本市场 ~$300T——比例小
- **道德双标**：批评化石燃料的同时使用其能源——"绿色虚伪"
