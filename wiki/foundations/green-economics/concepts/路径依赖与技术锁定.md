# 路径依赖与技术锁定

> Path Dependence and Technology Lock-in

历史选择决定当前结构，劣等技术可能因先发优势锁定整个市场。在能源系统中，路径依赖意味着**当前的化石燃料基础设施可能阻碍向清洁能源的转型**——即使后者社会上更优。

## Brian Arthur 的路径依赖理论

W. Brian Arthur 在 1980 年代提出的路径依赖动力学：

```
增加规模回报 + 锁定效应 + 历史小事件
       ↓
系统的最终状态由初始路径决定
       ↓
不一定收敛到效率最优解
```

→ 这与新古典经济学"自动收敛到均衡"的命题相悖。

## 锁定的四种来源

Arthur 的经典分类：

### 1. 学习经济（Learning by Doing）

- 累积生产 → 边际成本下降
- 先进入者优势放大
- → 化石能源已积累 200 年学习经验

### 2. 网络外部性

- 用户越多 → 价值越高
- 加油站网络 → 锁定汽油车
- 充电桩网络 → 起步阶段不利

### 3. 互补性资产

- 整套生态系统配合特定技术
- 内燃机 → 加油站、维修站、配件、人才
- 转换成本极高

### 4. 共适应预期

- 投资者认为某技术将主导 → 投资该技术
- 自我实现预期
- → 转折点很难启动

## 经典案例

### QWERTY 键盘（David 1985）

- 19 世纪机械打字机时代为防卡壳设计
- 现代电脑无此约束 → DSK 键盘理论上更优
- 但 QWERTY 已锁定（学习成本、产业惯性）
- → David 论证："劣等技术可永久占据市场"

### VHS vs Betamax

- 1970-80s 录像带战争
- Betamax 技术上更优
- VHS 因许可宽松、更长录制时间锁定市场
- → 多年后 Sony 自己都生产 VHS

### 内燃机 vs 电动车（早期）

- 1900 年初汽车市场：电、汽、蒸汽三足鼎立
- 电动车一度占 38% 市场份额
- 1910s 廉价石油 + Ford T 型车 → 内燃机锁定
- 电动车花了 100 年才重新崛起

## 在能源系统中的应用

### 化石能源锁定

```
基础设施投资（油田、管道、电厂）：
  寿命 30-50 年
  ↓
搁浅资产风险大
  ↓
利益相关者反对快速转型
  ↓
政治阻力（[[环境政策的稳定性]]）
```

### 清洁能源的"启动门槛"

风/光起步阶段难题：
- 累积产量小 → 单位成本高
- 网络效应弱 → 互补设施少
- 投资者观望 → 资金不足

→ 需要**外部冲击**打破锁定（补贴、碳税、技术突破）。

## 锁定的破解机制

### 机制 1：政策助推

- 德国 EEG（2000）→ 上网电价 → 启动光伏需求 → 学习曲线 → 全球价格下降
- 这是 Nordhaus 高度认可的政策

### 机制 2：技术突破

- 锂电池能量密度的渐进改进 → 跨越临界点 → 电动车爆发
- 太阳能效率从 10% → 25% → 跨越临界点

### 机制 3：地缘政治冲击

- 1970s 石油危机 → 短暂推动节能
- 2022 俄乌冲突 → 欧洲加速可再生能源
- → 但冲击效应通常不持久

### 机制 4：消费者偏好转变

- 年轻一代偏好清洁能源
- ESG 投资压力（[[ESG的三定义]]）
- → 但需要时间积累

## Nordhaus 的政策含义

> 路径依赖告诉我们：自由市场不会自动转向清洁能源。即使清洁技术成本下降到与化石能源持平，转换成本和锁定效应仍可能阻止转型。这强化了"早期碳价"的必要性。

→ 与新古典"市场自动调节"观点的对立。

### 实证含义

研究估算"锁定成本"：
- 若延迟碳价 10 年 → 转型总成本增加 ~15-20%
- 若延迟 20 年 → 增加 50% 以上
- → 现在不行动，未来代价指数增长

## 与 Wiki 已有概念的对话

### 与 [[Solyndra案例]] 的关联

Solyndra 部分输给中国硅基不仅是商业失败，也是路径依赖的体现：
- 中国先动手大规模投资硅基产能
- 学习曲线压低硅基成本
- Solyndra 的薄膜路径无法突破锁定

### 与 [[寻租]] / [[政治作为偏好聚合]] 的关联

- 化石能源锁定有政治维度
- 现有产业利益集团游说阻碍转型
- → 经济锁定 + 政治锁定 = 双重阻力

### 与 [[初始成本偏差]] 的关联

- 个人面对"初始投资高"的清洁选择
- 即使长期更便宜也不采纳
- → 微观层面的路径依赖

## 反面论点与数据空白

- **锁定强度的争议**：多强的锁定？经济学界估算差异大（5-50%额外成本）
- **新古典反驳**：完全市场假设下，价格信号足以打破锁定——但实证支持有限
- **过度悲观风险**：技术突破可能比预期更快（如 LED 取代白炽灯）
- **国家差异**：发达国家锁定深，发展中国家锁定浅——后者可能"跨越式"发展
- **测量难题**：如何精确测量"路径依赖效应"？反事实情景很难构建
