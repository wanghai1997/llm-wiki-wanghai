# 致死率 L

> Case Fatality Rate (CFR)

感染后死亡的人口比例。流行病严重性的另一关键参数（与 R0 共同决定全球死亡负担）。

## 各疾病的致死率

| 疾病 | 致死率 (L) |
|---|---|
| 普通感冒 | 接近 0% |
| 季节性流感 | 0.05-0.2% |
| 2009 H1N1 流感 | ~0.01% |
| 新冠（原始株 / 2020）| 0.5-2% |
| SARS | ~10% |
| 西班牙流感（1918-20）| ~3% |
| 中东呼吸综合征（MERS）| ~35% |
| 埃博拉 | ~50% |
| 禽流感（H5N1）| ~50-60% |
| 天花 | ~30% |

## R0 × L = 全球死亡负担的近似度量

$$
\text{潜在死亡} \approx \text{总人口} \times \text{易感比例} \times R_0\text{相关感染率} \times L
$$

实际更复杂，但 R0 × L 给出了 first-order 估计。

## 致死率的影响因素

1. **病毒/细菌的本质毒力**：基因学决定的"杀伤力"
2. **被感染者特征**：年龄、基础疾病、免疫状态
3. **医疗资源可获得性**：ICU 床位、疫苗、抗病毒药
4. **公共卫生响应**：早期检测、合理隔离

## 致死率与传染性的权衡

进化生物学论证：极高致死率的病原体往往**不**形成大流行——因为宿主死得太快无法传播。这一权衡解释了为什么人类大流行病历史上致死率多在 1-10% 范围。

例外：
- 西班牙流感（1918-20）：致死率 ~3%，但传染性高 → 全球 5000 万-1 亿死亡
- 黑死病（1331-53）：致死率 ~30%，传染性中等 → 欧洲约 1/3 人口死亡

## 反面论点与数据空白

- **致死率的测量困难**：分母（被感染者总数）通常不可观测——只有死亡和确诊数。新冠的"真实致死率"（IFR, infection fatality rate）经过抗体血清调查才能估计
- **致死率的人口异质性**：新冠对老年人致死率 5-15%，对儿童 < 0.01%——总体平均值掩盖了巨大异质性
- **医疗系统压力**：当 ICU 满载时致死率上升——这是封锁的间接收益
