# DICE 模型

> Dynamic Integrated Climate-Economy Model

Nordhaus 开发的动态综合气候经济模型，气候变化经济学最具影响力的定量工具。Ch 22-23 表 23.1/图 23.2 的数据来源。

---

## 模型结构

### 两大模块

```
经济模块 ←————————→ 气候模块
  ↑                        ↓
  └———————— 碳排放 ————————┘
```

**经济模块**：
- 新古典增长模型（Ramsey 框架）
- 生产函数：Y = A·K^α·L^(1-α)
- 碳排放 = 经济活动 × 碳强度

**气候模块**：
- 碳循环（大气/海洋/生物圈）
- 辐射强迫 → 温度变化
- 三箱碳循环模型

### 目标函数

最大化社会福利（折现效用和）：

```
W = Σ U(c(t)) · L(t) / (1+ρ)^t
```

- c(t)：人均消费
- L(t)：人口
- ρ：纯时间偏好率（~1.5%/年）
- 效用函数：U(c) = c^(1-η)/(1-η)（η = 2，相对风险厌恶）

---

## 关键方程

### 损害函数

```
D(T) = 1 / (1 + ψ1·T + ψ2·T^2)
```

- T：全球平均升温（°C）
- ψ1, ψ2：参数
- → 升温 3°C 时损害 ~2.5% GDP；6°C 时 ~8%

### 减排成本函数

```
Λ(μ) = θ1(t)·μ^θ2
```

- μ：减排率（0-1）
- θ1(t)：随时间下降（技术进步）
- θ2：成本弹性（~2.8）

---

## 主要情景

| 情景 | 描述 | 2100 升温 | 2100 碳价 |
|---|---|---|---|
| 基准（无政策） | 市场自发 | ~4.1°C | ~$30 |
| 最优 | 成本-收益最优 | ~3.5°C | ~$200 |
| 2°C | 温度约束 | ~2.0°C | ~$1000+ |
| 1.5°C | 巴黎目标 | ~1.5°C | 极高 |

→ **关键发现**：成本-收益"最优"路径仍允许 3.5°C 升温，远超巴黎目标。

## 批评与局限

### 1. 贴现率争议

- Nordhaus 用 ~4-5%（市场回报率）
- Stern 用 ~1.4%（伦理贴现率）
- → 差异使最优碳价差 5-10 倍

### 2. 损害函数低估

- 二次型假设：损害平滑递增
- 实际：临界点、非市场损害、分布不均
- Weitzman："fat tail"风险未被捕捉

### 3. 技术内生性不足

- 减排成本下降外生给定
- 实际：碳价推动创新（ learning-by-doing）

### 4. 区域聚合

- 全球单一区域模型
- 掩盖国别差异（热带国家损害更大）

## 反面论点与数据空白

- **参数敏感性**：贴现率、气候敏感度对结果影响巨大，但敏感度分析展示不足
- **损害函数形态**：二次型假设的实证基础薄弱
- **临界点纳入**：2019 年后版本改进，但仍不充分
- **区域不平等**：全球模型掩盖分配问题
- **适应行为**：人类适应能力的建模简化
- **政治可行性**：模型给出"最优"解，但未考虑政治约束
- **非 CO2 温室气体**：甲烷、N2O 的处理简化
- **负排放技术**：BECCS 等技术的可行性假设乐观
