# R0 与 Reff

> Basic vs Effective Reproduction Number

流行病学的两个核心参数：R0 = 基本传染数（无防护时一个感染者平均传染人数）；Reff = 有效传染数（采取防护措施后）。R0 决定流行病学的"难度"，Reff 决定实际控制效果。

## R0：基本传染数

定义：在没有任何预防措施和先前免疫的人群中，一个感染者平均传染的人数。

各疾病的 R0：

| 疾病 | R0 |
|---|---|
| 普通感冒 | 1.5-2 |
| 季节性流感 | 1.5-2 |
| 新冠（原始株） | ~3 |
| 新冠（Omicron） | 8-10 |
| 西班牙流感 | 2-3 |
| SARS | 2-4 |
| 麻疹 | 12-18 |
| 天花 | 3-7 |

R0 受三个因素影响：
1. **病原体的传染性**（如空气传播 vs 接触传播）
2. **接触模式**（人口密度、社交活动）
3. **持续传染期长度**（症状前传播 vs 仅症状后传播）

## Reff：有效传染数

定义：在采取了防护措施（口罩、社交距离、隔离、疫苗等）后，一个感染者实际传染的人数。

控制流行病的关键：**使 Reff < 1**。
- Reff > 1：每代感染人数增长 → 指数扩散
- Reff = 1：稳定 → 缓慢消退
- Reff < 1：每代感染人数下降 → 流行病消失

## 降低 Reff 的措施

| 措施 | 机制 |
|---|---|
| 隔离感染者 | 减少接触次数 |
| 社交距离 | 减少接触次数 |
| 口罩 | 减少传播概率/接触 |
| 疫苗接种 | 降低易感人数 |
| 接触者追踪 | 提前隔离 |
| 边境管控 | 减少输入病例 |

## 数学公式

简化的 SIR 模型中：
$$
R_{eff} = R_0 \cdot S
$$

其中 S 是易感人群占总人口的比例。

群体免疫阈值：当 S < 1/R0 时，Reff < 1，流行病自然消退。

## 新冠的 R0 估算

Nordhaus 引用 R0 ≈ 3 作为新冠原始株的估算：
> 假设 R0 = 2，那么，在没有采取保护措施的前提下，如果第 n 代有 1000 人感染，则第 (n+1) 代将有 2000 人感染。

R0 = 3 意味着：要使 Reff < 1，需要 67% 人口免疫——通过感染或疫苗。

## 反面论点与数据空白

- **R0 不是固定常数**：R0 取决于人群和环境——同一病毒在不同社会中 R0 可能差 2× 以上
- **测量 R0 的困难**：早期估计基于不完整数据，后续修正幅度大（新冠 R0 从初期估计 2.5 修正到 Omicron 时代 10+）
- **Reff 的实时估计**：Reff 滞后约 7-14 天——疫情期间难以实时调整政策
