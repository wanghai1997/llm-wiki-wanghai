# 税收的社会成本

> The Social Cost of Taxation

任何税收都产生**死重损失**（deadweight loss），但 [[庇古税]] 是例外——它**消除**外部性损失，可能产生净收益。

## 一般税收的死重损失

### 经典分析

设劳动税 t：
- 工资从 w 降到 w(1−t)
- 劳动供给减少 → 经济产出下降
- 减少量 = 死重损失

```
价格(工资)
  │
  │     供给曲线
  │      ╱
  │  w──╱─── 没有税时的均衡
  │    ╱      ┌── 死重损失（三角形）
  │ w(1-t)────┤
  │    ╲     ╲
  │     ╲     ╲ 需求曲线
  │      ╲     ╲
  └──────────── 劳动量
       L*  L_税
```

### 经验估算

经济学家估算劳动税的"边际死重损失"：
- 美国：约 30-40 美分/每 1 美元税收
- 欧洲：约 40-50 美分/每 1 美元税收

→ 这是任何"福利计划"都需考虑的隐性成本。

## 庇古税的特殊性

### 庇古税不是负担

[[庇古税]] 的精妙之处：
- 一般税：扭曲市场 → 死重损失
- 庇古税：**纠正**扭曲 → **创造**经济价值

### 论证

设外部性导致市场过量消费：
```
市场结果：消费 Q市场，但 SMC > PMC
→ 边际单位的消费造成净社会损失

加庇古税后：消费 Q*，PMC + t = SMC
→ 边际损失消失，社会福利提升
```

→ 庇古税本身**是**净收益（不算政府收入）。

### 双重红利的逻辑

[[双重红利假说]] 建立在此基础上：
- 减劳动税：消除一般税的死重损失（红利 1）
- 加碳税：消除外部性的死重损失（红利 2）

## 庇古税的政府收入是"额外"的

[CRITICAL] 这是 Nordhaus 反复强调的：

```
对一般税的福利分析：
  收入 = R
  死重损失 = -L
  净收益 = R - L < R

对庇古税的福利分析：
  收入 = R
  死重损失 = -L (一般税导致)
  + 外部性纠正 = +E
  净收益 = R - L + E

→ 如果 E ≥ L，庇古税的净社会收益 ≥ R
```

### 实践含义

碳税收入用于：
- ✅ 公共支出（如劳动税减免）：净收益更高
- ❌ 一般国库消失：失去双重红利

## Nordhaus 在 Ch 17 的政策建议

### 建议 1：碳税应优先于劳动税扩张

如果政府需增加收入：
- 优先：开征/增加碳税
- 其次：增加资本/消费税
- 最后：增加劳动税

理由：碳税的边际死重损失为**负**（净社会收益）。

### 建议 2：低估碳税的"净"作用

公众讨论碳税常忽视：
- 外部性纠正的价值
- 双重红利的潜力

→ Nordhaus 认为政治讨论应**纳入**这些维度。

## 反面论点与数据空白

- **外部性测算的不确定性**：庇古税的"创造价值"假设 E 测算正确——实际 SCC 估算 ±50%
- **次优问题**：现实税制有多种扭曲，加碳税的总效应可能复杂
- **行为非理性**：消费者对价格反应弱 → 庇古税的纠正效果打折
- **政治成本**：经济学上的"净收益"不等于政治可接受性
- **跨期问题**：当前死重损失测算 vs 长期外部性纠正——时间维度模糊
