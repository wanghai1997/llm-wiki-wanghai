# 庇古税

> Pigovian Tax (Pigouvian Tax)

[[Arthur-Pigou]] 1920 年《福利经济学》提出的概念：对产生**负外部性**的活动征税，使私人成本等于社会成本，恢复市场效率。这是 [[ch17-绿色税收]] 的理论基础。

## 核心原理

设某活动产生负外部性，记：
- PMC = 私人边际成本（Private Marginal Cost）
- SMC = 社会边际成本（Social Marginal Cost）
- E = 外部边际损害（Marginal External Damage）= SMC − PMC

**庇古定理**：
$$
t^* = E
$$

即**最优庇古税** = 边际外部损害。

## 图示

```
价格/成本
  │      SMC = PMC + t*
  │      ╱
  │     ╱  ←—— 庇古税 t*
  │    ╱  PMC
  │   ╱  ╱
  │  ╱  ╱
  │ ╱  ╱        D
  │╱  ╱        ╱
  └────────────── 数量
        Q*    Q市场
       (社会最优) (市场结果)
```

→ 未征税：市场过度供给（Q市场 > Q*）
→ 征税 t*：消费者面对 SMC，市场回归最优

## 庇古税的优点

### 1. 成本效率（Cost-Effectiveness）

→ 所有边际减排成本 ≤ t* 的减排措施都会被实施
→ 减排集中于**成本最低**的来源
→ 命令控制无法做到这一点

### 2. 收入循环（Revenue Recycling）

→ 税收可用于：
- 减少其他扭曲税（[[双重红利假说]]）
- 转移支付（缓解 [[碳税的累退性]]）
- 投资清洁技术（[[绿色创新政策组合]]）

### 3. 国际可协调

→ 价格信号比规制标准更易跨国对齐
→ [[欧盟排放交易体系ETS]] + [[国际碳税经验-北欧]] 验证

### 4. 鼓励技术创新

→ 持续的价格信号 → 持续的减排激励
→ [[路径依赖与技术锁定]] 的破解

## 难点

### 难点 1：测算 E

外部损害 E 难以精确测算：
- [[Nordhaus代际贴现率]] 的争议
- [[尾部事件]] 的概率分布
- 跨国损害的归属

→ Nordhaus DICE 模型是当代最严谨的尝试。

### 难点 2：政治可行性

碳税面临：
- **税收痛感**（[[税收痛感与政治可行性]]）
- 化石燃料利益集团反对
- 累退性争议（[[碳税的累退性]]）

### 难点 3：单边问题

单国征税可能导致 [[碳泄漏]]：
- 高碳产业转移到无税国
- 全球总排放可能不降

→ 需要 [[碳边境调节机制CBAM|碳边境调节]]

## 庇古税 vs 排放交易

详见 [[碳税vs排放交易]]。简要：

| 维度 | 庇古税 | 排放交易 |
|---|---|---|
| 政策变量 | 价格 | 数量 |
| 不确定性 | 数量不定 | 价格不定 |
| 收入归属 | 政府 | 拍卖时归政府 |
| Weitzman 定理 | 损害函数陡时优 | 减排成本陡时优 |

## 反面论点与数据空白

- **理论简洁 vs 实施复杂**：庇古定理 t = E 简洁，但 E 测算分歧极大
- **次优问题**：现实税制有其他扭曲（劳动税等），单加碳税可能不是最优（→ [[双重红利假说]]）
- **行为经济学反驳**：消费者对价格信号的反应可能弱于理论预测（[[初始成本偏差]]）
- **规制 vs 税收的稳定性**：[[环境政策的稳定性]] 显示规制更稳，但效率较低
- **科斯反驳**：[[科斯定理]] 主张低交易成本下私人协商可达最优——不需政府
