# EKC 实证检验

> Empirical Tests of the Environmental Kuznets Curve

EKC 假说在不同环境指标上表现不一：CO₂/GDP 显示倒 U，但 CO₂ 总量持续上升；PM2.5 在所有收入水平均下降——不遵循 EKC。Nordhaus 谨慎对待 EKC 的政策含义。

## 各指标的检验结果

### 1. CO₂ 强度（CO₂/GDP）：✓ 支持 EKC

图 14.2 显示明显倒 U：
- 转折点：~$15,000 人均 GDP
- 大多数国家遵循

但 Nordhaus 警告：
> 虽然图 14.2 中的环境库兹涅茨曲线看起来是倒 U 形的，但如果采取其他指标，则会有不同的结果。

### 2. CO₂ 总量：✗ 不支持 EKC

> 例如，如果图 14.2 的纵轴换成总碳排放量，我们会发现曲线无时无刻不在上升。

全球 CO₂ 总量从 1990 到 2020 持续上升——即使发达国家强度下降，总量仍增加。这是因为：
- 发达国家强度下降 < 全球 GDP 增长
- 发展中国家排放快速增长
- 富裕国家的"减排"部分通过碳泄漏（向发展中国家转移生产）

### 3. PM2.5：✗ 不支持 EKC

Nordhaus Ch 14：
> 最近的数据表明，颗粒物浓度并不遵循库兹涅茨曲线。相反，从 1990 年到现在，主要国家在各个产出水平上的细颗粒物浓度都在下降。

数据：
- 2010 年最贫穷 20 国平均 PM2.5：41 μg/m³
- 2010 年最富裕 20 国平均 PM2.5：14 μg/m³
- 但所有国家都在下降——不分发展阶段

→ PM2.5 的下降不依赖经济发展水平，而是技术扩散 + 政策学习的结果。

### 4. 生物多样性：✗ 不支持 EKC

物种灭绝率在所有收入水平国家均上升——经济发展并未"自然修复"生物多样性。

### 5. 局部空气污染（SO₂、NOx、TSP）：部分支持

EKC 的早期研究主要基于这些指标——通常显示倒 U（转折点在人均 GDP $5,000-$10,000）。

## EKC 适用性的总结

| 指标 | EKC 是否成立 |
|---|---|
| 局部空气污染（SO₂, NOx）| 部分支持 |
| CO₂ 强度 | 支持（转折点 ~$15,000） |
| CO₂ 总量 | 不支持 |
| PM2.5 | 不支持（所有水平均下降） |
| 水污染（BOD）| 部分支持 |
| 生物多样性 | 不支持 |
| 自然栖息地 | 不支持 |

## 经济发展水平 vs 民主水平

Nordhaus Ch 14 进一步分析：环境改善与"民主水平"的相关性可能比与"GDP 水平"的相关性更强。

详见 [[民主与环境质量]]。

## 政策含义

EKC 实证检验的政策含义：
1. **不能依赖"自动转折"**：CO₂ 总量仍在上升 → 必须主动减排
2. **PM2.5 改善不需等富裕**：发展中国家可直接采用清洁技术
3. **生物多样性需特殊保护**：经济发展不能修复物种灭绝
4. **政策可加速 EKC**：监管 + 技术 → 转折点可前移

## 反面论点与数据空白

- **指标选择影响结论**：EKC 支持者偏好显示倒 U 的指标，反对者偏好显示上升的指标——双方各取所需
- **样本偏差**：EKC 研究多基于发达国家的纵向数据——能否外推到发展中国家不清楚
- **气候临界点**：即使 CO₂ 强度下降，如果总量越过临界点，"EKC 转折"将无意义
