# 真实储蓄率

> Genuine Savings / Adjusted Net Saving (ANS)

世界银行自 1997 年起发布的可持续性指标：净储蓄 + 教育支出 - 自然资本折旧。捕捉国家的"真实"资本积累——既包括有形资本，也包括人力资本和自然资本。

## 计算公式

$$
\text{ANS} = \text{Gross Saving} - \text{Consumption of Fixed Capital} + \text{Education Expenditure} - \text{Natural Resource Depletion} - \text{Pollution Damage}
$$

简化为：

$$
\text{真实储蓄} = \text{净储蓄} + \text{人力资本投资} - \text{自然资本折旧}
$$

## 五个组分

1. **总储蓄**（Gross Saving）：国民收入未消费部分
2. **固定资本消耗**（Consumption of Fixed Capital）：有形资本的折旧
3. **教育支出**（Education Expenditure）：作为人力资本投资的代理
4. **自然资源消耗**（Natural Resource Depletion）：化石燃料、矿物、森林的消耗
5. **污染损失**（Pollution Damage）：CO₂ 和 PM₁₀ 的健康成本

## 政策含义

- **ANS > 0**：国家整体在积累资本（有形 + 人力 + 自然），可持续
- **ANS < 0**：国家正在消耗资本存量，不可持续
- **ANS / GNI（占国民总收入的比例）**：可持续性强度的国际比较

## 跨国数据（2018 年大致比较）

| 国家 | ANS / GNI | 类型 |
|---|---|---|
| 中国 | ~25% | 高储蓄 + 教育投资强 |
| 德国 | ~12% | 平衡型 |
| 美国 | ~5% | 储蓄低、自然消耗中等 |
| 沙特阿拉伯 | -10%~+5% | 资源依赖；高油价时正、低油价时负 |
| 尼日利亚 | ~-15% | 资源密集 + 教育不足 |

资源依赖型国家的 ANS 通常较低或为负——出售自然资本但未充分转化为人造资本。

## 与 Solow 标准的关系

ANS > 0 是 [[Solow可持续性标准]] 的**必要但不充分**条件：
- 必要：总资本不下降
- 不充分：还需要资本结构合理（如关键自然资本不应被替代）

## 反面论点与数据空白

- **教育支出 ≠ 人力资本**：低质量教育的支出可能不增加实际人力资本（很多发展中国家教育支出有效性低）
- **自然资源消耗的估值问题**：油价波动使资源消耗的货币化波动巨大——同一国家在 2014（高油价）与 2016（低油价）的 ANS 可能差异巨大
- **气候损害未充分计入**：ANS 不计入未来气候变化的存量损失——可能低估自然资本耗减
- **ANS 改善 ≠ 福利改善**：即使 ANS > 0，分配不平等加剧可能使大多数人福利下降
