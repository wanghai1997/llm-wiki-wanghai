# Kantian 和平

> Kantian Peace

民主国家之间不易开战的经验规律。Nordhaus 论证战争是环境的死敌，因此民主对环境有间接但重要的贡献——通过减少战争。

## 概念起源

康德 1795 *Perpetual Peace*：共和制（民主）国家因人民承担战争成本而不愿对外用兵。后经 Doyle 1983 等政治学家系统化，形成"民主和平论"（Democratic Peace Theory）。

实证：
- 1815 年以来，两个完全民主国家几乎从未直接交战
- 民主-非民主国家间冲突仍频繁
- 非民主国家间冲突最频繁

## Nordhaus 的环境关联

Ch 14：
> 你可能认为康德式和平与环境问题相去甚远，但事实上战争是环境的死敌。实际上，对人类和全球来说，最糟糕的结果无非是一场大规模的核战争和"核冬天"。

战争对环境的伤害：
1. **直接**：轰炸、化学武器、生态破坏
2. **能源消耗**：军事是最大的化石燃料消耗者之一（美国军队是全球最大单一石油消费者）
3. **机会成本**：军费挤压环保预算
4. **核冬天风险**：大规模核战争的全球气候后果

## 战争死亡率的下降（图 14.1）

Nordhaus 用 1946-2013 数据：
- 1946-50：战争死亡率 ~25/10万人
- 2010s：战争死亡率 ~1/10万人
- 下降约 25 倍

主要解释：
- 民主国家数量增加（从 ~25% 到 ~50%）
- 国际机构（UN）的介入
- 核武器的"恐怖平衡"
- 全球贸易增加战争成本

## 民主-和平-环境的因果链

```
民主扩散 → 民主和平 → 战争减少 → 环境保护改善
        → 言论自由 → 环境问题暴露 → 政策改善
        → 国际合作 → 全球协议 → 全球公共品供给
```

## 当代挑战

Kantian 和平在 21 世纪受到挑战：
- 俄乌战争（2022-）：部分民主国家间冲突（俄罗斯民主指数下降，乌克兰相对民主）
- 美中战略竞争：可能不直接战争但贸易战 + 技术冷战
- 气候诱发冲突：水资源、移民引发的区域冲突

→ 即使 Kantian 和平在主要国家间维持，气候+冲突的级联风险增加。

## 反面论点与数据空白

- **统计样本小**：完全民主-完全民主国家对的样本量小——Kantian 和平的实证显著性受质疑
- **民主的衡量**：使用不同的"民主"测度（Polity、Freedom House、V-Dem）得到不同结果
- **冷战的反证**：1980s 越南战争中"美国（民主）"vs"越南（民主集中制）"——分类争议
- **民主退化风险**：2020s 民主指数全球下降——若民主衰退，Kantian 和平可能失效
- **"核冬天"的不确定性**：大规模核战争的气候后果模型不一致——Robock-Toon 2010 估计大规模核战可使全球温度下降数年
