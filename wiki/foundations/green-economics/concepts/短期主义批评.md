# 短期主义批评

> Critique of Short-termism

企业过度关注季度财报、忽视长期价值——这种"短期主义"被认为是 ESG 失效、环境损害、研发不足的根源。Nordhaus 在 Ch 20 部分采纳此批评，但与 ESG 倡导者保持距离。

## 短期主义的定义

### 经典版本

> 管理层为短期股价/财报美化，牺牲长期股东价值或社会福祉的行为。

**典型表现**：
- 削减 R&D 投入提升当季利润
- 推迟必要的资本支出
- 过度回购股份提升 EPS
- 隐藏长期成本（环境、健康）

### 度量

短期主义的常用指标：
- 公司 R&D / 销售比例下降
- 资本投资 / 折旧比下降
- 股票回购 / 净利润比上升
- 股权激励的持有期短

## Nordhaus 的核心立场

> 企业应避免短期主义……应该从长远角度考虑什么能提高盈利能力和股东价值，这涉及构建管理层的激励机制。

→ Nordhaus：**支持长期主义但不放弃股东价值框架**。

### 关键区别：长期股东价值 ≠ ESG 利益相关者主义

```
立场 A：Friedman 命题
  → 短期股东价值最大化

立场 B：Nordhaus 修正
  → 长期股东价值最大化（隐含 ESG 元素）

立场 C：利益相关者主义
  → 多方利益平衡（不限于股东）
```

→ Nordhaus 主张 B，反对 A 和 C 的极端版本。

## 短期主义的源头

### 1. 季度报告制度

- 美国 SEC 要求季度财报（10-Q）
- 媒体 + 分析师密切关注
- 不达预期 → 股价下跌
- → 强化季度视角

### 2. 高管激励结构

- 股票期权 + 短期奖金
- 绩效与季度业绩挂钩
- → 鼓励"做账"而非"建造"

### 3. 机构投资者

- 共同基金、对冲基金的高换手率
- 平均持股期 ~6-12 个月
- → 难以为长期价值定价

### 4. 公司治理脆弱

- 董事会被动
- 高管任期短（CEO 平均 ~5 年）
- → 后任承担前任决定的代价

### 5. 财务工程

- 股票回购替代资本投资
- "调整后 EBITDA" 等会计变换
- → 数字游戏掩盖真实状况

## 实证：短期主义的指标

### R&D 强度下降

美国上市公司：
- R&D / 销售 1979：~3%
- R&D / 销售 2019：~5% 但集中于科技
- 传统行业 R&D 投入下降明显

### 股票回购上升

S&P 500 公司：
- 回购 / 净利润 1980s：~10%
- 回购 / 净利润 2010s：~50-60%
- → 现金流流向股东而非投资

### 资本支出下降

- CAPEX / 折旧比从 1.5 下降至 1.0
- 意味着资本存量逐渐萎缩

## 短期主义与环境议题

### 直接联系

- 长期环境投资被推迟
  - 排放控制设备
  - 节能改造
  - 清洁能源转型

### 间接联系

- 短期目标 → 削减合规支出
  - 大众柴油事件（[[大众汽车排放门]]）
  - BP 安全削减 → Deepwater Horizon
- 风险溢价不足
  - 气候过渡风险被低估

### 数据支持

- 公司 R&D / 销售 与碳强度负相关（部分研究）
- 长期股东主导的公司 ESG 表现更好

## 解决方案的争论

### 1. 监管路径

- 强制气候披露（SEC, ISSB）
- 长期任期奖励
- 限制股票回购
- → Nordhaus 部分支持

### 2. 治理路径

- 增加独立董事
- 强化审计委员会
- 长期持股比例要求
- → 实证效果有限

### 3. 投资者活动

- 长期持有者联盟
- ESG 整合投资策略
- 股东参与
- → 占总市场比例小

### 4. 取消季度报告

- 英国 2014 取消强制季度报告
- 部分研究显示短期主义指标改善
- → 但效应有限

## Nordhaus 的细致批评

### 同意的部分

> 长期股东价值受短期主义损害，这是显而易见的。

- 短期主义损害长期回报
- 需要治理改革
- 监管可以提供帮助

### 保留的部分

> 但批评短期主义不应被滥用为"做任何事都对"的借口。

- 不能用"长期"逃避当前责任
- 不能用 ESG 旗帜美化效率低下
- 长期承诺也需要短期纪律

### 与 [[Friedman企业目标命题]] 的对话

Friedman 1970 原文实际包含"在法律和道德框架内"——这暗含长期视角。
Nordhaus 同意此立场，反对 Friedman 命题的简化版本（"不择手段赚钱"）。

## 短期主义的辩护者

### 反命题：短期主义被夸大

- 短期反应市场效率的体现
- 季度纪律抑制管理层挥霍
- 长期承诺也常被滥用

### 引用：Roe 2018 的批评

- "短期主义"概念缺乏统一定义
- 多数实证研究证据弱
- "长期主义"可能掩盖低效

→ 学界仍在辩论。

## 中国语境

### "长期主义"在中国

- 国资委对央企的长期考核
- 创业板/科创板的减持限制
- 上市公司分红规则
- → 但 ESG 披露起步较晚

### 互联网企业的短期 / 长期

- 阿里、腾讯 R&D 投入大但回购也增加
- 美团、拼多多前期亏损追求规模
- → 短期 / 长期界限模糊

## 反面论点与数据空白

- **概念模糊**：什么是"短期"？6 个月、1 年、5 年？
- **测量困难**：R&D 下降可能是行业转型，不是短期主义
- **长期主义滥用**：高管也可用"长期"逃避当前问责
- **股东 vs 利益相关者**：长期股东价值 vs 多方利益平衡——仍存矛盾
- **政治化**：美国"反觉醒资本主义"将批评 ESG 政治化
- **行业差异**：制药、半导体的"长期"是 10-20 年，零售可能 1-2 年
