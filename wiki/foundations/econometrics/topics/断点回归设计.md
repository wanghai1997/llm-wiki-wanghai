# 断点回归设计

> Ch 4 导览页：连接 [[断点回归RD]] 的两个案例和方法论。

## 为什么 RD 强大

在 Furious Five 中，RD 经常被认为是**仅次于 RCT 的因果推断方法**——因为在断点附近，处理的分配几乎是"如其随机的"。RD 的因果声称被认为比回归/匹配和 IV（排他性约束更不可检验）更可信。

## RD 的逻辑

```
Running Variable: ──X────────[cutoff]────────X──→
                        ↓
               左：无处理    右：有处理
                        ↓
         断点处比较 ≈ 局部随机实验
```

只要个体不能**精确操纵**自己落在截断哪一侧，断点附近就是一个"局部 RCT"。

## 两种 RD 变体

| | Sharp RD | Fuzzy RD |
|---|---|---|
| 截断处处理变化 | 0 → 1（确定性地） | 概率跳变（不确定） |
| 识别 | 断点处 ATE | 断点处 LATE（需要 IV） |
| 案例 | [[MLDA饮酒年龄RD案例\|MLDA]] | [[波士顿拉丁学校RD案例\|波士顿拉丁学校]] |

## 关键实践选择

- **带宽**：小 → 低偏差/高方差，大 → 高偏差/低方差
- **函数形式**：局部线性（推荐）vs 高次多项式（有风险）
- **操纵检验**：McCrary 密度检验
- **稳健性**：报告多带宽结果

## RD 的边界

- **仅识别局部效应**——断点以外一概不知
- **外部有效性受限**——21 岁的 MLDA 效应≠18 岁的 MLDA 效应
- **断点可能被操纵**——如果个体能精确控制 running variable
