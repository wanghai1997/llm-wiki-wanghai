# 双重差分与面板方法

> Ch 5 导览页：连接 [[双重差分DiD]] 的两个案例和方法论。

## 为什么 DiD 无处不在

DiD 是应用微观经济学中**使用最广泛**的因果识别方法——因为它只需要**面板数据或重复横截面数据**+**政策/事件的时间-地点变异**，而不需要工具变量或断点的特殊制度条件。

## DiD 的核心逻辑

```
处理组：      Pre ────── Post
               │           │
               │  处理效应  │  总变化 = 趋势 + 处理
               │     +      │
               │  时间趋势  │
               ↓           ↓
控制组：      Pre ────── Post
                           总变化 = 趋势（无处理）
                           
DiD = 处理组变化 - 控制组变化 = 处理效应
```

## 两个案例的 DiD 结构

| | 大萧条银行危机 | MLDA DiD |
|---|---|---|
| **处理组** | 第六区银行 | MLDA 改变的州 |
| **控制组** | 第八区银行 | MLDA 未改变的州 |
| **处理前** | 1929 | MLDA 改变前 |
| **处理后** | 1933 | MLDA 改变后 |
| **结果** | 银行/企业破产、销售 | 18-20 岁死亡率 |
| **关键假设** | 两区趋势在无处理时平行 | 各州趋势在无处理时平行 |

## 平行趋势假设

[[平行趋势假设]] 是 DiD 的核心识别假设——**不可直接检验**但可通过以下方式间接支持：
- 处理前趋势图
- 事件研究法（加入处理前的 leads）
- 伪结果检验

## DiD 的当代发展和挑战

- **交错处理 DiD**：Goodman-Bacon (2021) 揭示了传统双向固定效应在交错处理下的问题
- **新 DiD 方法**：Callaway-Sant'Anna (2021)、Sun-Abraham (2021) 等
- **合成控制法**：Abadie-Gardeazabal (2003) 作为 DiD 的推广

## DiD 的边界

- **依赖平行趋势假设**——不可直接检验
- **时变混淆**——处理期间发生的其他事件可能被错误归因
- **仅识别 ATT**（处理组的处理效应）——不是 ATE
