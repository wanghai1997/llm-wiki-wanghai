# 运行变量与带宽选择

## 一句话定义

> **Running Variable** = 决定处理分配的连续变量（如年龄、考试分数、收入）。**Bandwidth** = RD 分析中截断点附近用于估计的窗口宽度——两者共同决定 RD 估计的**偏差-方差权衡**。

## 运行变量的性质

| 性质要求 | 为什么重要 |
|---------|-----------|
| **连续性** | 个体不能精确操纵自己落在截断的哪一侧 → 断点附近是"局部随机"的 |
| **可测量** | 精确地知道每个个体离截断点有多远 |
| **不可操纵** | McCrary (2008) 检验——截断点处的密度应该连续，不应出现"恰好过线的人异常多" |

### 可操纵性的检验

McCrary 检验：在截断点处检查 running variable 的密度函数是否存在跳跃——如果存在，说明有人在"操纵"自己落在哪一侧（如考试补考刚好过线）。

## 带宽选择

带宽是 RD 实践中**最关键也最具争议的选择**：

| 带宽 | 偏差 | 方差 |
|------|------|------|
| **大带宽** | ↑（远离断点的个体可能系统性地不同） | ↓（更多数据 → 更精确） |
| **小带宽** | ↓（更接近"局部随机"的理想） | ↑（更少数据 → 更不精确） |

### 选择方法

1. **交叉验证 (Cross-validation)**：将数据分成训练集和测试集，选择最小化预测误差的带宽（Imbens-Kalyanaraman 2012）
2. **Calonico-Cattaneo-Titiunik (CCT) 最优带宽**：基于均方误差最小化的数据驱动选择
3. **稳健性检验**：报告**多个带宽**下的估计结果——如果结论对带宽不敏感，增强可信度
4. **"甜甜圈" RD**：排除恰好落在截断点上的个体（如果怀疑精确操纵）

## 反面论点与数据空白

- **带宽选择的"自由度"**：研究者可能选择恰好产生显著结果的带宽——预注册（pre-registration）和预分析计划是部分解决方案。
- **局部线性 vs 全局多项式**：Gelman-Imbens (2019) 强烈建议不使用高次多项式——容易在断点远处产生奇怪的行为并影响断点处的估计。
- **多维 running variable**：当处理由多个连续变量的组合决定时（如综合评分），RD 需要推广到多维——理论和实践仍在发展中。
