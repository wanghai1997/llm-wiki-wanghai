# 控制函数方法

## 一句话定义

> **控制函数 (CF)** = 通过在结果方程中**显式加入内生性的代理项**（如第一阶段残差）来消除内生性——IV 是 CF 的一个特例，CF 可以处理更一般的非线性内生模型。

> **前置阅读**：[[工具变量IV]]（MM）/ [[两阶段最小二乘法2SLS]]（MM）。

## CF 与 IV/2SLS 的关系

- **2SLS 是线性的 CF**：第二阶段中的第一阶段残差 $\hat{v}$ 就是"控制函数"——控制它之后 $x$ 的外生变异被隔离
- **CF 超越 2SLS**：在非线性模型中（如 Probit with endogenous regressor），2SLS 的"代入预测值"方法失效——CF 仍适用

## CF 的一般步骤

1. **第一阶段**：$x_{endo} = \pi_0 + z\boldsymbol{\pi}_1 + \mathbf{x}_{exo}\boldsymbol{\pi}_2 + v$ → 获得残差 $\hat{v}$
2. **第二阶段**：$y = x_{endo}\beta + \mathbf{x}_{exo}\boldsymbol{\gamma} + \rho \hat{v} + \varepsilon$
   - 在线性模型中：$\hat{\beta}$ 精确等于 2SLS 估计量
   - 在非线性模型中（如 Probit）：加入 $\hat{v}$ 使内生变量被"净化"

## CF 什么时候优于 IV

| 情境 | IV/2SLS | CF |
|------|---------|-----|
| 线性模型 + 连续内生变量 | ✅（完全等价） | ✅ |
| 非线性模型 (Logit/Probit) + 内生变量 | ❌（"禁止回归"） | ✅ |
| 内生变量是二值的 | ✅（Wald/LATE） | ✅（可更有效地估计） |
| 需要估计 ATT（不只是 ATE） | 有限 | ✅（可以识别 ATT） |

## CF 中的内生转换模型

当处理是二值变量时：

$$y_1 = x\boldsymbol{\beta}_1 + u_1 \quad \text{（如果处理 = 1）}$$
$$y_0 = x\boldsymbol{\beta}_0 + u_0 \quad \text{（如果处理 = 0）}$$

处理方程：$D^* = z\boldsymbol{\gamma} + v$

CF 方法：
1. 从处理方程获得广义残差
2. 将广义残差加入结果方程
3. → 识别 ATT（处理组的处理效应）和 ATE

## 反面论点与数据空白

- **CF 对第一阶段模型的函数形式假设更敏感**：在非线性模型中，CF 的一致性依赖于第一阶段的正确指定（包括 $v$ 的分布假设）。
- **CF 的"残差生成器"问题**：$\hat{v}$ 是**估计的**残差而非**真实的** $v$——在非线性模型中这会传导额外的变异到第二阶段。
