# 多期面板的差分法

## 一句话定义

> 当面板有 $T > 2$ 期时，**一阶差分**可以推广为有 $T-1$ 个差分方程的**差分面板回归**——FD 估计量在所有时期上的加权版本。

## 从两期到多期

对于 $T$ 期面板（$t = 1, 2, ..., T$）：

$$\Delta y_{it} = \beta_1 \Delta x_{it} + \Delta u_{it}, \quad t = 2, 3, ..., T$$

- 每个个体贡献 $T-1$ 个观测（所有相邻期的差分）
- 需要加入**时期虚拟变量**以控制共同的时间效应：
  $$\Delta y_{it} = \theta_t + \beta_1 \Delta x_{it} + \Delta u_{it}$$

## 多期 FD 的关键假设

- **严格外生性**：$E(u_{it} | x_{i1}, x_{i2}, ..., x_{iT}, a_i) = 0$
  - 这意味着**任何时期**的 $x$ 与**任何时期**的 $u$ 不相关——比同期外生性强得多
  - 排除"反馈效应"——如 $y_{t-1}$ 影响 $x_t$

- **差分后的误差必须无序列相关**：否则 OLS 标准误不可靠 → 使用聚类标准误（对个体聚类）

## FD vs FE（固定效应）

在多期面板中：

| | FD | FE (Within) |
|---|---|---|
| 变换 | $y_{it} - y_{i,t-1}$ | $y_{it} - \bar{y}_i$（减去个体均值） |
| 在 $T=2$ 时 | = FE | = FD |
| 在 $T>2$ 时 | 不等价于 FE | 在无序列相关的严格外生下两者同等地一致 |
| 如果误差是随机游走 | FD 更有效（$\Delta u$ 无序列相关） | FE 的变换误差有序列相关 |
| 对小 $T$ 的适用性 | 好（丢失 1 期） | 好 |

## 政策分析的扩展——多期面板 DiD

加入处理变量在时间和个体维度的变异：

$$\Delta y_{it} = \delta \Delta D_{it} + \mathbf{\Delta x}_{it}'\boldsymbol{\gamma} + \Delta u_{it}$$

$\delta$ = 政策状态从 0 变为 1 的个体的 $y$ 变化，减去政策状态不变的个体的 $y$ 变化 → 个体 FE 版本的 DiD。

## 反面论点与数据空白

- **聚类标准误的必要性**：差分后的误差可能在个体内自动相关——必须使用聚类标准误（对个体 ID 聚类）。
- **不平衡面板**：某些个体在某些时期缺失 → FD 会丢失更多观测（因为需要连续两期数据）。
