# 面板数据在政策分析中的应用

## 一句话定义

> 面板数据为政策评估提供了三种关键方法：**FD/ FE DiD**（消除个体异质性）、**广义 DiD**（多期多组）和**事件研究面板**（动态处理效应）——比纯横截面方法更可信。

## 方法 1：双向 FE 的 DiD

$$y_{it} = \alpha_i + \lambda_t + \delta D_{it} + \mathbf{x}_{it}'\boldsymbol{\beta} + u_{it}$$

- $\alpha_i$ = 个体 FE（控制所有不随时间变化的个体差异）
- $\lambda_t$ = 时间 FE（控制所有个体共同的时期效应）
- $D_{it}$ = 处理虚拟变量（个体 $i$ 在时期 $t$ 是否被处理）
- $\delta$ = DiD 处理效应

→ 这是当代实证研究中**最常见**的政策评估模型。

## 方法 2：事件研究面板（Event-Study Panel）

$$y_{it} = \alpha_i + \lambda_t + \sum_{k=-m, k\neq -1}^{q} \delta_k D_{it}^k + u_{it}$$

其中 $D_{it}^k$ = 距处理发生还有 $k$ 期的虚拟变量。

- **预处理期虚拟（leads）**：$\delta_{-2}, \delta_{-3}, ...$ 应该 ≈ 0（平行趋势检验）
- **后处理期虚拟（lags）**：$\delta_0, \delta_1, \delta_2, ...$ = 处理效应的**动态路径**

→ 事件研究法不仅估计"平均处理效应"，而且追踪效应如何**随时间演变**。

## 方法 3：带协变量的面板政策评估

在 DiD/FE 中加入时间变化的控制变量：
- 控制**时变的混淆因素**（如随时间的收入变化、城市化等）
- **警告**：控制变量必须不受处理影响——否则引入 [[Bad-Controls问题|坏控制偏差]]

## 面板政策评估的关键挑战

| 问题 | 解决方案 |
|------|---------|
| 序列相关 → SE 低估 | 聚类标准误（对个体） |
| 处理在不同时间实施 | [[Callaway-Sant'Anna (2021)]] 等交错处理 DiD 方法 |
| 个体在政策实施前就有预期 | 加入"处理前 leads"来检验 |
| 处理效应随时间变化 | 事件研究法 + 动态处理效应 |

## 反面论点与数据空白

- **双向 FE 在交错处理下的问题**：Goodman-Bacon (2021) 证明，在个体在不同时间接受处理的设定下，传统双向 FE 的 $\hat{\delta}$ 是多个 2×2 DiD 的加权平均——可能包含负权重（"已经在处理的组"作为"还未经处理的组"的控制组时）。
- **面板数据中的耗损 (Attrition)**：个体可能因死亡、迁移、拒答而退出面板——如果耗损与处理相关 → FE 估计可能有偏。
