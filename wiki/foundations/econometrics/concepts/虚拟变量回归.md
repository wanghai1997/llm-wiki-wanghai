# 虚拟变量回归

## 一句话定义

> **虚拟变量 (Dummy Variable)** = 取值为 0/1 的变量，用于将**定性信息**（性别、地区、政策是否实行）纳入回归模型——通过虚拟变量可以比较**不同组之间的截距和斜率**。

## 截距虚拟变量

$$y = \beta_0 + \delta_0 D + \beta_1 x + u$$

- $D = 0$ 组：截距 = $\beta_0$
- $D = 1$ 组：截距 = $\beta_0 + \delta_0$
- $\delta_0$ = 两组在 $y$ 上的差异（**给定 $x$ 相同**）

> 如果将定性变量编码为 1/2/3 而非 0/1 → 错误地假设了类别之间的等距效应。

## 交互虚拟变量（不同斜率）

$$y = \beta_0 + \delta_0 D + \beta_1 x + \delta_1 (D \cdot x) + u$$

- $D = 0$ 组：$\frac{\partial y}{\partial x} = \beta_1$
- $D = 1$ 组：$\frac{\partial y}{\partial x} = \beta_1 + \delta_1$
- $\delta_1$ 检验的是：**$x$ 对 $y$ 的效应是否因组而异**

## Chow 检验——跨组回归是否不同

**问题**：一个回归函数对两组是否相同？

$$H_0: \text{两组的所有系数相等}$$

**方法**：
1. 估计合并模型（限制所有系数跨组相等）→ SSR_p
2. 分别估计每组自己的回归 → SSR_1 + SSR_2 = SSR_{ur}
3. $F = \frac{(\text{SSR}_p - \text{SSR}_{ur}) / (k+1)}{\text{SSR}_{ur} / (n - 2(k+1))}$
4. $F$ 大 → 拒绝同质性 → 两组确实不同

## 多类别虚拟变量

如果有 $g$ 个类别，加入 $g-1$ 个虚拟变量（基准组 = 全为零）：
- $\beta_j$ = 第 $j$ 类与基准组的差异
- 不能加入全部 $g$ 个虚拟变量 → 虚拟变量陷阱（完美共线性）

## 反面论点与数据空白

- **虚拟变量假设效应是"平移"**：截距虚拟只允许平移——如果处理改变分布的形状而不仅仅是位置，虚拟变量不够。
- **交互虚拟的正确解释**：加入交互后，主效应对应的系数是"当另一变量为零时"的效应——如果零不符合情境（如 $x=0$ 不在数据范围内），主效应的系数没有实质性意义。
