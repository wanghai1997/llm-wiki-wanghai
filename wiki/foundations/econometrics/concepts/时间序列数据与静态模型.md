# 时间序列数据与静态模型

## 一句话定义

> **时间序列数据** = 一个个体（国家/企业/个人）在多个时点上的观测值序列——核心特征是观测值之间存在**时间顺序**依赖，而不仅是随机抽样。

## 时间序列的基本特征

- **时间索引**：$t = 1, 2, ..., T$（频率可能是年/季/月/日）
- **数据频率**：决定了分析的时间单位
- **非独立**：$y_t$ 和 $y_{t-1}$ 相关的概率远高于横截面数据

## 静态模型 (Static Model)

$$y_t = \beta_0 + \beta_1 x_t + u_t$$

- $y_t$ 和 $x_t$ 标有相同的时间下标——同期的 $x$ 影响同期的 $y$
- **静态 ≠ 无动态**——误差 $u_t$ 可能包含序列相关
- 例子：Phillips 曲线的静态形式——本期通胀 = $\beta_0 + \beta_1$ 本期失业 + $u_t$

## 有限分布滞后模型 (FDL)

$$y_t = \beta_0 + \delta_0 x_t + \delta_1 x_{t-1} + \delta_2 x_{t-2} + ... + \delta_q x_{t-q} + u_t$$

- **冲击的传播**：$x$ 的变动对 $y$ 的影响分布在 $q+1$ 个时期内
- **冲击倾向 (Impact Propensity)** = $\delta_0$（当期效应）
- **长期倾向 (Long-Run Propensity, LRP)** = $\sum_{j=0}^q \delta_j$（累积效应）
- 例子：货币供给增加对 GDP 的影响分布在多个季度内

## 时间索引约定

Wooldridge 的约定：所有观测值应从同一日历时间开始。如果 $t=1$ 表示 1970 年，那么 $x_{t-1}$ 表示 1969 年——**滞后变量必须有对应的数据可查**。

## 反面论点与数据空白

- **静态模型通常是过于简化的**：经济行为几乎永远是动态的——期望、调整成本、惯性意味着过去值影响现在。
- **FDL 的 $q$ 需要主观选择**——$q$ 太小遗漏长期效应，$q$ 太大多重共线性使估计不稳定。
