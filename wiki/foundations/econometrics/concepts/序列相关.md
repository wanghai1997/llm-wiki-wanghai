# 序列相关

## 一句话定义

> **序列相关（自相关）** = 误差项在不同时点之间存在相关性：$\text{Cov}(u_t, u_{t-h}) \neq 0$——使 OLS 的**标准误和推断失效**，但不导致偏差或不一致性（在严格外生性下）。

## 对 OLS 的影响

| 性质 | 受影响？ |
|------|---------|
| 无偏性 | **否**（TS.3 保证） |
| 一致性 | **否**（TS.3 + 弱相依保证） |
| 标准误 | **是**——通常被**严重低估** |
| $t/F$ 检验 | **是**——过度拒绝（实际显著性水平 > 名义） |
| BLUE | **是**——OLS 不再是 BLUE |

## 常见的序列相关形式

### AR(1) 误差

$$u_t = \rho u_{t-1} + e_t, \quad |\rho| < 1$$

- $\rho > 0$（正序列相关）：最常见——一个时期的正冲击倾向于持续
- $\rho < 0$（负序列相关）：罕见——过冲后迅速反转
- 例子：GDP 冲击有持续性——如果上季度高于趋势，本季度也可能高于趋势

### 高阶 AR(p) 和 MA(q)

$$u_t = \rho_1 u_{t-1} + \rho_2 u_{t-2} + ... + \rho_p u_{t-p} + e_t$$

更灵活的序列相关结构——多用于金融数据和季节性数据。

## 检验

### AR(1) 的 t 检验

1. 从 OLS 获得残差 $\hat{u}_t$
2. 将 $\hat{u}_t$ 对 $\hat{u}_{t-1}$（及其他必要控制）回归
3. 检验 $\hat{\rho}$ 是否显著 → 如果是 → 拒绝无序列相关的 $H_0$

### Durbin-Watson (DW) 检验

- **经典检验**——在严格外生回归子下有效
- DW ≈ 2 - 2$\hat{\rho}$
- DW ≈ 2 → 无序列相关；DW 远离 2 → 有序列相关
- **不适用**于有滞后因变量的模型（此时需 Durbin's h 检验）

### Breusch-Godfrey (LM) 检验

- 可以检验**高阶**序列相关（AR(p) 而非仅 AR(1)）
- 不要求严格外生性——在有滞后因变量时仍可用
- **实际中最推荐的序列相关检验**

## 存在滞后因变量时的序列相关

当模型包含 $y_{t-1}$ 作为解释变量时：
- **序列相关 ≠ 仅推断无效**——OLS 变为**不一致**！
- 因为 $y_{t-1} = \beta_0 + \beta_1 x_{t-1} + ... + u_{t-1}$ → 如果 $\text{Cov}(u_t, u_{t-1}) \neq 0$ → $y_{t-1}$ 与 $u_t$ 相关 → **MLR.4/TS.3 被违反**

## 反面论点与数据空白

- **序列相关"标准误被严重低估"的幅度可能非常大**——Bertrand-Duflo-Mullainathan (2004) 发现 DiD 中的序列相关可使拒绝率从 5% 膨胀到 45% 以上。
- **序列相关修正 (FGLS) 可能比修正前更不可靠**——如果序列相关模型错了，FGLS 的推断同样失效。
