# 随机效应估计

## 一句话定义

> **随机效应 (RE)** = 假设 $a_i$ 与解释变量**不相关**——比 FE 更强的假设，但在此假设下 RE 比 FE **更有效**，且可以识别**不随时间变化的变量**的效应。

## RE 模型

$$y_{it} = \beta_0 + \beta_1 x_{it} + a_i + u_{it}$$

与 FE 的区别：RE 假设 $\text{Cov}(x_{it}, a_i) = 0$——即个体异质性与解释变量无关。

## 为什么 RE 更有效

在 RE 假设下，复合误差 $v_{it} = a_i + u_{it}$ 是序列相关的（因为 $a_i$ 在所有期相同）：

$$\text{Corr}(v_{it}, v_{is}) = \frac{\sigma_a^2}{\sigma_a^2 + \sigma_u^2}, \quad t \neq s$$

→ GLS（广义最小二乘）利用这个相关结构，比 OLS（或 FE）更有效。

RE 估计 = Quasi-demeaned 数据的 OLS：

$$y_{it} - \lambda \bar{y}_i = \beta_0(1 - \lambda) + \beta_1(x_{it} - \lambda \bar{x}_i) + (v_{it} - \lambda \bar{v}_i)$$

其中 $\lambda = 1 - \sqrt{\frac{\sigma_u^2}{\sigma_u^2 + T\sigma_a^2}}$

- $\lambda \to 1$（$\sigma_a^2 \gg \sigma_u^2$）：RE → FE（个体间差异主导）
- $\lambda \to 0$（$\sigma_a^2 \ll \sigma_u^2$）：RE → Pooled OLS（忽略个体异质性）

## FE vs RE

| | FE | RE |
|---|---|---|
| $\text{Cov}(x_{it}, a_i)$ 的假设 | **任何** | **必须 = 0** |
| 时间不变变量的效应 | **不能识别** | **可以识别** |
| 效率 | 在 RE 有效时不如 RE | **更高**（利用了个体间的变异） |
| 风险 | 如果 $x_{it}$ 几乎不随时间变化 → 非常不精确 | 如果 $x_{it}$ 与 $a_i$ 相关 → **不一致** |

## RE 还是 Pooled OLS？

Breusch-Pagan LM 检验：$H_0: \sigma_a^2 = 0$（无个体随机效应）
- 如果拒绝 → RE 或 FE（不用 Pooled OLS）
- 如果不能拒绝 → Pooled OLS 足够

## 反面论点与数据空白

- **RE 的 $\text{Cov}(x_{it}, a_i) = 0$ 在非实验数据中几乎永远可疑**：教育、收入、健康等变量几乎必定与个体不可观测特征相关。
- **RE 不做 Hausman 检验而直接使用是高风险的**——在许多情境下 RE 和 FE 给出截然不同的结论。
