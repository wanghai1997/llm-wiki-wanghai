# 无限分布滞后模型

## 一句话定义

> **无限分布滞后 (IDL)** = 允许 $x$ 的影响**无限期地**延续——而不像 [[时间序列数据与静态模型|FDL]] 需要在某个滞后期截断——但需要参数约束来减少待估参数。

## 为什么需要 IDL

FDL 要求预设最大滞后 $q$——但很多经济关系没有明确的"影响停止点"（如货币政策对 GDP 的影响、广告对销售的长期效应）。

IDL 解决了这个问题——但需要结构约束（否则无限个参数不可估）。

## 几何 (Koyck) 分布滞后

$$\begin{aligned}
y_t &= \alpha + \delta(x_t + \lambda x_{t-1} + \lambda^2 x_{t-2} + \lambda^3 x_{t-3} + ...) + u_t \\
&= \alpha + \delta x_t + \delta\lambda x_{t-1} + \delta\lambda^2 x_{t-2} + ... + u_t
\end{aligned}$$

- **几何衰减**：每推后一期，效应的乘数 $\times \lambda$（$0 < \lambda < 1$）
- **长期倾向** = $\delta / (1 - \lambda)$
- **中位滞后** = $-\ln 2 / \ln \lambda$（效应累积到一半的时期数）

### Koyck 变换

通过简单的代数操作，无限滞后模型可化为仅包含**两期滞后**的模型：

$$y_t = \alpha(1 - \lambda) + \delta x_t + \lambda y_{t-1} + (u_t - \lambda u_{t-1})$$

→ **仅需估计 3 个参数**（$\alpha, \delta, \lambda$）！

**代价**：变换后误差 = $u_t - \lambda u_{t-1}$ → 自动有序列相关（MA(1)）——OLS 不一致（因为 $y_{t-1}$ 与误差相关）。需要 IV。

## 有理分布滞后 (RDL)

Koyck 模型 + 额外滞后项：
- 允许更灵活的衰减模式（非单调、先升后降等）
- 本质上 = ARMA 误差的 FDL
- 通常使用非线性最小二乘法估计

## 反面论点与数据空白

- **几何衰减的强假设**：所有滞后效应的衰减速率完全相同——没有"延迟后加速衰减"或"周期性反弹"的灵活性。
- **Koyck 变换后 OLS 不一致的常见忽视**：尽管变换后模型只要 3 个参数就跑 OLS——但忽略 $y_{t-1}$ 与 MA(1) 误差的相关性会导致严重偏差。
