# 混合横截面与政策分析

## 一句话定义

> **混合横截面** = 多个时期的**独立随机样本**（每期抽取不同个体）合并为一个数据集——通过加入时间虚拟变量和交互项，可以实现**广义 DiD** 的政策评估。

> **前置阅读**：[[双重差分DiD]]（MM Ch 5）提供 DiD 的因果直觉。

## 混合横截面 vs 面板数据

| | 混合横截面 | 面板数据 |
|---|---|---|
| 个体追踪 | 不同时期**不同**个体 | 相同个体跨时期追踪 |
| 时间效应 | 时间虚拟变量 | 时间虚拟 + 个体 FE |
| 个体异质性 | 只能通过可观测变量控制 | 可通过 FE 消除不随时间变化的不可观测因素 |
| 数据结构 | 两个或多个独立的随机样本 | 同一批个体在多个时点 |

## 利用混合横截面做政策分析

### 基本 DiD 回归

$$y_{it} = \beta_0 + \beta_1 \text{Treat}_i + \beta_2 \text{Post}_t + \delta (\text{Treat}_i \times \text{Post}_t) + u_{it}$$

- $\delta$ = DiD 估计量 = 政策效应
- 即使个体在时期之间不同，只要每期都是随机样本，OLS 是一致的

### 加协变量的 DiD

$$y_{it} = \beta_0 + \delta (\text{Treat}_i \times \text{Post}_t) + \mathbf{x}_{it}'\boldsymbol{\gamma} + \beta_1 \text{Post}_t + u_{it}$$

- $\mathbf{x}_{it}$ 控制时期间的人口结构变化（成分效应）
- 重要：$\mathbf{x}_{it}$ 应该是**外生的**（不被政策影响）

## Wooldridge 的例子

**垃圾焚烧炉对房价的影响**（Kiel-McClain 1995）：
- 处理组：焚烧炉选址附近的房屋
- 控制组：远离选址的房屋
- 处理前：1978 年（选址公布前）
- 处理后：1981 年（焚烧炉建成后）
- DiD 估计：焚烧炉使房价下降约 10-15%

## 反面论点与数据空白

- **"随机抽样"假设在跨时期之间可能不成立**：人口迁移、出生/死亡、调查拒答率变化等导致样本组成变化。
- **混合横截面不能控制个体 FE**：与面板不同，无法消除不随时间变化的个体异质性 → 比面板数据更依赖可观测变量的控制。
