# 协整与误差修正模型

## 一句话定义

> **协整** = 两个或更多 I(1) 序列的**线性组合**是 I(0)（平稳）——意味着序列之间存在**长期均衡关系**，即使每个序列各自是随机游走。**误差修正模型 (ECM)** 同时捕捉短期动态和长期均衡校正。

## 为什么协整重要

- 两个 I(1) 序列 → [[谬误回归|不能直接回归水平值]]
- 但如果有经济理论预测它们之间有**长期关系**（如消费和收入、短期利率和长期利率） → 协整提供了回归框架
- **Granger 表述定理**：如果序列是协整的 → 必然存在 ECM 表示；反之亦然

## 协整检验：Engle-Granger 两步法

### 步骤 1：估计长期关系

$$y_t = \beta_0 + \beta_1 x_t + u_t$$

→ 获得残差 $\hat{u}_t$

### 步骤 2：检验残差是否平稳

$$\Delta \hat{u}_t = \theta \hat{u}_{t-1} + \sum \gamma_j \Delta \hat{u}_{t-j} + e_t$$

- $H_0$: $\theta = 0$（无协整——残差有单位根）
- 用 ADF 检验，但使用**修正的临界值**（Engle-Granger 临界值——比标准 ADF 更负，因为 $\hat{u}_t$ 是估计的）

## 误差修正模型 (ECM)

如果 $y_t$ 和 $x_t$ 是协整的：

$$\Delta y_t = \alpha + \delta_0 \Delta x_t - \gamma(\underbrace{y_{t-1} - \beta_0 - \beta_1 x_{t-1}}_{\text{第 }t-1\text{ 期的偏离}}) + u_t$$

三个组分：
1. $\delta_0 \Delta x_t$：**短期效应**（$x$ 变化的即时影响）
2. $-\gamma(\text{偏离})$：**误差修正项**——负号 + $\gamma > 0$ 确保向均衡**回归**
3. $\gamma$ 的倒数 = 偏离半衰期：偏离的一半被校正所需的时间

### ECM 的优点

- 同时估计**长期关系**（$\beta_1$ = 长期乘数）和**短期动态**（$\delta_0$）
- 所有变量都是 I(0)（$\Delta y_t$、$\Delta x_t$、协整残差） → 标准 OLS 推断有效
- 经济直觉清晰："偏离均衡 → 修正"

## 协整在实践中的例子

| 关系 | 协整的证据 |
|------|-----------|
| 消费和收入 | 强协整——长期消费函数 |
| 短期和长期利率 | 期限结构的预期理论预测协整 |
| 即期和远期汇率 | 无套利条件预测协整 |
| 股价和股息 | 现值模型预测协整 |

## 反面论点与数据空白

- **协整检验在小样本中功效低**：可能需要 100+ 年/季度的数据才有可靠的检验——许多经济时间序列不够长。
- **"协整是长期关系"但 $\beta_1$ 可能随时间变化**——结构突变可能改变长期均衡的斜率。单协整检验假设参数恒定。
- **"协整 ≠ 因果关系"**：协整只是统计上的长期共移——哪个变量"驱动"长期关系需要经济理论的支撑。
