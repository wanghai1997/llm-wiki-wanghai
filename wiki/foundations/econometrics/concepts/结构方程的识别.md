# 结构方程的识别

## 一句话定义

> **结构方程识别** = 回答"系统中有足够多的排他性外生变量来区分供给曲线和需求曲线吗？"——**阶条件**（必要）和**秩条件**（充分）提供了识别答案。

## 供需识别的直觉

在供需系统中：

$$Q = \alpha_0 + \alpha_1 P + \alpha_2 \underbrace{Z^s}_{\text{供给冲击}} + u^s$$
$$Q = \beta_0 + \beta_1 P + \beta_2 \underbrace{Z^d}_{\text{需求冲击}} + u^d$$

- **供给方程被识别**，因为 $Z^d$（需求冲击）在供给方程中被排除——$Z^d$ 移动需求曲线"画出"了供给曲线
- **需求方程被识别**，因为 $Z^s$（供给冲击）在需求方程中被排除——$Z^s$ 移动供给曲线"画出"了需求曲线

> 识别 = 有足够的外生变量来"固定"一个方程而"移动"另一个。

## 阶条件——识别的必要条件

**对系统中第 $g$ 个方程**：

$$\text{从该方程排除的外生变量数} \geq \text{该方程中包含的内生变量数} - 1$$

- 如果 = → **恰好识别**（exactly identified）→ 2SLS
- 如果 > → **过度识别**（overidentified）→ 2SLS + 检验过度识别约束
- 如果 < → **不可识别**（unidentified）→ 不能估计该方程

## 秩条件——识别的充分条件

$\text{rank}(\mathbf{R}_g) = M - 1$（$M$ = 系统中内生变量的总数）

其中 $\mathbf{R}_g$ = 从该方程排除的外生变量在包含该方程的简化式中的系数矩阵。

- **阶条件满足但秩条件不满足 → 结构方程仍不可识别**。
- 秩条件在实践中通常通过排除的外生变量具有显著的第一阶段来间接论证。

## 2SLS 估计结构方程

用系统中**所有外生变量**作为工具变量：
1. 第一阶段：内生解释变量对系统中所有外生变量回归
2. 第二阶段：代入预测值

→ 2SLS 自动使用"所有外生变量"来构造最优工具。

## 反面论点与数据空白

- **排他性约束的经济辩护是结构建模的核心难点**：供给冲击真的不影响需求吗？需求冲击真的不影响供给吗？——这种辩护在真实经济中通常是不完美的。
- **"过度识别约束可检验"但检验的零假设是"所有工具都有效"**——不可能区分"哪个工具违反了排他性"。
