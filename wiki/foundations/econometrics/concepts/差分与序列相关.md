# 差分与序列相关

## 一句话定义

> **差分**（$\Delta y_t = y_t - y_{t-1}$）是处理序列相关的**替代策略**——当误差接近随机游走（$\rho \approx 1$）时，差分比 FGLS 更简单且更稳健。

## 为什么差分有效

如果 $u_t$ 是**高度持续的**（接近单位根）：

$$u_t = u_{t-1} + e_t$$

则原始模型的误差是极度序列相关的（$\rho \approx 1$）。Cochrane-Orcutt 变换接近于差分：

$$y_t - y_{t-1} = \beta_1(x_t - x_{t-1}) + ... + e_t$$

→ **差分模型可以用 OLS 估计——因为 $e_t$ 是无序列相关的**。

## 差分 vs FGLS

| | 差分 | FGLS (Cochrane-Orcutt) |
|---|---|---|
| 假设 | $\rho \approx 1$ | $|\rho| < 1$ |
| 风险 | 如果 $\rho$ 实际远小于 1 → **过度差分** → 误差变为负序列相关 | 如果 $\hat{\rho}$ 估计不准 → 变换后的误差仍有序列相关 |
| 简单性 | ⭐⭐⭐ | ⭐ |
| 估计量 | 在 $\rho=1$ 时一致 | 需要 $\hat{\rho}$ 的一致性 |

## 过度差分的风险

如果 $\rho = 0$（无序列相关）而我们对模型进行了差分：

$$\Delta y_t = \beta_1 \Delta x_t + \Delta u_t = \beta_1 \Delta x_t + (u_t - u_{t-1})$$

- $\Delta u_t$ 的方差 = $\text{Var}(u_t) + \text{Var}(u_{t-1}) - 2\text{Cov}(u_t, u_{t-1}) = 2\sigma^2$（如果 $\rho=0$）
- 且 $\text{Cov}(\Delta u_t, \Delta u_{t-1}) = -\sigma^2 \neq 0$ → **引入负序列相关**
- → OLS 标准误仍然不可靠

## 实践中的决策规则

1. 估计原始模型的残差自相关 $\hat{\rho}$
2. 如果 $\hat{\rho} \approx 1$（如 > 0.9）→ 差分 + OLS
3. 如果 $\hat{\rho}$ 在中间范围（如 0.3-0.8）→ FGLS (Cochrane-Orcutt) 或 HAC SE
4. 如果 $\hat{\rho}$ 小（< 0.3）→ 报告 HAC SE 即可

## 反面论点与数据空白

- **差分会"扔掉"长期关系**：差分模型仅捕捉短期效应——如果理论关心的是 $x$ 和 $y$ 的**长期均衡关系**，需要[[协整与误差修正模型|误差修正模型]]而非纯差分。
- **$\hat{\rho}$ 本身有估计误差**——在小样本中，"$\hat{\rho} \approx 1$"的决策可能出错。
