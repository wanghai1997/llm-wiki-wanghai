# 动态完备模型

## 一句话定义

> **动态完备模型** = 模型中包含了足够的 $y$ 和 $x$ 的滞后项，使得误差 $u_t$ 在给定所有解释变量的过去值和当前值后**没有序列相关**——即误差中没有可预测的模式。

## 形式定义

模型 $y_t = \beta_0 + \beta_1 x_t + ... + \beta_k x_t^{(k)} + u_t$ 是**动态完备的**，当且仅当：

$$E(u_t | \mathbf{x}_t, y_{t-1}, \mathbf{x}_{t-1}, y_{t-2}, ...) = 0$$

即：一旦你知道了所有解释变量的当前值**和**所有过去的历史，$u_t$ 的期望为零。

## 动态完备与序列相关

**关键关系**：动态完备 ⇒ 无序列相关（但**反过来不成立**）。

- 如果模型是动态完备的 → 不存在遗漏的滞后效应 → $u_t$ 不应该在时间上可预测
- 但 $u_t$ 可以无序列相关而模型仍不是动态完备的（例如遗漏了当期变量）

## 如何实现动态完备

1. **加入 $y$ 的滞后项**：$y_{t-1}, y_{t-2}, ...$
2. **加入 $x$ 的滞后项**（FDL 形式）：$x_{t-1}, x_{t-2}, ...$
3. **检验残差**：如果残差仍显示序列相关 → 再添加更多的滞后

## 例子

**静态 Phillips 曲线**（可能不是动态完备的）：
$$\inf_t = \beta_0 + \beta_1 \text{unem}_t + u_t$$

如果通胀有惯性（通胀预期影响本期通胀）→ $u_t$ 包含过去通胀的信息 → 不是动态完备的。

**动态完备版**：
$$\inf_t = \beta_0 + \beta_1 \text{unem}_t + \gamma_1 \inf_{t-1} + u_t$$

加入了 $\inf_{t-1}$ → 如果 $\gamma_1$ 捕捉到了通胀惯性 → 模型更接近动态完备。

## 反面论点与数据空白

- **动态完备是"样本内"概念**：一个模型在给定可用数据下可能是动态完备的，但这不保证它捕捉了全部真实动态——可能遗漏了未观测到的滞后变量。
- **过度拟合的风险**：加入过多滞后项 → 损失自由度 → 估计不稳定 → 在预测中可能表现更差——AIC/BIC 提供了一种权衡。
