# 联立方程模型

## 一句话定义

> **联立方程模型** = 多个方程同时决定多个内生变量——每个方程中至少有一个解释变量本身是系统的内生结果——OLS 在每个结构方程中**不一致**，需要 2SLS 估计。

## 为什么 OLS 不一致

经典的供需系统：

$$Q^s = \alpha_0 + \alpha_1 P + \alpha_2 Z^s + u^s \quad \text{（供给）}$$
$$Q^d = \beta_0 + \beta_1 P + \beta_2 Z^d + u^d \quad \text{（需求）}$$

在均衡时 $Q^s = Q^d = Q$。价格 $P$ 由供给侧和需求侧的冲击**同时决定**——$\text{Cov}(P, u^s) \neq 0$ 且 $\text{Cov}(P, u^d) \neq 0$。

- 需求上涨 → $u^d \uparrow$ → $P \uparrow$ → $Q \uparrow$（沿供给曲线上移）
- OLS 估计的 $\alpha_1$（供给斜率）会混入 $\beta_1$（需求斜率）的信息

→ **联立性偏差 (Simultaneity Bias)**：OLS 在两个方程中都**不一致**。

## 结构方程 vs 约简式

| | 结构方程 | 约简式 (Reduced Form) |
|---|---|---|
| 变量 | 内生变量在两边 | 每个内生变量表达为**仅外生变量**的函数 |
| 例子 | $Q = \alpha_0 + \alpha_1 P + \alpha_2 Z^s + u^s$ | $P = \pi_0 + \pi_1 Z^s + \pi_2 Z^d + v^P$ |
| OLS 一致？ | 否 | **是**（外生变量在右边） |
| 经济含义 | 直接可解释（供给/需求函数） | 难以直接解释（P 由什么决定） |

## 联立性的来源

- **市场均衡**：价格和数量同时由供需决定
- **政策内生性**：警察数量 vs 犯罪率（警察更多 → 犯罪更低？还是犯罪更高 → 警察更多？）
- **期望反馈**：理性期望模型中，本期决策取决于对未来的预期
- **社会互动**：同伴效应——你的行为影响我，我的行为同时影响你

## 联立方程与遗漏变量/测量误差的区别

Wooldridge 强调：在现代实证研究中，**遗漏变量和测量误差**比联立性更常见作为使用 IV 的理由——但联立方程在特定领域（产业组织、宏观经济学）不可或缺。

## 反面论点与数据空白

- **联立方程模型在当代应用经济学中"过度使用"**：Wooldridge 本人认为，联立性偏差在实证中不如遗漏变量偏差常见——许多"结构模型"实际上用过于复杂的联立方程系统回答了简单问题。
- **正确的排他性约束是关键**：结构方程的识别依赖于正确的排他性约束（供给冲击不影响需求，需求冲击不影响供给）——这些约束在经济意义上是否合理需要深入验证。
