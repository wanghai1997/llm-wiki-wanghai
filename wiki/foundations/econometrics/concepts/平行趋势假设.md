# 平行趋势假设

## 一句话定义

> **平行趋势假设** = DiD 的核心识别假设——在没有处理的情况下，处理组和控制组的结果会以**相同的趋势**变化。

## 正式表述

$$E[Y_{0i,\text{post}} - Y_{0i,\text{pre}} | \text{Treat}_i = 1] = E[Y_{0i,\text{post}} - Y_{0i,\text{pre}} | \text{Treat}_i = 0]$$

处理组在反事实状态下（如果不接受处理）的变化 = 控制组的实际变化。

## 为什么不可直接检验

平行趋势假设涉及**无法观测的反事实**——处理组在未接受处理情况下的趋势。我们只能：
1. 检查**处理前**的趋势是否平行（间接证据）
2. 如果处理前趋势不平行 → 平行趋势假设可能不成立
3. 如果处理前趋势平行 → 支持但**不证明**平行趋势假设

## 判断平行趋势的方法

| 方法 | 做法 | 局限性 |
|------|------|--------|
| **视觉检查** | 画处理前-处理后的时间趋势图 | 主观、需要多期数据 |
| **事件研究的 DiD** | 加入 leads（处理前的虚拟处理项）| 可正式检验"处理前是否有假效应" |
| **伪结果检验** | 对不应该被处理影响的结果跑 DiD | 如果看到"假处理效应"→ 平行趋势有问题 |
| **加入趋势控制** | 控制组特定的线性时间趋势 | 如果系数稳定 → 增强可信度 |

## 在 Mastering 'Metrics 中的处理

Ch 5 用三张图（Figures 5.4-5.6）直观展示：
- **5.4**：平行趋势成立 → DiD 干净地识别因果效应
- **5.5**：趋势不平行 → DiD 会产生**虚假的因果效应**（spurious effect）
- **5.6**：即使趋势不完全平行，**真实的因果效应仍然可见**（叠加在趋势差异之上）

核心信息：平行趋势假设的重要性取决于**趋势差异相对于处理效应的大小**——小趋势差异 + 大处理效应 → DiD 仍有效。

## 反面论点与数据空白

- **处理前趋势平行 ≠ 处理后趋势平行**：处理本身可能改变趋势（如政策引发行为调整）——这是平行趋势假设中最隐蔽的威胁。
- **检验的统计效力**：处理前趋势可能看起来"平行"是因为样本量不够大——不能拒绝"趋势平行"的零假设 ≠ 趋势真正平行。
- **交错处理中的问题**：在交错 DiD 中，已处理组在后期作为"控制组"时，如果处理有动态效应，就违反了平行趋势假设——Goodman-Bacon (2021) 将此称为"禁止的比较"。
