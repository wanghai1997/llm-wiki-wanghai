# 政策评估的回归调整

## 一句话定义

> **回归调整 (Regression Adjustment)** = 在 RCT 或准实验中，用回归模型控制基线协变量——**提高处理效应估计的精度**（在不引入坏控制的前提下）。

> **前置阅读**：[[随机对照试验RCT]]（MM）提供随机实验的因果框架；本页补充回归调整的技术细节。

## 为什么在 RCT 中还需要回归

随机分配已经消除了选择偏差（处理和控制组在期望上等价）——但回归调整有两个作用：

1. **提高精度**：控制与结果强相关的基线变量 → 降低 $\sigma^2$ → 标准误减小
2. **校正运气不佳的随机化**：在有限样本中，处理组和控制组可能在某些基线变量上不平衡——回归调整可以部分校正

## 回归调整模型

$$y_i = \beta_0 + \tau D_i + \mathbf{x}_i'\boldsymbol{\gamma} + u_i$$

- $D_i$：处理虚拟变量
- $\mathbf{x}_i$：**基线**协变量（处理前测度）
- $\tau$：处理效应的**回归调整估计**
- **关键**：$\mathbf{x}_i$ 必须是处理前测度的——不能是处理的结果（[[Bad-Controls问题|坏控制]]）

## 非实验数据中的回归调整

当处理非随机分配时，回归调整用于**消除基于可观测变量的选择偏差**：

$$y_i = \beta_0 + \tau D_i + \mathbf{x}_i'\boldsymbol{\gamma} + u_i$$

如果 $\mathbf{x}_i$ 包含了所有与处理选择和结果同时相关的变量 → [[条件独立假设CIA|CIA]] 成立 → $\tau$ 识别平均处理效应。

**但这要求 $\mathbf{x}_i$ 是"好的控制"——处理前测度、不被处理影响、不阻断因果通路。**

## 与 [[双重差分DiD|DiD]] 的关系

回归调整 → 处理"水平差异"（控制基线水平）
DiD → 处理"趋势差异"（减去控制组的变化）

两者可以结合：将回归调整扩展到两期面板 → "回归 DiD"
$$y_{it} = \beta_0 + \tau (D_i \cdot \text{Post}_t) + \mathbf{x}_i'\boldsymbol{\gamma} + a_i + u_{it}$$

## 反面论点与数据空白

- **回归调整的"过度控制"风险**：如果控制变量 $\mathbf{x}_i$ 本身部分被处理影响（即便测度于基线后），回归调整可能引入偏差。
- **匹配 vs 回归调整的效率**：在有限样本下，精确匹配可能比回归调整更稳健（对函数形式错误的敏感性更小）。
- **高维控制变量的滥用**：加入大量控制变量可能"过度拟合"——偏差-方差权衡。
