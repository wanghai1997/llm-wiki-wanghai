# 时间序列预测

## 一句话定义

> **时间序列预测** = 利用历史数据预测未来值——不同于因果推断（不关心 $\beta$ 的因果解释），关注的是**预测误差最小化**。

## 因果推断 vs 预测

| | 因果推断 | 预测 |
|---|---|---|
| **目标** | 估计 $\beta_j$（为什么？） | 最小化预测误差 $\hat{y}_{T+1} - y_{T+1}$ |
| **变量选择** | 基于理论和 OVB 逻辑 | 只要提高预测精度就可以加入 |
| **"坏控制"** | 是要避免的 | 不是问题——只要能预测就好 |
| **评估** | $t$ 检验、$p$ 值、置信区间 | RMSE、MAE、Diebold-Mariano 检验 |

## 一步前向预测

在时点 $T$，使用截至 $T$ 的信息预测 $y_{T+1}$：

$$\hat{y}_{T+1} = \hat{\beta}_0 + \hat{\beta}_1 x_{T+1} + ...$$

如果 $x_{T+1}$ 也未知（最常情况），则先预测 $x$ 或使用无条件预测。

### 预测误差

$$\hat{e}_{T+1} = y_{T+1} - \hat{y}_{T+1}$$

两个误差源：
1. **未知的未来冲击** $u_{T+1}$（不可消除）
2. **参数估计误差** $\hat{\beta} - \beta$（在大 $T$ 下可忽略）

## 多步前向预测

预测 $y_{T+h}$（$h > 1$）——误差随 $h$ 增加而增大，因为：
- 误差累积：$\hat{y}_{T+h}$ 依赖于 $\hat{y}_{T+1}$，而 $\hat{y}_{T+1}$ 已经包含误差
- 越远的未来不确定性越大

## 预测评估

### 样本外评估

将数据分为**估计期**（$1, ..., T_E$）和**预测试期**（$T_E+1, ..., T$）：

$$\text{RMSE} = \sqrt{\frac{1}{T - T_E} \sum_{t=T_E+1}^T (y_t - \hat{y}_t)^2}$$

- **绝对度量**：RMSE 越小越好
- **相对度量**：Diebold-Mariano 检验——两个竞争预测模型的 RMSE 是否有显著差异

### 预测区间

95% 预测区间 ≈ $\hat{y}_{T+1} \pm 1.96 \cdot \text{SE}(\hat{e})$

> 预测区间 ≠ 置信区间——前者包含未来冲击的变异性（后者仅包含参数估计的变异性）→ 预测区间**永远更宽**。

## 预测趋势性、季节性和 I(1) 序列

- **趋势**：如果 $y_t$ 有确定趋势 → 在模型中加入 $t$ → 外推 $t = T+1, T+2, ...$
- **季节性**：季节性虚拟变量 → 使用正确的季节性指数
- **I(1) 过程**：预测 $\Delta y_{T+h}$ 然后通过累积恢复 $y_{T+h}$ 的预测

## 反面论点与数据空白

- **预测评估中的"样本外"不等于"真正的外推"**：如果预测试期的经济结构已发生变化（如 2008 年危机、2020 年疫情），基于旧数据估计的模型预测能力会急剧下降。
- **"RMSE 最小 = 最好"的陷阱**：RMSE 是对称损失——如果预测的正误差和负误差的代价不同（如库存不足 vs 库存过剩），需要非对称损失函数。
