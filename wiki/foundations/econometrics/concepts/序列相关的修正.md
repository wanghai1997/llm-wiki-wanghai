# 序列相关的修正

## 一句话定义

> 当检验发现序列相关时，有两条路径：**修正推断**（序列相关稳健标准误）或**修正估计**（FGLS 变换）——两者各有适用范围。

## 路径 1：序列相关稳健标准误

不改变 OLS 点估计——只修正标准误的计算。

**Newey-West HAC (Heteroskedasticity and Autocorrelation Consistent) 标准误**：
- 同时稳健于异方差和序列相关
- 需要选择**滞后截断参数** $g$（通常为 $g = \lfloor T^{1/4} \rfloor$）
- 在大 $T$ 下可靠——小 $T$ 可能不可靠

**优点**：不需要假定序列相关的具体形式（AR(1)？AR(p)？）
**缺点**：不如 FGLS 有效（如果序列相关形式已知）

## 路径 2：FGLS（可行广义最小二乘）

假设 $u_t = \rho u_{t-1} + e_t$（AR(1)）：

### Cochrane-Orcutt 变换

$$y_t - \rho y_{t-1} = \beta_0(1 - \rho) + \beta_1(x_t - \rho x_{t-1}) + ... + e_t$$

- 变换后的模型误差 = $e_t$（无序列相关）
- 但 $\rho$ 未知 → 需要先从 OLS 残差估计 $\hat{\rho}$ → "可行的" GLS

### Cochrane-Orcutt 迭代法

1. OLS → 获得 $\hat{u}_t$
2. 估计 $\hat{\rho}$（从 $\hat{u}_t$ 对 $\hat{u}_{t-1}$ 回归）
3. Cochrane-Orcutt 变换 → 新 OLS
4. 新的残差 → 再估计 $\hat{\rho}$
5. 重复步骤 3-4 直到 $\hat{\rho}$ 收敛

### 高序列相关模型的处理

如果 $\hat{\rho} \approx 1$ → 模型接近于差分形式——直接差分 $\Delta y_t$ 可能更简单且更稳健。

## OLS vs FGLS

| | OLS + HAC SE | FGLS (Cochrane-Orcutt) |
|---|---|---|
| 点估计 | OLS（可能不是最优） | 渐近等价于 GLS（更有效） |
| 推断 | HAC SE | 基于 GLS 残差的标准误 |
| 依赖性 | 不依赖序列相关模型的正确性 | **依赖** $\hat{\rho}$ 和 AR(1) 假设 |
| 稳健性 | ⭐⭐⭐ | ⭐⭐ |
| 效率 | ⭐⭐ | ⭐⭐⭐（在正确模型下） |

## 反面论点与数据空白

- **FGLS 在 $T$ 不太大时可能不如 OLS + HAC SE**：估计 $\rho$ 的误差在有限样本中传导到 FGLS 估计量。
- **AR(1) 假设可能过于简单**：如果真实的序列相关是 AR(2) 或更高价，AR(1)-FGLS 的推断仍然不正确。
