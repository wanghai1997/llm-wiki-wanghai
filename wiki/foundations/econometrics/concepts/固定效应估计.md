# 固定效应估计

## 一句话定义

> **固定效应 (FE)** = 通过减去个体均值（"within transformation"）消除所有**不随时间变化的个体异质性** $a_i$——FE 估计量在**任何** $\text{Cov}(x_{it}, a_i)$ 下都是一致的（只要严格外生性成立）。

> **前置阅读**：[[两期面板数据分析]]（FD 在两期下 = FE）。

## Within Transformation

$$y_{it} = \beta_1 x_{it} + a_i + u_{it}$$

减去个体均值 $\bar{y}_i = \frac{1}{T} \sum_t y_{it}$：

$$\underbrace{y_{it} - \bar{y}_i}_{\ddot{y}_{it}} = \beta_1 \underbrace{(x_{it} - \bar{x}_i)}_{\ddot{x}_{it}} + \underbrace{(u_{it} - \bar{u}_i)}_{\ddot{u}_{it}}$$

$a_i$ 被消除了——因为 $\bar{a}_i = a_i$ → $a_i - \bar{a}_i = 0$。

→ OLS 对去均值后的数据回归 = **FE 估计量**（又称 Within Estimator）。

## 虚拟变量回归的等价形式

FE 等价于加入 $N-1$ 个个体虚拟变量：

$$y_{it} = \beta_1 x_{it} + \sum_{i=1}^{N-1} \alpha_i D_i + u_{it}$$

两种方式给出**完全相同的** $\hat{\beta}_1$（Frisch-Waugh 定理）。

## 双向固定效应 (Two-Way FE)

加入时期虚拟变量以控制**所有个体共同的时间效应**：

$$y_{it} = \beta_1 x_{it} + a_i + \lambda_t + u_{it}$$

- $a_i$ = 个体 FE（不随时间变化的个体特征）
- $\lambda_t$ = 时间 FE（所有个体在该时期的共同冲击）

→ 这是政策评估面板数据中最常用的模型。

## 对时间不变变量的限制

FE **不能识别**不随时间变化的变量的效应（如性别、种族、出生年份）——因为这些变量在 within transformation 中被消除了。

如果研究关心时间不变变量的效应 → [[随机效应估计|RE]] 或 [[相关随机效应CRE|CRE]]。

## FE 的假设

- **严格外生性**：$E(u_{it} | x_{i1}, ..., x_{iT}, a_i) = 0$（所有时期的 $x$ 与所有时期的 $u$ 不相关）
- **满秩**：$x_{it}$ 中至少有一个变量随时间变化（否则 within transformation 后全是 0）
- **异方差/序列相关**：应使用聚类标准误（对个体聚类）

## 反面论点与数据空白

- **严格外生性在动态面板中不成立**：如果模型包含 $y_{i,t-1}$ → "动态面板偏差"（Nickell bias）——FE 在小 $T$ 下不一致。需要 Arellano-Bond GMM 等方法。
- **FE 消除了"跨个体变异"**：FE 只用了个体**内部**随时间变化的变异——如果主要变异来自个体间差异，FE 可能非常不精确。
