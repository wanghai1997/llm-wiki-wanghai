# 遗漏变量偏差——多变量情形

## 一句话定义

> **多变量 OVB** = 当遗漏变量与**多个**已包含解释变量相关时，所有 OLS 系数都可能产生偏误——方向不限于二元情形中的"向上或向下"。

> **前置阅读**：[[遗漏变量偏差公式]]（MM）提供二元情形的 OVB 公式；本页推广到一般多变量情形。

## 一般 OVB 公式

设真实模型为 $y = \beta_0 + \beta_1 x_1 + ... + \beta_k x_k + \beta_{k+1} x_{k+1} + u$，但我们遗漏 $x_{k+1}$ 而只估计 $k$ 个变量：

$$\text{plim } \hat{\beta}_j^{\text{short}} = \beta_j + \beta_{k+1} \cdot \delta_j$$

其中 $\delta_j$ 是 $x_{k+1}$ 对**所有已包含 $x$** 回归中 $x_j$ 的偏回归系数——即 $x_{k+1}$ 与 $x_j$ 的**偏相关**。

## 与二元情形的关键区别

| | 二元（一个遗漏变量 + 一个已包含变量） | 多变量 |
|---|---|---|
| $\delta$ 的含义 | 简单回归系数 | **偏回归系数** |
| 偏差方向 | 仅取决于 $\beta_{k+1}$ 和 $\text{Cov}(x_1, x_{k+1})$ | 取决于 $\beta_{k+1}$ 和 $x_{k+1}$ 与**每个** $x_j$ 的偏相关 |
| 是否可能符号反转 | 只可能向上或向下 | **可能的符号反转**——$\delta_j$ 的符号可能与直观相反 |

## 实用的偏差判断

Wooldridge 的实用法则：
- 关注遗漏变量与**你关心的关键解释变量**的关系——忽略与其他控制变量的关系通常不会产生严重误导
- 如果遗漏变量与其他已包含变量高度相关 → OVB 会污染多个系数
- 单靠直觉判断 $\delta_j$ 的符号在多变量中可能出错——最好跑回归看看

## 反面论点与数据空白

- **OVB 方向"直觉"在多变量下可能严重误导**：遗漏变量与 $x_j$ 的偏相关方向可能与简单相关方向相反（Simpson 悖论）。
- **包含无关变量也有成本**：OLS 从无偏到非 BLUE（方差膨胀）、自由度损失——不是"越多控制越好"。
