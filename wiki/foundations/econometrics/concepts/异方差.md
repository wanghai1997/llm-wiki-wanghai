# 异方差

## 一句话定义

> **异方差** = 误差项的方差**随解释变量变化**——$\text{Var}(u | x_1,...,x_k) \neq \sigma^2$（常数）——导致 OLS 的**标准方差公式无效**，但不导致 OLS 的**偏差或不一致性**。

## 产生原因

- 收入的方差随教育水平变化（高教育者的工资分布更广）
- 大公司的利润方差大于小公司
- 比例/百分比因变量的方差通常在均值附近更大

## 对 OLS 的影响

| 性质 | 受影响？ |
|------|---------|
| 无偏性 | **否**（MLR.4 保证） |
| 一致性 | **否**（大样本下仍趋近真值） |
| 标准方差公式 | **是**（$\text{Var}(\hat{\beta}_j)$ 的公式不再有效） |
| t/F 检验 | **是**（使用错误方差公式的推断不可靠） |
| BLUE 性质 | **是**（OLS 不再是最优线性无偏估计量） |

→ **异方差不破坏估计本身，但破坏推断。**

## 异方差稳健推断

### 异方差稳健标准误 (Heteroskedasticity-Robust SE)

$$\widehat{\text{Var}}(\hat{\beta}_j) = \frac{\sum \hat{r}_{ij}^2 \hat{u}_i^2}{\text{SST}_j^2}$$

- 不需要知道异方差的具体形式
- 在大样本下提供有效的推断
- 通常比同方差 SE 大（更保守），但也可能更小
- **应作为默认报告的 SE**（至少在横截面分析中）

### White 检验

1. 从原模型获得 OLS 残差 $\hat{u}_i^2$
2. 将 $\hat{u}_i^2$ 对 $x_{i1}, ..., x_{ik}$ 及其二次型和交互项回归
3. $LM = n \cdot R^2 \sim \chi^2_q$（$q$ = 回归子的数量）
4. 如果显著 → 拒绝同方差 → 使用异方差稳健 SE

## 异方差的处理层级

1. **什么都不做**：报告异方差稳健 SE（最简单、最常见）
2. **WLS/FGLS**：如果知道异方差的形式 → 更有效的估计（[[加权最小二乘法WLS|见 WLS]]）
3. **变量变换**：$\ln y$ 通常减少异方差

## 反面论点与数据空白

- **异方差稳健 SE 在小样本中可能不可靠**：MacKinnon-White (1985) 的 HC3 修正、Davidson-MacKinnon 的 wild bootstrap 在小样本中表现更好。
- **稳健 SE 不能替代好的模型**：如果异方差是由遗漏变量导致的，仅修正标准误而不修正模型可能掩盖问题。
- **聚类标准误 vs 异方差稳健标准误**：如果数据有组内相关，异方差稳健 SE 不够——需要聚类 SE（见 Ch 13-14 面板数据）。
