# 时间序列中的异方差

## 一句话定义

> 时间序列中的异方差 = 误差方差随时间变化——在高频金融数据中尤其常见（波动率聚集）。**ARCH 模型**是时间序列异方差的标准处理框架。

> **前置阅读**：[[异方差]]（Wooldridge Ch 8）— 横截面异方差的处理。

## 横截面 vs 时间序列中的异方差

| | 横截面 | 时间序列 |
|---|---|---|
| 来源 | 不同个体有不同的方差 | 不同时点有不同的方差 |
| 常见模式 | 方差随 $x$ 变化 | **波动率聚集**（大波动后跟大波动） |
| 诊断 | White 检验 | ARCH 检验 |
| 修正 | 异方差稳健 SE / WLS | HAC SE / ARCH 建模 |

## 检验时间序列中的异方差

### Breusch-Pagan 检验（TS 版）

- 残差 $\hat{u}_t^2$ 对解释变量回归（包括 $y_{t-1}$ 如果存在）
- 本质上与横截面版相同

### ARCH 检验（Autoregressive Conditional Heteroskedasticity）

在**没有序列相关**的前提下：
1. 获得 OLS 残差 $\hat{u}_t^2$
2. 将 $\hat{u}_t^2$ 对 $\hat{u}_{t-1}^2, \hat{u}_{t-2}^2, ..., \hat{u}_{t-q}^2$ 回归
3. $LM = T \cdot R^2 \sim \chi^2_q$
4. 显著 → ARCH($q$) 效应存在

## ARCH 模型 (Engle 1982)

$$\sigma_t^2 = \text{Var}(u_t | u_{t-1}, u_{t-2}, ...) = \alpha_0 + \alpha_1 u_{t-1}^2 + ... + \alpha_q u_{t-q}^2$$

- 今天的方差取决于近期的**冲击大小**（平方误差）
- 大冲击 → 大方差 → 更可能出现大冲击（波动率聚集）
- 应用：金融风险管理（VaR）、期权定价（随时间变化的波动率）

### GARCH 扩展

$$\sigma_t^2 = \alpha_0 + \alpha_1 u_{t-1}^2 + \beta_1 \sigma_{t-1}^2$$

- 不仅依赖过去的冲击，还依赖过去的方差本身（GARCH(1,1) 是最常用的形式）
- Bollerslev (1986) 提出

## 实践建议

- **如果仅关注系数的推断**：HAC 标准误（Newey-West）同时处理序列相关和异方差——很少需要单独建模异方差
- **如果关注方差本身**（如金融风险）：ARCH / GARCH 是核心工具

## 反面论点与数据空白

- **ARCH 效应在低频宏观数据中不常见**——通常限制在金融/高频数据。在年度或季度宏观数据中，序列相关是更重要的关注点。
- **ARCH/GARCH 模型预测波动率的能力有限**——在金融中，"波动率预测"的 $R^2$ 通常很低。
