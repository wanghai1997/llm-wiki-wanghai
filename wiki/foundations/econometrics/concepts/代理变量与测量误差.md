# 代理变量与测量误差

## 一句话定义

> **代理变量** = 用可观测的变量替代不可观测的混淆因素——在特定条件下消除或减少 OVB。**测量误差** = 变量被错误测度时，OLS 系数产生**衰减偏差**（解释变量误差）或**效率损失**（因变量误差）。

## 代理变量

### 问题

真实模型：$y = \beta_0 + \beta_1 x_1 + ... + \beta_k x_k + \gamma q + u$

但我们**无法观测** $q$（如"能力"），只能用**代理变量** $z$（如 IQ 分数）。

### 代理变量的有效条件

$$q = \delta_0 + \delta_1 z + v$$

其中 $v$ 是 $z$ 未捕获的"能力"部分。

代理变量 $z$ 有效的充分条件：
1. **冗余性**：$E(y | x, q, z) = E(y | x, q)$——一旦知道真实的 $q$，$z$ 不提供额外的 $y$ 信息
2. **相关性**：$\text{Cov}(z, q) \neq 0$，$\text{Cov}(x_j, q) = 0 \Rightarrow \text{Cov}(x_j, v) = 0$——$z$ 捕获了所有 $q$ 与 $x_j$ 相关的变异

→ 在实践中这些条件非常强硬——代理变量几乎永远是**不完美**的，只能减少而非消除 OVB。

### 常用代理变量

| 不可观测变量 | 常用代理 |
|-------------|---------|
| 能力 | IQ 分数、AFQT 分数 |
| 努力/动机 | 缺勤率、延迟满足测试分数 |
| 教育质量 | 师生比、生均支出 |
| 健康 | 自我报告健康、BMI |
| 社会资本 | 社团参与率、选举投票率 |

## 测量误差

### 因变量的测量误差

$$y^* = \beta_0 + \beta_1 x + u \quad \text{但观测到 } \tilde{y} = y^* + e$$

- $\hat{\beta}_1$ 仍**无偏、一致**
- 但 $\text{Var}(\hat{\beta}_1)$ 更大（因为 $\text{Var}(\tilde{y}) > \text{Var}(y^*)$）

### 解释变量的经典测量误差

$$y = \beta_0 + \beta_1 x^* + u \quad \text{但观测到 } \tilde{x} = x^* + e$$

在经典假设下（$e$ 与 $x^*$、$u$ 不相关）：

$$\text{plim } \hat{\beta}_1 = \beta_1 \cdot \frac{\text{Var}(x^*)}{\text{Var}(x^*) + \text{Var}(e)} = \beta_1 \cdot \lambda < \beta_1$$

→ **衰减偏差 (Attenuation Bias)**：OLS 低估 $\beta_1$ 的绝对值。

> **前置阅读**：[[测量误差偏差]]（MM Ch 6 附录）提供双胞胎案例中的经典衰减偏差分析。

### 非经典测量误差

如果 $e$ 与 $x^*$ 相关（如低教育者系统性地高报教育年限）→ 偏差方向不确定。

### IV 解决方案

用第二个测量（如双胞胎案例中的兄弟姐妹报告）作为 IV → 消除衰减偏差。

## 反面论点与数据空白

- **代理变量的"冗余性"在实践中不可检验**——我们永远不知道代理变量是否捕获了所有相关的 $q$ 变异。
- **IQ 作为能力代理的问题**：IQ 本身可能受教育影响 → 不是"前定"的 → 不是好的代理（它部分是被处理影响的结果）。
