# 事件研究法

## 一句话定义

> **事件研究法** = 分析一个"事件"（政策变动/监管改革/灾难）发生后，**处理单元**的时间序列在事件前后如何变化——当有控制组时，可以形成"时间序列版本的 DiD"。

## 两类事件研究

### 类型 1：单一处理单元，无控制组

$$y_t = \beta_0 + \beta_1 \text{Event}_t + u_t$$

其中 $\text{Event}_t = 0$ 在事件前，$= 1$ 在事件后。

- **严重假设**：在没有事件的情况下，$y_t$ 不受其他因素影响（无趋势/季节性/其他因素）
- 这个假设在宏观经济数据中**几乎永远不可信**——因为没有"反事实趋势"

### 类型 2：有控制组的事件研究（Wooldridge Ch 18 新增内容）

处理单元 + 控制单元 → 联合估计：

$$y_t = \beta_0 + \beta_1 \text{Event}_t + \beta_2 (\text{Event}_t \times \text{Treated}) + u_t$$

或更一般地：

$$y_{it} = \alpha_i + \lambda_t + \delta (\text{Treated}_i \times \text{Event}_t) + u_{it}$$

→ 这本质上是**时间序列 + 横截面**的 DiD。控制组提供了"在没有事件的情况下，处理单元的可能趋势"的估计。

## 与 DiD 的区别和联系

| | 标准 DiD | 事件研究法 |
|---|---|---|
| 数据结构 | 面板数据（多个个体 × 多个时点） | 时间序列（一个或少数单元 × 多期） |
| 处理的识别 | 处理组 vs 控制组 | 事件前 vs 事件后——控制组可选 |
| 方法的时代 | 现代政策评估 | 更早——金融和宏观中的经典方法 |

## 典型应用

- **金融**：并购公告对股价的影响（单一事件，窗口通常 ±3 天）
- **宏观**：央行政策转变对 GDP 增长路径的影响
- **健康经济学**：禁烟法规对吸烟率的时间路径
- **环境经济学**：碳税对排放的月度影响

## 事件研究的潜在陷阱

1. **事件时机不明确**：许多"事件"是逐渐发生的（阶段性的、预期的）而非在单一日期突然发生
2. **事件内生性**：事件的发生可能与过去的 $y$ 有关——如"危机后改革"
3. **控制组的选择**：控制组是否真正适用——需要平行趋势的辩护

## 反面论点与数据空白

- **单一时序的事件研究在因果声称上最弱**：没有控制组 → 任何同期发生的其他因素都可能混淆"事件效应"。
- **"事件窗口"的选择可能驱动结论**：选择 5 天、10 天还是 30 天的窗口 → 不同的选择可能突出或隐藏效应。
