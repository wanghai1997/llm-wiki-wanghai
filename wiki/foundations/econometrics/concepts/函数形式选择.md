# 函数形式选择

## 一句话定义

> **函数形式选择** = 决定变量以何种数学形式进入回归——对数/水平值/二次/交互项——直接影响系数的解释和模型的拟合质量。

## 四种基准函数形式

| 模型形式 | 方程 | $\beta_1$ 的解释 |
|---------|------|-----------------|
| **水平-水平** | $y = \beta_0 + \beta_1 x + u$ | $\Delta y = \beta_1 \Delta x$ |
| **对数-水平** | $\ln y = \beta_0 + \beta_1 x + u$ | $\%\Delta y \approx 100\beta_1 \Delta x$ |
| **水平-对数** | $y = \beta_0 + \beta_1 \ln x + u$ | $\Delta y \approx (\beta_1/100)\%\Delta x$ |
| **对数-对数** | $\ln y = \beta_0 + \beta_1 \ln x + u$ | $\%\Delta y \approx \beta_1 \%\Delta x$（弹性） |

## 二次型

$$y = \beta_0 + \beta_1 x + \beta_2 x^2 + u$$

- 边际效应**非常数**：$\frac{\partial y}{\partial x} = \beta_1 + 2\beta_2 x$
- $\beta_1 > 0, \beta_2 < 0$ → 效应递减（倒 U 形）
- 不能只看 $\beta_1$ 和 $\beta_2$ 各自的显著性——需要计算在特定 $x$ 值处的**边际效应 + 标准误**

## 交互项

$$y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \beta_3 (x_1 \cdot x_2) + u$$

- $x_1$ 的偏效应：$\frac{\partial y}{\partial x_1} = \beta_1 + \beta_3 x_2$
- **"主效应" $\beta_1$ 只在 $x_2 = 0$ 时有意义**
- 包含交互项后，不能独立解释 $\beta_1$ 为"$x_1$ 的效应"

## 平均偏效应 (APE)

当边际效应随 $x$ 变化时：

$$\text{APE} = \frac{1}{n} \sum_{i=1}^n \frac{\partial \hat{y}_i}{\partial x}$$

- 在所有人处计算偏效应后取平均——比在均值处计算更有意义
- 适用于 logit/probit 中的非线性模型（Ch 17）

## 选择函数形式的策略

1. **理论指引**：经济学理论通常建议某些函数形式（如 Mincer 方程用 $\ln$ 工资）
2. **RESET 检验**：检验函数形式是否错误
3. **拟合对比**：比较不同形式的 $R^2$（仅当因变量相同时有效）
4. **解释便利性**：在拟合差别不大时，选择解释更直观的形式

## 反面论点与数据空白

- **对数和水平值的选择是语义区别，而非因果区别**：哪种形式更好地逼近真实 CEF 是一个实证问题——不要预设一种形式为"正确"。
- **二次型很容易受离群值驱动**：$x$ 很高或很低的几个观测可以大幅改变 $\hat{\beta}_2$ 的符号。
