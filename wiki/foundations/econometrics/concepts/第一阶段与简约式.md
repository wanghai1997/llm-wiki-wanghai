# 第一阶段与简约式

## 一句话定义

> **第一阶段** = 工具变量 $Z_i$ 对处理 $D_i$ 的因果效应（$\phi$）。**简约式** = $Z_i$ 对结果 $Y_i$ 的总效应（$\rho$）。IV 估计量 $\lambda = \rho / \phi$——因果效应是简约式与第一阶段的比值。

## 第一阶段

$$\phi = E[D_i|Z_i=1] - E[D_i|Z_i=0]$$

- 测量"工具对处理的推动力"
- **必须强**（$F > 10$ 是经验法则——Staiger-Stock 1997）
- 弱第一阶段 → IV 估计有偏（趋近 OLS），标准误不可靠
- 在 [[KIPP特许学校彩票|KIPP 案例]] 中：$\phi = 0.74$——彩票使 KIPP 入学率提高 74 个百分点（强第一阶段）

## 简约式

$$\rho = E[Y_i|Z_i=1] - E[Y_i|Z_i=0]$$

- 测量"工具对结果的直接影响"（通过处理链的全部环节）
- 本身就是**因果效应**（ITT——意图-处理效应），只是不对应具体的处理单位
- 在 [[KIPP特许学校彩票|KIPP 案例]] 中：$\rho = 0.36\sigma$——中签使数学成绩提高 0.36σ

## 为什么需要将两者分离

- **ITT 低估处理效应**：$\rho$ 是"中签效应"——但 26% 的中签者并未入学 → 入学的真实效应被稀释
- **IV 恢复处理效应**：$\lambda = \rho / \phi = 0.36 / 0.74 = 0.48\sigma$——实际入学的效应
- **逻辑**：如果 $\phi < 1$，用 $\rho / \phi$ 将"处理采纳率不足"校正回来

## 在不同 IV 设计中的变体

| 设计 | 第一阶段 | 简约式 | IV |
|------|---------|--------|-----|
| KIPP 彩票 | 中签 → 入学 | 中签 → 成绩 | 入学 → 成绩 |
| Oregon OHP | 中签 → 参保 | 中签 → 健康 | 参保 → 健康 |
| 双胞胎 IV | 双胞胎 → 更多子女 | 双胞胎 → 子女教育 | 子女数 → 教育 |
| QOB IV | 出生季度 → 受教育年限 | 出生季度 → 收入 | 受教育 → 收入 |

## 反面论点与数据空白

- **第一阶段弱时 2SLS 的偏差**：即使在大样本中，如果第一阶段弱，2SLS 的偏差可能使人误以为效应比 OLS 估计的更大——Bound-Jaeger-Baker (1995) 的经典警告。
- **简约式有时就是政策参数**：在某些情境下，政策制定者关心的恰恰是 ITT——"中签对健康的影响"比"实际参保对健康的影响"更有政策意义（因为政策不能强制参保，只能提供机会）。
