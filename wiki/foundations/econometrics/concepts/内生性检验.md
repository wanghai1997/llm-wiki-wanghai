# 内生性检验

## 一句话定义

> **内生性检验** = 比较 OLS 和 IV 估计量的差异——如果两者在统计上显著不同 → 存在内生性 → 应使用 IV；如果无显著差异 → OLS 可能足够（更有效）。

## 为什么需要

- IV 比 OLS 的方差更大（效率更低）——如果内生性不严重，用 OLS 是更好的选择
- 内生性检验提供了证据：是否需要付出 IV 的效率代价

## Hausman 内生性检验

### 回归版（Wooldridge 方法）

1. 第一阶段：$x_{endo} = \pi_0 + \pi_1 Z_1 + ... + \pi_k Z_k + \mathbf{x}_{exog}'\boldsymbol{\gamma} + v$
2. 获得残差 $\hat{v}$
3. 在原始方程中加入 $\hat{v}$：
   $$y = \beta_0 + \beta_1 x_{endo} + \mathbf{x}_{exog}'\boldsymbol{\delta} + \rho \hat{v} + u$$
4. 检验 $H_0: \rho = 0$（$x_{endo}$ 是外生的）
5. 如果 $\hat{\rho}$ 显著 → 拒绝 $H_0$ → $x_{endo}$ 是内生的 → 使用 IV

### 逻辑

如果 $x_{endo}$ 是外生的 → $\text{Cov}(x_{endo}, u) = 0$ → $\hat{v}$（$x_{endo}$ 中与 $u$ 可能相关的部分）应该与 $y$ 无关（在控制原始变量后）。

## OLS vs IV 差异的实证含义

- **差异大 + 显著**：内生性严重 → 必须用 IV
- **差异小 + 不显著**：内生性可能不严重 → 可以报告 OLS（或同时报告两者）
- **差异小但工具弱**：检验可能无功效——不能得出"无内生性"的结论

## 反面论点与数据空白

- **内生性检验依赖于"至少有一个有效工具"**：如果所有工具都无效，检验无意义——排他性约束是检验的前提。
- **检验不显著 ≠ 无内生性**：可能是工具太弱导致检验功效不足。
