# 截取与截断回归

## 一句话定义

> **截取 (Censored)** = 真实值在某些阈值外被**隐藏**但观测值仍存在于数据中。**截断 (Truncated)** = 某些观测值**完全缺失**——不仅 $y$ 不可见，整个观测都消失了。两者都需要 MLE 修正。

## 截取回归——数据收集问题

### 从上截取 (Censoring from Above)

$$y_i^* = x_i\boldsymbol{\beta} + u_i \quad \text{但只观测到 } y_i = \min(y_i^*, c_i)$$

- $y^*$ 是真实值，但在 $c_i$ 处被截取
- 观测值 $y_i$ 和回归子 $x_i$ 都可见——只是 $y_i$ 不等于 $y_i^*$ 
- 例子：收入调查中收入 > $100,000 被记录为 $100,000（高收入被截取）

### 截取回归 vs Tobit

| | Tobit 角点解 | 截取回归 |
|---|---|---|
| 零的来源 | **选择的结果** | **数据收集规则** |
| 零意味着什么 | 最优决策 = 不参与 | 真实值 < 0 被强制设为 0 |
| 例子 | 捐赠 = 0（最优解） | 工资 < 最低工资被记录为最低工资 |

### 截取 MLE

$$L = \prod_{y_i=c_i} P(y_i^* \geq c_i | x_i) \cdot \prod_{y_i<c_i} f(y_i | x_i)$$

- 对截取观测：使用概率（$y^*$ 超过截取点的概率）而非密度——因为我们不知道确切值
- 对非截取观测：使用正常密度

## 截断回归——样本选择问题

**截断**：如果 $y_i^*$ 低于（或超过）某阈值，整个观测都**不出现**在样本中。

例如：只调查有工作的人 → 工资的观测被截断（没有工作的人的工资完全不可见）。

### 截断 MLE

$$f(y_i | x_i, y_i > c) = \frac{f(y_i | x_i)}{P(y_i > c | x_i)}$$

- 条件密度 = 原始密度 / 被观测到的概率
- 忽略截断直接用 OLS → **不一致**（因为样本不再是随机样本）

## 截取 MLE vs OLS

- OLS 在截取数据上**不一致**——真实关系被"压平"（截取点处的观测被向阈值挤压）
- 截取 MLE 恢复一致估计——但依赖正态性和同方差假设

## 反面论点与数据空白

- **截取和截断的 MLE 对分布假设高度敏感**：如果 $u$ 不是正态的 → MLE 可能比 OLS 更不一致。使用"更稳健"的 MLE 不如使用更好的数据收集设计。
- **在实践中，截取回归使用得不多**——因为大多数"截取"实际上是角点解——研究者经常混淆这两个概念。
