# 倾向得分方法

## 一句话定义

> **倾向得分** = 给定协变量时个体被处理的概率——Rosenbaum-Rubin (1983) 证明，在无混淆假设下，以倾向得分为条件等价于以所有协变量为条件——**降维**使匹配/分层/加权可行。

## 倾向得分的三种用途

| 方法 | 如何用 PS | 优势 |
|------|----------|------|
| **PS 匹配** | 将 PS 相似的处理组和控制组配对 | 直观、在医学研究中标准 |
| **PS 分层/子类** | 将样本按 PS 分 5-10 层，每层内比较 | 简单、不需要配对决策 |
| **IPW** | 用 PS 的倒数加权 | 与回归调整结合可双稳健 |

## PS 诊断——重叠假设

**重叠 (Overlap)** = 对于每个 $x$ 值，$0 < P(D=1|x) < 1$——即每个个体都有**非零概率**被处理或不被处理。

检查方法：
1. PS 分布的直方图——处理组和控制组的 PS 应该有充分重叠的区间
2. 如果某些区间只有处理组或只有控制组 → **缺乏重叠** → 那些观测不应被用于因果比较

## PS 平衡性诊断

加权/匹配后，检查协变量在处理组和控制组之间的**标准化差异**：

$$\text{SMD} = \frac{\bar{x}_{treated} - \bar{x}_{control}}{\sqrt{(s^2_{treated} + s^2_{control})/2}}$$

- |SMD| < 0.1 通常被视为良好的平衡（但这不是硬阈值）
- 如果某些变量在匹配/加权后仍不平衡 → PS 模型可能需要修正（加交互项/非线性项）

## PS 的优缺点

| 优点 | 缺点 |
|------|------|
| 降维：将 $k$ 维协变量缩减为 1 维得分 | 仍假设无混淆——与回归无本质区别 |
| 直观："相似的个体比较" | 对 PS 模型形式敏感——遗漏重要的交互项 → 不平衡 |
| 平衡性可检验 | 重叠假设不可修复——没有重叠的地区不能估计因果效应 |

## 实践建议

- 使用 PS 前先检查**变量平衡**——如果未匹配时处理组和控制组差异非常大，倾向得分的作用有限
- 报告匹配/加权前后的 SMD 表
- 不要只报告一种 PS 方法——PS 匹配 + IPW + 回归调整一起报告可以增强稳健性
