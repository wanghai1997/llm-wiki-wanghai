# 可贷资金市场

> **一句话定义**:**Loanable Funds Market**,把国民储蓄 $S$ 解释为"资金供给"、投资 $I$ 解释为"资金需求"、实际利率 $r$ 解释为"资金价格"的市场比喻。在 [[古典宏观长期模型]] 中,$r^*$ 由 $S(r) = I(r)$ 出清决定,是连接储蓄、投资、利率的标准框架。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 3.4 *Equilibrium in the Market for Goods and Services*
- 这是 Ch 3 整章的高潮——把生产侧 $Y$、消费侧 $C$、投资侧 $I$、政府 $G$/$T$ 整合在一张图里

## 标准图

```
r ↑
   |    \           /
   |     \    S(r) /
   |      \       /
   |       \     / I(r)
r* +........X   /
   |       / \ /
   |      /   X
   |     /   / \
   |    /   /   \
   +-------+---------> S, I
            S* = I*
```

- $S(r)$ 上斜:利率上升 → 现期消费机会成本上升 → 储蓄增加(教材简化为垂直线 $\bar{S}$ 也常见)
- $I(r)$ 下斜:利率上升 → 投资项目 NPV 下降 → 投资需求减少
- 均衡点 $(S^*, r^*)$

## 关键比较静态

### 1. 政府赤字 ↑

$G \uparrow$ 或 $T \downarrow$ → 公共储蓄 $T - G \downarrow$ → $S$ 左移 → $r^* \uparrow$、$I^* \downarrow$ → **挤出私人投资**(详见 [[挤出效应]])

### 2. 投资需求扩张

技术革命 / 投资税抵免 → $I$ 右移 → $r^* \uparrow$、$S^* \uparrow$ → 储蓄增加但只是部分被吸收

### 3. 储蓄偏好上升(节俭)

$S(r)$ 右移 → $r^* \downarrow$、$I^* \uparrow$ → 投资增加,长期资本形成加快

## 与货币市场的关系

- 古典模型:可贷资金市场决定**实际利率** $r$,货币市场决定**价格水平** $P$,两者分立(参见 [[古典二分法]])
- 凯恩斯模型(Ch 11+):流动性偏好理论决定名义利率,可贷资金市场被替代为商品市场
- Mankiw Ch 3 古典 + Ch 11+ 凯恩斯的对比是教材结构核心

## 与微观侧的对比

- 微观侧 [[禀赋经济]] / [[跨期消费选择]] 给出单个消费者的储蓄函数 $S^i(r)$
- 宏观侧把所有 $S^i(r)$ 加总为 $S(r)$,假设代表性消费者
- 微观投资由企业 [[生产函数]] + [[厂商最优化选择]] 决定

## 反面论点与数据空白

- **凯恩斯反对**:Keynes 1936 在 General Theory Ch 14 系统反驳可贷资金市场——主张利率由货币市场("流动性偏好")决定,储蓄被动适应投资,$S = I$ 通过收入而非利率调整。这场争论延续 90 年仍未完全解决。详见 [[李嘉图等价]] / [[凯恩斯消费函数]] [CONTRADICTION]
- **MMT 反驳**:政府支出无需"借入"私人储蓄,而是通过央行直接创造。"政府与私人争夺资金"叙事在主权货币体制下不成立。
- **零利率下限挑战**:实证中 2008-2022 美日欧实际利率长期接近零或负,但储蓄 / 投资差距未显著缩小——挑战 $r$ 作为均衡价格的角色。可能解释:Summers 2013 长期停滞、Carvalho-Ferrero 老龄化储蓄过剩、Caballero-Farhi 安全资产稀缺。
- **国际可贷资金市场**:开放经济中,$r$ 由全球资金供求决定;美国持续吸纳全球储蓄(经常账户赤字)使国内 $S \neq I$ 长期存在。教材 Ch 3 假设封闭经济。
- **金融体系细节被抽象**:可贷资金市场把银行 / 影子银行 / 资本市场简化为单一定价机制——遗漏了 2008 危机暴露的"金融脆弱性"维度(Minsky 1986)。
