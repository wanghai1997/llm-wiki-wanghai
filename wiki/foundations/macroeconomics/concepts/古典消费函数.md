# 古典消费函数

> **一句话定义**:**Classical Consumption Function**(教材 Ch 3 简化版本),消费 $C$ 是可支配收入 $Y - T$ 的增函数:
$$ C = C(Y - T),\quad 0 < MPC < 1 $$
其中 $MPC = dC/d(Y - T)$ 是边际消费倾向。这是 Keynes 1936 *General Theory* 引入的"心理基本规律"在古典模型中的简化形式。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 3.3 *The Components of the Demand for Goods and Services*
- Ch 3 假设 $C$ 仅依赖 $Y - T$,不依赖于利率 $r$;Ch 16(后续 Batch)放松此假设,讨论永久收入、生命周期、行为偏差等更精致的消费理论

## 教材公式

### Mankiw Ch 3 标准形式

$$ C = \bar{C} + c (Y - T),\quad 0 < c < 1 $$

- $\bar{C}$:自主消费(基础生活成本,与收入无关)
- $c = MPC$:边际消费倾向,典型值 0.6-0.9
- $1 - c = MPS$:边际储蓄倾向

### 边际消费倾向(MPC)的实证估计

| 研究 / 数据 | MPC 估计 | 时段 |
|---|---|---|
| Keynes 1936 估计 | 0.7-0.9 | 1929 经济崩盘截面 |
| Friedman 1957(永久收入) | 短期低 / 长期 1.0 | 1929-1955 |
| Souleles 2002(税收回扣) | 0.2-0.6 | 1980 美国减税 |
| Parker-Souleles-Johnson-McClelland 2013 | 0.5-0.9(异质性) | 2008 stimulus checks |
| Fagereng-Holm-Natvik 2021 挪威彩票 | ~0.5 | 微观面板 |

实证 MPC 在 0.2-0.9 区间,**异质性**显著(贫困家庭 MPC 接近 1,富裕家庭 MPC 接近 0)。

## 与现代消费理论的对比

| 理论 | 时间 | 核心 | 对古典 $C(Y-T)$ 的修正 |
|---|---|---|---|
| Keynes 1936 | "心理基本规律" | $C \uparrow$ 慢于 $Y \uparrow$ | 古典版本采纳 |
| Friedman 1957 永久收入 | 消费平滑 | $C = c \cdot Y^P$ | 短期波动小 |
| Modigliani 生命周期 | 跨期最优 | $C$ 取决于一生收入与年龄 | 引入财富效应 |
| Hall 1978 随机游走 | 理性预期 | $C_{t+1} = C_t + \epsilon$ | 不可预测变化 |
| Laibson 1997 双曲贴现 | 行为时间偏好 | 短期过度消费 | 引入心理偏差 |
| Kaplan-Violante 2014 HANK | 异质代理人 | "hand-to-mouth"消费者 ~30% | MPC 异质性 |

Mankiw Ch 3 用最简单的 $C(Y-T)$ 是为了快速建立古典模型;Ch 16 系统讨论上述各派,这是后续 Batch 的内容。

## 反面论点与数据空白

- **过度简化**:$C(Y-T)$ 把储蓄决策当成静态选择,忽略跨期最优、流动性约束、预期、风险——使古典模型在解释 2008 后消费行为时严重失败。
- **MPC 异质性不可忽略**:把 $c$ 当常数掩盖了财富分布对加总 MPC 的影响。Auclert 2019 *Monetary Policy and the Redistribution Channel* 显示:加总 MPC 跨周期波动主要由财富分配变化驱动。
- **跨期决策被忽略**:Friedman 永久收入 / Modigliani 生命周期 / Hall 随机游走都隐含**跨期最优化**,与古典 $C(Y-T)$ 静态决策框架不兼容。详见 [[微观基础]] 中关于 Lucas 批判的讨论。
- **行为偏差**:[[Robert Shiller]] / Akerlof Animal Spirits、Laibson 双曲贴现、Thaler 心理账户等显示真实消费行为偏离任何"理性"模型——但教材 Ch 3 完全忽略此维度。
- **regional-bias**:MPC 估计集中在美国;发展中国家因金融排斥、非正式部门规模庞大,MPC 异质性可能更极端。[regional-bias]
