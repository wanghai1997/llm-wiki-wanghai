# 汇率制度

> **一句话定义**:汇率制度是国家货币当局对汇率形成机制的制度安排——从完全由市场决定的**浮动汇率**到完全由政府设定的**固定汇率**(以及中间形态如爬行盯住、货币局、管理浮动等),不同制度在货币政策独立性、汇率稳定性和资本流动性之间形成权衡。

## 汇率制度光谱

### IMF 分类(简化)

| 制度 | 描述 | 例子 |
|---|---|---|
| **硬盯住** | 汇率固定于锚货币或货币联盟 | 欧元区、美元化(巴拿马) |
| **软盯住** | 汇率围绕中心汇率窄幅波动 | 港币联系汇率(7.8 HKD/USD) |
| **爬行盯住** | 中心汇率按预设路径调整 | 1990s 中国(事实上的爬行盯住) |
| **管理浮动** | 市场主导但央行间歇干预 | 中国(2005 后)、新加坡 |
| **自由浮动** | 汇率完全由市场决定 | 美国、日本、英国、欧元区(对非欧元货币) |

### 教材侧重:固定 vs 浮动

Mankiw 教材主要对比两种极端:

| 维度 | 固定汇率 | 浮动汇率 |
|---|---|---|
| **汇率决定** | 央行设定并维持 | 外汇市场供求 |
| **货币政策** | 丧失独立性(必须维持汇率) | 保留独立性 |
| **贸易确定性** | 高(减少汇率风险) | 低(需对冲) |
| **投机攻击风险** | 有(若储备不足) | 无 |
| **自动调节** | 弱(需国内价格调整) | 强(汇率吸收外部冲击) |

## 三元悖论(不可能三角)

> 教材未明确使用此术语,但这是理解汇率制度的核心框架

$$\text{资本自由流动} + \text{固定汇率} + \text{货币政策独立} = \text{只能选其二}$$

| 选择 | 组合 | 例子 |
|---|---|---|
| A | 资本流动 + 固定汇率 | 香港(放弃货币政策独立) |
| B | 资本流动 + 货币政策独立 | 美国、日本(浮动汇率) |
| C | 固定汇率 + 货币政策独立 | 中国(资本管制) |

## 教材提及的案例

### 欧元区

- 货币联盟内部汇率固定(1:1),对外共同浮动
- **特殊之处**:单一货币 + 多元财政 → 成员国丧失货币政策 + 汇率工具,但财政不统一 → 危机时调整痛苦(2010s 欧债危机)

### 中国的汇率管理

- 1994-2005:盯住美元(8.28 CNY/USD)
- 2005-2015:管理浮动,参考一篮子货币
- 2015 后:"有管理的浮动",中间价形成机制多次改革
- **关键**:资本账户未完全开放 → 三元悖论中选择"固定汇率 + 货币政策独立 + 资本管制"

## 反面论点与数据空白

- **中间汇率制度的脆弱性**:Obstfeld-Rogoff 1995 指出"中间制度"(爬行盯住、目标区)最易遭受投机攻击;1997 亚洲金融危机中泰国、马来西亚、印尼的中间制度崩溃印证了此点。教材未深入。[CONTRADICTION]
- **最优货币区理论**:Mundell 1961 提出——货币联盟要求劳动力流动、财政转移、经济周期同步。欧元区显然不满足(劳动力流动低、财政转移少、南北周期不同步),这是欧债危机的制度根源。教材 Ch 12 简述但未展开。
- **汇率制度与增长的关系**:实证无稳健结论。固定汇率可降低通胀(锚定效应)和汇率风险(促进贸易),但也可能放大外部冲击传导(无法汇率缓冲)。
- **数字货币冲击**:CBDC(央行数字货币)可能使资本管制更难实施(数字钱包跨境使用),改变三元悖论的约束结构。教材 2016 出版,未涉及。[regional-bias]
- **regional-bias**:案例集中于美元、欧元、人民币;拉美(阿根廷货币局崩溃 2001)、非洲(CFA 法郎区)、中东(海湾国家盯住美元)等未涉及。
