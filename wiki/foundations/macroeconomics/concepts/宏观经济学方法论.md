# 宏观经济学方法论

> **一句话定义**:研究总量经济现象(GDP、通胀、失业、增长)的方法论体系,核心是用"模型 + 数据 + 政策"循环理解经济波动。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 1 *The Science of Macroeconomics*
- 镜像微观:[[实证经济学与规范经济学]](Nechyba Ch 1)

## 核心要素

### 1. 三大测量任务

宏观经济学首先是一门**测量科学**。它要回答三个问题:
1. **总产出**:经济体生产了多少?——[[GDP]]
2. **价格水平**:总体价格水平如何变化?——[[CPI]] / [[GDP平减指数]]
3. **就业 / 失业**:多少人在工作 / 找工作?——[[失业率]] / [[劳动力参与率]]

这三个测量构成宏观分析的"测度三件套",决定了所有后续模型的"被解释变量"。

### 2. 用模型理解世界

[[经济模型]]是简化的世界版本。Mankiw 强调"所有模型都是错的,但有些有用"——模型应:
- 区分**内生变量**(模型解释的)与**外生变量**(模型给定的);
- 做明确的**简化假设**,只保留与问题相关的特征;
- 接受**经验检验**(可证伪)。

### 3. 长期 / 短期二分

Mankiw 9e 的标志性方法论:
- **长期(几年到几十年)**:[[市场出清假设]]——价格灵活,供需总能平衡。古典模型适用(Part II-III)。
- **短期(几个月到一两年)**:**价格粘性**——价格调整慢,产出 / 就业可偏离潜在水平。凯恩斯模型适用(Part IV)。

这一二分见 [[价格灵活性与价格粘性]]。

### 4. 微观基础(Microfoundations)

Lucas 批判后,宏观模型应可追溯到家庭与企业的最优化决策。但 Mankiw 在 Part IV 仍使用 IS-LM 等"非微观基础化"模型——是教学便利与方法论严格性的折衷。详见 [[微观基础]]。

## 与微观经济学方法论的对比

| 维度 | 微观([[实证经济学与规范经济学]]) | 宏观(本页) |
|---|---|---|
| 主体 | 单个消费者 / 厂商 | 总量(GDP / CPI / 失业) |
| 默认假设 | 市场瞬时出清 | 长期出清,短期粘性 |
| 模型形式 | 效用 / 利润最大化 | 总量 IS-LM / AD-AS / Solow |
| 福利测度 | CV / EV / DWL | GDP 增长 / 失业率 / 通胀率 |
| 政策工具 | Pigou 税 / 信息制度 | 财政 / 货币 / 汇率 |
| 时间维度 | 静态 / 比较静态 | 长 / 短期分割,显式时间 |

## 反面论点与数据空白

- **方法论二元的内在张力**:Mankiw 同时承认长期市场出清与短期粘性,但**两套模型未在统一框架下推导**。[CONTRADICTION] Lucas-Sargent 1979 *After Keynesian Macroeconomics* 直接质疑这种"权宜之计",要求宏观模型必须有统一微观基础。Mankiw 在 Part V 用 Ramsey + Keynesian Cross 部分回应,但仍未达成 RBC / DSGE 派的严格性。详见 [[微观基础]]。
- **DSGE 的危机失灵**:2008 危机前,Smets-Wouters 等 DSGE 模型未能预测金融失稳;Paul Romer 2016 *The Trouble with Macroeconomics* 公开攻击微观基础范式"装作科学"。这一争议在 Mankiw 9e 中只在 Epilogue 有简短提及。
- **MMT(现代货币理论)的方法论挑战**:MMT 主张主权货币国家不存在"财政破产"约束,通胀才是真正的约束。这一立场对 Mankiw 9e 的"政府预算约束"叙事(Ch 15-19)构成根本挑战。教材未提及。[BIAS]
- **异端经济学的方法论替代**:Steve Keen *Debunking Economics*、Foley *Adam's Fallacy*、Shaikh *Capitalism: Competition, Conflict, Crises* 提供与新凯恩斯综合派完全不同的方法论框架。这些在主流中级教材中通常缺席。
