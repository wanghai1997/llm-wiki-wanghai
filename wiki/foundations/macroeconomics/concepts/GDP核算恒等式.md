# GDP 核算恒等式

> **一句话定义**:[[GDP]] 在支出法下的核算恒等式 $Y \equiv C + I + G + NX$,把总产出分解为消费、投资、政府支出与净出口。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 2.1.5
- 跨章应用:全书几乎每个宏观模型(IS-LM / 开放经济 / 财政政策)都从此恒等式出发

## 公式

$$Y \equiv C + I + G + NX$$

其中:
- $Y$:[[GDP]],总产出 / 总收入 / 总支出
- $C$:**Consumption**,居民消费(耐用品 + 非耐用品 + 服务)
- $I$:**Investment**,投资(企业固定投资 + 居民住房投资 + [[存货投资]])
- $G$:**Government purchases**,政府购买(**不**含转移支付如社保)
- $NX$:**Net Exports**,净出口 $= X - M$(出口减进口)

## 恒等的含义

注意"$\equiv$"而非"$=$":这是**会计恒等式**(accounting identity),不是行为方程。它在每一时期都成立,因为:
- 任何最终产品的销售必然落入 $C, I, G, X$ 之一;
- 进口 $M$ 减去是因为 $C, I, G$ 包含了对进口品的支出,需扣除以保留"国内生产"的范围。

### 简单数值例:2014 美国 GDP 分解

| 项 | 占比 GDP | 备注 |
|---|---|---|
| C(消费) | 68% | 服务约 47%, 商品约 21% |
| I(投资) | 16% | 含住房 / 设备 / 软件 / 存货 |
| G(政府购买) | 18% | 联邦 + 州 + 地方;**不**含转移支付 |
| NX(净出口) | -3% | 美国长期贸易逆差 |

(数据:[[美国经济分析局BEA]] NIPA;Mankiw Ch 2 表 2-1)

## 关键易错点

### 1. 政府支出 G 不含转移支付

社会保障、医疗补贴、失业救济属于**转移支付**(transfer payments),不构成 $G$——因为政府未直接购买商品 / 服务。但个人收到转移支付后用于消费,会计入 $C$。

### 2. 投资 I 包含存货变动

企业生产但未售出的产品计入当期 GDP(通过 [[存货投资]] 计入 $I$),保证生产法与支出法一致。

### 3. 进口减去是为了"国内生产"

若中国制造的手机在美国销售,该笔交易计入 $C$ 同时计入 $M$,净效应为零,符合"美国 GDP 不含中国生产"的边界。

## 与微观经济学的关系

- 微观侧的"市场出清"$Q^d = Q^s$ 是单一市场的需求 = 供给;
- 宏观侧的 $Y \equiv C + I + G + NX$ 是**所有市场加总**的会计恒等式;
- 二者本质不同:微观恒等式可推论行为(供需均衡),宏观恒等式只是定义,**不**单独决定均衡。

## 反面论点与数据空白

- **恒等式的"科学伪装"**:作为定义,$Y \equiv C + I + G + NX$ **不告诉我们任何因果**——它是真理性等式而非经验命题。但教科书常含蓄地把它当作"凯恩斯总需求 = 总供给"的因果论据。Davidson、Robinson、Keen 反复批评这种"恒等即模型"的滑坡。[BIAS]
- **金融部门的隐形**:恒等式中"投资 I"是非金融固定投资(主要是设备 / 建筑),金融市场上股票债券交易**不**计入 GDP。这一边界使 GDP 难以反映 2008 危机前金融脆弱性的累积。Brunnermeier-Sannikov 2014 等提出"金融加速器"补充。
- **数字经济测度盲点**:Wikipedia / 开源软件 / 社交媒体的"零价格商品"创造消费者剩余但不计入 $C$。Brynjolfsson et al. 2019 GDP-B 估计这一缺口可达美国 GDP 5-10%。详见 [[GDP的局限性]]。
- **regional-bias**:进口 $M$ 的处理方式在中国 SNA(支出法核算时单独列出)与美国 NIPA(并入 $C, I, G$ 后扣除)略有差异。
