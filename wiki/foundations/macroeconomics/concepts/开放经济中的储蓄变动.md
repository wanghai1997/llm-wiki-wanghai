# 开放经济中的储蓄变动

> **一句话定义**:在小型开放经济中,任何提高国民储蓄的因素(消费紧缩、财政紧缩、私人储蓄激励)都会在世界利率不变下增加净出口(贸易顺差扩大)和实际汇率升值;储蓄是开放经济中国际收支状况的根本决定因素。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 6.2-6.3 政策应用部分
- 与 [[开放经济中的财政政策]] 形成镜像:财政扩张降低储蓄、恶化贸易余额;储蓄增加则相反

## 核心机制

### 储蓄增加的传导链

$$S \uparrow \Rightarrow (S - I) \uparrow \Rightarrow NX \uparrow \Rightarrow \epsilon \uparrow$$

具体步骤:
1. 私人储蓄增加(如退休账户激励、预防性储蓄)或政府储蓄增加(财政盈余)
2. $r^*$ 不变 → $I$ 不变
3. $S - I$ 缺口扩大 → $NX \uparrow$(顺差扩大)
4. 外汇市场:本币需求增加(资本流出增加) → 实际汇率升值

### 图形分析

```
  NX, S-I
  │╲        S-I₁ (储蓄增加后右移)
  │ ╲       │
  │  ╲  S-I₀│
  │   ╲ │   │
  │    ╲│   │
  └─────┴───┴─── ε
       ε₀  ε₁
```

- $S - I$ 垂直线右移 → 均衡实际汇率 $\epsilon^*$ 上升(实际升值)
- 净出口 $NX^*$ 上升(顺差扩大)

## 储蓄变动的来源

### 1. 私人储蓄增加

- **消费函数下移**:消费者变得更节俭
- **预防性储蓄**:收入不确定性增加(如金融危机、疫情)
- **退休储蓄激励**:IRA、401(k) 税收优惠
- **财富效应逆转**:房价/股价下跌 → 财富减少 → 储蓄增加

### 2. 公共储蓄增加(财政紧缩)

- $G \downarrow$ 或 $T \uparrow$ → 政府预算盈余 → 国民储蓄 $S$ 增加
- 教材案例:1990s 美国财政整固(Clinton 时代增税 + 削减赤字)

### 3. 产出增加

- $Y \uparrow$(技术进步、要素积累) → $S = Y - C - G$ 增加(假设 $C$ 增速低于 $Y$)

## 全球储蓄与全球失衡

### 全球储蓄过剩假说(Global Saving Glut)

- **Bernanke 2005 提出**:2000s 美国长期贸易逆差反映的是全球储蓄过剩
- **来源**:
  - 新兴市场积累外汇储备(亚洲金融危机后的自我保险)
  - 石油出口国石油美元回流
  - 人口老龄化国家的储蓄增加
- **含义**:美国贸易逆差不是美国"过度消费"的单一故事,而是全球结构性因素——储蓄供给超过投资需求,美国作为"吸收者"

### 安全资产稀缺

- **Caballero-Farhi-Gourinchas 2017**:全球对美国国债等安全资产的过度需求
- 美国通过发行安全资产(国债)吸收全球储蓄 → 资本流入 → 贸易逆差
- 这不是简单的 "$S < I$",而是**资产组合选择**的结果

## 反面论点与数据空白

- **储蓄-投资相关性的 Feldstein-Horioka 之谜**:若资本完全流动,各国 $S$ 和 $I$ 应不相关;但实证显示 1960s-90s OECD 国家 $S-I$ 相关性仍高(0.6-0.9)。这说明资本流动性不如模型假设的完全。教材未涉及。[CONTRADICTION]
- **储蓄率的文化与制度差异**:Modigliani 生命周期假说、社会安全网完善程度、金融发展程度均影响储蓄率;模型将储蓄视为外生或仅由当前收入决定,过于简化。详见 [[消费函数]](后续 Batch)。
- **企业储蓄的崛起**:2000s 后全球企业储蓄(未分配利润)大幅上升,部分抵消了家庭储蓄下降。企业储蓄动机(税务筹划、不确定性、投资机会缺乏)与家庭不同。教材未区分。
- **regional-bias**:案例集中于美国;中国高储蓄率(预防性储蓄 + 金融抑制 + 人口结构)、德国高储蓄-高顺差模式、日本 1990s 后储蓄下降等未深入。
