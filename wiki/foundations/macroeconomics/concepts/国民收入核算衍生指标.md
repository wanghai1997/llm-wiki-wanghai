# 国民收入核算衍生指标

> **一句话定义**:从 [[GDP]] 出发的概念栈——NDP、NI、PI、DPI——逐层减去折旧、企业留存、转移到家庭可支配收入。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 2.1.6 *Other Measures of Income*
- 制度:[[美国经济分析局BEA]] NIPA 表 1.7.5

## 概念栈(从 GDP 到 DPI)

```
GDP(国内生产总值)
  − 折旧(Consumption of Fixed Capital)
= NDP(Net Domestic Product,国内生产净值)

NDP
  + 净海外要素收入 NIA
  − 间接税 + 补贴
= NI(National Income,国民收入)

NI
  − 公司未分配利润
  − 公司税
  − 社保税
  + 政府转移支付
  + 个人利息收入
= PI(Personal Income,个人收入)

PI
  − 个人所得税
= DPI(Disposable Personal Income,个人可支配收入)
```

## 各指标的含义

| 指标 | 简写 | 经济含义 | 主要应用 |
|---|---|---|---|
| GDP | - | 境内生产总规模 | 国际比较、增长分析 |
| NDP | - | 扣除资本耗用后的"净"产出 | 长期可持续增长指标 |
| NI | - | 国民要素收入总额 | 收入分配分析 |
| PI | - | 居民部门得到的收入 | 消费 / 储蓄分析 |
| DPI | - | 居民可自由支配收入 | 消费函数建模 |

## 在 Mankiw 教材后续 Batch 的应用

- **Batch 7 Ch 16 消费理论**:消费函数通常表达为 $C = f(\text{DPI})$,例 [[Keynes消费函数]] $C = a + b \cdot Y_d$;
- **Batch 7 Ch 15 财政政策**:转移支付 + 税收的政策效应通过 PI / DPI 传导;
- **Batch 5 Ch 10 IS-LM**:简化版常用 GDP 替代 DPI(Mankiw 9e 教学便利)。

## 关键易错点

### 折旧不同定义

- **GAAP 折旧**:企业账面折旧,基于历史成本与会计规则;
- **NIPA 折旧**:经济折旧,基于现期重置成本(replacement cost);
- 两者数值常显著不同;NIPA 折旧才是 GDP → NDP 的扣除项。

### 转移支付的位置

转移支付(社保 / 失业救济)**不**计入 GDP(因不是新生产),但**计入** PI / DPI。这一区别在分析"政府支出"政策效应时关键:
- 政府购买($G$)直接计入 GDP;
- 转移支付通过 DPI → 消费函数 → GDP 的间接渠道。

## 反面论点与数据空白

- **NDP 的边缘化**:经济理论上 NDP 比 GDP 更准确(扣除资本损耗),但媒体与政策几乎只讨论 GDP——因 NDP 的折旧测度依赖资本存量估算,争议大。这意味着官方"经济增长"叙事系统性高估"净"增长。Coyle 2014 指出这是 GDP 拜物教的延伸。[BIAS]
- **DPI 测度对税收政策敏感**:个人所得税扣除直接影响 DPI,但不同税种(联邦 / 州 / 地方 / 社保税)的归类边界存在统计争议;美国 NIPA 与英国 ONS 处理不同。
- **regional-bias**:中国 NBS 历史上不发布完整 PI / DPI 体系,只发布"居民可支配收入";直到 2013 后才与城镇 / 农村调查数据并行公布。
