# 最低工资

> **一句话定义**:最低工资(minimum wage)是政府设定的法定工资下限,若高于市场出清水平则标准竞争模型预测失业增加;但 [[David Card]]-[[Alan Krueger]] 1994 新泽西自然实验发现就业未下降,引发对竞争模型适用性的根本质疑——买方垄断(monopsony)模型可提供一致解释,但 Mankiw 教材回避此框架。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 7.3 *Real-Wage Rigidity and Structural Unemployment*
- 作为 [[实际工资刚性]] 的制度来源之一呈现

## 标准竞争模型预测

### 模型

```
  W/P
  │    LS (劳动供给)
  │      ╲
  │   W̄  ╲────── 最低工资
  │        │  ╲ LD (劳动需求)
  │        │    ╲
  │        │      ╲
  └────────┴────────── L
       LD   LS
```

- 均衡工资 $W/P_{eq}$
- 最低工资 $\bar{w} > W/P_{eq}$
- 就业量 = $LD(\bar{w})$ < $LS(\bar{w})$
- 失业 = $LS - LD$

### 政策含义

- 最低工资提高 → 低技能工人失业增加
- 对贫困的缓解效果有限(许多穷人已失业或非劳动力)
- 替代政策:劳动收入税收抵免(EITC)

## Card-Krueger 自然实验(1994)

### 设计

- **处理组**:新泽西州,1992 年最低工资从 $4.25 提升至 $5.05/小时
- **控制组**:相邻的宾夕法尼亚州,最低工资维持 $4.25
- **数据**:快餐店(Burger King、KFC、Wendy's、Roy Rogers)就业调查
- **方法**:双重差分法(DiD)

### 发现

| 指标 | 新泽西(处理组) | 宾州(控制组) | 差异 |
|---|---|---|---|
| 就业变化 | +0.6% | -2.1% | **+2.7%** |
| 工资变化 | +$0.53 | +$0.04 | +$0.49 |

- 新泽西最低工资提升后,快餐店就业**未下降**,相对宾州甚至微升

### 后续验证

| 研究 | 数据 | 结论 |
|---|---|---|
| Neumark-Wascher 2000 | 行政 payroll 数据 | 质疑 Card-Krueger 调查数据可靠性,发现小幅负效应 |
| Dube-Lester-Reich 2010 | 州级边界 county 配对 | 确认 Card-Krueger 结论,控制空间相关 |
| Cengiz et al. 2019 | 138 个州级最低工资变动 + 行政数据 | 确认"无显著负效应",但发现低薪工作**小时数**小幅下降 |
| Jardim et al. 2022 | 西雅图 $15 最低工资 | 混合结果:总就业不变但低薪工人工作时间下降 |

## 买方垄断(Monopsony)解释

### 为什么最低工资不增加失业?

标准模型假设企业是**工资接受者**;现实中许多劳动力市场存在**买方垄断**(单一或少数雇主):

```
  W
  │      S (向上倾斜的劳动供给)
  │        ╲
  │    W̄   ╲───── 最低工资
  │          │  ╲ MFC (边际要素成本)
  │          │    ╲
  │          │      ╲ VMP (边际产品价值)
  └──────────┴────────── L
       LD    LS
```

- 买方垄断企业面临**向上倾斜的劳动供给曲线**
- 边际要素成本 $MFC > W$(多雇一人需提高所有工人工资)
- 利润最大化: $VMP = MFC$ → 就业 $L_m$ < 竞争水平 $L_c$,工资 $W_m$ < $W_c$
- **适度最低工资**($W_m < \bar{w} < W_c$):降低 MFC → 就业 **增加**
- **过高最低工资**($\bar{w} > W_c$):才导致失业

### 教材的处理

Mankiw 教材:
1. 先讲标准竞争模型 → 最低工资 → 失业
2. 然后引用 Card-Krueger 结果
3. 以脚注"一些经济学家认为结果不稳健"消解
4. **不引入买方垄断模型**

**[BIAS]**:最低工资竞争模型占主导,买方垄断解释被边缘化。微观 Nechyba Ch 26 有劳动买方垄断详述,但宏观教材回避,造成知识断裂。

## 反面论点与数据空白

- **[CONTRADICTION] 教材回避买方垄断**:Card-Krueger 结果最自然的理论解释是劳动力市场买方垄断,但 Mankiw 教材仅在脚注提及争议,正文维持竞争模型主导。这与微观 [[利润最大化问题]] Ch 26 的劳动买方垄断分析直接矛盾。[CONTRADICTION]
- **适用范围争议**:Card-Krueger 研究快餐店(低技能、高流动性、局部垄断雇主);结果推广至制造业、高最低工资情境需谨慎。Cengiz et al. 2019 发现当最低工资超过工资中位数 59% 时,就业出现下降。
- **青少年 vs 成人效应**:最低工资对青少年(16-19 岁)就业的负效应在文献中更稳健;对成人就业影响较小。教材未区分。
- **EITC 与最低工资的互补性**:许多经济学家主张最低工资 + 劳动收入税收抵免(EITC)组合——最低工资确保雇主支付合理工资,EITC 由财政补充收入。教材未涉及此政策组合。
- **平台经济中的最低工资**:Uber / 外卖平台工人的"最低工资"如何定义?按在线时间、接单时间、还是实际工作时间?平台经济的最低工资执法面临定义和监测挑战。教材未涉及。
- **regional-bias**:美国州级实验为主;巴西、印尼等发展中国家的全国最低工资覆盖大部分劳动力,但实证文献较少;欧洲(法国 SMIC、英国 NLW)的最低工资制度与美国差异大。
