# 恶性通胀

> **一句话定义**:**Hyperinflation**,通胀率达到极端水平(传统定义:[[Phillip Cagan]] 1956 标准 = 月度通胀率 ≥ 50%,即年化 ≥ 12,800%)。恶性通胀几乎总是政府赤字过度货币化的结果——是 [[铸币税与通胀税]] 拉弗曲线右侧的崩溃。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 5.5 *Hyperinflation*
- 教材作为通胀理论的极端案例研究

## Cagan 1956 标准

- **月度通胀率 ≥ 50%**(年化通胀 ≥ 12,800%)
- 数学:$(1.50)^{12} - 1 = 12,875\%$
- 这是任意数学切分,不是经济性质的根本区别——但便于实证操作

## 历史案例(扩展自 Cagan 1956 + 后续)

| 国家 | 时段 | 月度峰值 | 触发因素 |
|---|---|---|---|
| 奥地利 | 1921-22 | ~134% | 一战赔款 + 政治混乱 |
| 德国 | 1922-23 | **32,400%** | 凡尔赛赔款 + 鲁尔危机 |
| 匈牙利 1 | 1923-24 | ~98% | 一战后重建 |
| **匈牙利 2** | **1945-46** | **$\sim 4.19 \times 10^{16}\%$** | **史上最高**,二战重建 + 苏联占领 |
| 波兰 | 1923 | ~275% | 一战后政治不稳定 |
| 苏联(俄罗斯) | 1921-24 | ~213% | 内战 + 战时共产主义 |
| 希腊 | 1944 | ~85,500% | 二战占领期 |
| 中国国统区 | 1947-49 | ~5,000% | 内战 + 财政崩溃 |
| 玻利维亚 | 1985 | ~120% | 财政赤字 + 政治混乱 |
| 阿根廷 | 1989-90 | ~200% | 长期财政失衡 |
| **巴西** | **1989-94** | **~80%/月** | **持续 5 年的高通胀,Plano Real 终结** |
| **南斯拉夫** | **1992-94** | **~313,000%(月)**| **解体战争** |
| **津巴布韦** | **2007-2008** | **~$7.96 \times 10^{10}\%$** | **土地改革 + 财政崩溃** |
| **委内瑞拉** | **2016-2020** | **~233%(月度峰值)**| **石油价格暴跌 + 制裁 + 货币化赤字** |

## 共同的政治经济学根源

### 1. 财政崩溃

- 政府无力征税但必须支出(战争 / 债务 / 福利) → 印钞融资 → 通胀
- "通胀税是最后的税"

### 2. 货币需求崩溃

- 通胀超过临界点 → 居民迅速减少货币持有(去美元化、物物交换)
- $V$ 大幅上升 → 价格进一步上升
- 形成自我加速

### 3. 政治可信度丧失

- 居民不相信政府能控制通胀 → 通胀预期失锚
- 通胀税收入下降(拉弗曲线右侧)→ 财政更紧张 → 印更多钞 → 通胀加速

## 终结模式

### Sargent 1982 *The Ends of Four Big Inflations*

研究德、奥、匈、波 1923-25 的恶性通胀终结,发现共同特征:

1. **可信的财政改革**(预算平衡 + 央行独立)
2. **货币改革**(发行新货币 + 旧币兑换比)
3. **国际背书**(国联贷款 + 援助)
4. 一旦市场确信改革可信,通胀**几乎瞬间停止**——而不是渐进下降

### 现代恶性通胀终结案例

- **1985 玻利维亚**:Sachs 经济学休克疗法 → 数月内通胀从 24,000% 降到 0
- **1991 阿根廷可兑换计划**(currency board):比索锚定美元 → 通胀迅速消失(但 2001 不可持续)
- **1994 巴西 Plano Real**:渐进锚定 + URV 过渡单位 → 平稳终结

## 现代特殊形式

### 1. 美元化(Dollarization)

- 厄瓜多尔 2000、津巴布韦 2009、萨尔瓦多 2001
- 直接放弃本币 → 用美元 → 通胀立即降到美国水平
- 代价:失去货币政策独立性

### 2. 加密美元化

- 委内瑞拉 / 阿根廷 2020+ 居民部分使用 USDT、USDC
- 比传统美元化更分布式,无需政府授权

### 3. 货币局(Currency Board)

- 香港(1983-)、保加利亚(1997-)
- 法币严格按外汇储备发行 → 自动消除超额货币创造

## 反面论点与数据空白

- **恶性通胀始终是货币现象?**:Friedman 名言"通胀始终是货币现象"在恶性通胀几乎总成立——但触发因素是**财政崩溃**而非货币当局自主选择。这使"货币 vs 财政"二分法在恶性通胀中失去意义。
- **MMT 反驳**:MMT 主张恶性通胀的本质是"实际产出能力崩溃",而非货币供给过度——委内瑞拉、津巴布韦的案例支持(石油价格 / 农业崩溃 → 实际产出萎缩 → 货币化赤字超过经济承受力)。
- **拉弗曲线在极端通胀中的崩溃**:Cagan 模型预测通胀税在 $\pi^* = 1/\eta$ 处达峰值,但津巴布韦 / 委内瑞拉数据显示 $\eta$ 本身随通胀漂移 → 简单 Cagan 模型在 monthly $\pi > 50\%$ 时失效。
- **政治经济学维度被忽略**:恶性通胀的"成本"主要是政治后果(政府倒台、内战、外部干预)→ 经济学家的"福利损失"估计严重低估。
- **加密美元化的新动力学**:委内瑞拉、阿根廷 2020+ 居民通过 P2P 平台使用 USDT —— 改变了 Cagan 时代的货币替代速度。教材未充分讨论。
- **regional-bias**:Cagan 七案例集中在 20 世纪上半叶欧洲 + 中国;非洲、亚洲、近期拉美的恶性通胀经验研究有限。[regional-bias]
