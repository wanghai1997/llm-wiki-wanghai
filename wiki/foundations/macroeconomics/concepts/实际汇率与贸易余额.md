# 实际汇率与贸易余额

> **一句话定义**:实际汇率($\epsilon$)与净出口($NX$)的关系构成开放经济均衡的核心机制——实际汇率调整使贸易余额等于储蓄-投资缺口($NX = S - I$),从而同时出清商品流动市场与资本市场。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 6.3 *Exchange Rates* (后半部分)

## 核心机制

### 净出口函数

$$NX = NX(\epsilon), \quad NX'(<0$$

- $\epsilon$ 上升(实际升值):国内商品相对变贵 → 出口竞争力下降 → $NX \downarrow$
- $\epsilon$ 下降(实际贬值):国内商品相对变便宜 → 出口竞争力上升 → $NX \uparrow$

### 均衡条件

$$NX(\epsilon) = S - I(r^*)$$

- **垂直线**:$S - I(r^*)$ 由国内储蓄、投资与世界利率决定,**不依赖**实际汇率
- **向下倾斜线**:$NX(\epsilon)$ 随实际汇率上升而下降
- **交点**:决定均衡实际汇率 $\epsilon^*$

```
  NX, S-I
  │╲    S-I (垂直)
  │ ╲   │
  │  ╲  │
  │   ╲ │    NX(ε) 向下倾斜
  │    ╲│
  └─────┴─────── ε
        ε*
```

### 调整逻辑

1. 若 $\epsilon > \epsilon^*$:$NX(< S - I$ → 外汇市场本币过剩 → 本币贬值 → $\epsilon \downarrow$ → 回到均衡
2. 若 $\epsilon < \epsilon^*$:$NX(> S - I$ → 外汇市场本币稀缺 → 本币升值 → $\epsilon \uparrow$ → 回到均衡

## 政策变动分析

### 财政扩张($G \uparrow$)

- $S \downarrow$ → $S - I$ 左移(垂直线左移)
- $NX(\epsilon)$ 不变
- $\epsilon^* \downarrow$(实际贬值)
- $NX^* \downarrow$(逆差扩大)
- **名义汇率**:若价格水平不变,名义汇率随实际汇率贬值

### 世界利率上升($r^* \uparrow$)

- $I(r^*) \downarrow$ → $S - I$ 右移
- $\epsilon^* \uparrow$(实际升值)
- $NX^* \uparrow$(顺差扩大)

### 贸易保护主义($NX$ 曲线右移)

- 关税/配额 → 在任何 $\epsilon$ 下 $NX$ 更高
- $NX$ 曲线右移
- $\epsilon^* \uparrow$(实际升值)
- **但 $NX^*$ 不变!**——储蓄-投资缺口未变,汇率升值完全抵消贸易保护效果
- 教材结论:**保护主义不改变贸易余额,只改变汇率**

## 反面论点与数据空白

- **J 曲线效应**:教材假设汇率变动即时影响 $NX$;实际中由于合同刚性、库存调整、消费者习惯,$NX$ 对汇率的反应存在时滞——短期可能向相反方向移动(J 形),长期才回归理论预测。[CONTRADICTION]
- **马歇尔-勒纳条件**:教材隐含假设 $|\eta_X + \eta_M| > 1$(出口与进口需求弹性之和大于 1);若此条件不满足,贬值反而恶化贸易余额。实证上发展中国家往往不满足此条件(低替代弹性)。
- **保护主义的多维效果**:教材结论"保护主义不改变贸易余额"过于简洁。关税收入可增加政府储蓄、改变收入分配、触发报复性关税、扭曲资源配置;汇率升值的传导可能不完全(价格粘性)。
- **全球价值链使 $NX$ 函数退化**:中间品多次跨境使"出口"和"进口"高度交织;汇率对 $NX$ 的影响被价值链稀释。传统 $NX(\epsilon)$ 框架的适用性下降。
- **regional-bias**:案例集中于美国贸易逆差;中国"出口导向 + 汇率管理"模式、德国高附加值出口竞争力、资源出口国汇率-大宗商品联动等未涉及。
