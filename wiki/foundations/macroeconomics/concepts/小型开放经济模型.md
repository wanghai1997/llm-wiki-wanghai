# 小型开放经济模型

> **一句话定义**:小型开放经济模型(Small Open Economy Model)假设一国是世界资本市场的**价格接受者**(price taker)——世界实际利率 $r^*$ 外生给定;国内储蓄 $S$ 由收入与财政政策决定,国内投资 $I(r^*)$ 由世界利率决定;两者的缺口通过净出口 $NX$ 自动调整,维持国际收支平衡。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 6.2 *The Small Open Economy*
- 将 [[储蓄-投资均衡]] 从封闭经济($S = I$,利率内生)扩展到开放经济($r = r^*$, $NX$ 调节)

## 模型结构

### 假设清单

| 假设 | 含义 | 现实偏离 |
|---|---|---|
| **小型** | 资本流动规模不足以影响世界利率 | 美国、中国、欧盟显然不满足 |
| **开放** | 资本完全自由流动,无管制 | 中国资本账户管制、战后欧洲资本管制 |
| **价格接受者** | $r = r^*$,世界利率外生 | 大国政策影响全球 $r^*$ |
| **古典长期** | 价格灵活,产出 $Y = F(K,L)$ 由要素决定 | 短期价格粘性(Ch 10+) |

### 核心方程

**储蓄函数**:
$$S = Y - C(Y - T) - G$$
- $S$ 不依赖利率(简化假设;教材注:更一般地 $S$ 可随 $r$ 微增)

**投资函数**:
$$I = I(r^*), \quad I'(r^*) < 0$$
- 投资由**世界利率**决定,而非国内储蓄

**净出口/净资本流出**:
$$NX = S - I(r^*) = NCO$$

**实际汇率(后续)**:
$$NX = NX(\epsilon), \quad NX'(<0$$
- 详见 [[实际汇率与贸易余额]]

## 图形分析

```
  r
  │    S(垂直线——储蓄不依赖r)
  │    │
r*───┼────┼────┐
  │    │    │    I(r) 向下倾斜,但此处 r* 外生
  │    │    │
  └────┴────┴─────── I, S, NX
       │←S-I(r*)=NX→│
```

- 若 $S > I(r^*)$:NX > 0,贸易顺差,资本净流出
- 若 $S < I(r^*)$:NX < 0,贸易逆差,资本净流入

## 政策应用

### 财政政策扩张($G \uparrow$ 或 $T \downarrow$)

- $S = Y - C - G \downarrow$
- $r^*$ 不变(小型假设) → $I$ 不变
- $NX = S - I \downarrow$(逆差扩大)
- **结论**:财政扩张完全挤出**净出口**而非投资(封闭经济中挤出投资)
- 教材案例:1980s Reagan 减税 + 军备扩张 → 美国巨额贸易逆差

### 储蓄激励政策

- $S \uparrow$(如退休账户税收优惠)
- $I$ 不变
- $NX \uparrow$(顺差扩大)

### 世界利率上升($r^* \uparrow$)

- $I(r^*) \downarrow$
- $S$ 不变
- $NX = S - I \uparrow$(顺差扩大)

## 反面论点与数据空白

- **[CONTRADICTION] "小型"假设对美国不适用**:美国是全球最大经济体,其财政/货币政策显然影响全球 $r^*$。教材自承"大型开放经济"将在后续章节处理,但全书未展开。Ch 12 Mundell-Fleming 仍假设小型开放经济。[CONTRADICTION]
- **[CONTRADICTION] 资本管制使模型对主要经济体失效**:中国实行资本账户管制,使 $NCO$ 不能自由调整至 $S - I$;印度、巴西等新兴市场也有管制。教材未在正文中标注此 [regional-bias],仅在脚注提及。
- **全球储蓄过剩假说**:Bernanke 2005 提出美国长期贸易逆差反映"全球储蓄过剩"(新兴市场积累外汇储备 + 石油美元回流)——这不是美国国内 $S < I$ 的单纯故事,而是全球结构性因素。教材未涉及。[regional-bias]
- **安全资产稀缺**:Caballero-Farhi-Gourinchas 2017 提出美国贸易逆差的另一面是全球对美国安全资产(国债)的过度需求——NX 的决定因素超越简单的 $S-I$ 缺口。
- **双顺差悖论**:中国 2000s 同时存在贸易顺差(NX > 0)和资本顺差(NCO < 0,即外资流入 > 对外投资),在标准小型开放经济模型中不可能出现。原因在于强制结售汇制度 + 外资 FDI 激励 + 出口导向政策——制度因素使会计恒等式以非标准方式满足。

## 与微观经济学的连结

| 宏观侧(小型开放经济) | 微观对应 |
|---|---|
| 世界利率 $r^*$ 外生 | 价格接受者假设(完全竞争) |
| $S - I = NX$ | [[跨期贸易与套利]] 的国际版本 |
| 财政扩张 → NX 下降 | 公共支出替代私人出口需求 |
