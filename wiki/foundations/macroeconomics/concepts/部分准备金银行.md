# 部分准备金银行

> **一句话定义**:**Fractional Reserve Banking**,银行只为部分存款保留准备金、其余用于放贷的银行制度。这一制度使银行**创造货币**——若准备金率为 10%,则 100 美元基础货币可支撑 1000 美元广义货币。是现代银行系统货币创造的核心机制。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 4.2 *The Role of Banks in the Money Supply*
- 这是 Ch 4 从 M0 到 M1/M2 货币创造的关键章节

## 100% 准备金 vs 部分准备金

### 100% 准备金(Full Reserve)

- 银行为所有存款保留 100% 准备金
- 银行只是"金库"+ 支付服务,不放贷
- 货币供给等于基础货币:$M = M_0$
- 现代倡议者:Hayek 1976、Friedman 1960(部分)、Cochrane "Equity-Financed Banking"

### 部分准备金(Fractional Reserve)

- 银行为存款保留 $\rho$%(典型 10%)的准备金
- 其余 $(1-\rho)$% 用于放贷
- 贷款产生新的存款 → 再放贷 → 货币创造
- 现代主流银行制度

## 货币创造机制(数值例子)

假设 $\rho = 10\%$,T-Account 演进:

### 第一轮:中央银行注入 $1000

| 银行 A | 资产 | 负债 |
|---|---|---|
| | 准备金 +1000 | 存款 +1000 |

### 第二轮:银行 A 保留 100,贷出 900

| 银行 A | 资产 | 负债 |
|---|---|---|
| | 准备金 100 | 存款 1000 |
| | 贷款 900 | |

900 美元贷款 → 借款人花掉 → 流入银行 B:

### 第三轮:银行 B 收到 900 存款

| 银行 B | 资产 | 负债 |
|---|---|---|
| | 准备金 +900 | 存款 +900 |

银行 B 保留 90,贷出 810……

### 总货币创造

$$ M = 1000 + 900 + 810 + 729 + \cdots = \frac{1000}{0.1} = 10,000 $$

这就是 [[货币乘数]] $1/\rho = 10$ 的来源。

## 现代银行的资产负债表

| 资产 | 负债 |
|---|---|
| 准备金(法定 + 超额) | 存款(支票 + 储蓄 + 定期) |
| 贷款(商业 + 个人 + 房贷) | 短期借款(同业拆借) |
| 证券(国债 + 抵押贷款支持证券) | 长期债券 |
| 物业、设备 | **股东权益(资本)** |

资本 vs 负债的比率即 [[银行资本与杠杆]] 中的 leverage。

## 部分准备金的脆弱性

### 银行挤兑(Bank Run)

- 如果存款人怀疑银行偿付能力 → 集中提现 → 银行被迫低价抛售资产 → 偿付能力进一步恶化 → 倒闭
- 1907 美国银行恐慌 / 1930-33 大萧条期间银行倒闭潮 / 2008 Lehman、2023 SVB
- 解决方案:[[存款保险与金融稳定]] / 央行最后贷款人(Lender of Last Resort)

### Diamond-Dybvig 1983 模型

- 提供银行挤兑的微观基础
- 银行同时承担**流动性转化**(短借长贷)和**风险分担**——但这一组合内生地产生**多重均衡**(好均衡 = 无挤兑;坏均衡 = 全面挤兑)
- 政策含义:存款保险 + LoLR 是必要的制度补丁

## 反面论点与数据空白

- **奥地利学派批判部分准备金**:Murray Rothbard 1983 *Mystery of Banking* 认为部分准备金本质上是"合法欺诈"——同一存款被多次承诺。Hayek、Mises 主张回到 100% 准备金。[BIAS]
- **Cochrane Equity-Financed Banking**:John Cochrane 2014 主张银行只能用股权融资 + 100% 准备金,把"流动性转化"功能转移到分离的货币市场基金——可消除挤兑风险。但实务上未被采纳。
- **影子银行的去监管化**:大量金融机构(投资银行、对冲基金、保险公司)进行**银行式活动**(短借长贷)却不受银行监管 → 2008 危机的核心。Mankiw Ch 4 集中在传统商业银行,对影子银行讨论有限。
- **2020 后零准备金**:美联储 2020 年 3 月把法定准备金率降为 0%——Mankiw Ch 4 的 $\rho > 0$ 假设在制度上已失效。准备金现在主要由超额准备金 + IOER 调节。
- **MMT 视角**:MMT 主张准备金不约束放贷——银行先放贷再获取准备金,故"$M$ 由 $M_0$ 与 $\rho$ 决定"叙事颠倒了因果。
- **regional-bias - 中国官方采纳内生货币论**:[[孙国峰]] 《健全现代货币政策框架》(2021) 直接引用 [[BoE 2014 报告]] 的 "loans create deposits" 框架,**中国央行官方文件**首次把内生货币论纳入主流叙事——这是与 Mankiw 教材外生货币论的根本理论分歧。中国货币政策框架因此采用 [[央行三大约束-流动性资本利率|三大约束方法论]](流动性 + 资本 + 利率)而非简单乘数模型。详见 [[现代货币政策框架]] / [[货币乘数]]。[regional-bias] [CONTRADICTION]
- **regional-bias**:讨论以美国 / 英国为标准。日本 / 欧洲 / 中国的银行制度差异(主银行制、关系银行)未被涵盖。[regional-bias]
