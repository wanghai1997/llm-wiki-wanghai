# Beveridge曲线

> **一句话定义**:Beveridge曲线描述失业率($u$)与职位空缺率($v$)之间的负相关关系;曲线**沿线的移动**反映周期性波动(经济衰退时 $u$ 升、$v$ 降),曲线**本身的移动**反映结构性变化(匹配效率恶化或工资刚性加剧)。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 7.2 *Job Search and Frictional Unemployment*
- 教材提及 Beveridge 曲线作为"职位空缺与失业关系的经验规律",但未深入 DMP 模型推导

## 基本关系

### 定义

- **横轴**:失业率 $u = U/L$
- **纵轴**:职位空缺率 $v = V/L$
- **曲线**:向下倾斜的负相关关系

### 经验规律

```
  v(职位空缺率)
  │
  │     ╱ 正常时期
  │    ╱
  │   ╱   2008后外移
  │  ╱  ╱
  │ ╱  ╱
  │╱  ╱
  └────────── u(失业率)
```

- 经济繁荣: $u$ 低, $v$ 高(右上象限左下角)
- 经济衰退: $u$ 高, $v$ 低(沿曲线向左上移动)

## 两种移动的经济含义

### 沿曲线移动(Cyclical Movement)

- 总需求冲击 → 企业招聘需求变化
- 经济衰退:企业减少招聘($v \downarrow$),裁员增加($u \uparrow$) → 沿曲线向左上移动
- 经济扩张:相反

### 曲线外移(Structural Shift)

- 匹配效率恶化 → 同样失业率对应更高职位空缺率
- 可能原因:
  - **技能错配**:衰退行业工人技能不匹配新兴行业需求
  - **地理错配**:工作机会与劳动力分布不一致
  - **搜索摩擦增加**:UI 延长、信息不对称加剧
  - **劳动力市场制度变化**:就业保护加强、工会权力变化

## 美国 Beveridge 曲线的历史

| 时期 | 特征 | 解释 |
|---|---|---|
| 1960s-2000s | 曲线稳定 | 匹配效率相对稳定 |
| 2008-2010 | 沿曲线左上移动 | 金融危机,总需求崩溃 |
| 2010-2020 | 曲线显著外移 | 长期失业导致技能退化;地理错配;UI 延长 |
| 2020-2022 | 先外移后内移 | COVID 冲击 → 后快速恢复("大辞职"时期 $v$ 极高) |
| 2022-2024 | 沿曲线回移 | 通胀紧缩, $u$ 微升、$v$ 下降 |

## DMP 模型的理论解释

### 匹配函数

Diamond-Mortensen-Pissarides 模型:

$$M = m(U, V) = A \cdot U^\alpha \cdot V^{1-\alpha}$$

- $M$:新就业人数(匹配流)
- $A$:匹配效率参数
- $\alpha$:弹性(通常约 0.5)

### 从匹配函数到 Beveridge 曲线

稳态条件:

$$s \cdot (1 - u) = m(u, v)$$

对数线性化后:

$$\ln v = -\frac{\alpha}{1-\alpha} \ln u + \frac{1}{1-\alpha} \ln s - \frac{1}{1-\alpha} \ln A$$

- $A \downarrow$(匹配效率下降) → 曲线外移
- $s \uparrow$(离职率上升) → 曲线外移

## 反面论点与数据空白

- **Mankiw 教材的简化**:教材仅提及 Beveridge 曲线作为经验规律,未引入 DMP 模型推导。这使得"曲线外移 = 结构性变化"的论断缺乏微观基础。[BIAS]
- **测量问题**:职位空缺数据(JOLTS 调查)的可靠性、覆盖范围(小企业、非正规部门)存疑;失业率测量(U-3 vs U-6)影响曲线位置。
- **2010s 外移的争论**:美国 2010s Beveridge 曲线外移被归因于结构性变化(技能错配);但 Kobos 2015 等认为仅是测量问题(UI 延长使工人搜索强度下降)。2020s 曲线快速内移似乎支持"并非永久性结构变化"的解释。
- **欧洲的 Beveridge 曲线**:欧洲多国(尤其南欧)的 Beveridge 曲线在 1980s 后持续外移,被归因于劳动力市场僵化(就业保护、高 UI 替代率)。但改革后(德国 Hartz 改革 2003-05)曲线内移,证明制度可改变匹配效率。
- **regional-bias**:美国 JOLTS 数据为主;中国无系统的职位空缺统计(招聘网站数据分散且不可靠),无法绘制可靠 Beveridge 曲线。发展中国家非正规部门占主体,职位空缺概念本身不适用。
