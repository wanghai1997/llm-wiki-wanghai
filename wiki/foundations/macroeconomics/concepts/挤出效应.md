# 挤出效应

> **一句话定义**:**Crowding Out**,政府支出扩张或减税导致政府赤字增加 → 国民储蓄下降 → 实际利率上升 → 私人投资减少。在 [[古典宏观长期模型]] 中,挤出效应是**完全的**(政府支出 1 美元挤出 1 美元投资);在凯恩斯短期模型中可能仅部分挤出。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 3.4(古典挤出)、Ch 11-12(IS-LM 部分挤出,后续 Batch)
- 挤出效应是财政保守主义的经济学论据基石

## 古典完全挤出机制

### 第一步:政府赤字增加

$G \uparrow$(或 $T \downarrow$)→ 公共储蓄 $S^g = T - G$ 下降 ΔG。

### 第二步:国民储蓄下降

私人储蓄不变(古典消费函数下),故国民储蓄 $S = S^p + S^g$ 下降 ΔG。

### 第三步:可贷资金市场 $S$ 左移

$S(r)$ 曲线左移 ΔG → 沿着 $I(r)$ 曲线移动 → $r^*$ 上升、$I^*$ 下降。

### 第四步:完全挤出

由 $S = I$ 恒等式,$\Delta I = -\Delta G$ ——**1:1 完全挤出**。

## 教材数值例子

Mankiw Ch 3 用美国 1980s Reagan 减税 + 国防支出扩张作为案例:
- 1980-1986 政府赤字从 GDP 的 ~2% 上升至 ~5%
- 实际利率从 ~3% 上升至 ~6%
- 私人投资 / GDP 下降约 2pp

但因果识别不严格(同期还有 Volcker 反通胀、商业周期、技术变革)。

## 不完全挤出的情形

教材在 Ch 11-12(后续 Batch)讨论:

1. **凯恩斯短期(IS-LM)**:粘性价格 + 失业资源 → 财政扩张提升 $Y$ → 储蓄随之上升 → 部分抵消挤出
2. **流动性陷阱**:零利率下限时,$LM$ 水平 → 财政乘数 ≈ 1,几乎无挤出
3. **公共投资 vs 公共消费**:若 $G$ 是基础设施投资 → 提升未来生产率 → 反而 crowd in 私人投资(Aschauer 1989)
4. **开放经济**:可贷资金市场是全球的 → 财政赤字部分由外资融资 → 国内利率上升幅度小

## 实证检验

| 研究 | 估计挤出程度 | 时段 |
|---|---|---|
| Friedman-Schwartz 1963 | 接近完全 | 战时 vs 平时 |
| Aschauer 1989 | 公共投资 crowd in | 1949-85 美国 |
| Auerbach-Gorodnichenko 2012 | 衰退期 ~0(乘数 ~2.5)/ 扩张期 ~0.5 | 1947-2008 美国 |
| Ramey 2019 综述 | 状态相依,平均 0-1 之间 | 多国数据 |

## 反面论点与数据空白

- **零利率下限挑战完全挤出**:2008-2022 美日欧大规模财政扩张,利率不升反降——古典完全挤出预测严重失败。这一段经验已成为教材 Ch 3 古典框架的"反例集"。[CONTRADICTION]
- **MMT 反驳**:在主权货币体制下,政府支出不需要"挤占"私人储蓄——直接由央行融资,挤出叙事是金本位 / 商品货币时代的遗存。Kelton 2020 *The Deficit Myth* 系统阐述。
- **公共投资的不同性质**:把 $G$ 一刀切为"消费"忽略了基础设施 / 教育 / 研发投资的乘数效应。Aschauer 1989 显示美国 1970s 后基础设施投资减少与生产率放缓相关——可能"crowd in"而非 crowd out。
- **乘数依赖于经济状态**:Auerbach-Gorodnichenko 2012 的状态相依乘数表明:衰退期挤出几乎为零,扩张期挤出明显。古典完全挤出至多在充分就业时近似成立。
- **政治经济学含义被夸大**:挤出叙事常被用于反对所有政府支出。但即使完全挤出成立,只是说"$\Delta I$ 等于 $\Delta G$"——若 $\Delta G$ 比 $\Delta I$ 更高效(如教育、医疗、绿色基建),完全挤出仍可提升福利。
- **regional-bias**:实证证据集中在美欧;新兴市场(如阿根廷、土耳其)可能因主权风险溢价使挤出更剧烈。[regional-bias]
