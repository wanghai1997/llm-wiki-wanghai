# 未预期通胀的再分配

> **一句话定义**:**Redistribution from Unexpected Inflation**,实际通胀偏离预期 → 名义合同(债务、薪资、租金)的实际价值偏离原意 → 在借贷双方、雇佣双方、租赁双方之间进行**未签约的财富转移**。这是通胀最严重的福利成本——破坏合同的可信度与长期规划基础。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 5.3 *Arbitrary Redistribution of Wealth*
- 教材作为通胀六大成本中**最重要**的一项专题讨论

## 推导

### Fisher 方程的事前 / 事后差异

- 事前合同利率:$i = r^e + \pi^e$
- 事后实际利率:$r^{ex post} = i - \pi$
- 通胀超预期($\pi > \pi^e$)→ $r^{ex post} < r^e$ → **借款人受益,贷款人损失**
- 通胀低于预期 → 反向再分配

### 例子

借贷合同:借款 100 万,1 年后还本 + 5% 名义利息 = 105 万

- $\pi^e = 3\%$ 时,贷款人预期实际购买力 = 105/1.03 = 101.94
- 若实际 $\pi = 8\%$,事后实际购买力 = 105/1.08 = 97.22
- 贷款人**实际损失** 5% 购买力 → 财富向借款人转移

## 历史案例

### 1970s 美国房贷"赎回"

- 1960s 美国 30 年固定利率房贷利率 ~6%
- 1970s 通胀飙升至 ~10%,实际利率 -4%
- **债务人实质免费住房,银行系统血流成河**
- 触发 1980s S&L 危机的根源

### 德国 1920s 恶性通胀

- 战前以马克计价的政府债券持有人(普遍是中产 + 退休军人)
- 1923 通胀使债券价值归零
- 中产阶级被洗劫 → 政治后果(支撑纳粹兴起)
- Galofré-Vilà 等 2017 研究证实这一政治经济学传导

### 阿根廷 / 委内瑞拉持续高通胀

- 名义合同失去意义 → 美元化(私人合同以美元计价)
- 银行系统萎缩,长期信贷消失

## 谁受益,谁受损?

### 通胀超预期(净借款人受益)

| 受益者 | 受损者 |
|---|---|
| 政府(国债的最大发行者) | 国债持有人(养老金、保险) |
| 房贷者(固定利率) | 银行 |
| 工会(若工资合同长期固定) | — |
| 浮动利率的存款人 | 固定利率工资的雇员 |

### 通胀低于预期(净贷款人受益)

- 1980s 早期 Volcker 反通胀 → 之前签订的高利率合同价值上升
- 2008 后通缩担忧 → 实际利率上升

## 通胀不确定性的额外成本

仅通胀超 / 低于预期已造成再分配,通胀**不确定性**本身还有额外成本:

- 长期合同变得稀有(因风险溢价上升)
- 长期投资减少(无法可靠预测实际回报)
- 经济短期化(更倾向短期合同 + 短期投资)
- Friedman 1977 诺奖致辞专题讨论此点

## 部分缓解机制

### 1. 通胀挂钩资产(Inflation-Indexed Securities)

- 美国 TIPS(1997 起)、英国 Gilts(1981 起)、智利 UF 单位(1967 起)
- 把名义合同改造为实际合同 → 消除未预期通胀的再分配

### 2. 工资指数化(COLA)

- 部分工会合同含 cost-of-living adjustment
- 但 1980s 后逐渐被简化(因为通胀目标制使预期通胀更可预测)

### 3. 浮动利率合同

- 房贷、信用卡利率随基准利率调整 → 减少借贷双方的通胀风险敞口

## 反面论点与数据空白

- **再分配 vs 净福利损失**:严格说,未预期通胀的再分配是零和博弈(借款人收益 = 贷款人损失)→ 不直接降低 GDP。但**期望损失**很大——人们因此减少借贷活动 → 经济活动下降 → 这是真正的福利成本。
- **政治经济学维度**:再分配不是中性的——通胀通常使中产阶级 / 退休者损失最大,引发社会不满 → 政治不稳定。20 世纪多次法西斯崛起与通胀危机相关。
- **MMT 视角**:Kelton 等主张未预期通胀对穷人的影响夸大——只要工资指数化 + 福利转移到位,通胀的再分配可被中和。
- **行为经济学**:Shafir-Diamond-Tversky 1997 显示人们存在货币幻觉 → 即使理性预期模型预测 Fisher 效应工作,行为偏差使再分配持续发生。
- **2021-2022 通胀的再分配研究**:Cardoso-Ferreira-Garcia 2024 等开始量化美国 / 欧洲 2021-2023 通胀冲击的再分配规模——初步估计约 GDP 的 1-2%,主要从养老金 / 长期债券持有人 → 政府 + 房贷者。
- **regional-bias**:案例集中在美国 + 1920s 德国 + 拉美;非洲、中亚等地区的通胀再分配机制研究缺失。[regional-bias]
