# 微观基础

> **一句话定义**:把宏观行为追溯到家庭与企业的最优化决策——Lucas 批判(1976)以来宏观经济学的方法论标准。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 1.3 + Part V(Ch 16-19)的回填
- 镜像微观:[[消费者最优化选择]] / [[厂商最优化选择]]

## 核心内容

### Lucas 批判(Lucas Critique)

Robert Lucas 1976 *Econometric Policy Evaluation: A Critique* 指出:**基于历史数据估计的宏观方程,在政策环境变化时会失效**——因为家庭与企业会根据预期重新优化。这一观点导致:
- 宏观模型应建立在**家庭最优化**(消费 / 储蓄)与**企业最优化**(生产 / 投资 / 定价)的基础上;
- 经济参数(如 [[Phillips曲线]] 斜率)不是结构常数,而是政策的函数;
- "结构性"参数(偏好 / 技术)才能用于政策反事实分析。

### Mankiw 9e 的渐进策略

教材的微观基础引入是**渐进式**的:
- **Part II-IV**(Ch 3-14):大部分模型(IS-LM、AD-AS、Phillips)**不严格微观基础化**,作为"教学便利";
- **Part V**(Ch 16-19):回填微观基础——
  - Ch 16 消费理论:[[Keynes消费函数]] / [[生命周期假说]] / [[永久收入假说]] / [[行为消费理论]]
  - Ch 17 投资理论:[[Tobin q]] / [[融资约束]]
  - Ch 18 货币需求:Baumol-Tobin 平方根公式
  - Ch 19 政策:Ricardian 等价、时间不一致性

### 与 DSGE 范式的距离

主流宏观研究使用 **DSGE**(Dynamic Stochastic General Equilibrium)模型,严格遵循 Lucas 批判的微观基础原则——所有方程从代表性家庭 / 企业最优化推导。Mankiw 9e 仅在 Epilogue 简要提及 DSGE,**不**作为主线工具。

## 反面论点与数据空白

- **Romer 2016 *The Trouble with Macroeconomics***:Paul Romer 公开攻击 DSGE 微观基础"装作科学",实质是用"代表性主体 + 完美预期 + 抽象冲击"构造的"宏观经济学版后真相"(post-real macroeconomics)。Romer 提出宏观应"接受异质性、有限理性、网络效应"。[BIAS]
- **2008 危机的预测失灵**:Smets-Wouters DSGE 模型(联储与 ECB 主力工具)在 2007-08 间未能预测金融危机。这暴露了"代表性家庭 + 没有金融部门"的根本缺陷;Brunnermeier-Sannikov 2014 等近期工作尝试纳入金融摩擦。
- **代表性主体的不平等盲点**:Krusell-Smith 1998、Heathcote-Storesletten-Violante 2009 的异质代理模型证明,异质性对货币政策传导有 50%+ 量级的影响。Mankiw 9e 在 Part V 简单提及,未深入。
- **后凯恩斯派的整体反驳**:Steve Keen *Debunking Economics*、Foley *Adam's Fallacy* 主张微观基础是"还原论谬误"——宏观涌现属性(emergent properties)不能简单从微观加总推出。后凯恩斯派坚持 Keynes-Minsky 路径,直接从总需求 / 金融脆弱性出发建模。
- **Mankiw 自己的位置**:Mankiw 是 New Keynesian 综合派,接受微观基础但允许特设性的价格粘性假设——介于 RBC 严格派与后凯恩斯反对派之间。这一中间立场使其在两派眼中都不够纯粹。
- **行为宏观的兴起**:Akerlof-Shiller 2009 *Animal Spirits*、Gabaix 2014 sparsity-based 模型,将有限理性 / 注意力约束系统纳入宏观。这是对"完美预期最优化"微观基础的根本修正。
