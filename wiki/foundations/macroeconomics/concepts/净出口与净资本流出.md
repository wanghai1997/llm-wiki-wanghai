# 净出口与净资本流出

> **一句话定义**:净出口(NX)是一国出口与进口之差;净资本流出(NCO)是国内储蓄超出国内投资的部分。两者由国民收入核算恒等式锁定为相等——$NX = NCO$,即贸易顺差必然等于资本净流出。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 6.1 *The International Flows of Goods and Capital*
- 直接承接 [[GDP核算恒等式]] $Y = C + I + G + NX$ 与 [[储蓄-投资均衡]] $S = Y - C - G$

## 核心恒等式

### 从 GDP 核算到开放经济恒等式

封闭经济:$$Y = C + I + G \quad \Rightarrow \quad S = I$$

开放经济:

$$Y = C + I + G + NX$$

$$S = Y - C - G = I + NX$$

$$\boxed{S - I = NX}$$

定义 **净资本流出**(net capital outflow):

$$NCO = S - I$$

则:

$$\boxed{NX = NCO}$$

### 经济直觉

| 情形 | $S$ vs $I$ | $NX$ | $NCO$ | 含义 |
|---|---|---|---|---|
| 贸易顺差 | $S > I$ | $NX > 0$ | $NCO > 0$ | 国内储蓄过剩 → 借给外国 → 外国欠本国 |
| 贸易逆差 | $S < I$ | $NX < 0$ | $NCO < 0$ | 国内投资超过储蓄 → 向外国借入 → 本国欠外国 |
| 平衡 | $S = I$ | $NX = 0$ | $NCO = 0$ | 封闭经济情形 |

## 净出口(NX)的构成

$$NX = EX - IM$$

- **出口(EX)**:国内生产、国外消费的商品与服务
- **进口(IM)**:国外生产、国内消费的商品与服务
- **贸易余额**:NX > 0 为顺差;NX < 0 为逆差;NX = 0 为平衡

### 与微观贸易理论的衔接

- 微观 [[国际贸易福利]] 分析单个国家开放贸易的福利增益;
- 宏观 NX 是**流量概念**(一国在某时期的净出口额),不直接度量福利——贸易顺差国只是"借出更多",不等于更富;详见 [[GDP的局限性]]

## 净资本流出(NCO)的构成

$$NCO = \text{购买外国资产} - \text{外国购买本国资产}$$

- $NCO > 0$:本国居民净购买外国资产(资本流出)
- $NCO < 0$:外国居民净购买本国资产(资本流入)

### 资产类型

- 外国直接投资(FDI)
- 外国股票投资
- 外国债券投资

## 双视角等价性

| 视角 | 恒等式 | 经济含义 |
|---|---|---|
| **商品流** | $NX = EX - IM$ | 出口 > 进口 → 顺差 |
| **资本流** | $NCO = S - I$ | 储蓄 > 投资 → 资本流出 |
| **统一** | $NX = NCO$ | 两次记账(商品侧 + 资本侧)的同一事实 |

> 这是**国际收支恒等式**的核心:每一笔跨境交易都同时记录在商品账户与资本账户两侧。

## 反面论点与数据空白

- **恒等式 ≠ 因果**:教材易让读者误以为 $S - I$ "导致" $NX$ 或相反。实际上两者是**同一枚硬币的两面**,由会计定义锁定;因果分析需要行为方程(如 [[小型开放经济模型]] 中 $S$ 和 $I$ 由各自函数决定,$NX$ 被动调整)。[CONTRADICTION]
- **MMT / 后凯恩斯视角**:主权货币国家(浮动汇率)的贸易逆差不是"需要偿还的债务",而是外国对本国资产的净需求;固定汇率国家(欧元区成员国)才受 NX 约束。教材未区分此关键差异。[CONTRADICTION]
- **跨国公司的内部贸易**:全球价值链使 $EX$ 和 $IM$ 包含大量企业内部转移定价,不反映真实"国家间"贸易;NX 作为政策指标的可靠性下降。
- **regional-bias**:Mankiw 案例集中在美国(1980s-2000s 贸易逆差);中国长期双顺差(贸易顺差 + 资本顺差,即 "双顺差悖论")、德国结构性顺差、资源出口国波动等案例缺失。
