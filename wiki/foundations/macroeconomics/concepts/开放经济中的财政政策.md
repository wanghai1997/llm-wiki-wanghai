# 开放经济中的财政政策

> **一句话定义**:在小型开放经济中,财政扩张(减税或增支)降低国民储蓄,在世界利率不变下不改变国内投资,因此**完全挤出净出口**——表现为贸易逆差扩大和实际汇率升值;这与封闭经济中"挤出私人投资"的机制截然不同。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 6.2-6.3 政策应用部分
- 与 [[挤出效应]] 形成对照:封闭经济挤出投资,开放经济挤出净出口

## 核心机制

### 封闭经济 vs 开放经济的财政扩张

| 维度 | 封闭经济 | 小型开放经济 |
|---|---|---|
| **储蓄变化** | $S \downarrow$ | $S \downarrow$ |
| **利率反应** | $r \uparrow$ | $r = r^*$,不变 |
| **投资反应** | $I \downarrow$(被挤出) | $I$ 不变 |
| **调整变量** | 投资 | 净出口 $NX$ |
| **最终结果** | $I \downarrow$, $NX = 0$ | $NX \downarrow$, $I$ 不变 |

### 开放经济中的传导链

$$G \uparrow \text{ 或 } T \downarrow \Rightarrow S \downarrow \Rightarrow (S - I) \downarrow \Rightarrow NX \downarrow \Rightarrow \epsilon \downarrow$$

具体步骤:
1. 政府减税或增支 → 可支配收入或公共储蓄下降 → 国民储蓄 $S \downarrow$
2. 世界利率 $r^*$ 不变(小型假设) → 国内投资 $I$ 不变
3. $S - I$ 缺口缩小 → 净出口 $NX$ 下降(逆差扩大)
4. 外汇市场:本币供给增加(资本流出减少) → 名义汇率贬值 → 实际汇率 $\epsilon$ 调整

### 图形分析(实际汇率-NX 空间)

```
  NX, S-I
  │╲    S-I₀
  │ ╲   │
  │  ╲  │  S-I₁ (财政扩张后左移)
  │   ╲ │    │
  │    ╲│    │
  └─────┴────┴─── ε
       ε₁  ε₀
```

- $S - I$ 垂直线左移 → 均衡实际汇率 $\epsilon^*$ 下降(本币实际贬值)
- 净出口 $NX^*$ 下降(逆差扩大)
- **注意**:实际汇率贬值但 $NX$ 下降,因为 $S-I$ 垂直线左移的幅度超过 $NX$ 曲线的价格反应

## 教材案例:1980s Reagan 时代

- **政策**:1981 年减税(Economic Recovery Tax Act) + 军备扩张
- **结果**:美国从 1980 年贸易平衡转为 1980s 持续巨额逆差
- **教材解释**:财政扩张 → $S \downarrow$ → $NX \downarrow$,与实际汇率升值共存
- **争议**:实际中美元在 1980-85 年**名义大幅升值**(而非贬值),因为高利率吸引资本流入——这超出小型开放经济模型的预测(模型假设 $r = r^*$,无利率差异)

## 反面论点与数据空白

- **[CONTRADICTION] 美国不是小型开放经济**:Reagan 时代美元升值无法用小型开放经济模型解释——美国财政扩张推高了美国利率(超越 $r^*$),吸引全球资本流入,导致美元**名义升值** + 贸易逆差扩大。小型模型预测实际汇率贬值,实际却是升值。这暴露了"price taker"假设的失败。[CONTRADICTION]
- **大国开放经济模型缺失**:教材未建立 $r$ 内生的两国模型;Dornbusch 1976 超调模型、Obstfeld-Rogoff  Redux 模型可解释利率-汇率联动,但全书未涉及。
- **李嘉图等价的可能性**:若消费者预期未来增税(偿还当前赤字),则 $C$ 不增、$S$ 不降——财政扩张不改变 $NX$。Barro 1974 李嘉图等价在开放经济中意味着财政政策对贸易余额**无效**。教材 Ch 16(后续 Batch)讨论。
- **跨期视角**:财政扩张可能是暂时性的(平滑税收);暂时性赤字对 $S$ 的影响小于永久性赤字。教材使用静态分析,未区分暂时/永久。[regional-bias]
- **欧洲财政紧缩的经验**:欧元区成员国(无独立货币政策)财政紧缩 → $G \downarrow$ → $S \uparrow$ → $NX \uparrow$,这是 2010s 南欧"内部贬值"的核心机制。教材未涉及。

## 与微观经济学的连结

- 微观 [[公共品]] 与 [[税收归宿]] 分析财政支出的福利效应;
- 宏观开放经济分析财政政策的**国际溢出**——一国财政扩张通过 $NX$ 将需求溢出至贸易伙伴。
