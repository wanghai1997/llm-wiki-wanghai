# 摩擦性失业

> **一句话定义**:摩擦性失业(frictional unemployment)是劳动力在正常流动过程中(换工作、搬家、毕业、重新进入劳动力市场)因**信息不完全**和**匹配需要时间**而产生的短期失业;它是健康劳动市场的"润滑剂"而非病态,政策目标是缩短而非消除。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 7.2 *Job Search and Frictional Unemployment*
- 构成 [[自然失业率]] 的两个组成部分之一(另一为 [[结构性失业]])

## 产生原因

### 1. 正常流动

- **辞职**:寻找更好的职业机会
- **搬家**:地理迁移导致暂时失业
- **毕业**:学生进入劳动力市场的搜寻期
- **重新进入**:育儿、退休后的回归

### 2. 部门转移(Sectoral Shifts)

- **Lilien 1982**:不同产业扩张/收缩速度不同 → 劳动力需跨部门重新配置
- 例:制造业萎缩、服务业扩张;[[AI重塑企业组织|AI 替代]]加速此过程
- 部门转移加剧 → $s$ 上升或 $f$ 下降 → 摩擦性失业增加

### 3. 信息不完全

- 工人不知道所有职位空缺
- 企业不知道所有求职者
- 匹配质量需时间验证

## 流量模型中的摩擦性失业

在 [[自然失业率]] 的 $u_n = s/(s+f)$ 中:

- 摩擦性失业对应**正常的 $s$ 和 $f$**水平
- 若 $s$ 因部门转移上升 → 摩擦性失业增加
- 若 $f$ 因信息改善上升 → 摩擦性失业减少

## 工作搜寻模型

### 保留工资(Reservation Wage)

- 失业者设定一个**保留工资** $w_R$:低于此工资的工作拒绝接受
- $w_R$ 取决于:
  - 失业保险福利(越高 → $w_R$ 越高 → 搜寻时间越长)
  - 财富水平
  - 对未来工资分布的预期
  - 搜寻成本

### 最优停止规则

- 每次面试获得一个工资报价 $w$
- 若 $w \geq w_R$:接受
- 若 $w < w_R$:继续搜寻
- $w_R$ 由"接受当前报价的期望收益 = 继续搜寻的期望收益"决定

## 缩短摩擦性失业的政策

| 政策 | 机制 | 效果 |
|---|---|---|
| **就业服务** | 提供职位信息、匹配平台 | 提高 $f$ |
| **工作培训** | 帮助工人获得新技能 | 提高 $f$,降低错配 |
| **搬迁援助** | 补贴地理流动 | 降低地区性摩擦 |
| **互联网求职平台** | 降低信息成本 | 提高 $f$ |

### 失业保险(UI)的权衡

- **收益**:为失业者提供消费保险,避免贫困
- **成本**:降低搜寻激励 → $f \downarrow$ → 摩擦性失业增加
- **最优设计**:渐进递减的福利(初期高、后期低)、要求求职证明、提供培训

## 反面论点与数据空白

- **DMP 搜索模型的简化**:Mankiw 教材使用简化的 $s,f$ 流量方程,回避了 Diamond-Mortensen-Pissarides 搜索匹配模型的核心机制(匹配函数 $M = m(U,V)$、议价分割、职位创造内生性)。这使得"摩擦性失业"在教材中几乎等同于"正常流动",失去了搜索理论的深度。[BIAS]
- **AI 对搜寻匹配的影响**:算法招聘(LinkedIn、Indeed、AI 简历筛选)可能同时提高匹配效率(缩短失业)和加剧歧视(算法偏见排斥某些群体)。教材未涉及。
- **平台经济与零工就业**:Uber / 外卖骑手等"非标准就业"模糊了"就业/失业"边界——骑手在无订单时是否算失业?平台经济的失业统计挑战现有框架。
- **地理错配与住房市场**:美国 Rust Belt 衰退 + Sun Belt 增长,但住房负资产(underwater mortgage)限制工人地理流动,使摩擦性失业持久化。2010s 此现象显著。
- **regional-bias**:美国 CPS 数据为主;欧洲(Eurostat)、中国(农民工流动受户籍限制 → 摩擦性失业被人为抬高)、日本(终身雇佣制 → $s$ 极低)的制度差异未深入。
