# 家庭调查与机构调查

> **一句话定义**:[[美国劳工统计局BLS]] 同时进行的两套就业调查——**家庭调查**([[当前人口调查CPS|CPS]],单位是人)与**机构调查**(*CES*,单位是工作岗位)——经常给出显著不同的就业人数。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 2.3
- 制度:BLS 月度同步发布

## 两调查的核心差异

| 维度 | 家庭调查(CPS) | 机构调查(CES) |
|---|---|---|
| **测量对象** | 个人(基于家庭报告) | 工作岗位(基于雇主报告) |
| **抽样单位** | 家庭 | 雇主 / 业务地点 |
| **样本量** | 60,000 户(~130,000 人) | 144,000 雇主(~690,000 业务地点) |
| **首次发布** | 1940 | 1915 |
| **是否含农业** | 含 | **不**含 |
| **是否含自雇** | 含 | **不**含 |
| **是否含家庭佣工** | 含 | **不**含 |
| **第二份工作** | 不重复计入 | **重复计入**(每个岗位一票) |
| **修正幅度** | 较小 | 通常每月修正幅度大 |

## 为什么数字常不同?

**2012-13 间** 两调查就业人数差距曾达 100 万。原因:

1. **统计单位不同**:同一人有两份兼职 → CPS 计 1 人,CES 计 2 个岗位;
2. **覆盖范围不同**:CPS 含农场 / 自雇,CES 不含;
3. **样本误差**:CPS 抽样误差 ±0.4%,CES ±0.2%;
4. **时滞**:CES 要 6-9 个月才完全反映新企业 / 关闭企业(通过年度 benchmark 修正);
5. **季节调整算法不同**。

## 为什么 BLS 都发布?

两调查互补:
- **CES**:更精确的**就业岗位变化**(月度变化);
- **CPS**:含**所有人**(自雇、农业、家庭佣工),提供失业率与劳动力参与率;
- 经济学家通常引用 CES 测就业增长(月度新增工作),引用 CPS 测失业率。

## "Strange Months"现象

某些月份两调查给出**完全相反**信号:
- 2012.4:CPS 显示就业 +119k,CES 显示 -38k;
- 2014.1:CPS +76k,CES -120k;
- 这种月份称为"奇异月"(strange months),媒体报道时会引发混乱。

## 政策含义

- **Fed 货币政策**:更关注 CES(因更精确的月度变化);
- **失业救济政策**:基于 CPS 失业率定义;
- **学术研究**:Krueger、Card 等研究人员经常在 CPS 微观数据上构建论证。

## 反面论点与数据空白

- **修正幅度的政策风险**:CES 初步估计与最终修正常相差 25%+。例:2008.12 CES 初步估计 −600k,后修正为 −800k——意味着实时政策决策依据的数据**严重失真**。
- **零工经济导致的归类困境**:Uber 司机 / 外卖骑手在 CES 不计入(自雇),CPS 计入但归类为"自雇就业"——两调查都低估"零工就业的不稳定性"维度。
- **大流行中的两调查背离**:2020.4-12,CPS 与 CES 就业数据剧烈背离,主要因临时停工(temporary layoff)的归类——CPS 把休假的人计入"就业",CES 视雇主报告而定。这导致两调查对就业冲击规模的判断差异大。
- **regional-bias**:本页基于美国 BLS 体系;欧盟 LFS 主要类比家庭调查,机构调查体系较弱;中国月度发布城镇调查失业率(类比 CPS),但无完善机构调查体系。
