# 美联储工具

> **一句话定义**:**Federal Reserve Policy Tools**,美联储调节货币供给与利率的工具组合。传统三大工具:**公开市场操作 OMO**、**贴现率**、**法定准备金率**。2008 后新工具:**超额准备金利率 IOER**、**逆回购利率 ON-RRP**、**量化宽松 QE**、**前瞻指引**等。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 4.2 *How the Central Bank Controls the Money Supply*
- 教材按"传统三工具 + 现代工具"两层介绍

## 传统三大工具(2008 前主导)

### 1. 公开市场操作(Open Market Operations, OMO)

- 央行在二级市场买卖国债
- **买入国债**:释放储备金 → 银行系统流动性增加 → 联邦基金利率下降
- **卖出国债**:回收储备金 → 流动性减少 → 联邦基金利率上升
- 是日常调节联邦基金利率的主要工具

### 2. 贴现率(Discount Rate)

- 银行向美联储贴现窗口借款的利率
- 当银行流动性紧张时的"最后贷款人"渠道
- 通常高于联邦基金利率,作为"惩罚利率"
- 历史上较少使用,因银行担心声誉风险("stigma")

### 3. 法定准备金率(Required Reserve Ratio, $\rho$)

- 银行必须为存款保留的准备金最低比率
- 改变 $\rho$ 直接影响 [[货币乘数]]
- 美联储很少使用此工具(因调整成本高)
- **2020 年 3 月美联储把 $\rho$ 设为 0%**,此工具事实上停用

## 现代工具(2008 后核心)

### 4. 超额准备金利率(Interest on Excess Reserves, IOER / IORB)

- 美联储 2008 年起对银行超额准备金支付利息
- 这是**利率走廊上限**——银行不会以低于 IOER 的利率放贷
- 2008-2024 IOER 从 0.25% 调整到 5.4%(随政策利率)
- 2021 改名 IORB(Interest on Reserve Balances)
- 这是 QE 时代央行控制利率的核心工具

### 5. 隔夜逆回购利率(Overnight Reverse Repo, ON-RRP)

- 货币市场基金(non-bank)向美联储进行逆回购的利率
- 利率走廊下限——MMF 不会以低于 ON-RRP 的利率放贷
- 2014 年起作为永久工具

### 6. 量化宽松(Quantitative Easing, QE)

- 详见 [[量化宽松]]
- 在零利率下限时大规模购买长期资产 → 压低长期利率 → 刺激信贷与资产价格

### 7. 前瞻指引(Forward Guidance)

- 央行公开承诺未来政策路径(如"未来 12 个月维持低利率")
- 通过预期渠道影响当前长期利率
- 2003-2004、2009-2014、2020-2022 美联储多次使用

### 8. 紧急贷款工具(2008 / 2020 创设)

- 商业票据 funding facility (CPFF)、PDCF、TALF、PPPLF 等
- 直接向特定金融市场注入流动性
- 是央行作为"最后做市商"(LoLR → MoLR)的扩展

## 利率走廊机制(2008 后)

```
        |
联邦基金 |    <- 上限:贴现率
利率目标 |    <- 政策利率(FFR target range)
        |    <- 下限:IOER (银行) / ON-RRP (MMF)
```

通过设定 IOER 与 ON-RRP,联储让所有市场参与者面对统一的"无风险下限利率"——使利率精确锚定。

## 美联储 2025 年主要操作模式

- **充足储备金体系**(Ample Reserves Regime):银行系统持有大量超额储备金
- 通过 IORB + ON-RRP 直接设定利率,不需要日常 OMO 微调
- 资产负债表政策(QE / QT)是独立工具,与利率政策可分离

## 与中国央行工具体系的对照

[[孙国峰]] 《健全现代货币政策框架》(2021) 提出的中国版工具体系与美联储平行但有显著差异:

| 工具类别 | 美联储 | 中国 PBoC |
|---|---|---|
| 短期政策利率 | 联邦基金利率(市场利率)| [[OMO公开市场操作-中国\|OMO 7 天逆回购利率]](工具利率)|
| 中期政策利率 | (无)| [[MLF中期借贷便利\|MLF 1 年利率]] → [[LPR贷款市场报价利率\|LPR]] 加点 |
| 走廊上限 | 贴现率 | [[SLF常备借贷便利\|SLF]] |
| 走廊下限 | IORB / ON-RRP | 超额准备金利率(常被击穿)|
| 数量工具 | 资产负债表政策(QE / QT)| 准备金率(仍频繁使用)+ MLF 投放 |
| 结构性工具 | 紧急工具(CPFF / TALF / PPPLF)+ 主街贷款 | [[结构性货币政策工具]](再贷款 / 再贴现 / 直达工具 / 永续债 + CBS)|
| 资本工具 | (无,Basel 由其他监管管)| [[宏观审慎评估MPA]] + [[CBS央行票据互换]] + [[永续债银行资本工具]] |

**关键理论差异**:孙国峰文区分两种利率政策路径:第一类(美联储)"将市场利率作为操作目标",第二类(中国)"将工具利率即政策利率,操作目标 / 政策利率 / 工具利率合而为一"。详见 [[央行政策利率体系-中国]]。

## 反面论点与数据空白

- **2008 后货币政策范式转变**:Mankiw Ch 4 的"准备金率 + 公开市场操作 + 货币乘数"框架在零下限 + 充足储备金时代基本失效——但教材仍用此框架介绍。这一脱节是教学中的主要痛点。[CONTRADICTION]
- **货币政策的分配后果**:QE / 低利率推升资产价格 → 富人受益(因资产持有比例高)→ 加剧不平等。Saez-Zucman 2019、Bivens 2015 的实证支持此点。但 Mankiw 教材未充分讨论。
- **央行独立性的政治压力**:Trump、Erdogan 等领导人公开施压央行降息——央行独立性是制度而非自然规律,可能被侵蚀。2018-2024 多个新兴市场央行独立性受损。
- **MMT 反驳工具叙事**:MMT 认为联储工具的真正约束是政治意愿,而非"准备金"或"乘数"——主权货币国家的央行原则上可无限扩表,只受通胀约束。
- **数字货币时代的工具变化**:CBDC(央行数字货币)可能让央行直接控制居民货币——彻底颠覆"通过银行系统传导"的传统机制。中国 2020+ 数字人民币是先例。
- **regional-bias**:Mankiw 工具列表以美联储为标准;欧央行、日央行、人民银行的不同工具(MLF、TLTRO、PSL)未被涵盖。[regional-bias]
- **regional-bias - 中国"OMO + MLF"双轨结构**:中国采用**短期(OMO 7 天)+ 中期(MLF)**双轨政策利率,与美联储**单一短期利率(FFR)**结构差异显著。中国央行同时通过 [[结构性货币政策工具]] 直达实体,部分功能近似美联储 2008 / 2020 紧急工具,但中国是常态化使用。详见 [[央行政策利率体系-中国]] / [[MLF中期借贷便利]] / [[再贷款再贴现]]。注:2024 后中国正在向单一短期利率(7 天逆回购)转型,与美联储趋同。[regional-bias]
