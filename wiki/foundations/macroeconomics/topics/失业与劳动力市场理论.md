# 失业与劳动力市场理论

> **本页目的**:整合 [[Macroeconomics-Mankiw-9e]] Ch 7 介绍的失业理论。这是古典长期模型对劳动市场的修正——承认即使长期也存在失业,将其分解为**摩擦性**(正常流动)和**结构性**(工资刚性)两部分。与 Ch 3 古典模型假设"充分就业"形成张力,是后续短期波动模型(Phillips 曲线)中"周期性失业"的理论基础。

## 在教材中的位置

- 来源:[[Macroeconomics-Mankiw-9e]] Ch 7 *Unemployment and the Labor Market*
- 完成 [[古典宏观长期模型]](Ch 3 假设充分就业)后的修正扩展
- 后续衔接:Ch 14 [[Phillips曲线]](Batch 6)引入周期性失业与通胀权衡

## 核心公式:自然失业率的流量模型

$$\boxed{u_n = \frac{s}{s + f}}$$

- $s$:离职率(separation rate)
- $f$:入职率(job finding rate)
- $u_n$:自然失业率

## 自然失业率的两大构成

$$u_n = u_{\text{摩擦性}} + u_{\text{结构性}}$$

### 摩擦性失业(Frictional)

- **来源**:正常流动(换工作、搬家、毕业)、部门转移、信息不完全
- **特征**:短期、工资处于市场出清水平
- **政策**:缩短而非消除——就业服务、工作培训、互联网求职平台
- 详见 [[摩擦性失业]] / [[工作搜寻模型]] / [[Beveridge曲线]]

### 结构性失业(Structural)

- **来源**:实际工资刚性 > 均衡工资 → 劳动力供给过剩
- **特征**:长期、工资高于市场出清
- **政策**:消除工资刚性来源
- 详见 [[结构性失业]] / [[实际工资刚性]]

## 工资刚性的三大来源

| 来源 | 机制 | 性质 |
|---|---|---|
| **最低工资** | 政府设定工资下限 | 制度强制 |
| **工会与集体谈判** | Insider-outsider:工会代表已就业者利益 | 集体行动 |
| **效率工资** | 企业自愿支付高工资以提高生产率 | 市场激励 |

- 详见 [[最低工资]] / [[工会与集体谈判]] / [[效率工资]]

## Beveridge 曲线:周期的镜子

- 失业率 $u$ vs 职位空缺率 $v$ 的负相关关系
- **沿曲线移动**:周期性波动(总需求冲击)
- **曲线外移**:结构性变化(匹配效率恶化、技能错配)
- 详见 [[Beveridge曲线]]

## 与 Friedman-Phelps 自然率假说的衔接

- 1968 年 [[Milton Friedman]] 与 [[Edmund Phelps]] 同时独立提出:长期 Phillips 曲线垂直于自然失业率
- 货币政策只能暂时使 $u < u_n$(通过意外通胀),长期必然回归
- Ch 7 提供 $u_n$ 的微观基础;Ch 14(后续 Batch)处理 Phillips 曲线

## 模型的边界与矛盾

### 假设清单与张力

| 假设 | 含义 | 矛盾 |
|---|---|---|
| 流量方程代表行为人 | $u_n = s/(s+f)$ 是总量方程 | DMP 搜索匹配模型需要异质性;教材简化 |
| 自然率稳定 | $u_n$ 由 $s,f$ 决定 | 滞后效应:衰退可永久性提高 $u_n$ |
| "自然"不可改变 | 名称暗示外生 | 制度可显著改变 $u_n$(德国 Hartz 改革) |
| 古典框架 | 长期价格灵活 | 但承认工资刚性 → 市场不出清 |

### 关键矛盾

- **[CONTRADICTION] Ch 3 充分就业 vs Ch 7 长期失业**:Ch 3 古典模型假设 $L = \bar{L}$(充分就业);Ch 7 承认 $u_n > 0$。教材未清晰解释"古典充分就业 = 自然率下的就业"这一语义转换。[CONTRADICTION]
- **[CONTRADICTION] "自然失业率"名不副实**:政策可显著改变其水平(失业保险替代率、培训、最低工资)。后凯恩斯派批评这是为放任政策辩护的意识形态构造。[CONTRADICTION]
- **[CONTRADICTION] 最低工资竞争模型 vs Card-Krueger 证据**:教材先讲标准模型(最低工资 → 失业),再引用 Card-Krueger 1994(就业未下降),但不引入买方垄断(monopsony)解释。微观 [[利润最大化问题]] Ch 26 有劳动买方垄断,宏观教材回避。[CONTRADICTION]

## 与微观经济学的连结

| 宏观侧(失业理论) | 微观对应 |
|---|---|
| 自然失业率流量模型 | 微观无直接对应;DMP 模型提供微观基础 |
| 摩擦性失业(搜寻) | [[劳动供给]] 中的转换成本、信息不完全 |
| 结构性失业(工资刚性) | [[劳动力市场均衡]] 中工资不下调 |
| 最低工资 | [[价格下限]] → 过剩供给 |
| 工会(insider-outsider) | [[垄断]] / [[进入壁垒]] |
| 效率工资(偷懒) | [[信息不对称]] 中的道德风险 |
| 买方垄断(缺失) | [[利润最大化问题]] Ch 26 劳动买方垄断 |

## 反面论点与数据空白

- **滞后效应(Hysteresis)**:Blanchard-Summers 1986 提出欧洲 1980s 高失业可能具有滞后性——短期衰退侵蚀人力资本、降低 $f$,使 $u_n$ 永久性上升。教材仅在脚注提及。[CONTRADICTION]
- **AI / 自动化的结构性冲击**:Acemoglu-Restrepo "任务模型"预测 AI 替代常规任务将产生长期结构性失业。教材"部门转移"框架过于温和,未充分评估 AI 冲击的规模和持久性。
- **平台经济与失业统计**:Uber / 外卖骑手模糊了"就业/失业"边界——现有 BLS 统计框架是否适用于平台经济?
- **欧洲青年失业危机**:西班牙/希腊 2010s 青年失业率 >50%,是结构性失业的典型案例——教材未深入。
- **中国劳动力市场制度**:户籍制度限制农民工进入城市正规就业;高校毕业生供给超过白领岗位需求;标准"工资刚性"框架不完全适用。
- **regional-bias**:美国 CPS/JOLTS 数据为主;欧洲(Eurostat)、日本(终身雇佣制下低 $s$)、中国(户籍限制流动)的制度差异未深入。
- **[BIAS] 工会正向作用被忽略**:教材仅强调工会的失业负面效应;Freeman-Medoff 1984 系统记录工会提高技能投资、减少离职、改善安全等正向效应。
