# 货币与通胀理论

> **本页目的**:整合 [[Macroeconomics-Mankiw-9e]] Ch 4-5 介绍的货币、通胀、利率长期理论框架。该框架建立在 [[古典二分法]] 之上——长期内货币只决定名义变量,实物经济独立运行。这是 [[货币数量论]] 的现代化教学体系,也是 [[Milton Friedman]] 1956 数量论复兴的成果。

## 框架结构

### 三层因果链

```
[政策选择: M 增速]
       ↓
[长期: π = M̄/M - g]    ← 货币数量论
       ↓
[Fisher 方程: i = r + π]   ← 名义利率被通胀决定
       ↓
[古典二分法: r 由实物决定, P 由 M 决定]
       ↓
[长期货币中性: 所有实际变量不受 M 影响]
```

## 五大模块整合

### 模块 1:[[货币三职能]] + [[法币与商品货币]]

- **货币是什么**:交易媒介、价值储藏、计价单位
- **货币是哪种**:商品货币(金银)vs 法币(主权信用)
- 现代世界的货币体系是法币 + 部分央行管理

### 模块 2:[[货币供给定义]] + [[部分准备金银行]] + [[货币乘数]]

- **基础货币 $M_0$ 与广义货币 $M$ 的关系**
- 部分准备金制度通过 [[货币乘数]] 把 $M_0$ 放大为 $M$
- 多层货币定义(M0 / M1 / M2)反映流动性差异

### 模块 3:[[美联储工具]] + [[量化宽松]]

- 央行通过公开市场操作、贴现率、准备金率、IOER 等工具调控 $M$
- 2008 后非常规工具(QE、前瞻指引)成为重要补充
- 配套制度:[[银行资本与杠杆]]、[[存款保险与金融稳定]]

### 模块 4:[[货币数量论]] + [[实际货币余额与货币需求]] + [[铸币税与通胀税]]

- $MV = PY$ 与货币需求函数 $L(Y, i)$
- 长期通胀 = 货币增速 - 实际增长
- 印钞融资政府赤字 = 铸币税 / 通胀税

### 模块 5:[[名义利率与实际利率]] + [[费雪效应]] + [[通胀的成本]]

- Fisher 方程 $i = r + \pi^e$
- 费雪效应:长期 $\Delta i = \Delta \pi^e$
- 通胀成本六大类型:鞋皮、菜单、相对价格、税收、会计、再分配

## 长期 vs 短期视角

### 长期(Mankiw Ch 4-5,本主题主线)

- 货币中性:$\Delta M$ 只影响 $P$,不影响 $Y$、$L$、$r$
- 古典二分法:实物 vs 名义子模型独立
- 政策含义:央行长期目标只能是通胀率

### 短期(Mankiw Ch 13-14,Batch 5+)

- 粘性价格 + 工资使货币短期非中性
- 货币政策影响产出、失业、实际利率
- 政策含义:相机抉择 vs 规则之争

教材的"长短期二元论"是教学便利,实证中边界模糊。

## 与 [[古典宏观长期模型]] 的关系

两个主题页的相互独立 + 整合:

| 主题 | 决定 | 不决定 |
|---|---|---|
| [[古典宏观长期模型]] | $Y, C, I, r, W/P, R/P$ | $P, M, i$ 名义水平 |

## 政策含义集合

### 1. 央行独立 + 通胀目标

- 长期通胀由货币当局选择 → 央行独立 + 透明目标(如 2%)成为主流
- 1990s 后多国央行采纳:新西兰 1990、加拿大 1991、英国 1992、美国 2012(隐含目标)

### 2. 反对货币化赤字

- 政府赤字若长期由央行印钞融资 → 通胀失控
- 铸币税拉弗曲线告诉我们:试图用通胀税融资过头会触发恶性通胀

### 3. 通胀目标 2% 的逻辑

- 0% 目标:零下限风险(衰退期央行无降息空间)
- 4% 目标:通胀税成本上升 + 预期失锚风险
- 2% 是经验上的折中

### 4. 反通胀的代价(后续 Batch 13)

- Volcker 1979-82 反通胀使失业率升至 11%
- "牺牲比率"(sacrifice ratio):每 1pp 通胀下降需要 ~5pp 累计失业上升
- 这是短期非中性的强证据

## 反面论点与数据空白

- **Keynes vs 古典数量论**:Keynes 1936 General Theory 第 14 章直接攻击数量论——主张 $V$ 在流动性陷阱下不稳定,使数量论政策含义失效。后续 Batch 5+ 在 IS-LM 框架中重提此点。[CONTRADICTION]
- **MMT 全盘反对货币数量论**:Wray、Kelton 等主张货币是内生的,数量论的因果方向颠倒。"通胀始终是货币现象"在 MMT 视角下是误解。
- **2008-2022 全球零利率经验**:大规模 QE 未引发 2010s 持续通胀,但 2021-2022 通胀冲击突然出现。简单数量论难以解释这一时间结构,可能需要补充供给冲击 + 财政货币联动机制。
- **行为宏观对货币幻觉**:[[Robert Shiller]] / Akerlof 显示真实预期形成偏离理性 → 古典 Fisher 体系的实证基础减弱。
- **金融创新 + 加密货币的影响**:稳定币、CBDC 改变货币边界。教材主体框架基于"商业银行 + 央行"二层结构,可能在数字时代部分失效。
- **regional-bias**:框架以美 / 欧 / OECD 经验为标准模板;新兴市场美元化、外汇管制、外汇危机等使货币与通胀的关系本质不同。[regional-bias]
