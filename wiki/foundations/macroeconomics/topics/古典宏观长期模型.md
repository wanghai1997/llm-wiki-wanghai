# 古典宏观长期模型

> **本页目的**:整合 [[Macroeconomics-Mankiw-9e]] Ch 3 介绍的古典长期模型。这是宏观经济学教学体系的"基石模型"——长期内**实物经济决定一切实际变量**,货币只决定名义变量(参见 [[古典二分法]])。所有后续模型(Solow 增长、IS-LM、AD-AS、Phillips 曲线)都是在此基础上的扩展或偏离。

## 模型的元结构

### 输入(外生变量)

- 资本存量 $\bar{K}$
- 劳动力 $\bar{L}$
- 政府支出 $G$
- 税收 $T$
- 技术参数(隐含在生产函数 $F$ 中)

### 输出(内生变量,实际)

- 总产出 $Y$
- 消费 $C$
- 投资 $I$
- 实际工资 $W/P = MP_L$
- 实际利率 $r$
- 实际资本租金 $R/P = MP_K$

### 排除的变量

- 货币 / 价格水平 / 名义利率(由 Ch 4-5 单独决定)
- 失业率(假设充分就业,Ch 7 单独讨论)
- 短期波动(假设市场出清)

## 模型的五大砖块

### 砖块 1:[[生产函数(宏观)]]

$$ Y = F(K, L) $$

- 假设 [[规模报酬不变]]、边际产品递减
- 通常用 Cobb-Douglas:$Y = K^\alpha L^{1-\alpha}$

### 砖块 2:[[边际生产力理论]]

$$ \frac{W}{P} = MP_L,\quad \frac{R}{P} = MP_K $$

- 完全竞争 + 厂商最优化的 FOC
- 决定 [[实际工资]] 与 [[实际利率(古典)]]

### 砖块 3:[[国民收入分配]]

$$ Y = MP_K \cdot K + MP_L \cdot L $$

- 由 CRS 欧拉定理保证
- Cobb-Douglas 下:资本份额 $= \alpha$,劳动份额 $= 1-\alpha$

### 砖块 4:[[古典消费函数]]

$$ C = C(Y - T),\quad 0 < MPC < 1 $$

- 消费仅依赖可支配收入
- 简化版的 Keynesian 消费函数

### 砖块 5:[[可贷资金市场]] / [[储蓄-投资均衡]]

$$ S(r) = I(r) $$

- 国民储蓄 $S = Y - C - G$
- 投资需求 $I = I(r)$
- 实际利率 $r^*$ 调节使两者均衡

## 模型的主要应用

### 应用 1:财政政策的长期效应

- $G \uparrow$ → 国民储蓄 $\downarrow$ → $r^* \uparrow$ → $I^* \downarrow$
- **结论:政府支出完全 [[挤出效应|挤出]] 私人投资**(古典完全挤出)
- 教材数值案例:1980s Reagan 时代

### 应用 2:税收政策的长期效应

- 仅影响私人 vs 公共储蓄分配,长期不影响 $r^*$ 与 $I^*$(若 [[李嘉图等价]] 成立)
- 教材 Ch 16(后续 Batch)系统讨论

### 应用 3:技术冲击

- $F$ 函数右移 → $Y$ 上升 → $S$ 与 $I$ 都增加
- 长期增长的根源(Ch 8-9 后续 Batch 中的 Solow 模型)

## 模型的边界与限制

### 假设清单

| 假设 | 含义 | 何时失效 |
|---|---|---|
| 完全竞争 | $W/P = MP_L$、$R/P = MP_K$ | 工会、垄断、信息不对称 |
| 价格灵活 | 市场即时出清 | 短期粘性价格(Ch 13 后续 Batch) |
| 充分就业 | $L = \bar{L}$ | 失业(Ch 7 后续 Batch) |
| 封闭经济 | $S = I$ | 开放经济(Ch 6 后续 Batch) |
| 一种产品 | 单一 $Y$ | 多部门、相对价格变化 |
| 同质资本 | 单一 $K$ | [[Cambridge Capital Controversy]] |

### 模型的"长期"含义

教材没有给"长期"明确时间界定,但隐含 5+ 年——价格充分调整 + 产能恢复后

## 反面论点与数据空白

- **完全竞争与边际生产力的实证基础脆弱**:1980+ 美国劳动份额下降 5pp,无法用古典模型解释 → 需要垄断 / 自动化 / 全球化等附加机制(参见 [[国民收入分配]] 反面论点)。[CONTRADICTION]
- **凯恩斯的根本反对**:Keynes 1936 主张古典模型只在充分就业的极端情况下成立——常规经济中存在大量过剩产能 + 有效需求不足,使古典推论失效。这一争论延续 90 年。
- **Cambridge Capital Controversy**:严格逻辑下,异质资本无法跨品加总 → 宏观生产函数不存在 → 整个古典长期模型在严格意义上不自洽。详见 [[Cambridge Capital Controversy]] [CONTRADICTION]
- **2008 后零下限挑战**:零利率 + QE 时代,$S(r) = I(r)$ 的标准均衡叙事失效——可能源于 Summers 长期停滞、人口老龄化、安全资产稀缺等因素。
- **MMT 反驳**:政府赤字 → 挤出私人投资的因果链在主权货币国家不成立——主权货币政府不需要"借入"私人储蓄。
- **微观基础革命**:Lucas 1976 [[卢卡斯批判]] 指出古典模型缺乏微观基础——后续 Batch 4+ 的 Solow / DSGE 模型部分回应此批评。
- **regional-bias**:Mankiw 教材数据集中在美国;开放经济、新兴市场制度、非正式部门等使古典模型外推性受限。[regional-bias]
