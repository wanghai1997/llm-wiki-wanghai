# T 型人才

**T 型人才（T-shaped People）** 是 [[Tim-Brown|Tim Brown]] 和 [[IDEO]] 倡导的理想创新团队成员画像——兼备深度专业能力和广度跨领域理解力。

## T 的构成

```
    广度（跨学科理解）
    ←————————————→
    |            |    ↑
    |            |   深度
    |     |      |  （专业技能）
    |     |      |    ↓
```

- **垂直深度（|）**：某一领域的深厚专业能力——可能是一个博士学位或十年经验
- **水平广度（—）**：跨学科的理解和共情能力——能与不同背景的人有效合作

## 为什么 T 型对设计思维重要

- 纯"|"型人才（只有深度）→ 只看到自己的学科视角，难以跨界协作
- 纯"—"型人才（只有广度）→ 缺乏将想法落地的深度技能
- T 型 → 在自己的领域有发言权 + 能与其他领域的 T 型人才共同创作

## 创新团队 = T 型人才的组合

[[IDEO]] 的团队由多个 T 型人才组成——人类学家、工程师、心理学家、商业策略师、工业设计师等。他们各自的深度技能互补，而广度使其能有效协作。
