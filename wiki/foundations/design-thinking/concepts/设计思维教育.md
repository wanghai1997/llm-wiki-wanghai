# 设计思维教育

**设计思维教育** 是 Brown 在《[[设计改变一切]]》结语中提出的重要命题——"设计未来的设计思考者"。设计思维不仅是一种专业方法，更应成为一种通识素养。

## 核心主张

- 设计思维应纳入基础教育——就像阅读和数学一样是基础素养
- 当前教育体系训练汇聚式思维远多于发散式思维 → 抑制天生的创造力
- 不是培养更多设计师，而是培养更多"具有设计思维的______"（工程师、医生、管理者、教师）

## 关键能力培养

| 传统教育训练 | 设计思维教育增加 |
|------------|----------------|
| 找到正确答案 | 提出更好的问题 |
| 分析 | 分析 + 综合 |
| 文字 / 数字表达 | 视觉 / 叙事 / 文字 / 数字 多维表达 |
| 个体竞争 | 个体贡献 + 团队协作 |
