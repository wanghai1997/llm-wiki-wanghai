# 金融经济学 foundations 总览

> 基于 [[金融经济学-徐高|徐高《金融经济学二十五讲》]] 建立的 Wiki 金融经济学基础层。与微观经济学（风险/期望效用）和宏观经济学（投资/消费/金融危机）形成"三柱互补"。

## 学科定义

**金融经济学** 是研究人们在不确定环境中如何进行资源跨期配置的学科。两个不可缺的维度：**时间**（现在 vs 未来）和 **不确定性**（未来存在多种可能状态）。

## 全书逻辑脉络

```
人的行为（不确定性下的选择）
    ↓ 导出
资产需求 + 资产供给
    ↓ 均衡
资产定价 ← 两条路径 → 均衡定价（绝对定价）
                     无套利定价（相对定价）
    ↓ 引入摩擦
金融摩擦（信息不对称/有限套利/非理性）
    ↓ 真实世界应用
公司金融 / 银行 / 金融危机 / 行为金融
```

## 两条定价路径对比

| | 均衡定价 | 无套利定价 |
|------|---------|-----------|
| **别名** | 绝对定价 | 相对定价 |
| **起点** | 偏好 + 禀赋 + 市场结构 | 已知资产价格 + 无套利条件 |
| **优点** | 可从无到有定价；连接经济环境 | 精确；可用于实务 |
| **缺点** | 不精确；假设强 | 需已知价格信息 |
| **应用** | 理论界研究工具 | 金融衍生品市场 |
