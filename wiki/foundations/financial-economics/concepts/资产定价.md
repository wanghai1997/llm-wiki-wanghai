# 资产定价

**资产定价（Asset Pricing）** 是金融经济学的核心问题：给定资产未来的支付分布，判断资产当前应该值多少钱（或其期望回报率应该是多少）。判定回报率是否合适是金融业务的核心。

## 两条定价路径

| | [[均衡定价]] | [[无套利定价]] |
|------|-----------|------------|
| **别名** | 绝对定价 | 相对定价 |
| **思路** | 从供需入手，通过市场均衡确定价格 | 基于已知价格+无套利条件推导相关资产价格 |
| **信息需求** | 偏好+禀赋+市场结构 | 已知资产价格信息 |
| **优点** | 可从无到有定价；连接宏观经济环境 | 精确；可用于金融实务 |
| **缺点** | 不精确；假设强 | 不能从无到有定价 |
| **应用** | 理论界研究工具 | 衍生品定价/金融市场实务 |

## 均衡是有效的必要条件

- 均衡的市场一定是无套利的——如果存在套利机会，投资者可以通过套利做得更好，市场就不可能是均衡的
- 但无套利的市场未必是均衡的——无套利不保证市场出清
- 无套利是比均衡更弱的条件：不要求设定偏好、禀赋、市场结构

## 核心直觉：好资产期望回报率低

见 [[资产-金融]] 中的讨论——坏资产必须提供更高期望回报率才能让人持有。这是理解资产定价均衡逻辑的起点。

## 反面论点与数据空白

1. **均衡vs套利之争**：两种定价思路各有致命缺陷——均衡定价不精确，套利定价依赖已有价格信息
2. **联合假说问题**：任何资产定价检验都是对"定价模型+市场效率"的联合检验——无法单独拒绝定价模型
3. **因子动物园（Cochrane 2011）**：文献中已发表数百个"定价因子"，但多数在样本外失效——哪种定价模型是"正确的"尚无共识
