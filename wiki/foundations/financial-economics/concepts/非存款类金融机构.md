# 非存款类金融机构

**非存款类金融机构（Non-Depository Financial Institution）** 是没有货币创造能力的金融机构，组成丰富。

## 主要类型

| 类型 | 核心功能 |
|------|---------|
| **证券公司（券商/投资银行）** | 帮助发行者发行证券——把经济利益包装成金融资产出售 |
| **基金公司** | 募集资金进行组合投资 |
| **保险公司** | 承保风险 + 运用保费投资 |
| **信托公司** | 受托管理资产 |
| **期货公司** | 期货经纪与交易服务 |

## "卖方"（Sell Side）

证券公司被称为 **卖方（Sell Side）**，因为它们的核心工作是把各种金融产品"卖"出去。对券商来说，声誉至关重要——声誉越高，企业越愿意找它发行证券，它包装出来的金融资产也越容易找到买家。券商会投入大量资源打造研究团队、发布研究报告来塑造品牌。

## 与存款类机构的区别

| | [[存款类金融机构]] | 非存款类金融机构 |
|------|------|------|
| **货币创造** | 参与 | 不参与 |
| **代表** | 央行 + 商业银行 | 券商/基金/保险/信托/期货 |
| **作用** | 决定全社会资金供给和利率 | 充当资金融通的中介和服务商 |
