# 衍生品

**衍生品（Derivative）** 是其价值衍生自其他基础资产（如股票、债券、商品）的金融合约。与现货交易（一手交钱一手交货）不同，衍生品交易的标的物交割发生在未来。

## 基本类型

| 类型 | 定义 |
|------|------|
| **远期合约（Forward）** | 约定未来以固定价格买卖基础资产的合约 |
| **期货（Futures）** | 标准化的远期合约，在交易所交易 |
| **期权（Option）** | 提供给持有人以约定价格买卖的 **权利**（而非义务） |

## 衍生品的功能

- **风险管理**：农场主用远期锁定秋天卖价，避免价格波动风险
- **价格发现**：衍生品价格包含市场对未来价格的预期
- **完善市场**：帮助完成无衍生品时无法实现的资源配置

## 衍生品与次贷危机

2008 年次贷危机的一个重要机制是 CDO（Collateralized Debt Obligation，担保债务凭证）：

1. 银行将多笔按揭贷款（含次级）打捆 → 分层（优先级 ~75% AAA → 中间级 → 垃圾级）
2. 次级按揭摇身变为 AAA 资产 → 卖给养老金等审慎投资者
3. 垃圾级再被打捆 → CDO² → CDO³ → CDO⁴
4. 2007 年房价回落 → 按揭违约 → 连优先级也违约 → 系统性崩溃

徐高的评价：衍生品需要折中态度——既不能视为洪水猛兽，也需时时关注风险。
