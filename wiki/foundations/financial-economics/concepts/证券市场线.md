# 证券市场线

**证券市场线（Security Market Line, SML）** 是 [[CAPM]] 的定价方程在 $\beta - E(r)$ 平面上的图形化表示。

## 方程

$$E(r_i) = r_f + \beta_i \cdot [E(r_M) - r_f]$$

- 纵轴：期望回报率 $E(r_i)$
- 横轴：Beta $\beta_i$
- 截距：无风险利率 $r_f$
- 斜率：市场风险溢价 $E(r_M) - r_f$

## SML 的核心含义

- 在均衡中，**所有资产和组合** 都应位于 SML 上
- 偏离 SML 的资产 → 存在 Alpha（定价错误/套利机会）
- Beta = 1 的资产 → 预期回报 = 市场回报
- Beta = 0 的资产 → 预期回报 = 无风险利率

## SML vs CML

| | SML | [[资本市场线|CML]] |
|------|-----|-----|
| **横轴** | Beta（系统性风险） | 总风险 $\sigma$ |
| **适用范围** | **所有资产和组合** | 仅有效组合 |
| **功能** | 定价是否合理 | 组合是否有效 |

SML 是 CAPM 最重要的实践工具——判断资产是被高估还是低估。
