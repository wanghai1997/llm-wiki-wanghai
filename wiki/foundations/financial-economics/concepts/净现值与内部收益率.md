# 净现值与内部收益率

**净现值（NPV）** 和 **内部收益率（IRR）** 是金融决策的两个基本工具，用于评估投资项目是否值得进行。

## 净现值（Net Present Value）

$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t}$$

其中 CF_t = 第 t 期现金流，r = 贴现率。

- **NPV > 0**：项目创造价值，应该投资
- **NPV < 0**：项目毁损价值，不应该投资
- 贴现率 r 通常取市场利率或投资者要求的回报率

## 内部收益率（Internal Rate of Return）

IRR 是使 NPV = 0 的贴现率：

$$0 = \sum_{t=0}^{n} \frac{CF_t}{(1 + IRR)^t}$$

决策规则：若 IRR > 投资者要求的回报率，则投资。

## NPV vs IRR

| | NPV | IRR |
|------|-----|-----|
| **输出** | 金额（元） | 百分比 |
| **优势** | 直接衡量价值创造 | 直观的收益率表述 |
| **局限** | 需要确定合适的贴现率 | 非标准现金流下可能多解 |
