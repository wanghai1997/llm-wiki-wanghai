# Diamond-Dybvig 银行模型

**Diamond-Dybvig 模型（DD 模型，1983）** 是现代银行理论的奠基之作——在一个极简框架中展示了银行最本质的功能（期限转换）和银行内在脆弱性（挤兑风险）。

## 银行的核心功能：期限转换

投资者面临"流动性冲击"风险——不知道是否会提前需要资金。银行通过 **期限错配** 解决这一难题：
- 吸收短期存款（投资者可随时提取）
- 发放长期贷款（资金投入不可逆项目）
- 池化所有投资者的流动性风险 → 提供流动性保险

## 银行挤兑的机制

DD 模型的关键洞见：**银行挤兑可以是一个自我实现的预言**：
- 好均衡：所有人相信银行安全 → 不挤兑 → 银行安全
- 坏均衡：所有人相信银行会倒闭 → 争先提取 → 银行真的倒闭（长期资产被迫折价甩卖 → 不够覆盖所有存款）

这种多重均衡意味着：即使银行基本面完全健康，纯粹的信心危机也可以导致挤兑。

## 存款保险的作用

存款保险 = 消除坏均衡的制度安排——储户即使不挤兑也不会有损失 → 坏均衡不再自我实现。

## DD 模型的局限

- 没有分析银行的资产端风险（假设贷款是无风险的）
- 没有讨论银行资本结构（杠杆率）的作用
- 忽视了银行间市场和系统性风险

## 反面论点与数据空白

1. **模型过于简化**：DD 模型假设贷款无信用风险——现实中银行风险也来自资产端（坏账）
2. **挤兑触发机制**：DD 模型中挤兑是纯粹的太阳黑子（sunspot）现象——但许多实际银行危机有明确的基本面触发因素（资产恶化）
3. **存款保险的道德风险**：DD 模型推荐的存款保险制度本身带来道德风险——银行知道被保险后会冒险（风险转嫁），这又需要资本监管来制衡
4. **互联网金融的挑战**：徐高认为互联网无法消灭银行中介——但 DeFi/数字货币的出现是否正从根本上挑战银行的中介功能？DD 模型没有回答这个问题
