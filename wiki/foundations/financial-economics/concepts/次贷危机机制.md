# 次贷危机机制

徐高第 24 讲以金融经济学视角系统分析了 2008 年次贷危机的机制链条。

## 危机链条

```
房价持续上涨预期 → 银行降低放贷标准
    ↓
次级按揭 + 忍者贷款（NINJA）大量发放
    ↓
银行通过 CDO 打包出售按揭 → 腾出资金继续放贷
    ↓
CDO 分层魔法：次级 → AAA（优先级 ~75% 被认为绝对安全）
    ↓
CDO² / CDO³ 再打包 → 衍生品嵌套
    ↓
2007 年房价回落 → 按揭违约 → 连优先级也违约
    ↓
雷曼倒闭（2008-09-15）→ 对手方信心崩溃
    ↓
流动性全面枯竭 → 金融危机 → 实体经济衰退
```

## 金融理论的教训

1. **风险的复杂化不等于风险的消除**：CDO 分层重新分配了风险但没有消除底层资产的信用风险
2. **评级机构的系统性偏差**：AAA 评级使投资者低估了尾部风险
3. **动态对冲的失败**：在极端市场条件下对冲策略集体失效（1987 年的教训被遗忘）
4. **VaR 的局限**：风险价值模型假设正态分布，完全忽略了尾部事件的相依性

## 微观风险管理的失败

单家机构层面的风险管理（VaR、压力测试）在系统性危机面前失效——当所有人同时被迫出售相同资产时，价格下跌 → 触发更多 VaR 限制 → 更多出售 → 死亡螺旋。
