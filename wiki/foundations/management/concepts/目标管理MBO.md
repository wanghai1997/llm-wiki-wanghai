# 目标管理 MBO

## 一句话定义

> **目标管理 (MBO)** = [[Peter-Drucker|Drucker]] 1954 年提出的管理系统——下属与上级**共同设定绩效目标**，基于目标实现程度评估绩效——用"目标"来管理，而非用"控制"来约束。

## MBO 的四要素

| 要素 | 含义 |
|------|------|
| **具体目标** | 模糊的"做得更好"不可用——必须是可衡量、可沟通的目标 |
| **参与决策** | 下属与上级共同设定目标——不是上级单方面下达 |
| **明确时间期限** | 每个目标有明确的完成时间——3 个月、6 个月、1 年 |
| **绩效反馈** | 持续地提供关于目标进展的反馈——不是等到年底才知道 |

## MBO 的逻辑链

```
组织总目标
    ↓ 层层分解
部门目标
    ↓ 层层分解
个人目标 ←── 员工参与设定
    ↓
持续反馈 + 定期评估
    ↓
基于目标实现程度的奖惩
```

## MBO 的优点与问题

| 优点 | 问题 |
|------|------|
| 目标清晰——人人知道要做什么 | 过分聚焦目标→忽视实现目标的过程 |
| 参与提升承诺感 | 在变化快速的环境中目标快速过时 |
| 便于绩效评估的客观化 | 可能导致"你考核什么,我就做什么"——忽视不被考核但重要的工作 |

## MBO 与 OKR

OKR (Objectives and Key Results) 是 MBO 在科技公司的当代版本（Intel→Google）：
- **目标 (Objective)**：定性、鼓舞人心、方向性
- **关键结果 (Key Results)**：定量、可衡量、3-5 个
- OKR 的更新频率远高于 MBO（通常是季度制）且强调"有野心的目标"——70% 完成 = 成功
