# Maslow 需求层次

## 一句话定义

> **Maslow 的五层需求** = 人的动机由从低到高的五种内在需求驱动——未满足的需求是激励的来源，已满足的需求不再驱动行为。

## 五层金字塔

```
         ┌──────────────┐
         │ 自我实现     │ ← 成为你能成为的一切
         ├──────────────┤
         │ 尊重需求     │ ← 自尊、认可、地位
         ├──────────────┤
         │ 社交需求     │ ← 归属、爱、友谊
         ├──────────────┤
         │ 安全需求     │ ← 身体和经济安全
         ├──────────────┤
         │ 生理需求     │ ← 食物、水、住所
         └──────────────┘
```

## 需求层次的管理启示

| 员工处于哪个层级 | 有效的激励手段 |
|----------------|-------------|
| 生理 | 足够的基本工资、工作餐、休息时间 |
| 安全 | 工作保障、健康保险、养老金 |
| 社交 | 团队活动、友好的工作氛围、归属感 |
| 尊重 | 头衔、认可、有挑战性的任务、反馈 |
| 自我实现 | 自主权、创造性机会、个人成长项目 |

## 当代修正

- **并非严格的阶梯**：人可以同时追求多个层级——不是必须"完全满足低层才能上高层"
- **文化差异**：在个体主义文化中自我实现是终极目标，在群体主义文化中"归属"和"社会认可"可能高于自我实现
- **情景变化**：经济危机可能使高层的需求暂时"降级"
