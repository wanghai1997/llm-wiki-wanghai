# 领导力特质理论

## 一句话定义

> **特质理论** = 最早的领导力研究方法——寻找"领导者与非领导者的区别特征"——研究发现了八种区分特征，但**单独的特质不能预测谁是有效的领导者**。

## 区分领导者的八种特质

| 特质 | 含义 |
|------|------|
| **驱动力 (Drive)** | 高努力水平、高成就动机、高主动性和精力 |
| **领导欲** | 想要影响和引导他人——对权力的积极态度 |
| **诚实与正直** | 言行一致、信任是领导力的货币 |
| **自信** | 对自己能力的信念——影响下属对领导的信任 |
| **智慧** | 收集、整合和解释海量信息的能力 |
| **与工作相关的知识** | 对行业、技术、组织运作的深度理解 |
| **外向性** | 精力充沛、善于社交——Big Five 中最稳定与领导力相关的特征 |
| **内疚倾向** | 对他人影响有责任感和道德敏感性 |

## 特质理论的局限

- **"有这些特质 = 会成为领导者"是错误的**：特质预测的是**谁被感知为领导者**（领导力涌现），而非**谁成功了**（领导力效能）
- **忽略情境**：同一个特质在不同情境中作用不同——将军的领导力特质在初创公司是否有效？
- **忽略追随者**：领导力不是领导者的属性——它是领导者-追随者关系的产物
