# Porter 五力模型

## 一句话定义

> **五力模型** = [[Michael-Porter|Porter]] 1980 年提出的行业竞争强度分析框架——五力共同决定了行业的**平均利润率**和竞争的**本质**。

## 五力

```
                    新进入者的威胁
                          ↑
    供方的议价能力 → 行业内现有竞争者 ← 买方的议价能力
                          ↑
                     替代品的威胁
```

| 力量 | 强（压低利润） | 弱（允许高利润） |
|------|-------------|---------------|
| **新进入者** | 进入壁垒低（低资本、无专利保护） | 进入壁垒高（高资本、强品牌、政府管控） |
| **替代品** | 替代品多且便宜 | 替代品少或差 |
| **买方** | 买方集中、产品标准化、转换成本低 | 买方分散、产品差异化、转换成本高 |
| **供方** | 供应商集中、原材料独特、转换成本高 | 供应商分散、原材料标准化 |
| **现有竞争者** | 竞争者多且均衡、增长慢、退出壁垒高 | 竞争者少、有明确领导者、有差异化 |

## 五力模型的核心用途

- **判断一个行业"是否值得进入"**：五力越弱→行业越有吸引力（平均利润越高）
- **理解"为什么这个行业很难赚钱"**：如航空业——买方强（比价容易）+ 供方强（飞机制造商+燃油）+ 竞争者多+ 新进入者不断
- **指导战略定位**：选择五力最弱的细分市场、建立壁垒

## 五力模型的局限

- **假设行业边界清晰**——在平台经济和生态竞争中行业边界模糊
- **忽视互补品**：某些产品/服务的价值依赖于互补品的存在（如电动汽车需充电桩网络）——"第六力"被一些学者提出
- **静态分析**：五力分析某一时点的行业结构——不能预测颠覆性变化
