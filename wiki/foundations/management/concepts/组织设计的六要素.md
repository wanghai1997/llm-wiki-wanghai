# 组织设计的六要素

## 一句话定义

> **组织设计** = 决定组织结构的六个关键要素——工作专门化·部门化·指挥链·管理幅度·集权与分权·形式化——每个要素的选择决定了组织的"形状"和行为模式。

## 六要素

| 要素 | 核心问题 | 低端 | 高端 |
|------|---------|------|------|
| **工作专门化** | 任务被分解到什么程度？ | 一人做多种工作 | 极度细分——每人重复一个动作 |
| **部门化** | 按什么基础分组？ | — | 职能、产品、地区、流程、客户 |
| **指挥链** | 谁向谁报告？ | 扁平（少层） | 高耸（多层） |
| **管理幅度** | 一个管理者能有效管理多少人？ | 窄（3-5 人） | 宽（20-30+ 人） |
| **集权与分权** | 决策权集中在顶层还是下沉？ | 分权（基层决策） | 集权（高层决策） |
| **形式化** | 工作被标准化到什么程度？ | 低（灵活、自主） | 高（严格规则和程序） |

## 六要素的组合

这六个要素不是独立的——它们共同定义了组织结构的"形状"：

| | [[机械式与有机式组织|机械式]] | [[机械式与有机式组织|有机式]] |
|---|---|---|
| 专门化 | 高度 | 低度 |
| 部门化 | 严格的职能划分 | 跨职能团队 |
| 指挥链 | 清晰、多层 | 模糊、扁平 |
| 管理幅度 | 窄 | 宽 |
| 集权 | 中央 | 分散 |
| 形式化 | 高 | 低 |
