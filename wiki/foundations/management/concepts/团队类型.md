# 团队类型

## 一句话定义

> **团队** = 两个或更多人通过**协调的努力**完成共同目标——不同于"群体"（群体只是共享信息，团队追求集体绩效）。四种团队类型按**自治程度**排列。

## 四种团队类型

| 类型 | 自治度 | 特征 | 典型场景 |
|------|--------|------|---------|
| **问题解决团队** | 低 | 来自同一部门，定期会议讨论改进——给予建议但无权执行 | 质量圈 (Quality Circle) |
| **自我管理团队** | 中-高 | 成员自行分配任务、制定工作时间、甚至评估彼此的绩效 | 生产车间的自主班组 |
| **跨职能团队** | 中 | 来自不同部门的成员——打破部门壁垒完成特定任务 | 新产品开发团队 |
| **虚拟团队** | 可变 | 地理分散——通过数字工具协作——可能跨越时区和组织边界 | GitHub 开源项目、全球咨询团队 |

## 团队 vs 群体

| | 群体 (Group) | 团队 (Team) |
|---|---|---|
| 目标 | 共享信息 | 集体绩效 |
| 协同 | 中立（有时负面） | **正面**（整体的产出大于个体产出之和） |
| 责任 | 个人 | 个人 + 共同的 |
| 技能 | 随机的 | 互补的 |

## 虚拟团队的独特挑战

- **信任构建更难**：缺少面对面互动→缺少社交信号→信任发展慢
- **沟通误解更高**：非语言信息（肢体、面部表情、语调）在文字沟通中丢失
- **"社会惰化" (Social Loafing)** 更难察觉：不积极参与的人在虚拟团队中更容易隐藏
