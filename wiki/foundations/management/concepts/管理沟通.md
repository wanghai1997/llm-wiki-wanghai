# 管理沟通

## 一句话定义

> **管理沟通** = 信息从发送者→编码→渠道→解码→接收者的传递过程——**噪声**贯穿全程。有效沟通的关键障碍：过滤、选择性知觉、信息过载、情绪、语言差异。

## 沟通过程

```
发送者 → 编码 → 信息 → 渠道 → 解码 → 接收者
    ↑                                    ↓
    └──────── 反馈 ←──────────────────────┘
              ↑ 噪声（贯穿全程）
```

## 沟通的障碍

| 障碍 | 机制 |
|------|------|
| **过滤** | 发送者故意操纵信息使接收者更易接受——"下属告诉老板想听的" |
| **选择性知觉** | 接收者只看到符合已有信念/期望的信息 |
| **信息过载** | 太多信息→接收者无法处理→忽略或延迟 |
| **情绪** | 极端情绪（愤怒、焦虑）使接收者无法理性处理信息 |
| **语言差异** | 专业术语、行话、跨代际/跨文化的用词差异 |
| **沟通焦虑** | 对口头/书面沟通的强烈恐惧——回避沟通情境 |

## 克服障碍

- **积极倾听**：不是等对方说完然后说自己的——是真正尝试理解对方的视角
- **反馈闭环**：发送者验证接收者是否真正理解了——"你复述一下我理解的是什么"
- **简化语言**：用接收者能理解的语言——减少术语和缩写
- **控制情绪**：在情绪极端时不进行重要沟通

## 正式 vs 非正式沟通

- **正式**：按组织的指挥链和规定的报告关系——可靠、可追溯但慢
- **非正式**：个人网络、跨部门交流——快、灵活但可能失真（小道消息）
