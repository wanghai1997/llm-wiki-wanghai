# 团队效能模型

## 一句话定义

> **团队效能模型** = 团队的有效性取决于**情境**（资源、结构、信任）→**组成**（能力、人格、角色、多样性）→**过程**（共同目标、冲突水平、社会惰化）→**结果**（绩效 + 成员满意度）的因果链。

## 四层模型

```
┌─────────────────────────────────────────┐
│  情境 (Context)                          │
│  充足资源·领导与结构·信任氛围·绩效评估系统  │
├─────────────────────────────────────────┤
│  组成 (Composition)                      │
│  成员能力·人格·角色分配·多样性·团队规模    │
├─────────────────────────────────────────┤
│  过程 (Process)                          │
│  共同目标·具体目标·团队效能感·冲突管理·     │
│  社会惰化控制                              │
├─────────────────────────────────────────┤
│  结果 (Outcomes)                         │
│  绩效（数量+质量）+ 成员满意度             │
└─────────────────────────────────────────┘
```

## 关键发现

- **最优团队规模**：5-9 人——小于 5 人缺少多样性，大于 9 人协调困难、社会惰化上升
- **共同目标和具体目标两者都需要**：共同目标提供方向（"为什么做"），具体目标提供可操作性和衡量标准（"做到了什么程度"）
- **社会惰化 (Social Loafing)**：个人在团队中的努力小于独立工作时的努力——避免滥竽充数需要个体绩效的可见性和责任心

## 有效团队的标志

- 成员互相信任
- 清晰的角色和职责
- 开放和诚实的沟通
- 冲突被公开讨论而非隐藏
- 成员对团队有认同感和归属感
