# 组织行为学基础

## 一句话定义

> **组织行为学 (OB)** = 研究个体、群体和组织结构对组织内行为的影响——OB 三层次：**个体→群体→组织**——目标是用这些知识改进组织的效能。

## OB 三层次

```
┌──────────────────────────────────────┐
│  组织层 (Organization)               │
│  结构·文化·HR 实践·变革              │
├──────────────────────────────────────┤
│  群体层 (Group)                      │
│  团队·沟通·冲突·领导·权力与政治        │
├──────────────────────────────────────┤
│  个体层 (Individual)                 │
│  人格·知觉·态度·动机·决策·学习        │
└──────────────────────────────────────┘
```

## OB 的核心因变量（我们要解释什么）

- **生产力**：效率和效能的结合
- **缺勤**：不出现在工作岗位的行为
- **离职**：自愿或非自愿离开组织
- **组织公民行为 (OCB)**：超越正式职责的自愿的助人行为
- **反生产行为**：故意危害组织或其成员的行为
- **工作满意度**：对工作的积极情感评价

## 行为是可预测的

- 个体的行为**不是随机的**——它由人格、情境和过去学习的交互决定
- OB 的目标不是"100% 准确预测每一个行为"——而是识别**系统性规律**（什么因素使离职可能上升？什么因素促进 OCB？）
