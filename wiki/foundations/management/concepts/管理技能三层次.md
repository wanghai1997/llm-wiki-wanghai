# 管理技能三层次

## 一句话定义

> **Katz 的管理技能** = 所有管理者都需要**技术技能·人际技能·概念技能**三种能力——不同管理层级对三种技能的需求比例不同。

## 三种技能（Katz 1955）

| 技能 | 定义 | 例子 |
|------|------|------|
| **技术技能 (Technical)** | 特定领域的知识和熟练度 | 会计、编程、机械操作 |
| **人际技能 (Human/Interpersonal)** | 与人（个体和团队）有效合作 | 沟通、激励、冲突解决 |
| **概念技能 (Conceptual)** | 将组织视为整体、理解各部分关系、战略性思考 | 行业趋势判断、商业模式设计 |

## 管理层级与技能分布

```
基层管理者          中层管理者          高层管理者
┌─────────┐      ┌─────────┐      ┌─────────┐
│ ██████  │      │ ██████  │      │ ██████  │  技术技能
│ ██████  │      │ ██████  │      │ ██████  │  人际技能
│ ████    │      │ ██████  │      │ ██████  │  概念技能
└─────────┘      └─────────┘      └─────────┘
```

- **基层管理者**：技术技能最重要——"会做事"
- **中层管理者**：三种技能均衡——"会管事也会管人"
- **高层管理者**：概念技能主导——"想得清楚、看得远、能决策"

> 人际技能在所有层级都同等重要。

## 反面论点与数据空白

- **Katz 模型是 1955 年的**：在数字化时代，"数字技能"应该作为第四种技能独立列出——介于技术和概念之间。
- **"人际技能最重要"的盲目**：在高度技术化的管理领域（如风险管理、合规），技术技能的缺口可能是最致命的。
