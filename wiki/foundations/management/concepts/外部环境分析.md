# 外部环境分析

## 一句话定义

> **外部环境** = 组织边界之外的所有影响组织绩效的因素——管理者必须持续扫描和评估环境以识别**机会和威胁**。

## 外部环境的层次

```
┌──────────────────────────────────┐
│           一般环境 (General)       │
│   PESTEL: 政治·经济·社会·技术·环境·法律 │
│  ┌──────────────────────────┐    │
│  │   任务环境 (Task/Specific)  │    │
│  │  顾客·竞争者·供应商·劳动力市场  │    │
│  │  ┌──────────┐             │    │
│  │  │   组织    │             │    │
│  │  └──────────┘             │    │
│  └──────────────────────────┘    │
└──────────────────────────────────┘
```

## 环境不确定性矩阵

| | 简单 | 复杂 |
|---|---|---|
| **稳定** | 低不确定性 | 低-中不确定性 |
| | 少数外部因素+变化慢 | 多因素+变化慢 |
| | 例：软饮料制造商 | 例：大学 |
| **动态** | 中-高不确定性 | **高不确定性** |
| | 少数因素+变化快 | 多因素+变化快 |
| | 例：时尚零售商 | 例：科技公司 |

## 利益相关者管理

- **利益相关者 (Stakeholders)** = 受组织决策和行动影响的任何群体
- 关键利益相关者：员工、顾客、股东、供应商、社区、政府、媒体
- 管理者的任务：平衡竞争性的利益相关者需求——不能只服务一个
