# 商业模式画布

## 一句话定义

> **商业模式画布 (BMC)** = Osterwalder & Pigneur 的九要素可视化工具——在一页纸上展示组织如何**创造、交付和捕获价值**。

## 九大构建块

| 块 | 核心问题 |
|----|---------|
| **客户细分** | 我们在为谁创造价值？最重要的客户是谁？ |
| **价值主张** | 我们解决了什么客户问题？提供什么价值？ |
| **渠道** | 如何触达客户、交付价值主张？ |
| **客户关系** | 如何获取、维系、增长客户？ |
| **收入流** | 客户为哪些价值付费？如何付费？ |
| **关键资源** | 需要哪些资源来使商业模式运转？ |
| **关键活动** | 需要做哪些最重要的行动？ |
| **关键伙伴** | 谁是我们最重要的合作伙伴？ |
| **成本结构** | 最重要的成本是什么？什么驱动成本？ |

## 画布的逻辑

```
┌───────────────┬───────────────┬───────────────┐
│  关键伙伴      │  关键活动      │  价值主张      │
│               │               │               │
├───────────────┤               ├───────────────┤
│               │  关键资源      │               │
│  成本结构      │               │  收入流        │
└───────────────┴───────────────┴───────────────┘
┌───────────────┬───────────────┬───────────────┐
│  客户关系      │  客户细分      │  渠道          │
└───────────────┴───────────────┴───────────────┘
```

## BMC 的价值

- **一页沟通**：整个商业逻辑在一页上——减少沟通偏差
- **假设追踪**：用便签标注已验证/未验证的假设——精益创业的核心工具
- **迭代便捷**：在画布上探讨"如果...会怎样"只需移动便签

## 反面论点与数据空白

- **BMC 是"静态快照"**：它不展示商业模式如何随时间演变——在快速变化的行业中，需要连续多个版本的画布。
- **忽略竞争**：BMC 聚焦于内部一致性——不直接显示竞争对手的定位。
