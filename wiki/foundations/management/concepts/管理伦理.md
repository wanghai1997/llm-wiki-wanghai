# 管理伦理

## 一句话定义

> **管理伦理** = 管理者在决策和行为中区分**对与错**的原则、价值观和信念——是组织文化的道德基础。

## 道德发展六阶段 (Kohlberg)

| 层级 | 阶段 | 行为动机 |
|------|------|---------|
| **前惯例** (Preconventional) | 1. 服从与惩罚 | 避免惩罚 |
| | 2. 工具性 | 获得奖励 |
| **惯例** (Conventional) | 3. 人际期望 | 符合"好孩子"形象 |
| | 4. 法律与秩序 | 尊重权威和规则 |
| **后惯例** (Principled) | 5. 社会契约 | 多数人同意的价值观 |
| | 6. 普遍伦理原则 | 内在的正义和权利原则 |

→ 多数成年人停留在阶段 3-4。

## 影响伦理决策的因素

- **个人特征**：道德发展水平、价值观、自我强度 (ego strength)、控制点 (locus of control)
- **组织文化**：什么行为被**实际奖励**（而非口号）
- **问题强度**：后果的大小、社会共识度、影响概率、时间紧迫性等

## 促进伦理行为的组织方法

1. **伦理准则 (Code of Ethics)**：书面声明组织的价值观和伦理规则
2. **高层领导的榜样**——CEO 的言行塑造伦理文化的"语气"(tone)
3. **伦理培训**：研讨会、情境讨论
4. **保护举报人 (Whistle-blowers)**：提供安全的报告渠道
5. **独立社会审计**：外部机构评估组织的伦理/社会责任实践

## 反面论点与数据空白

- **"伦理准则 ≠ 伦理行为"**：Enron 有精美的伦理准则——真正的伦理文化是由"发生问题时谁被保护、谁被牺牲"决定的。
- **Kohlberg 模型的局限**：基于西方男性样本——可能低估了关系性伦理（care ethics, Gilligan）和文化差异（某些文化重视群体和谐高于个体权利）。
