# 人力资源管理过程

## 一句话定义

> **人力资源管理 (HRM)** = 获取、开发、保留和有效利用组织的人力资源——八大步骤：规划→招聘→甄选→培训→绩效→薪酬→发展→劳动关系。

## HRM 八步骤

| 步骤 | 核心行动 |
|------|---------|
| **1. HR 规划** | 评估当前人力库存和未来需求——人员过剩还是短缺？ |
| **2. 招聘** | 吸引合格的候选人——内部 vs 外部招聘 |
| **3. 甄选** | 从候选人中选择最佳匹配——面试·测试·评估中心 |
| **4. 入职与培训** | 帮助新员工融入 + 更新技能 |
| **5. 绩效管理** | 评估和反馈绩效——与 [[目标管理MBO]] 对接 |
| **6. 薪酬与福利** | 设计报酬体系——固定/浮动/福利的组合 |
| **7. 职业发展** | 帮助员工规划长期职业路径 |
| **8. 劳动关系** | 管理雇佣合同、集体谈判、争议解决 |

## HRM 的战略角色

传统上 HRM 被视为"行政支持"——发薪、处理假期、合规。当代视角：**HRM 是战略伙伴**——人力资源是最重要的[[核心竞争力|竞争优势来源]]之一。

## 甄选的有效性

甄选工具从最有效到最差：
1. 工作样本测试 / 评估中心
2. 认知能力测试
3. 结构化面试
4. 非结构化面试（有效性最低、但最常用）

## 反面论点与数据空白

- **"年度绩效评估"的全球性退潮**：Adobe、Microsoft、GE 已放弃强制排名/年度绩效评估——改为持续反馈。但"无评估"是否更好仍缺系统证据。
- **AI 招聘的偏见**：算法从历史数据中学习→如果历史数据有偏见→AI 放大而非消除偏见。
