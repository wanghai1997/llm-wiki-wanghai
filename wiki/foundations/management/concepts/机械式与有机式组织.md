# 机械式与有机式组织

## 一句话定义

> **机械式组织** = 高度正式化、集中化、专门化——像机器。**有机式组织** = 灵活、分散、适应性——像生物体。Burns & Stalker (1961) 的经典二分法——没有"更好"，只有"更适合情境"。

## 两种形态

| | 机械式 (Mechanistic) | 有机式 (Organic) |
|---|---|---|
| **结构** | 高耸的金字塔 | 扁平、网络化 |
| **专门化** | 高度——岗位狭窄、定义清晰 | 低度——岗位灵活、边界模糊 |
| **形式化** | 高度——规则和程序手册 | 低度——价值导向、自主判断 |
| **决策** | 集中——顶层决策 | 分散——问题在哪里就在哪里决策 |
| **沟通** | 垂直——按等级链上下 | 横向——跨层级、跨部门 |
| **适用** | 稳定环境、常规技术、大型组织 | 动态环境、非常规技术、创新驱动 |
| **例子** | 大型制造企业、政府机构 | 科技初创公司、咨询公司、研发实验室 |

## 权变因素——什么决定该用哪种

- **战略**：成本领先 → 机械式；差异化 → 有机式
- **规模**：越大 → 越机械（需要标准化来协调）
- **技术**：常规技术 → 机械式；非常规技术 → 有机式
- **环境不确定性**：稳定 → 机械式；动态 → 有机式
