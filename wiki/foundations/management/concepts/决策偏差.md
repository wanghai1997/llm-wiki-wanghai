# 决策偏差

## 一句话定义

> **决策偏差** = 管理者在决策中系统性地偏离理性的认知捷径——Kahneman-Tversky 的行为决策研究表明这些偏差是**系统性、可预测的**，可以通过意识和流程来缓解。

## 主要决策偏差

| 偏差 | 描述 | 例子 |
|------|------|------|
| **过度自信** | 高估自己的能力、知识、预测准确性 | "这个项目我能按时完成"——实际延后 50% |
| **即时满足** | 选择立即获得回报的方案，放弃长期更有价值的方案 | 砍掉研发预算以满足季度利润目标 |
| **锚定效应** | 过分依赖最先获得的信息 | 第一次听说的价格变成了"合理价格"的基准 |
| **选择性知觉** | 只看到支持自己预期的信息 | 只注意对新产品正面的市场反馈 |
| **确认偏误** | 寻找支持已有观点的证据，忽略反面证据 | 在数据分析中有意排除"不利的"数据 |
| **框架效应** | 决策被问题的表述方式影响 | "成功率 90%"vs"失败率 10%”——统计相同，选择不同 |
| **可得性偏误** | 最容易想起的事件被认为更可能发生 | 刚看过空难新闻→高估飞行风险 |
| **代表性偏误** | 用相似性判断概率（忽视基础概率） | "她爱读书→应该当图书管理员——即使在超市碰到的人更可能是顾客" |
| **随机性偏误** | 在随机数据中看到"模式" | 连续掷出 3 个正面→"下一个一定是反面" |
| **沉没成本** | 将已经不可收回的成本纳入未来决策 | "已经投了这么多钱,不能停" |
| **自利偏误** | 成功归功于自己，失败归因于外部 | "我的战略对，市场环境不对" |
| **事后聪明** | 结果发生后声称"我早就知道" | "金融危机——我早就预料到了" |

## 缓解策略

- **意识到偏误的存在**——第一步
- **"红队"（devil's advocate）**：指派某人专门挑战主流意见
- **预验尸 (Premortem)**："假设一年后失败了——什么出了问题？"
- **数据驱动的决策**：用系统数据而非印象/回忆来判断
- **结构化决策流程**：强制使用标准和权重（见 [[决策过程八步骤]]）

## 反面论点与数据空白

- **偏差清单的"知道但不改变"问题**：意识到偏差不等于减少偏差——行为改变需要情境/流程的约束而非仅凭意识。
- **偏差在组织决策中可能被放大**：群体思维 (groupthink) 和层级的"向上过滤"可能放大个体偏差。
