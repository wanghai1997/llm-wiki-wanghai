# 多样性管理

## 一句话定义

> **劳动力多样性** = 组织中的人在**年龄、性别、种族、能力、性取向、文化背景、认知风格**等多维度上的差异——管理多样性不仅是法律合规问题，更是**竞争优势**的来源。

## 表面层级 vs 深层级多样性

| | 表面层级 | 深层级 |
|---|---|---|
| 可见性 | 容易观察到 | 需要深入了解 |
| 例子 | 年龄、性别、种族 | 价值观、人格、工作风格偏好 |
| 初始互动 | 基于刻板印象 | 不直接可见 |
| 随时间 | 差异的重要性下降 | 差异的重要性上升 |

## 偏见的类型

| 偏见类型 | 定义 |
|---------|------|
| **刻板印象** | 基于其所属群体的概括性判断 |
| **偏见** | 基于先入为主的、通常是负面的态度 |
| **歧视** | 基于偏见的**行为**——将态度转化为不公平对待 |
| **玻璃天花板** | 使女性和少数族裔难以晋升到高层的无形障碍 |

## 多样性管理的策略

- **高层的明确承诺**——多样性需要从 CEO 开始
- **导师制**——帮助少数群体获取组织内的社会资本
- **多样性培训**——提高意识、减少刻板印象
- **员工资源小组 (ERG)**——自愿的、由员工领导的基于共享身份的网络

## 反面论点与数据空白

- **多样性培训的有效性被质疑**：多数多样性培训项目只有短期效果——行为改变需要结构性的激励变革而非两天的培训。
- **"商业案例"框架的隐患**：用"多样性→更好的财务表现"来论证多样性——当财务数据不支持时（研究确实不一致），多样性的伦理理由反而被削弱。
