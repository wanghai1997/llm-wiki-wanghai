# 颠覆性创新

## 一句话定义

> **颠覆性创新** = Christensen 的理论——新进入者从市场的低端或边缘开始，提供更简单、更便宜或更便利的替代品——现有企业在**高端市场利润的诱惑**下选择向上逃离——最终低端创新改进到足以满足主流市场时，"颠覆"发生了。

## 颠覆 vs 维持性创新

| | 维持性创新 | 颠覆性创新 |
|---|---|---|
| 目标市场 | 现有高端客户 | 被忽视的低端/新市场 |
| 技术方向 | 更好、更快、更强 | 更简单、更便宜、更便利 |
| 现有企业的反应 | 积极投入——这是他们的核心客户 | 忽视或回避——利润太低 |
| 例子 | 每代 iPhone 的升级 | Netflix 的 DVD-by-mail→流媒体 |

## 为什么现有企业"看不到"颠覆

- **"好的管理"恰恰是问题**：倾听最好的客户 + 追求最高的利润 + 投资在高回报市场 → 系统性地**向上迁移**，把低端市场让给新进入者
- **颠覆者的路径**：低端市场 → 逐步改进 → 质量达到主流标准 → 现有企业突然发现自己被淘汰了

## 刺激创新的组织因素

| 结构 | 文化 | 人力资源 |
|------|------|---------|
| 有机式组织 | 容忍失败 | 培训和发展 |
| 充裕的资源 | 鼓励实验 | 工作保障 |
| 跨职能沟通 | 奖励创新 | 创新冠军 |

## 创造力 vs 创新

- **创造力** = 提出新奇的想法
- **创新** = 将这些想法转化为有用的产品/服务/流程
- 创造力是创新的必要但不充分条件
