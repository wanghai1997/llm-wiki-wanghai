# 林区制度成本与生态补偿

王有志等提出：林区生态补偿的有效性不能独立于林区的高制度成本来评估。林区面临的不仅是补偿标准偏低的"价格问题"，更是基础设施、公共服务、市场可达性全面薄弱的"结构问题"。

## 林区三重困境

1. **地理困境**：偏远、分散、交通不便 → 任何商品和服务的流通成本被地理距离放大
2. **制度困境**：林权碎片化、集体行动困境、村集体治理能力薄弱 → 生态服务的规模化供给缺乏组织载体
3. **市场困境**：远离消费市场 → 林下经济产品（中草药、食用菌、蜂蜜）面临"有货无市"或"有市无价"

## 补偿资金的"漏出"机制

生态补偿资金（公益林 ~15 元/亩·年）发放到林农后，一部分被用于支付高企的交通、教育、医疗支出（而非全部转化为保护激励）。在偏远林区，这实质上是"公共服务缺口→补偿资金填补→保护激励稀释"的恶性循环：

```
公共服务严重不足 → 补偿资金被迫用于替代公共服务支出
    → 林农从补偿中获得的净保护激励下降
    → 生态保护积极性不高
    → 生态退化风险 → 需要更多补偿 → ...
```

## 政策含义

- 单纯提高补偿标准（如 15→30 元/亩）效果可能有限——如果林区的制度成本（道路、通信、医疗、教育）未改善，增量资金仍会被公共服务缺口吸收
- "生态补偿 + 公共服务均等化"的组合政策可能比单纯的补偿标准提升更有效

## 反面论点与数据空白

- **制度成本的量化**：王有志的"制度成本"概念本身尚未被精确定义和度量——缺乏可操作的指标体系，目前停留在定性分析层面
- **公共服务改善的成本远高于生态补偿增量**：一个偏远林区通一条硬化路的成本可能等于该县全部公益林补偿额 10 年之和——组合政策的财政可行性存疑
