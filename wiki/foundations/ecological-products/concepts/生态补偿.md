# 生态补偿

**生态补偿**（Eco-compensation）是中国版 PES（Payment for Ecosystem Services）的核心制度安排。定义为：以保护和可持续利用生态系统服务为目的，以经济手段为主调节相关者利益关系的制度安排。

## 与西方 PES 的对比

| 维度 | 国际 PES | 中国生态补偿 |
|------|---------|------------|
| **理论框架** | Coase 自愿交易为主 | Pigou + Coase 双路径 |
| **核心原则** | "受益者付费" | "谁受益谁补偿、谁保护谁受偿" |
| **主导力量** | 市场/项目制 | 政府主导 |
| **空间尺度** | 多为局地/单一服务 | 跨省/全国系统性安排 |
| **附加目标** | 环境效率 | 环境效率 + 扶贫 + 区域均衡 |
| **资金来源** | 受益者直接支付 | 财政转移支付为主 |

## 经济学逻辑

生态补偿本质上是对**正外部性的内部化**：

- 生态保护者承担了保护成本，但生态效益（清洁水源、碳汇、生物多样性）流向了下游和全社会
- 如果没有补偿，保护者的理性选择是转为开发——因为私人收益 < 社会收益
- 补偿将社会收益的一部分返还保护者，使其保护行为的私人收益 ≥ 开发收益

## 补偿标准的经济学

补偿标准应在两个界限之间：

- **下限**：保护者的机会成本（如果不保护而去开发能赚多少钱？）
- **上限**：受益者的支付意愿（生态服务的边际社会价值）

中国的实际问题：下限常常就已经非常低（因为很多保护区的替代发展机会极少），但同时上限也非常高（因为受益者分散且搭便车严重）。补偿标准通常按下限设定，而非上限。

## 四种补偿类型

| 类型 | 方向 | 典型案例 |
|------|------|---------|
| 纵向补偿 | 中央 → 地方/农户 | 重点生态功能区转移支付、退耕还林、公益林 |
| 横向补偿 | 受益地区 → 保护地区 | [[新安江流域生态补偿]] |
| 市场化补偿 | 企业/消费者 → 保护者 | 碳汇交易、水权交易、绿色认证溢价 |
| 社会补偿 | 公益组织/社区 → 保护者 | 自然保护信托、社区共管基金 |

## 反面论点与数据空白

- **"补偿"vs"购买"的语义陷阱**：补偿暗示"弥补损失"，而非"购买服务"。这可能导致补偿定价系统性地偏向成本逻辑（保护者损失了多少）而非价值逻辑（生态服务值多少）。
- **补偿依赖症**：长期输血式补偿可能使保护地区形成财政依赖，丧失自主发展能力——造血式补偿的理论合理性远大于实践经验。
- **贫困与补偿的关系**：生态补偿的减贫效应被高度政治化——但实际上，重点生态保护区往往是"最不适合发展"的地区，补偿可能只是将贫困从"发展型贫困"变为"保护型贫困"。
- **反腐与补偿资金挪用**：基层补偿资金的发放渠道（村集体→农户）存在套取、截留风险。实证文献对此几乎不涉及。
