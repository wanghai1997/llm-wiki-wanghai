# 新安江流域生态补偿

> 中国首个跨省流域横向生态补偿试点（2012-），也是被政策文献引用最频繁的生态补偿案例。位于安徽（上游）—浙江（下游），下游千岛湖是长三角重要的战略水源地。

## 基本信息

| 项目 | 内容 |
|------|------|
| **流域** | 新安江（安徽黄山→浙江淳安千岛湖→钱塘江） |
| **启动年份** | 2012（第一轮试点） |
| **保护方** | 安徽省（黄山市为主） |
| **受益方** | 浙江省（千岛湖水源） |
| **补偿形式** | 水质对赌——以跨界断面水质（高锰酸盐指数、氨氮、总磷、总氮）为考核指标 |
| **资金规模** | 第一轮（2012-2014）：中央 3 亿 + 皖浙各 1 亿/年 |
| **已进行** | 四轮（2012-2021，第四轮延续中） |

## 机制设计

"水质对赌"的博弈结构：

- 若安徽保护达标（II-III 类水比例≥约定值） → 浙江支付补偿金给安徽
- 若安徽保护不达标 → 安徽支付违约金给浙江
- 补偿系数逐年提高（从 1 亿/年→4 亿/年），但水质标准也逐步加严

## 三重效果

### 1. 环境效果（显著）
- 新安江流域水质保持 II-III 类，千岛湖保持 I 类
- 安徽黄山市关停 200+ 家污染企业，退养 6000+ 亩网箱养鱼

### 2. 经济效果（混合）
- 黄山市放弃了 ~40 个工业投资项目（自我估算机会成本 >500 亿）
- 生态旅游和服务业增长部分弥补
- 三轮补偿总额约 50 亿，远低于机会成本

### 3. 社会效果（转型）
- 农户就业从污染型（养猪、网箱养鱼）转向生态旅游/有机农业
- 减贫效应存在但对中等收入群体有限——"托底不托中"
- 转型过程中部分农户经历过渡期收入下降

## 模式的推广价值与局限

**可推广的元素**：
- "对赌"机制的可操作性——指标明确、激励方向清楚
- 中央资金的引导角色（"种子资金"撬动地方参与）

**不易复制的条件**：
- 上下游关系简单（一对一，而非一对多）
- 下游浙江经济发达、支付意愿高
- 上游仅黄山市一个地区，协调成本低
- 千岛湖作为战略水源地的极高政治优先级

对于上下游关系复杂（多个上游省份）、经济发达程度差异巨大、缺乏战略水资源政治压力的流域，新安江模式的完全复制面临重大挑战。
