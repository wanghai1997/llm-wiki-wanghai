# 南平市生态银行

> 福建省南平市首创的"**生态银行**"模式，是生态产品价值实现中最具原创性的机制设计之一。核心创新：将碎片化、难交易的自然生态资源，通过"资源→资产→资本"的转化链条，整合为可运营、可融资、可交易的资产包。

## 基本信息

| 项目 | 内容 |
|------|------|
| **地理位置** | 福建省北部，武夷山国家公园所在地 |
| **启动时间** | 2018 年 |
| **总面积** | 2.63 万平方公里 |
| **核心资产** | 国有/集体林地、水域、农田、古村落 |

## 运作机制

### 三步转化链

```
自然资源 → 聚合为生态资产 → 转化为生态资本
  (碎片)       (整合)            (金融化)
```

### 1. 资源收储
- 将分散在林农手中、产权碎片化、难以独立经营的林地/水域/古村等自然资源
- 通过租赁、托管、入股等方式集中到县级国有"生态银行"平台
- 类似土地银行的逻辑——化零为整

### 2. 资产运营
- 生态银行整合后引入专业运营商
- 分类运营：森林康养、水域养殖权拍卖、古村品牌民宿群
- 资产规模化后吸引社会资本进入（单家独户的碎片化资源对资本无吸引力）

### 3. 资本转化
- 以整合后的生态资产包为抵押获得银行贷款
- 发行绿色债券
- 未来探索生态资产证券化（ABS）

## 与土地银行的对比

| 维度 | 土地银行 | 南平生态银行 |
|------|---------|------------|
| 收储对象 | 农地承包经营权 | 林地/水域/古村落生态权益 |
| 运营方向 | 规模化农业 | 森林康养/生态旅游/水资源开发 |
| 金融化方式 | 土地经营权抵押 | 生态资产整体质押 + 绿色债券 |
| 政策逻辑 | 粮食安全 + 规模经营 | 生态保护 + 价值转化 |

## 关键挑战

1. **估值难题**：生态资产的存量价值（尤其是调节服务价值）极难评估——缺乏抵押品定价参照系，银行接受度有限
2. **流动性风险**：生态资产的终极买家远少于土地——如果资产包运营失败，银行的退出路径是什么？
3. **分配问题**：林农将林地托管给生态银行后获得固定租金——但生态银行运营成功后的增值收益如何回馈原林农？
4. **规模依赖性**：生态银行的运营需要达到最小可行规模（碎片化资源的"临界质量"），规模不足则运营成本吞噬净收益
