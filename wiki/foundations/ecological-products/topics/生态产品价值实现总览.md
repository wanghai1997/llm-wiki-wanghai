# 生态产品价值实现总览

> 本导览页是"生态产品价值实现"知识板块的中枢入口。定位为：与 [[绿色经济学foundations总览|Nordhaus 西方环境经济学]] 形成 **"西方—中国"双柱对照**——西方柱回答"碳定价 + 全球公共品 + 绿色创新"，中国柱回答"生态产品价值转化 + 生态补偿 + 两山理论"。

## 核心问题

**如何让"绿水青山"变成"金山银山"？** ——这既是习近平生态文明思想的核心命题，也是中国环境经济学的独特学术议程。与西方 PES（Payment for Ecosystem Services）聚焦于"为生态服务付费"不同，中国的"生态产品价值实现"是一个更广阔、更制度化的框架，涵盖政府主导的转移支付、市场驱动的产权交易、社会参与的品牌溢价三条路径。

## 三大实现路径

1. **政府主导路径**：财政转移支付、生态补偿、政府采购、主体功能区规划
2. **市场驱动路径**：碳汇交易（CCER）、水权/排污权交易、生态银行、绿色金融
3. **社会参与路径**：生态产品认证/品牌溢价、社区共管、PPP 模式

## 与西方框架的关键差异

| 维度 | 西方 PES | 中国生态产品价值实现 |
|------|---------|-------------------|
| 理论根基 | Coase 定理 / Pigou 税 | "两山"理论 / 社会主义生态文明 |
| 核心机制 | 自愿交易为主 | 政府主导 + 市场驱动 + 社会参与 |
| 覆盖范围 | 可交易的生态服务 | 纯公共/准公共/私人生态产品全覆盖 |
| 核算工具 | SEEA-EA（联合国） | GEP（中国自主） |
| 典型案例 | 哥斯达黎加 PES / 纽约 Catskill | 丽水 / 南平 / 新安江 / 三江源 |
