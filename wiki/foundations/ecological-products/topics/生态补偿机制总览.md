# 生态补偿机制总览

> 本页是生态补偿/PES（Payment for Ecosystem Services）专题的导览中枢。生态补偿是生态产品价值实现中**政府主导路径**的核心制度安排，也是中国环境经济政策中实施最早、规模最大的组成部分。

## 什么是生态补偿？

**生态补偿**（Eco-compensation）是中国版的 PES（Payment for Ecosystem Services）——通过经济手段调节生态保护者与受益者之间的利益关系，使生态保护的正外部性内部化。核心原则是"谁受益、谁补偿；谁保护、谁受偿"。

## 十对基本关系

靳乐山提出中国生态补偿的**十对基本关系**，构成了政策设计的分析框架：

| 关系对 | 核心张力 |
|--------|---------|
| 补偿主体 vs 补偿客体 | 谁出钱？补给谁？ |
| 纵向补偿 vs 横向补偿 | 中央→地方 vs 区域→区域 |
| 政府补偿 vs 市场补偿 | Pigou 路径 vs Coase 路径 |
| 输血式补偿 vs 造血式补偿 | 现金补助 vs 产业扶持 |
| 公平目标 vs 效率目标 | 谁最需要 vs 一元的补偿产生最大的生态效益 |
| 补偿标准 vs 财政承受 | 科学定价 vs 预算约束 |
| 一次性补偿 vs 持续性补偿 | 资产买断 vs 流量支付 |
| 现金补偿 vs 实物/技术补偿 | 给钱 vs 给能力 |
| 个体补偿 vs 社区补偿 | 到户 vs 到村集体 |
| 环境绩效 vs 经济绩效 | 生态改善 vs 农户增收 |

详见 [[生态补偿十对关系]]。

## 理论根基

生态补偿的经济学理论基础是 [[外部性]] 理论中的两条经典路径：

- **Pigou 路径**：政府通过税收/补贴矫正外部性 → **纵向生态补偿**的逻辑
- **Coase 路径**：在产权清晰的前提下通过自愿谈判解决外部性 → **横向生态补偿**和**市场化补偿**的逻辑

详见 [[生态补偿的Pigou与Coase路径]]。

## 中国生态补偿体系

| 层级 | 名称 | 法律依据 | 规模 | 成熟度 |
|------|------|---------|------|--------|
| 纵向 | 国家重点生态功能区转移支付 | 财政部办法 | 最大（~千亿级/年） | 成熟 |
| 横向 | 跨省流域生态补偿 | 协商协议 | 中等 | 推广中 |
| 市场化 | 碳汇交易、排污权 | 试点 | 较小 | 起步 |

### 纵向体系（成熟）

- **国家重点生态功能区转移支付**（2008-）：覆盖 800+ 县，年度资金 ~1000 亿元
- **天然林保护工程**、**退耕还林** 等专项补偿
- **生态公益林补偿**：~15 元/亩·年

### 横向体系（推广中）

- **新安江流域**（2012-）：皖-浙跨省补偿，"水质对赌"模式
- **汀江-韩江**、**东江**、**引滦入津**等流域
- 缺乏国家层面的横向补偿立法，依赖地方协商

### 市场化体系（起步）

- 碳汇交易（CCER）
- 排污权交易（多省试点）
- 水权交易（中国水权交易所，2016-）

## 当前制度的主要缺陷

1. **补偿标准偏低**：公益林 ~15 元/亩·年，远低于林地转为开发用地的机会成本
2. **缺乏横向法定框架**：跨省补偿靠"关系"而非制度
3. **重建设轻管护**：退耕还林/还草工程的后续管护资金不足
4. **绩效评估缺失**：补偿资金的生态产出效果缺乏系统评估
