### 1.1 微观经济学基底（Batch 1-3，foundation）

> 本节由 Nechyba Ch 1-13 摄入提供，定位为本 Wiki 分析"AI / 平台 / 算力"叙事的标准工具集。`status: foundation` 区别于上方 AI/管理叙事的 `draft`——它代表已被主流教材沉淀的分析框架，而非两文互证的强论断。

- **三件套范式**：任何消费者 / 工人 / 储蓄者问题都化简为 [[预算约束]] + [[偏好类型]] + [[效用最大化问题]] / [[拉格朗日法]] 的标准结构。详见 [[消费者最优化选择]]。
- **SE-IE 分解作为比较静态统一引擎**：外生预算下是标准 [[替代效应]]；[[禀赋经济中的SE-IE]] 加上禀赋价值变化项后，可统一推出 [[劳动供给后弯]] / [[Laffer曲线]] / [[资本供给曲线]] 的非单调形态。
- **对偶系统作为 Ch 10 封顶**：[[效用最大化问题]] ↔ [[支出最小化问题]]，[[间接效用函数]] ↔ [[支出函数]]，由 [[Slutsky方程]] / [[Shephard引理]] / [[Roy恒等式]] / [[包络定理]] 锁死。详见 [[消费者对偶性]]。
- **厂商侧四件套（Batch 2）**：技术（[[生产函数]]）+ 价格 $(p, w, r)$ + 优化器（[[利润最大化问题|PMP]] / [[成本最小化问题|CMP]]）→ 解集（[[无条件投入需求]] / [[输出供给曲线]] / [[条件投入需求]]）+ 值函数（[[利润函数]] / [[成本函数]]）。详见 [[厂商最优化选择]]。
- **生产侧对偶系统**：PMP ↔ CMP，$\pi^*$ ↔ $C$，由 [[Hotelling引理]] / [[Shephard引理]] / "厂商 Slutsky"分解 / [[包络定理]] 锁死。结构上**组合型**（$\pi^* = \max_x\{px - C\}$）而非消费侧**反演型**（V↔E），原因在于利润货币度量 vs 效用序数。详见 [[厂商对偶性]]。
- **市场均衡（Batch 3）**：Batch 1-2 的个体需求 + 供给加总为 [[市场需求曲线]] / [[市场供给曲线]] → 短期均衡（$J$ 固定）→ 长期均衡（自由进入退出,$p^{LR} = \min LAC$,$\pi = 0$）。行业类型（constant/increasing/decreasing-cost）决定 [[长期供给曲线]] 形状。详见 [[竞争性市场均衡]]。
- **福利分析（Batch 3）**：[[第一福利定理-部分均衡]]（完全竞争 LR 均衡使社会剩余最大化）→ 价格管制 / 税收 / 贸易壁垒的 DWL 分析（[[市场扭曲下的福利损失公式]]）。详见 [[社会剩余]] / [[税收归宿]] / [[国际贸易福利]]。
- **一般均衡（Batch 3）**：Edgeworth 盒 → 契约曲线 → 核 → Walras 均衡。第一 / 第二福利定理。Arrow-Debreu 风险 GE（状态相依商品）。详见 [[一般均衡]] / [[风险与状态偏好]]。
- **跨域应用**：上方 AI/管理叙事的 [[Token工厂经济学]] / [[美团骑手管理平台]] / [[NVIDIA]] / [[AI重塑企业组织]] 均以**单向 see-also** 形式接入此工具集——不改写其主线。主题导览页（[[消费者最优化选择]] §5、[[厂商最优化选择]] §6、[[竞争性市场均衡]] / [[一般均衡]] / [[风险与状态偏好]] / [[市场失灵：外部性]] / [[市场失灵：信息不对称]] 跨域段）各自给出跨域桥接段。
- **市场失灵：外部性（Batch 4，Ch 21）**：外部性 / Pigou 税 / Coase 定理 / 交易成本。第一福利定理的经典失效模式之一——负外部性（污染）导致 $Q_{\text{市场}} > Q_{\text{社会最优}}$，正外部性（疫苗）导致 $Q_{\text{市场}} < Q_{\text{社会最优}}$。Pigou 税（政府路径）与 Coase 定理（市场路径）形成对照。详见 [[市场失灵：外部性]]。
- **市场失灵：信息不对称（Batch 4，Ch 22）**：逆向选择 / 信号传递 / 信息筛选 / 分离-混同均衡 / 均衡非存在性。第一福利定理的经典失效模式之二——隐藏信息导致市场平均质量下降（Akerlof 柠檬市场），隐藏行动导致道德风险。Rothschild-Stiglitz 1976 证明竞争性均衡可能不存在。详见 [[市场失灵：信息不对称]]。
- **价格扭曲深化（Batch 4，Ch 18-20）**：弹性与剩余分配 / 非价格配给 / 土地税 / 一般均衡税收归宿 / 跨期贸易 / 移民与外包。Batch 3 Ch 15 的深化——弹性决定税收归宿分配、Henry George 土地税（DWL=0）、跨期套利、劳动力流动与商品贸易的对称性。
- **不完全竞争 / 市场势力（Batch 5，Ch 23-26）**：垄断定价 / 寡头竞争（Cournot / Bertrand / Stackelberg）/ 博弈论（纳什均衡 / 子博弈精炼 / 贝叶斯均衡）/ 产品差异化 / 进入壁垒。第一福利定理的策略性失效模式——市场势力使 $P > MC$。详见 [[不完全竞争与博弈论]]。
- **公共品 / 政治经济学（Batch 5，Ch 27-28）**：公共品 / 搭便车 / Lindahl 定价 / 市民社会供给 / 寻租 / Arrow 不可能定理 / 社会选择理论。详见 [[公共品与政治经济]]。
- **行为经济学 / 规范经济学（Batch 6，Ch 29）**：现时偏向偏好 / Beta-delta 模型 / 参照依赖偏好 / 损失厌恶 / 框架效应 / 自由主义家长主义 / 幸福经济学 / Easterlin 悖论 / 效用可能性边界 / 社会无差异曲线 / 无知之幕 / 基尼系数。详见 [[行为经济学与规范经济学]]。
- **制度平衡（Batch 6，Ch 30）**：三条腿凳子（市场 / 市民社会 / 政府）/ 自发秩序 / 第一福利定理 6 条件回顾 / 可解理 vs 不可解理分歧。详见 [[市场、市民社会与政府的平衡]]。
- **全书工具链闭环**：Batch 1-2（个体最优化）→ Batch 3（市场均衡 / 一般均衡 / 风险）→ Batch 4（外部性 / 信息不对称）→ Batch 5（不完全竞争 / 公共品 / 政治经济）→ Batch 6（心理偏差 / 规范评价 / 制度比较）。Ch 30 的 6 条件框架将全书 29 章工具统摄为"市场有效的 6 条假设"，任一假设违反即对应一个 Part 的分析工具。

### 1.3 宏观经济学基底扩展（Mankiw Batch 2，Ch 3-5，foundation）

> 本节由 Mankiw 9e Ch 3-5 摄入提供，古典长期理论核心——实物经济（Ch 3）+ 货币体系（Ch 4）+ 通胀理论（Ch 5）。

- **古典长期模型作为"基石"**：[[古典宏观长期模型]] 整合生产函数 / 边际生产力 / 国民收入分配 / 古典消费函数 / 可贷资金市场五大砖块。长期内价格灵活 → 市场出清 → 充分就业；货币只决定名义变量（价格水平 $P$、名义利率 $i$），实物经济独立决定实际变量（$Y, C, I, r, W/P$）。这是全书后续模型（Solow / IS-LM / AD-AS / Phillips）的扩展基准或偏离对象。
- **货币与通胀的三层因果链**：[[货币与通胀理论]] 整合货币三职能 → 货币供给（$M_0$ + 部分准备金 + 货币乘数）→ 央行工具（Fed / QE）→ 货币数量论（$MV = PY$）→ Fisher 方程（$i = r + \pi$）→ 古典二分法 → 货币中性。长期通胀由货币增速选择决定 → 央行独立 + 通胀目标（2%）成为主流制度。
- **微观-宏观镜像深化**：宏观 Cobb-Douglas $Y = K^\alpha L^{1-\alpha}$ 是微观 [[生产函数]] 的总量版本；边际生产力 $W/P = MP_L$ 是微观 [[要素需求]] 的宏观表达；可贷资金市场 $S(r) = I(r)$ 是微观 [[禀赋经济中的SE-IE]] 的加总。古典消费函数 $C(Y-T)$ 是微观 [[预算约束]] 的简化。已在各概念页"与微观经济学的连结"段明示。
- **政策含义集合**：政府支出完全 [[挤出效应|挤出]] 私人投资（古典完全挤出）；反对货币化赤字（铸币税拉弗曲线）；通胀目标 2% 的零下限风险 vs 通胀税成本权衡。详见 [[货币与通胀理论]] §"政策含义集合"。
- **历史人物脉络**：Hume 1752 → Fisher 1911 → Keynes 1936（反对者）→ Friedman + Schwartz 1963（数量论复兴）→ Cagan 1956（恶性通胀）→ Lucas 1972（理性预期）→ Mankiw 1985（菜单成本 / 新凯恩斯）。已在 [[货币与通胀理论]] §"历史人物地图"展开。

### 1.4 宏观经济学基底扩展（Mankiw Batch 4，Ch 8-9，foundation）

> 本节由 Mankiw 9e Ch 8-9 摄入提供，增长理论核心——Solow 外生增长模型（Ch 8）+ 技术进步 / 增长核算 / 政策 / 内生增长（Ch 9）。完成 Part III 增长理论全部两章。

- **Solow 模型作为增长理论的基石**：[[Solow增长模型]] 从资本积累方程 $\Delta k = sf(k) - (\delta+n+g)k$ 出发，推导稳态、Golden Rule、条件收敛。核心洞察：储蓄率只有**水平效应**（level effect）而无**增长效应**（growth effect）；长期人均增长唯一来源于外生技术进步 $g$。
- **从外生到内生**：[[Paul Romer]] (1990) 将技术进步内生于 R&D 决策——知识非竞争性 → 规模效应 → 政策（教育、R&D 补贴、专利制度）可影响长期增长率。Aghion-Howitt (1992) 以创造性 destruction 为替代机制。详见 [[内生增长理论]] / [[研发微观基础]] / [[创造性破坏]]。
- **增长核算与 TFP**：[[增长核算与TFP]] 将产出增长分解为要素积累（资本、劳动、人力资本）与全要素生产率增长。实证发现：跨国收入差异的 ~2/3 来自 TFP/效率差异，仅 ~1/3 来自要素积累（Hall-Jones 1999; Klenow-Rodríguez-Clare 1997）。[[Alwyn Young]] 的东亚分解则显示要素积累在东亚快速增长中占主导——与全球样本结论形成张力。
- **制度作为最深决定因素**：[[Daron Acemoglu]]-Johnson-Robinson (2001) 的殖民制度假说将现代收入差异追溯至欧洲殖民者建立的制度差异（extractive vs settler institutions）。但 Albouy (2012) 数据修正、Sachs (2003) 地理假说、亚洲发展例外均对该因果主张提出挑战。详见 [[制度与经济增长]]。
- **管理实践与生产率**：[[Nicholas Bloom]]-Van Reenen 的世界管理调查（WMS）发现管理质量差异解释 ~1/4-1/3 的跨国 TFP 差距。随机实验（印度纺织厂）提供因果证据。但早期样本集中于美/英/法/德，可能隐含 Anglo-American 管理偏见。详见 [[管理实践与生产率]]。
- **微观-宏观桥接**：宏观增长模型的生产函数 $Y = F(K, L \times E)$ 是微观 [[生产函数]] 的动态化；资本积累方程是微观 [[跨期预算约束]] 的加总；人力资本在 [[Mankiw-Romer-Weil模型]] 中的作用对应微观 [[人力资本投资]] 概念。已在各概念页"与微观经济学的连结"段明示。
- **历史人物脉络**：Malthus 1798 → Solow 1956 / Swan 1956 → Phelps 1961 (Golden Rule) → Kaldor 1961 (stylized facts) → Lucas 1988 (human capital) → Romer 1986, 1990 (endogenous growth) → Aghion-Howitt 1992 (creative destruction) → AJR 2001 (institutions) → Bloom-Van Reenen 2007 (management)。已在 [[增长理论]] §"Historical Development"展开。

### 1.5 宏观经济学基底扩展（Mankiw Batch 7，Ch 15-20 + Epilogue，foundation）

> 本节由 Mankiw 9e Ch 15-20 + Epilogue 摄入提供，全书最后一批——微观基础回填（消费 / 投资 / 货币需求）+ 政策辩论（稳定化 / 债务 / 规则 vs 相机）+ 金融危机（金融加速器 / 2008 / 宏观审慎）。完成 Mankiw 9e 全书 20 章 + Epilogue 摄入，宏观经济学基底闭环。

- **消费理论六代谱系（Ch 16）**：从 [[Keynes消费函数]]（$C = \bar{C} + cY$，当前收入驱动）→ [[Fisher跨期选择模型]]（两期优化、消费平滑）→ [[生命周期假说]]（Modigliani 1954，终身收入平滑）→ [[永久收入假说]]（Friedman 1957，永久 vs 暂时收入分解）→ [[随机游走假说]]（Hall 1978，理性预期下消费变化不可预测）→ [[行为消费理论]]（Laibson 1997+，双曲贴现、现时偏向、心理账户）。每一代修正前代的局限，但全部基于代表性代理人假设——HANK模型（Kaplan-Moll-Violante 2018）发现异质性代理人下的aggregate MPC与representative agent预测截然不同。详见 [[消费理论]]。
- **投资理论三模型（Ch 17）**：[[新古典投资模型]]（$MPK = r + \delta$，利润最大化决定 desired capital）→ [[Tobin q理论]]（股票市场估值信号驱动投资，$q > 1$ 则投资）→ [[融资约束]]（Fazzari-Hubbard-Petersen 1988，现金流对投资的影响，尤其小企业）。q理论经验解释力仅10-20%（Blanchard-Rhee-Summers 1993），现金流往往比q更有预测力——信贷摩擦是投资波动的核心。详见 [[投资理论]]。
- **货币需求理论演进（Ch 18）**：从 [[货币数量论]]（$MV = PY$，Fisher/Friedman）→ [[Baumol-Tobin模型]]（交易成本的存货理论，平方根公式 $M^* = \sqrt{bY/2i}$）→ [[货币需求投资组合理论]]（Tobin 1958，货币作为资产组合中的无风险锚）。但1980s后金融创新使货币需求函数不稳定（Goldfeld 1976 "missing money"），央行已从货币供应量目标转向利率目标。详见 [[货币需求理论]]。
- **RBC vs 新凯恩斯的方法论分歧（Ch 19）**：[[实际经济周期模型]]（Kydland-Prescott 1982，技术冲击驱动、市场始终出清、政策无效）vs [[新凯恩斯主义模型]]（Calvo定价 + 名义刚性 + 货币政策有真实效应）。RBC在2008后被边缘化；新凯恩斯DSGE成为央行主流工具，但其单一代表性代理人假设和缺失的金融部门在危机预测中失灵。详见 [[实际经济周期模型]] / [[新凯恩斯主义模型]]。
- **规则与相机抉择的政策辩论（Ch 19）**：[[时间不一致性]]（Kydland-Prescott 1977， discretionary policy 导致通胀偏差）→ [[规则与相机抉择]]（Friedman固定规则 vs Keynesian灵活响应 vs Taylor规则折中）。现代央行实践"有约束的相机抉择"（constrained discretion）——通胀目标提供名义锚，但保留极端冲击下的灵活性。详见 [[规则与相机抉择]]。
- **金融危机与金融加速器（Ch 20）**：[[金融加速器]]（Bernanke-Gertler-Gilchrist 1999，信贷摩擦放大冲击）是理解 [[2008金融危机]] 的核心机制。住房泡沫→次贷违约→证券化传染→雷曼破产→全球信贷冻结→大衰退。后危机监管框架以 [[宏观审慎政策]]（Basel III逆周期资本缓冲、LTV限制、SIFI附加资本）为核心，但监管套利（资金流向影子银行）和政治经济阻力（繁荣期收紧信贷不受欢迎）使有效性存疑。
- **全书闭环与共识审视（Epilogue）**：[[宏观经济学共识与分歧]] 整理六大共识（长期增长靠TFP、货币长期中性、预期重要、短期波动涉及AD/AS、金融放大冲击、政策有 tradeoffs）与四大分歧（周期来源、稳定化政策角色、DSGE有效性、不平等/气候/分配）。但教材的"共识"排除了后凯恩斯主义、MMT、生态经济学等重要传统——呈现为"虚假中和"。
- **微观-宏观全书镜像闭环**：Mankiw Ch 16（消费）对应 Nechyba Ch 1-10 [[消费者最优化选择]]；Ch 17（投资）对应 Nechyba Ch 11-13 [[厂商最优化选择]]；Ch 18（货币需求）对应 Nechyba 的预算约束与资产选择；Ch 19-20（政策与金融）对应 Nechyba Ch 21-30 的市场失灵与制度分析。两本教材在方法论上形成"个体最优化 → 市场均衡 → 市场失灵 → 政策干预"的完整闭环。
- **跨教材总 [BIAS] 标记更新**：Nechyba 25 + Mankiw 30 = **55 处**（Batch 7 新增 3 处：消费理论的"美国中产阶级"默认 / RBC-NK "虚假对称" / 2008危机"技术性"叙事）。
- **历史人物脉络扩展**：Modigliani 1954（生命周期）→ Friedman 1957（永久收入）→ Hall 1978（随机游走）→ Laibson 1997（双曲贴现）→ Tobin 1969（q理论）→ FHP 1988（融资约束）→ Kydland-Prescott 1982（RBC）→ Calvo 1983（定价）→ Bernanke-Gertler-Gilchrist 1999（金融加速器）。

### 1.6 中国货币政策框架基底（中国货币政策实践 Batch 1，foundation）

> 本节由 [[孙国峰]] 《健全现代货币政策框架》(2021-01-13, PBoC 货币政策司司长权威政策框架文章) 摄入提供，定位为本 Wiki 的中国货币政策标准基底；与上方 [[Macroeconomics-Mankiw-9e|Mankiw 美式柱]] 形成"**美—中双柱**"对照结构——美式柱回答"普适理论 + 美国数据"，中国柱回答"新兴市场 / 转轨经济体 / 双循环格局下的货币政策实践"。所有页面位于 `wiki/foundations/china-monetary-policy/`。

- **内生货币论作为方法论起点**：[[央行三大约束-流动性资本利率]] 系统替代 Mankiw 教材的外生 [[货币乘数]] 框架——商业银行先放贷创造存款（信贷扩张），再寻找准备金满足约束。三大约束（流动性 / 资本 / 利率）是央行影响银行行为的微观渠道：央行通过 OMO/MLF 调节流动性、通过 MPA 监管资本充足率、通过政策利率引导存贷款定价。这与 [[Milton Friedman]] 的外生货币论形成方法论张力——但 PBoC 政策实践选择性引用 Friedman 的"通胀控制"立场而非"外生货币"立场。详见 [[现代货币政策框架]]。
- **双轨政策利率体系**：[[央行政策利率体系-中国]] 区别于美联储的单一 FFR——OMO（7 天逆回购，短期流动性管理）+ MLF（1 年期，中期政策利率）双轨制。MLF→[[LPR贷款市场报价利率|LPR]]→贷款利率的传导路径是中国版利率走廊设计。详见 [[MLF中期借贷便利]] / [[LPR贷款市场报价利率]] / [[OMO公开市场操作-中国]] / [[SLF常备借贷便利]]。
- **数量与价格双锚定**：中国货币政策在数量目标（[[M2与社会融资规模|"M2 与名义 GDP 基本匹配"]]）和价格目标（政策利率引导）之间维持双锚定，区别于美联储的单一通胀目标制。[[社会融资规模]] 是中国独有的总量监测指标，覆盖直接融资（债券+股票），弥补 M2 监测盲区。详见 [[M2与社会融资规模]] / [[社会融资规模]]。
- **结构性货币政策工具的"精准滴灌"哲学**：[[结构性货币政策工具]] 体系（再贷款再贴现、直达实体工具、CBS 央行票据互换）区别于美式 QE 的总量"大水漫灌"——通过激励兼容机制（incentive-compatible mechanism）影响银行行为，定向支持小微 / 三农 / 绿色 / 科创等领域。详见 [[再贷款再贴现]] / [[CBS央行票据互换]] / [[永续债银行资本工具]]。
- **宏观审慎与货币政策的"双支柱"**：[[宏观审慎评估MPA]]（2016 创设）是中国版 Basel III + 双支柱框架——通过 7 维度（资本与杠杆 / 资产负债 / 流动性 / 定价行为 / 资产质量 / 跨境业务 / 信贷政策）按季度评估金融机构,以激励兼容方式引导行为。这是 [[宏观审慎政策]] 的中国变体,与 Basel III 单一资本充足率监管形成结构性差异。详见 [[宏观审慎评估MPA]]。
- **跨周期政策设计与新发展格局**：[[跨周期政策设计]] 区别于美式逆周期调节,加入"跨周期"维度——为了支持 [[新发展格局]]（双循环 / 内需主导 / 高质量发展）的长期目标,货币政策不仅响应短期波动,也协调长期结构性目标。这与 Mankiw Ch 15 [[稳定化政策]] 的标准凯恩斯逆周期框架形成新维度对照。
- **现代中央银行制度的中国特色**：[[现代中央银行制度]] 在国际惯例（央行独立 + 通胀目标制）基础上加入"党的领导 + 技术独立"的中国式安排——技术决策独立于行政干预,但战略方向受党中央集中统一领导。这与美联储 / ECB / BoJ 的"完全独立"模式形成制度对照。详见 [[现代中央银行制度]]。
- **财政货币严格分离立场**：[[财政赤字货币化]] 词条系统记录 PBoC 反对赤字货币化的立场——区别于 MMT（Wray / Kelton）和美联储 QE 的财政-货币模糊地带,中国坚持央行不直接购买国债（一级市场）的纪律。详见 [[财政赤字货币化]]。
- **人民币汇率市场化的渐进路径**：[[人民币汇率市场化]] 记录 8.11 汇改 / 2019 "破 7" / 双向波动的管理浮动制——区别于 Mankiw Ch 13 [[Mundell-Fleming模型]] 的浮动 / 固定二元化,中国选择"中间制度"。[[利率市场化改革-中国]] 记录 1996-2019 利率"双轨制并轨"的制度演进。
- **美—中双柱对照结构建立**：本 Wiki 已在 [[宏观经济学foundations总览]] §8 建立完整对照表（货币创造 / 政策利率 / 政策工具 / 数量目标 / 利率传导 / 汇率制度 / 资本流动 / 财政货币关系 / 宏观审慎 / 央行制度 10 维度）。同时在 13 个 Mankiw 概念页（[[货币供给定义]] / [[部分准备金银行]] / [[货币乘数]] / [[美联储工具]] / [[货币数量论]] / [[Mundell-Fleming模型]] / [[不可能三角]] / [[宏观审慎政策]] / [[宏观经济学共识与分歧]] / [[2008金融危机]] / [[Milton Friedman]] / [[规则与相机抉择]]）追加 [regional-bias] 段落,反向回到 Mankiw 对应章节。
- **"千招万招,管不住货币就是无用之招"作为思想遗产**：[[孙国峰]] 对 Friedman "Inflation is always and everywhere a monetary phenomenon" 的中文意译,作为中国坚持稳健货币政策、反对"大水漫灌"的论据。这一表达在中国政策语境中频繁使用,特别是 2008 年 4 万亿后货币超发的反思。详见 [[Milton Friedman]] §"在中国语境的引用"。
- **历史人物脉络（中国柱）**：[[孙国峰]] 1996 加入 PBoC,1996 年 *经济研究* 论文提出"贷款创造存款"的内生货币论,2018 年任货币政策司司长,2021 年完成《健全现代货币政策框架》系统综述。[[中国人民银行]] 1948 年成立,1984 年与商业银行职能分离成为真正的央行,1995 年《中国人民银行法》确立独立地位,2003 年银监会分立,2018 年银保监会合并,2023 年金融监管总局再调整。

### 1.7 生态产品价值实现基底（ecological-products, foundation）

> 本节由 ~47 篇中国生态产品价值实现/生态补偿学术论文 + 4 政策文档摄入提供（2026-05-05, Batch 1-3），定位为本 Wiki 的中国环境经济学标准基底；与上方 [[绿色经济学foundations总览|Nordhaus 西方环境经济学]] 形成 **"西方—中国"双柱对照**——西方柱回答"碳定价 + 全球公共品 + 绿色创新"，中国柱回答"生态产品价值转化 + 生态补偿 + 两山理论"。所有页面位于 `wiki/foundations/ecological-products/`。

- **四柱框架作为知识结构**：[[生态产品价值实现总览]] 以"概念基础→价值核算→实现机制→制度保障"四柱组织 ~45 个页面。概念基础回答"什么是生态产品"（[[生态产品]] / [[生态产品分类体系]]）；价值核算回答"值多少钱"（[[生态系统生产总值GEP]] / [[生态价值核算方法总览]]）；实现机制回答"谁买单"（[[生态产品价值实现机制]] / [[机制复合体框架]]）；制度保障回答"政策怎么设计"（[[生态补偿]] / [[关于建立健全生态产品价值实现机制的意见]]）。
- **三重路径按产品分类匹配**：[[生态产品价值实现机制]] 提出政府主导（纯公共品：转移支付、政府采购）、市场驱动（准公共/私人品：CCER、品牌溢价）、社会参与（社区共有资源：合作社、PPP）三条路径。路径选择的基础是 [[生态产品分类体系]]——按排他性和竞争性将生态产品分为纯公共/准公共/私人三类。这不是意识形态选择而是经济学分类的技术推论。
- **机制复合体框架的三维互动**：[[丘水林]]（2023）提出 [[机制复合体框架]]——制度维（产权/法律/绩效考核）、市场维（价格信号/交易平台/金融工具）、技术维（GEP核算/卫星遥感/数据平台）三维互动决定机制绩效。核心洞察：短板效应（任一维滞后拖累整体）、时序匹配（技术迭代月/季、市场建设年、制度变革3-10年——速度差是失灵主因）、地区异质性（东部三维均高、中西部均低，不可一刀切）。
- **四大实践模式构成连续光谱**：从市场化到政府主导的连续排列——丽水（品牌溢价，GEP 3.6×GDP，近长三角消费市场）→ 南平（资产资本化，碎片资源聚合→生态银行→金融化）→ 新安江（跨界对赌，上下游水质协议，中央种子资金撬动）→ 三江源（纯公共品兜底，年供水>600亿m³惠及>5亿人，市场化几乎为零，只能国家财政）。详见 [[生态产品价值实现：核心机制与实践模式]]。
- **GEP 与绿色 GDP 的核算哲学分野**：[[生态系统生产总值GEP]] 采用"加法逻辑"（独立核算生态系统的正向产出），与 [[绿色GDP]]（Nordhaus）的"减法逻辑"（GDP 减去环境损耗）是两种完全不同的核算哲学。GEP 由中国学者 2013 年首次提出（欧阳志云等），定位为"生态版 GDP"——与 GDP 形成"双核算"体系。但 GEP 核算值 vs 实际现金流的转化率可能 <5%。
- **中国制度实验的全球独特性**：中国"生态产品价值实现"是全球唯一将生态系统服务价值化纳入国家系统政策框架的制度实验。2021 年两办印发《[[关于建立健全生态产品价值实现机制的意见]]》提出"六个机制"——比国际 PES（Payment for Ecosystem Services）更广阔：不仅是市场交易，更包含国家主导的生态补偿、空间管制（[[主体功能区生态补偿|主体功能区]]）、自主 GEP 核算体系、"[[两山理论]]"政治话语——四者耦合为整体系统。
- **跨实践共性挑战**：GEP 转化率 <5%（"算出来了"远不等于"实现了"）；补偿标准系统性偏低（公益林 ~15 元/亩·年 vs 商品林 ~100-300 元/亩·年，"象征性安抚而非真正购买"）；选择性偏差（成功案例全来自生态本底最优+政策资源最集中的地区）；政府主导路径的财政脆弱性（依赖转移支付，经济下行压缩风险）；碳汇 additionality 根本性质疑（CCER 体系中尚未解决）。
- **与西方环境经济学的双柱对照**：本 Wiki 已在 [[生态产品价值实现总览]] 建立对照框架——西方柱（Nordhaus）聚焦碳定价和全球公共品（效率中心、市场与政府平衡、碳价为基础），中国柱聚焦生态产品的价值转化和跨区域补偿（政府主导+市场驱动+社会参与）。详见 [[生态产品价值实现：核心机制与实践模式]] §五。
- **跨域桥接**：[[生态补偿的Pigou与Coase路径]] 直接连接微观经济学 [[Pigou税]] / [[Coase定理]] 标准工具；[[生态系统生产总值GEP]] 与 [[GDP的局限性]] / [[绿色GDP]] 对话；[[AI生产率悖论]]（本批次附属概念）连接 [[Token工厂经济学]] 与 [[GDP的局限性]]；中国柱的建立使本 Wiki 环境经济学维度从单一西方视角扩展为"西方—中国"双柱——后续可纳入欧/日/印度/巴西环境政策实践。

### 1.8 绿色经济学基底扩展（Nordhaus Batch 4，Ch 22-25，foundation）

> 本节由 Nordhaus《绿色经济学》Ch 22-25 摄入提供（2026-05-05），覆盖第五篇"全球绿色问题"（Ch 22-23）+ 第六篇"批评与反思"（Ch 24-25）。绿色经济学六篇 25 章全部摄入完毕，全书闭环。与 §1.7 生态产品价值实现（中国柱）形成"西方—中国"环境经济学双柱对照。

- **DICE 模型与碳价鸿沟（Ch 22）**：[[DICE模型]] 是 Nordhaus 气候经济学的核心工具——2020 年最优碳价 ~$40/吨，但全球实际碳价 <$5/吨。这一鸿沟不是模型错误而是政治失灵。[[气候变化经济学]] 系统记录从科学认知到经济分析再到政策设计的完整链条。[[气候临界点]]（格陵兰冰盖/AMOC/亚马逊雨林/永冻土）的不可逆性和非边际性对标准 CBA 框架构成最深层的挑战。[[Martin-Weitzman]] 的"厚尾"论证（2009, 2014）为这一挑战提供了理论表达——当灾难分布的尾部足够厚时，标准成本收益分析的贴现框架失效。
- **气候俱乐部作为制度创新（Ch 23）**：[[气候俱乐部]] 是全书最具政策原创性的提案——统一碳价 + 惩罚非参与者的贸易机制（碳关税），解决全球气候合作的搭便车困境。其理论完善（Nordhaus 2015 AER），但 2021 年仍无实施先例。与 [[京都议定书]]（1997，自上而下国别上限，美国未批/加拿大退出）和 [[巴黎协定]]（2015，自下而上 NDC，无惩罚机制）构成三代国际气候制度的演进。[[碳边境调节机制]]（CBAM）是气候俱乐部的单边简化版——EU 2023 年率先实施，但 WTO 兼容性和对发展中国家的歧视性影响存在重大争议。
- **批评光谱与 Nordhaus 的回应（Ch 24）**：三类批评形成意识形态光谱——[[深绿色运动]]（反增长/去增长：消费不可替代 + 系统变革）← **[[绿色精神]]**（Nordhaus：效率中心 + 碳价 + 增长可持续）→ [[自由市场环保主义]]（碳税共识但反监管）→ [[科氏集团与环境政治|土棕]]（[[气候否认者]]：否认气候科学或反对任何政策行动）。Nordhaus 承认深绿对"消费可替代性"的质疑有其学理基础，但反对其反增长的政策结论——历史数据显示技术进步使经济增长与碳排放可以脱钩（CO₂ 强度持续下降）。
- **绿色精神作为全书结论（Ch 25）**：[[绿色精神]] 总结全书四大支柱——效率中心（资源最优配置）、市场与政府平衡（碳价为基础 + 政府纠正外部性 + 市场配置资源）、碳价为基础（统一全球碳价是 Nordhaus 认为最有效的单一政策）、全球协调为目标（气候俱乐部是理想制度形式）。同时承认四条"绿色法则"的局限性：知识不完备（科学不确定性使最优碳价区间宽达 $20-$100）、政治阻力（碳税的政治可行性低）、全球搭便车（主权国家体系缺乏强制执行机制）、代际伦理不可解（贴现率的选择本质上是伦理判断而非科学问题）。
- **全书闭环与双柱对照**：Nordhaus《绿色经济学》六篇 25 章全部摄入完毕，绿色经济学 foundations 层 ~210 页。西方柱（Nordhaus）聚焦碳定价 + 全球公共品 + 绿色创新，中国柱（生态产品价值实现）聚焦生态产品价值转化 + 跨区域补偿 + 两山理论。两个体系面临共同的挑战——科学定价与政治定价的鸿沟（DICE $40 vs 实际 <$5 vs 公益林 ~¥15/亩·年）、制度执行的搭便车困境、代际公平的伦理不可解。气候俱乐部 vs [[横向生态补偿|新安江模式]] 在结构上高度相似（多边协商 + 惩罚机制），尺度不同。

### 1.9 数字经济基础（digital-economy, foundation）

> 本节由 [[江小涓]] 11 篇数字经济/平台治理/服务业论文摄入提供（2026-05-05），定位为中国数字经济**宏观政策层**——与 Wiki 已有的 AI/组织/生产率叙事（微观技术层：[[Token工厂经济学]] / [[AI生产率悖论]] / [[AI重塑企业组织]]）形成互补。所有页面位于 `wiki/foundations/digital-economy/`。

- **平台治理的范式演变**：[[平台治理]] 从 1.0"包容审慎"（鼓励创新优先）→ 2.0"规范治理"（反垄断/数据合规/算法透明）→ 3.0"协同治理"（政府+平台+社会多元共治）的三阶段范式演变。平台的三重角色——市场组织者（撮合交易）、规则制定者（算法即规则）、公共品提供者（数据基础设施）——使其治理挑战远超传统企业。中国平台经济治理在"鼓励创新"与"防范资本无序扩张"之间摆动，2021 年反垄断风暴是 2.0 的峰值，2023 年后转向 3.0。详见 [[十四五数字经济治理重点]]。
- **服务全球化的"第二波"**：[[服务全球化-数字时代]] 是继货物贸易全球化后的第二波——数字技术使传统"不可贸易"的服务业变成高度可贸易。四重渠道：跨境交付（软件/SaaS/云服务）、境外消费（在线教育/远程医疗）、商业存在轻量化（数字平台替代物理分支）、自然人移动增强（远程办公使"人"不必物理移动）。这与 Mankiw 宏观的 [[开放经济理论]] 标准框架形成补充——标准模型以货物贸易为基础，服务贸易的"无形性"使其不符合 $NX(e)$ 的简单汇率-贸易余额机制。
- **Baumol 成本病的数字时代修正**：[[服务业增长的重估]] 对 Baumol 经典"成本病"命题（服务业因无法标准化而效率停滞）进行了数字时代的修正——数字技术使服务业出现"停滞型"（面对面理发/餐饮）与"数字型"（SaaS/在线教育/数字金融）的分化。数字型服务业具有制造业特征：高固定成本+低边际成本（复制近乎零成本）、规模经济（服务全球）、效率持续提升。这一修正直接连接 [[AI生产率悖论]]——AI 作为通用目的技术（GPT）正在将更多"停滞型"服务转化为"数字型"。
- **科技经济融合的"压缩周期"**：[[科技经济融合]] 的核心发现是"科技即产业"——基础研究→技术开发→商业化的转化周期从传统的数十年压缩到数月。创新策源（前沿突破）与追赶-吸收（技术引进）的双轨并行是中国特色。"科学家+企业家+政府"三螺旋在中国语境下加入"党委领导"的第四维度。连接 [[NVIDIA]] 的 [[Token工厂经济学]]——算力芯片从科学计算→游戏→AI 训练的三次转型恰是科技经济融合的典型案例。
- **开源作为第三种生产组织方式**：[[开源与开放产业体系]] 提出开源是非市场（价格信号）非政府（行政命令）的第三种生产组织方式——基于自愿协作 + 声誉激励 + 开放许可证的分布式生产。中国开源战略从"跟随使用"→"积极参与"→"引领生态"，但面临 [[CONTRADICTION]]：中国 AI 论文全球领先但核心框架（PyTorch/TensorFlow/CUDA）不在中国。开源 AI（Llama/Mistral）vs 闭源 AI（GPT-4/Gemini）的竞争不仅是商业模式之争，更是"技术扩散+安全可控"vs"商业控制+集中治理"的治理范式之争。
- **与微观/宏观/AI 叙事的跨域连接**：[[数字经济与服务业效率]] 的五大部门实证（零售/金融/教育/医疗/政务）直接连接 [[Agent与AaaS]]——Agent 化服务是数字型服务业的终极形态。[[数字技术-文化互动]]（生产民主化/算法守门人/文化权力转移）连接 [[美团骑手管理平台]] 的算法治理困境。平台治理连接 Mankiw [[宏观经济学共识与分歧]] 的"新经济测度"争论——GDP 框架无法捕获免费数字服务的消费者剩余。[[数据价值链]]（本批次附属概念）连接生态产品数字交易的可能路径。

### 1.10 管理学基础（management, foundations）

> 本节由 Robbins & Coulter《Management》全书 18 章 + 管理思想史摄入提供（2026-05-04, Batch 1-3），定位为本 Wiki 的**管理学标准理论层**——围绕 POLC（计划·组织·领导·控制）四职能框架完整闭环。与 Wiki 已有管理实践案例（[[华为]]、[[IBM]]、[[美团]]、[[盒马]]）形成"理论↔实践"双向补充。所有页面位于 `wiki/foundations/management/`。

- **POLC 四职能作为全书骨架**：[[管理职能-POLC]] 是 Fayol 1916 提出的经典框架——计划（Plan: 战略/创业/决策）→ 组织（Organize: 结构设计/HRM/团队）→ 领导（Lead: 沟通/行为/激励/领导力）→ 控制（Control: 监控/运营/改进）。全书 18 章按此四块展开，~66 个页面覆盖全部核心概念。详见 [[管理学foundations总览]]。
- **管理思想史五流派**：[[管理思想的演变]] 从古典管理（[[科学管理-Taylor|Taylor 科学管理]] + [[科层制-Weber|Weber 科层制]] + [[Henri-Fayol|Fayol 职能管理]]）→ 行为学派（Hawthorne 实验 → OB）→ 定量学派（OR/MS/SCM）→ 系统学派（开放系统/权变）→ 当代（学习型组织/敏捷/数字化）。[[管理技能三层次]]（技术·人际·概念）与 [[管理者角色]]（Mintzberg 十大角色）构成对人的分析维度。
- **战略与组织设计的核心工具**：[[Porter五力模型]]（新进入者·替代品·买方·供方·竞争者）决定行业利润结构。[[Porter通用战略]]（成本领先/差异化/聚焦）给出三种竞争定位。[[核心竞争力]]（VRIN：有价值·稀缺·不可模仿·不可替代）是资源基础观的核心。[[组织设计的六要素]]（专门化·部门化·指挥链·管理幅度·集权·形式化）决定组织结构形态——从 [[机械式与有机式组织]] 到 [[职能-分部-矩阵-项目型结构]] 四种基本型。
- **领导与激励的行为科学基础**：激励理论从内容理论（[[Maslow需求层次]] → [[Herzberg双因素]]）到过程理论（[[期望理论|Vroom E×I×V]] → [[目标设置理论]] → [[公平理论]]）再到当代方法（[[当代激励方法|Pink 驱动力 3.0：自主·专精·目的]]）。领导理论从特质→行为（Ohio State/Michigan/管理方格）→权变（Fiedler/Hersey-Blanchard/House 路径-目标）→当代（变革型·魅力型·服务型·真诚领导）。[[组织行为学基础]] 以个体→群体→组织三层次为分析框架。
- **控制与运营**：[[控制过程]] 三步骤（测度→比较→行动）+ [[控制类型|三种类型]]（前馈/同期/反馈）。[[运营管理]] 涵盖价值链管理、精益生产、JIT、六西格玛——消除七种浪费（缺陷/过度生产/等待/非利用人才/运输/库存/动作/过度加工）。
- **与 Wiki 管理实践的理论映射**：[[华为LTC流程]] 对应 POLC 的计划与组织维度；[[IBM三维矩阵]] 对应矩阵结构的实际运行；[[让听见炮声的人呼唤炮火]] 对应授权与领导边界；[[自働化]] 对应控制职能（异常自动检测）；[[中等规模陷阱]] 对应科层化的规模弊端；[[AI重塑企业组织]] 对应变革管理与组织设计当代趋势。

### 1.11 计量经济学技术工具层扩展（Wooldridge Batch 2-4，foundation）

> 本节由 Wooldridge《Introductory Econometrics》第 8 版 Ch 10-20 摄入提供（2026-05-04，Batch 2-4），完成全书 20 章摄入。定位为本 Wiki 的计量"技术工具层"——与 [[Mastering-Metrics]]（Angrist-Pischke"因果直觉层"）互补：MM 回答"为什么这样做"，Wooldridge 回答"技术怎么做"。与微观/宏观形成"三柱"结构（微观·宏观·计量）。

- **时间序列分析（Batch 2，Ch 10-12 + 18）**：从 [[时间序列数据与静态模型|静态模型与有限分布滞后]] → [[平稳性与弱相依|平稳性与I(0)/I(1)]] → [[高度持续序列与单位根|单位根与随机游走]] → [[序列相关|序列相关检验与修正（Newey-West HAC）]] → [[协整与误差修正模型|协整与ECM]] → [[时间序列预测|预测方法]] → [[事件研究法]]。核心张力：[[谬误回归]]（Granger-Newbold 1974 模拟显示 I(1) 变量间回归 DW < R² 是危险信号）→ 一阶差分 vs 协整的选择取决于是否存在长期均衡关系。[[单位根检验]]（ADF/Phillips-Perron）的功效有限——在小样本中几乎无法区分 I(1) 和 I(0.9)。
- **面板数据方法（Batch 3，Ch 13-14）**：从 [[混合横截面与政策分析|独立混合横截面 + 广义 DiD]] → [[两期面板数据分析|一阶差分 FD]] → [[固定效应估计|FE（within transformation）]] → [[随机效应估计|RE（GLS）]] → [[Hausman检验|Hausman 检验（显著就用 FE）]] → [[相关随机效应CRE|CRE（Mundlak 装置）]] → [[面板数据在政策分析中的应用|双向 FE DiD + 事件研究面板]]。核心递进：FD/FE 消除时间不变的不可观测异质性 → RE 更高效但要求 $c_i$ 与 $X_{it}$ 不相关 → Hausman 检验判断 → CRE 折中（FE 稳健 + RE 灵活性 + 允许时间不变变量）。
- **联立方程与 IV 技术深化（Batch 3-4，Ch 15-16）**：[[联立方程模型]] 处理供需系统等双向因果关系——[[结构方程的识别|阶条件+秩条件]] 判断结构参数是否可识别。[[弱工具变量问题]]（$F > 10$ 经验法则，Stock-Yogo 2005 临界值表，LIML 替代 2SLS）是 IV 实践中最关键的诊断。[[过度识别检验]]（Sargan-Hansen J）在恰好识别时不可检验。[[内生性检验]]（Hausman 内生性检验）的局限：检验功效依赖于 IV 的有效性——如果 IV 本身也内生，检验没有意义。
- **受限因变量（Batch 4，Ch 17）**：从 [[二值响应模型-Logit与Probit|Logit/Probit（APE 解释）]] → [[Poisson回归与指数均值模型|Poisson 计数模型]] → [[Tobit模型-角点解|Tobit 角点解（两通道效应）]] → [[截取与截断回归|截取/截断 MLE 修正]] → [[样本选择修正-Heckman两步法|Heckman 两步法（逆 Mills 比率 + 排他性约束）]]。核心教训：二值响应模型的系数不是边际效应——必须报告 APE；样本选择偏差的修正关键在排他性约束（影响选择但不影响结果的变量）。
- **进阶因果推断与实证实践（Batch 4，Ch 19-20）**：[[倾向得分方法|倾向得分（PS 匹配/分层/加权/IPW）]] → [[回归调整与IPW的结合|Doubly Robust（IPW-RA，双保险原理）]] → [[控制函数方法|控制函数（CF vs 2SLS）]] → [[RD的放松假设|Fuzzy RD / 安慰剂断点 / Donut RD]]。[[实证研究项目设计]] 提供五阶段流程；[[计量经济学写作规范]] 提供六段式论文结构和诚实报告标准。
- **三柱结构的方法论闭环**：微观（Nechyba）→ 个体行为理论 → 宏观（Mankiw）→ 总量关系 → 计量（MM + Wooldridge）→ 因果识别 + 技术实现。Wooldridge 全书 20 章摄入完毕，与 MM 6 章合并构成本 Wiki 完整的计量经济学基础层。

### 1.12 生产性服务业基底（Batch 1，foundation）

> 本节由 11 篇中国生产性服务业学术论文（2006-2026）摄入提供。定位为本 Wiki 的**产业结构升级理论层**——围绕"概念基础→集聚机制→赋能效应→政策应用"四层框架，与已有数字经济层（[[江小涓]]）、生态产品层、经济学基础层形成多向交叉。

- **生产性服务业定义与特征**：满足中间生产需求、通过市场化模式提供中间投入服务的产业。三个核心特征——无形产出（产业结构软化）、中间服务（非最终消费）、人力资本与知识资本载体（现代产业竞争力源泉）。2024 年占中国 GDP ~31.5%，比美国低 ~24.5%。详见 [[生产性服务业]]。
- **与制造业关系四阶段演化**：[[需求遵从论]]（制造业附属）→ [[供给主导论]]（生产率前提）→ [[互动论]]（相互促进）→ [[融合论]]（边界消失）。当前中国处于互动→融合过渡期，AI 加速融合进程。详见 [[生产性服务业与制造业关系四论]]。
- **互动机理**：生产性服务业与制造业存在双向互动关系——要素分解+联立方程估计确认两者互为因果（高觉民 2011）。详见 [[生产性服务业与制造业互动机理]]。
- **两种集聚形态**：[[生产性服务业专业化集聚]]（马歇尔外部性：规模经济+技术外溢）vs [[生产性服务业多样化集聚]]（雅各布斯外部性：跨界知识溢出）。中国呈现"双重中心-外围"空间分化——沿海/中心城市从专业化向多样化转变，内陆/外围城市多样化增强、专业化减弱。详见 [[生产性服务业集聚]] / [[双重中心-外围结构]]。
- **赋能效应与发展阶段**：生产性服务业的赋能效应随发展阶段由弱变强——投入产出结构变化影响产业结构调整，部门关联效应影响增长和福利。当赋能效应增强后，全国统一大市场建设的收益将超过区域一体化（钟粤俊、陆铭 2026）。详见 [[生产性服务业赋能效应]] / [[统一大市场与生产性服务业]]。
- **技术扩散与制造业升级**：多样化集聚促进城际技术扩散（通过专利转让网络中的节点影响力），专业化集聚对此有抑制作用。但制造业结构升级方面，专业化集聚同时具有本地+周边效应，多样化集聚仅本地有效。详见 [[生产性服务业与技术扩散]] / [[生产性服务业与制造业结构升级]]。
- **政策驱动的多维路径**：AI 突破供需适配+要素约束（余泳泽 2026）、跨境电商促进专业化集聚但抑制多样化集聚（刘玉荣 2023）、政府产业基金通过资源配置效率+创新活力促进协同集聚（马铭晨 2026）、最低工资上涨→间接用工服务商增加（马双 2026）、排污权交易实现经济共富但扩大环境差距（谢慧明 2026）。详见各政策应用概念页。
- **跨域连接**：生产性服务业集聚的外部性理论连接微观经济学 [[外部性]]/[[Pigou税]]/[[Coase定理]]；熊彼特内生增长框架连接 [[创造性破坏]]；AI 赋能路径连接 [[AI冲击三层框架]]；排污权交易连接 [[新安江流域生态补偿]]；服务业效率讨论连接 [[数字经济与服务业效率]]。

  - **第一福利定理无前提乐观（Batch 3）** ：Nechyba 反复重复"完全竞争 + 自由市场使福利最大化",但 5 条假设同时满足在现实中不存在。Lipsey-Lancaster 1956 第二最优定理:任意假设违反时,保持其他假设未必使福利提高。详见 [[第一福利定理]] / [[第一福利定理-部分均衡]] [BIAS] 段。

  - **独立性公理无问题（Batch 3）** ：Ch 17 默认 vN-M 公理成立,只简单提及 Allais 悖论作为"例外"。Allais 1953 / Ellsberg 1961 / Kahneman-Tversky 1979 prospect theory 证明独立性系统性失效。详见 [[独立性公理]] [BIAS] 段。

  - **信息不对称模型的"二元类型"简化（Batch 4）** ：Ch 22 的保险/信号模型通常只处理两种类型。现实中的类型空间是连续的，二元模型给出的分离/混同结论在连续类型下可能不成立。详见 [[信号传递]] / [[分离均衡]] [BIAS] 段。
  - **逆向选择 vs 道德风险混淆（Batch 4）** ：Ch 22 主要聚焦逆向选择，对道德风险处理不足。但现实中两者交织。详见 [[信息不对称]] [BIAS] 段。

  - **垄断无谓损失的局部均衡局限（Batch 5）** ：Ch 23 用静态 DWL 三角形衡量垄断效率损失，但垄断利润可能用于研发（动态效率），且价格歧视可能扩大产出。局部均衡可能低估或高估真实福利损失。详见 [[垄断无谓损失]] [BIAS] 段。

### 2.1 生态产品价值实现领域的活跃争论

> 以下张力来源于 ~47 篇中国生态产品/生态补偿学术论文的内部观点分歧。与上方教材偏置 [BIAS] 不同，这些是领域内部的 genuine disagreement，而非教学简化与实证复杂性之间的差距。

- **[TENSION] 政府主导 vs 市场驱动——中国生态产品的路径之争**：[[丘水林]] 的机制复合体框架强调制度维（政府）的基础性，认为市场化路径的前提是产权制度和核算体系的完善——在制度和技术维度薄弱时，政府主导是不可跳过的阶段。[[曾贤刚]] 则强调市场化供给条件（排他性+竞争性），主张能市场化的应尽快市场化，政府主导路径存在财政脆弱性和激励扭曲。这一张力贯穿整个领域——不是"要不要市场化"而是"何时、何地、何种产品"可市场化。
- **[TENSION] Pigou 加强版 vs Coase 培育版——生态补偿改革的核心理论分歧**：王前进等主张加强 Pigou 路径（政府补偿），理由是中国纯公共生态产品占比高+产权制度不完善+受益者极分散，Coase 谈判的交易成本在多数场景下不可接受。冯俏彬等主张培育 Coase 路径（市场化补偿），理由是政府补偿标准过低（公益林 ~15 元/亩·年，远低于机会成本）且长期不可持续，必须通过产权改革和交易平台建设走向市场化。实际政策在两者间摆动——新安江模式（Pigou 种子资金 + Coase 双边协商）展示了混合路径的可能性，但尚未形成可推广的混合模式模板。
- **[CONTRADICTION] GEP"加法" vs 绿色 GDP"减法"——两种核算哲学的对立**：[[生态系统生产总值GEP]] 独立核算生态系统的正向产出（"生态创造了多少价值"），[[绿色GDP]] 在 GDP 基础上减去环境损耗（"经济消耗了多少自然"）。两者逻辑互补但政策含义相反——GEP 高不一定意味环境好（高 GEP 地区可能也在破坏生态），绿色 GDP 低则直接警告不可持续性。目前中国政策实践偏重 GEP（正面叙事+政绩激励），但学术批评认为不扣除生态损耗的"加法"可能给出虚假的安全感。这一张力与 [[GDP的局限性]] / [[绿色国民经济核算]] 的宏观测度争论直接连接。
- **[TENSION] 补偿公平 vs 补偿效率——生态补偿分配的核心权衡**：[[靳乐山]] 十对基本关系中，公平（最需要的人得到补偿 → 扶贫导向）与效率（补偿产生最大生态效益的地方 → 生态优先导向）构成根本张力。当前中国实践偏重公平（生态补偿与扶贫/共同富裕捆绑），但效率论者指出：如果补偿按贫困程度而非生态重要性分配，则生态补偿退化为收入转移支付，丧失了"购买生态服务"的经济学含义。[[生态补偿与城乡收入差距]] 的实证发现"托底不托中"——补偿缩小了最贫困群体的收入差距但对中等收入群体无显著效应——侧面印证了这一张力。

### 2.2 绿色经济学终章（Nordhaus Ch 22-25）的活跃争论

- **[CONTRADICTION] 京都"按国别设上限" vs Weitzman"价格投票更易达成一致"**：[[京都议定书]]（1997）采用自上而下的国别排放上限——各国分配减排配额，违约无强制执行。Weitzman（1974）"价格 vs 数量"框架指出：当边际收益曲线平坦（减排收益不敏感于排放量）而边际成本曲线陡峭（减排成本敏感于减排量）时，价格工具（碳税）优于数量工具（排放上限）——因为数量上限在成本不确定性下会产生更大的死重损失。气候俱乐部试图以"价格统一 + 贸易惩罚"解决这一问题，但无实施先例。
- **[TENSION] 自由市场自发改善 vs 监管加速改善**：美国 SO₂ 排放数据——1990 酸雨计划（cap-and-trade 监管）实施后 SO₂ 下降速率 -7.4%/年 vs 之前自发下降 -1.9%/年——是 Nordhaus 论证"监管比市场自发更有效"的关键证据。但 [[自由市场环保主义]] 反驳：环境 Kuznets 曲线（EKC）显示收入增长本身驱动环境改善，监管只是加速器而非必要条件。这一争论直接连接 [[环境库兹涅茨曲线EKC]] / [[EKC实证检验]] 的实证混合结果。
- **[TENSION] 深绿色反增长 vs Nordhaus 消费可替代性**：[[深绿色运动]] 核心主张——自然资本与人力资本不可替代（强可持续性），增长在有限地球上不可持续——从根本上否定 Nordhaus 的弱可持续性 + 技术替代框架。Nordhaus 以历史数据回应（CO₂ 强度持续下降证明增长与排放可脱钩），但承认深绿对"消费可替代性"的质疑在逻辑上无法被实证反驳——这是一个先于科学的价值选择。

### 2.3 数字经济领域的活跃争论

- **[TENSION] 平台效率提升 vs 外部成本内化**：平台经济的效率增益（交易成本降低/长尾匹配/信息聚合）与外部成本（骑手社保缺失/算法压榨/交通违法/中小商户依赖）存在系统性张力。江小涓主张将外部成本纳入平台治理框架（3.0 协同治理），但"如何内化 + 谁来承担"尚未形成学术共识。连接 [[美团骑手管理平台]] 的 [CONTRADICTION] 标记——骑手"自愿"接单与算法规训的结构性不对称。
- **[TENSION] AI 开源 vs 闭源的治理范式之争**：开源 AI（技术扩散 + 安全透明 + 社区治理）vs 闭源 AI（商业控制 + 集中安全审计 + 规模经济）的竞争未定论。中国 AI 论文全球领先但核心框架不在中国——[[CONTRADICTION]]：开源理想（技术民主化）与地缘技术竞争（芯片禁令/框架控制）的现实鸿沟。连接 [[OpenClaw]]（开源 Agent 操作系统）和 [[NVIDIA]]（CUDA 闭源生态）。
- **[CONTRADICTION] 中国 AI 论文全球领先 vs 核心框架/模型不在中国**：中国在 AI 论文数量和部分 benchmark 上全球领先，但核心训练框架（PyTorch/TensorFlow）、硬件架构（CUDA）、基础模型（GPT-4/Gemini）均不在中国。这是"科技即产业"（[[科技经济融合]]）在 AI 领域的核心困境——论文产出的领先未能转化为框架/模型/芯片的控制力。

### 2.4 生产性服务业领域的活跃争论

> 以下张力来源于 11 篇生产性服务业学术论文内部的发现分歧。

- **[CONTRADICTION] 多样化集聚：促技术扩散 vs 无制造业升级溢出**：[[金培振]](2026) 发现多样化集聚显著提升城市技术引进能力和节点影响力，促进城际技术扩散。[[韩峰]](2020) 发现多样化集聚对周边地区制造业结构升级无显著空间外溢效应，中西部多样化集聚甚至产生不利影响。可能解释：技术扩散 ≠ 直接转化为制造业升级——技术流动与产业升级之间存在转化效率损失，但两个发现的张力揭示了政策叙事的模糊性。
- **[TENSION] 跨境电商抑制多样化集聚——反直觉发现**：[[刘玉荣]](2023) 的 DID 估计显示跨境电商显著提高专业化集聚水平但**抑制多样化集聚**。直觉预期跨境电商应促进多元化服务需求，但实证结果相反——可能机制：CBEC 天然依赖信息传输、软件等特定服务环节，强化了专业化而非多样化。
- **[TENSION] 政府角色的双面性**：政府规模与服务业发展负相关（江波和李江帆 2013，引用于陈建军 2009）vs [[马铭晨]](2026) 发现政府产业基金显著促进产业协同集聚。政府角色的正面与负面效应可能取决于工具类型：行政干预型 vs 市场运作型基金（如"合肥模式"）。但"合肥模式"的外部条件可复制性存疑。
- **[TENSION] 统一市场的经济效率 vs 环境公平**：[[钟粤俊]](2026) 显示全国一体化提升经济效率和福利 vs [[谢慧明]](2026) 发现排污权交易扩大环境质量地区差距。统一大市场建设的多维目标（GDP、福利、环境、区域均衡）之间存在取舍——生态补偿可作为平衡机制。

- 货币乘数在 2008 后 QE 时代的实证失效（Basel III / IOER / 超额准备金囤积使乘数不稳定）。教材"乘数"框架对现代货币政策的解释力下降。
- Friedman 1963 *A Monetary History* 的计量经济学争议（Temin 1976 / Romer-Romer 1989）：大萧条"货币解释"是否被后续文献推翻？本 Wiki 已在 [[Milton Friedman]] 提及但未展开。
- Cagan 1956 七案例的当代重估：Reinhart-Rogoff 2009 / Hanke-Krus 2012 恶性通胀数据库对 Cagan 阈值（月通胀 50%）的扩展。
- 2008-2022 全球零利率 + QE 经验对古典货币中性叙事的挑战：QE 未引发 2010s 持续通胀，但 2021-22 通胀冲击突然出现——简单数量论的时间结构空白。
- MMT（Wray / Kelton / Tcherneva）对货币数量论的全盘反对：已在 [[货币与通胀理论]] 标注 [CONTRADICTION]，但缺一手文献深入。
- 加密货币 / CBDC / 稳定币对"货币边界"与货币乘数框架的冲击：教材基于"央行 + 商业银行"二层结构，数字时代部分失效。
- 银行资本与杠杆的巴塞尔框架演进（Basel I 1988 / II 2004 / III 2010 / III Finalized 2017）vs Mankiw 教材的简化叙述。
### 宏观经济学（Mankiw Batch 3，Ch 6-7）

- 大国开放经济模型缺失：美国不是小型开放经济的 price taker，Dornbusch 超调模型 / Obstfeld-Rogoff Redux 模型可解释利率-汇率联动，但全书未展开。
- 全球储蓄过剩（Bernanke 2005）与安全资产稀缺（Caballero-Farhi-Gourinchas 2017）对美国长期贸易逆差的解释：教材未涉及。
- Feldstein-Horioka 之谜：1960s-90s OECD 国家 $S-I$ 相关性仍高（0.6-0.9），资本流动性不如模型假设的完全。
- Balassa-Samuelson 效应：生产率增长快的国家实际汇率长期升值，与 PPP 预测的实际汇率恒定矛盾。教材未涉及。
- J 曲线效应：汇率变动对贸易余额的影响存在时滞，短期可能向相反方向移动。教材假设即时传递。
- 中国的双顺差悖论（贸易顺差 + 资本顺差）与资本账户管制：标准小型开放经济模型完全不适用。
- Card-Krueger 后续研究：Cengiz-Dube-Lindner-Zimmerman 2019 大数据验证、Jardim et al. 2022 西雅图 $15 最低工资研究，教材未涵盖。
- 买方垄断模型的宏观应用：最低工资不增失业的完整理论解释，教材回避造成微观-宏观知识断裂。
- 滞后效应（Hysteresis）：Blanchard-Summers 1986 欧洲高失业的持久性，短期衰退可永久性提高自然率。教材仅在脚注提及。
- AI / 自动化失业：Acemoglu-Restrepo "任务模型"预测 AI 替代常规任务将产生长期结构性失业。教材"部门转移"框架过于温和。
- 平台经济与失业统计：Uber / 外卖骑手模糊了"就业/失业"边界，BLS 统计框架面临挑战。
- 欧洲青年失业危机：西班牙/希腊 2010s 青年失业率 >50%，是结构性失业典型案例——教材未深入。
- 中国劳动力市场制度：户籍制度限制农民工进入城市正规就业；高校毕业生供给超过白领岗位需求。
### 宏观经济学（Mankiw Batch 5，Ch 10-13）

- **IS-LM 的现代批评与替代**：IS-LM 自 1970s 起受到 Lucas critique、Sargent-Wallace 政策无效性命题、Taylor rule 等挑战。教材未充分呈现这些批判，使 IS-LM 显得仍是"主流"工具。实际上现代央行决策主要依赖 DSGE 模型而非 IS-LM。
- **零利率下限与负利率**：教材 2016 年版仅简要提及 liquidity trap，未涵盖 2010s 发达经济体大规模的 QE、负利率政策(NIRP)、前瞻指引(forward guidance)和收益率曲线控制(YCC)。
- **金融加速器与信贷周期**：Bernanke-Gertler-Gilchrist (1999) 的金融加速器模型——信贷市场摩擦放大经济波动——在 2008 危机后被认为是 Keynesian 框架的必要补充，但教材完全未出现。
- **现代货币政策框架**：通胀目标制(inflation targeting)、平均通胀目标制(AIT, Powell 2020 Jackson Hole)、双支柱框架(ECB)等现代央行制度超出教材的"货币供给"操作概念。
- **2010s 全球生产率减速(Productivity Slowdown)**：Robert Gordon "The Rise and Fall of American Growth" (2016) 指出发达经济体 TFP 增长结构性放缓。
- **AI 与数字经济对增长核算的挑战**：Brynjolfsson 等提出 GDP 未能捕捉免费数字服务价值；AI 作为通用目的技术(GPT)是否进入索洛生产率悖论（"计算机时代无处不在，但在生产率统计中无踪"）。
- **气候变化与波动的权衡**：教材对增长的讨论隐含"增长是好的"立场，未涉及 Stern Review (2006)、碳预算约束下的增长路径、去增长(degrowth)文献。
- **财政乘数的时变性与状态依赖**：Auerbach-Gorodnichenko (2012, 2013) 发现财政乘数在衰退期显著大于扩张期；Blanchard-Leigh (2013) 对 IMF 财政乘数预测的修正。教材的财政乘数仍停留在单一数值表述。
- **全球价值链与 Mundell-Fleming**：全球价值链(GVC)、安全资产需求(Caballero et al.)、全球储蓄过剩(Bernanke 2005)等议题使 Mundell-Fleming 的简单 $NX(e)$ 机制严重过时。
- **汇率制度的中间地带**：教材将汇率制度二元化为固定 vs 浮动，忽略爬行钉住、篮子货币、区间浮动等"中间制度"的普遍性（"害怕浮动"现象）。
- **数字货币与汇率制度**：CBDC 可能改变跨境资本流动模式、汇率制度选择和货币政策传导机制。
### 1.5 宏观经济学基底扩展（Mankiw Batch 5，Ch 10-13，foundation）

> 本节由 Mankiw 9e Ch 10-13 摄入提供，短期经济波动理论核心——AD-AS 框架（Ch 10）+ IS-LM 模型（Ch 11-12）+ Mundell-Fleming 模型（Ch 13）。完成 Part IV 短期波动理论前四章。

- **AD-AS 作为短期分析的"地图"**：[[AD-AS模型]] 把 [[总需求曲线]]（价格水平与产出需求的负相关，财富效应+利率效应+汇率效应）与 [[总供给曲线]]（短期向上倾斜因价格粘性，长期垂直因古典二分法）组合为分析短期波动的核心框架。需求冲击使产出与价格同向变动；供给冲击造成滞胀（stagflation）。
- **IS-LM 作为 AD 的微基础**：[[IS-LM模型]] 从 [[IS曲线]]（产品市场均衡，$Y = C(Y-T) + I(r) + G$）与 [[LM曲线]]（货币市场均衡，$M/P = L(r,Y)$）的交点决定 $(r^*, Y^*)$。财政政策移动 IS，货币政策移动 LM；Ch 12 从 IS-LM 正式推导出向下倾斜的 AD 曲线。
- **政策组合与极端情形**：[[财政政策与货币政策的相互作用]] 分析四种政策组合（扩张/紧缩 × 扩张/紧缩）对产出和利率的差异化影响。[[流动性陷阱]]（LM 水平，$r \approx 0$）使货币政策失效、财政政策完全有效——这是 2008 后全球刺激的理论依据。[[古典区域]]（LM 垂直）使财政政策完全挤出、货币政策高度有效。
- **开放经济扩展**：[[Mundell-Fleming模型]] 在完美资本流动+小型开放经济假设下，将 IS-LM 扩展至开放环境。核心结果：浮动汇率下货币政策有效、财政政策无效（汇率升值完全挤出净出口）；固定汇率下财政政策有效、货币政策无效（央行被动适应）。[[不可能三角]]：资本自由流动、固定汇率、独立货币政策三者不可兼得。
- **微观-宏观桥接**：$C(Y-T)$ 是微观 [[消费者最优化选择]] 的总量形式；$I(r)$ 是微观投资理论的宏观表达；$L(r,Y)$ 是微观货币需求的加总；$NX(e)$ 是微观 [[国际贸易福利]] 的宏观表达。已在各概念页"与微观经济学的连结"段明示。
- **历史人物脉络**：Keynes 1936（《通论》，有效需求革命）→ Hicks 1937（IS-LM 形式化）→ Hansen-Samuelson（新古典综合，美国 Keynesianism）→ Mundell 1963 / Fleming 1962（开放经济短期均衡）→ Friedman 1968（自然率假说，货币主义批判）→ Lucas 1976（Lucas 批判，理性预期）→ Taylor 1993（Taylor 规则，现代央行操作框架）。已在 [[短期经济波动]] §"Historical Episodes"展开。

### 宏观经济学基底扩展（Mankiw Batch 3，Ch 6-7，foundation）

> 本节由 Mankiw 9e Ch 6-7 摄入提供，完成 Part II 古典长期理论——开放经济（Ch 6）+ 失业与劳动力市场（Ch 7）。

- **开放经济的古典模型**：[[小型开放经济模型]] 将 [[储蓄-投资均衡]] 从封闭经济（$S = I$，利率内生）扩展到开放经济（$r = r^*$ 外生，$NX$ 调节）。核心恒等式 $S - I = NX = NCO$ 将商品流与资本流统一。财政政策在开放经济中不再挤出投资，而是挤出净出口（Reagan 时代案例）。实际汇率 $\epsilon$ 调整使贸易余额等于储蓄-投资缺口。详见 [[开放经济理论]]。
- **PPP 作为长期汇率基准**：[[购买力平价]] 从 [[古典二分法]] 推导——货币只影响名义变量（名义汇率），不影响实际变量（实际汇率）。但教材自承 PPP 短期大幅偏离（Rogoff 1996 "PPP 之谜"：偏离半衰期 3-5 年）；Big Mac Index 作为经验检验显示实际汇率长期大幅偏离 PPP。详见 [[购买力平价]]。
- **自然失业率的流量模型**：[[自然失业率]] $u_n = s/(s+f)$ 将失业分解为摩擦性（正常流动）和结构性（工资刚性）。承认即使长期也存在失业，修正了 Ch 3 古典模型的"充分就业"假设。但"自然"一词高度误导——$u_n$ 内生于制度设计（失业保险、最低工资、工会密度、培训政策）。详见 [[失业与劳动力市场理论]]。
- **工资刚性的三大来源**：[[实际工资刚性]] 由最低工资（[[David Card]]-[[Alan Krueger]] 1994 自然实验颠覆标准竞争模型预测）、工会/集体谈判（insider-outsider 理论）、效率工资（Akerlof 礼物交换 / Shapiro-Stiglitz 不偷懒约束）构成。教材呈现 Card-Krueger 结果但回避买方垄断(monopsony)解释，造成微观-宏观知识断裂。
- **Beveridge 曲线作为周期与结构的镜子**：[[Beveridge曲线]] 描述失业率-职位空缺率负相关；沿线移动反映周期波动，曲线外移反映结构性变化（匹配效率恶化、技能错配）。Mankiw 教材提及但未深入 DMP 搜索匹配模型推导。
- **微观-宏观镜像深化**：Ch 6 开放经济对接微观 [[国际贸易福利]] / [[跨期贸易与套利]]（国际价格/套利 vs 宏观汇率/NX）；Ch 7 失业对接微观 [[劳动供给]] / [[劳动力市场均衡]] / [[利润最大化问题]]（劳动买方垄断是 Card-Krueger 结果的最自然解释，但教材回避）。

- **Mankiw Batch 4-7 待续**：增长理论（Ch 8-9）/ 短期波动（Ch 10-14）/ 微观基础 + 政策 + 金融（Ch 15-20 + Epilogue）。

### 生态产品价值实现（ecological-products）

- **GEP 转化率实证真空**：GEP 核算值 vs 实际现金流的系统证据缺失——全国 GEP 转化率估算可能 <5%，但无权威实证研究支撑。"算出来了"远不等于"实现了"，目前缺乏对 GEP 核算→实际收入转化的全链条追踪数据。
- **南平生态银行的可复制性**：南平模式（碎片资源聚合→县级国有平台运营→金融化）的独创性高但可复制性存疑——需要县级国有平台的强运营能力、足够的生态资产规模门槛、以及制度支持。其他地区的复制尝试尚未有系统评估。
- **横向生态补偿的协商成本**：新安江"一对一"上下游关系（安徽→浙江）的特殊性使其难以推广——多上下游省份的流域协商成本极高。横向补偿的搭便车问题、谈判僵局、执行机制缺乏系统研究。
- **碳汇交易的 Additionality 根本性质疑**：被交易的林业碳汇是否真正"额外"？——这一根本问题在中国 CCER 体系中尚未解决。缺乏 additionality 验证的碳汇交易可能导致"购买污染许可"而非"减排"。
- **生态补偿减贫效应的长期追踪**：已有实证发现"托底不托中"（补偿缩小最贫困群体收入差距但对中等收入群体无显著效应），但缺 10 年以上长期追踪数据。补偿退出后农户是否返贫？补偿依赖是否抑制了内生发展能力？——均无系统证据。
- **生态产品价值实现的财政可持续性**：政府主导路径高度依赖财政转移支付，经济下行期的压缩风险未被系统评估。土地出让金下滑（地方财政支柱）对生态补偿资金的挤出效应待量化。
- **生态产权制度的法律空白**：[[生态产权制度]] 指出三权分置在生态资源领域的适用性尚未法律明确——生态资源使用权、收益权、处置权的界定模糊，是市场化的根本制度障碍。

### 绿色经济学（Nordhaus Ch 22-25，Batch 4）

- **DICE 模型参数敏感性的政策含义**：最优碳价对贴现率 δ 和气候敏感度参数的敏感性极高——δ=1.5%（Nordhaus）→ 碳价 ~$40/吨，δ≈0.1%（Stern）→ 碳价 ~$266/吨。参数选择本质上是代际伦理判断，但教材以 Nordhaus 偏好为默认，未充分呈现 Stern 侧的论证强度。
- **气候俱乐部的实际可行性**：2015 年提出，2021 年仍无实施先例。核心障碍：大国退出威慑不可信（惩罚非参与者意味贸易战——惩罚者自己也受损）、发展中国家"共同但有区别责任"（CBDR）的公平性诉求、以及 WTO 兼容性（碳边境调节可能被裁定为歧视性贸易壁垒）。
- **碳边境调节机制（CBAM）的 WTO 兼容性**：EU 2023 年率先实施，但面临多重法律挑战——是否违反最惠国待遇（MFN）？是否构成对发展中国家的事实歧视？如何验证出口国的隐含碳排放？——均缺乏国际法判例。
- **深绿色运动的实证强度**：Nordhaus 以 CO₂ 强度下降论证"增长与排放可脱钩"，但深绿反驳：绝对排放量仍在上升（只是增速放缓），且物质吞吐量（material throughput）与 GDP 的绝对脱钩在全球尺度上尚未实现。这一争论缺乏决定性实证裁判——双方挑选对己有利的指标。
- **气候临界点的经济建模空白**：DICE 模型的平滑损害函数无法处理临界点（AMOC 关闭/格陵兰冰盖崩塌/亚马逊 dieback）的非连续性和不可逆性。Weitzman 的"厚尾"论证指出了问题，但尚未被整合进主流 IAM 模型——这是气候经济学最重大的方法论缺口。

### 数字经济（digital-economy）

- **数字型服务业的实际比重**：中国数字型服务业在服务业总增加值中的确切占比未有共识——统计分类滞后于业态变化。传统 SNA 行业分类无法区分"数字型"与"停滞型"服务业。
- **跨境数据流动的国际规则**：数据作为生产要素的跨境流动规则尚未建立——中国的"数据本地化" vs 美国的"数据自由流动" vs 欧盟的 GDPR"有条件流动"三套框架并立。对数字服务贸易和服务全球化的影响未量化。
- **开源 AI 的安全治理框架**：开源 AI 模型（Llama/Mistral）可以被任意下载和微调——如果被恶意使用，没有中心化的审计和控制机制。"开源安全"是否存在？——这一根本问题未有共识。
- **平台 3.0 协同治理的制度设计**：如何将政府监管、平台自治、社会监督形成可操作的制度安排？骑手社保/算法透明/数据产权等具体议题缺乏可推广的制度模板。
- **AI 论文领先→产业控制力落后的转换机制**：为何中国 AI 论文全球领先但核心框架/模型/芯片不在中国？——这一"论文-产业"鸿沟的深层原因（基础研究→工程化→商业化的链条断裂点）缺乏系统诊断。

### 生产性服务业（producer-services，2026-05-11 新增）

- **生产性服务业与制造业"融合论"的经验证据**：顾乃华(2006) 提出的四论中的"融合论"——制造业与服务业边界消失——在中国语境下的系统经验证据仍薄弱，多为案例描述而非因果识别。
- **AI 赋能生产性服务业的因果效应量**：余泳泽(2026) 为框架性论述——AI 对生产性服务业效率提升、就业结构、区域分布的实际效应量尚未被严格估计。
- **间接用工的规模测度**：马双(2026) 自述——用"新设间接用工服务商数量"仅为代理变量，间接用工总量（人数/工资额）缺乏系统统计。上市公司自 2012 年披露劳务外包但非上市企业数据空白。
