# NVIDIA

## 在本 Wiki 的引用脉络

[[黄仁勋]] 在 GTC 2026 演讲中将 NVIDIA 定位为"AI 基础设施和工厂公司"，提出 [[Token工厂经济学]] 与 [[极致协同设计]] 作为未来增长的底层商业逻辑。

## 战略要点

- **垂直整合，横向开放**：自研架构 / 系统 / 软件栈，但允许整合进任何合作伙伴平台。
- **三大平台**：CUDA-X 平台、系统平台、AI 工厂平台。
- **CUDA 飞轮**：装机量（数亿块 GPU）→ 开发者 → 算法突破 → 新市场 → 更多装机量。CUDA 已积累 20 年。
- **客户结构**：60% 收入来自前五大超大型云服务商（Azure / AWS / Google Cloud / Oracle / CoreWeave 等），40% 分散于主权云、企业、工业、机器人、边缘计算。

## 收购与生态

- **[[Groq]]**：完成收购与技术授权，组建非对称分离推理（[[Vera Rubin]] + Groq）方案。
- **NeMo Cloud / [[OpenClaw]] / NeMo Claw**：企业级 Agent 参考框架。
- **Nemotron 联盟**：投资数十亿美元推进 AI 基础模型，成员含 BlackForest Labs、Cursor、LangChain、Mistral、Perplexity、Reflection、Sarvam、Thinking Machines 等。

## 其他披露

- **太空数据中心**：Thor 芯片已通过辐射认证；Vera Rubin Space-1 项目研发中。
- **保密计算**：NVIDIA GPU 是全球首批支持 Confidential Computing 的 GPU。
- **CPO 量产**：声称 Spectrum X 是首款量产共封装光学交换机。

## 数据可信度提示

- 所有性能/收入/增长数据均出自 NVIDIA 自身或友好分析机构。需以 MLPerf / SPEC 等独立基准、第三方云成本对比作交叉验证。

## 微观经济学视角（伏笔）

> 单向 see-also——把 NVIDIA 作为算力市场的"卖方禀赋经济主体"放入 [[Microeconomics-Nechyba-2e|Nechyba 微观经济学]] 的分析框架。**不**改写本页的主线叙事。

### 消费者侧（[[消费者最优化选择]] §5）

- **NVIDIA 作为净卖家** ：芯片产能 $(e_{chip}, e_{capital})$ 是禀赋；价格 $p_{chip}$ 上涨同时增加销售收入与禀赋市场价值——这是 [[禀赋经济中的SE-IE]] 在**净卖家**一侧的标准场景。教材 Ch 8 指出,净买家与净卖家对同一价格变化的福利方向**相反**。
- **CUDA 飞轮 = 替代弹性 $\sigma$ 极低** ：CUDA 锁定降低买家替代到非 NVIDIA 平台的能力 → 整个市场表现得像 [[偏好类型|完全互补]]型偏好（$\sigma \to 0$） → 与 [[替代弹性]] 极低对应,使买家议价权弱化。
- **客户结构集中（60% 来自前 5 云厂商）** ：使 NVIDIA 与其超大客户构成**双向独占**（双向单一买卖方 / bilateral monopoly）——这超出 Ch 1-10 完全竞争模型,要到 Ch 24-25 不完全竞争 / 议价论才有完整工具。
- **路线图作为禀赋扩张** ：Vera Rubin / Feynman 的迭代相当于"禀赋点跨期外移"——见 [[资本供给曲线]] 中"禀赋数量变化时曲线移动"的几何。

### 厂商侧（[[厂商最优化选择]] §6）

- **NVIDIA 作为生产者** ：把芯片代工厂（TSMC）+ 设计 / CUDA 软件作为"生产函数 $f(L, K)$"的投入；产品价格 $p_{chip}$ 给定下决策 PMP——但 IRS 显著（CUDA 飞轮 + 软件边际成本趋零）使标准 [[利润最大化问题|PMP]] FOC 失效（详见 [[规模报酬]] [BIAS]）。
- **MR ≠ p（垄断 / 准垄断）** ：在 AI 加速卡市场（>80% 份额）下 NVIDIA 是价格制定者,FOC 应为 $MR \cdot MP_L = w$ 而非 $p \cdot MP_L = w$（Ch 23 范围）。本 Wiki [[利润最大化问题]] §"反面论点"已铺垫。
- **短期 vs 长期决策** ：Hopper / Vera Rubin 一旦量产,$K$ 短期固定（$\bar K$） → 短期供给曲线 = SMC 在 SAVC 之上；Feynman 决策对应"长期 $K$ 调整"（[[短期成本与长期成本]]）。
- **关闭条件失效** ：标准 [[关闭条件]] $p < AVC_{\min}$ 触发短期停产；NVIDIA 短期不太可能触发,因为算力市场需求 + CUDA 锁定使 $p$ 持续高于 $LAC_{\min}$（即长期都盈利,自由进入失效——非完全竞争行业）。
- **跨期 IRS 故事** ：CUDA 飞轮 = 装机量↑ → 开发者↑ → 算法↑ → 装机量↑ 的正反馈,使 LAC 跨期下移。这是教材 Ch 11 的 IRS 难以处理的"动态 IRS"——超本 Batch 范围,见 Batch 5 不完全竞争。

### Batch 3 市场均衡视角([[竞争性市场均衡]] / [[一般均衡]])

- **半导体行业的混合行业类型**:NVIDIA 所属的行业历史上是 [[完全竞争行业类型|increasing-cost]](晶圆厂资本密集、ASML EUV 光刻机稀缺)+ decreasing-cost(Moore 定律学习曲线、共享 EDA 工具生态)的混合。教材的静态三分法无法捕捉这一动态。
- **长期供给曲线的非常规性**:AI 芯片市场的 LR 供给不是水平(constant-cost)或正斜率(increasing-cost),而是**负斜率且叠加网络效应**——CUDA 生态使在位厂商成本持续下降,但新进入者面临极高壁垒。这是 decreasing-cost 的极端形式,[[长期供给曲线]] 的教材几何无法表达。
- **国际贸易中的"大国"模型**:NVIDIA 在 AI 加速器市场占 >80% 份额,其定价策略影响全球算力成本。用 [[小国-大国贸易模型]] 的"大国最优关税"框架反推:下游国家(进口算力的国家)面临"最优进口关税"动机以改善贸易条件——但技术封锁 / 出口管制使这一框架更复杂。
- **一般均衡中的风险维度**:半导体供应链受地缘政治风险(台海、中美技术脱钩)冲击。Arrow-Debreu [[一般均衡-风险版]] 的"状态相依商品"框架可把"芯片断供"作为特定状态,定价其状态价格 $\pi_{断供}$。Stern 2007 气候风险框架可迁移至此。

### Batch 4 外部性视角([[市场失灵：外部性]])

- **算力生产的负外部性**:1 GW 数据中心的能耗外部性([[生产外部性]])——电力来自化石燃料 → 碳排放;冷却系统消耗大量淡水 → 水资源外部性。NVIDIA 声称"每瓦 Token 吞吐最高"等价于把外部性内部化到厂商成本函数,但 Token 消费者支付的单价不包含碳社会成本 → [[Pigou税]]框架下应对算力征收碳税以矫正。
- **供应链外部性**:GPU 制造涉及稀土开采(环境破坏)、晶圆厂化学品处理(水污染)、电子垃圾(消费外部性)。这些外部性分散在全球供应链中([[市场缺失]]——"污染权"跨国界难以界定) → Coase 定理的谈判解决不可行。
- **正外部性(网络效应)**:CUDA 生态 = 开发者网络的正外部性——每个新开发者使 CUDA 对所有现有开发者更有价值([[消费外部性]]中的网络外部性)。这与 [[规模报酬]] 的 IRS 叠加,使 NVIDIA 市场趋向自然垄断(Ch 23-25 范围)。

### Batch 5 不完全竞争视角([[不完全竞争与博弈论]])

- **GPU 市场的寡头结构**：NVIDIA 占 AI 加速器市场 >80% 份额 → [[垄断定价]] 适用。$MR = MC < P$ → 价格高于边际成本 → 消费者剩余被攫取。CUDA 生态系统的网络效应构成 [[进入壁垒]]——新进入者（如 AMD ROCm）面临极高的开发者迁移成本。
- **数据中心的买方集中度**：60% 收入来自前五大云厂商 → 云厂商作为买方拥有议价权（oligopsony）。NVIDIA 与超大客户的关系是**双边垄断/寡头**——定价通过议价而非市场出清决定，超出标准垄断模型的单一定价者假设。
- **合谋与卡特尔风险**：NVIDIA 与台积电、三星的产能分配协议可能具有 [[合谋与卡特尔]] 特征——通过限制产量维持高价。但芯片制造的资本密集性和技术复杂性使显性合谋困难，更可能表现为默契合谋（tacit collusion）。
- **进入威慑**：NVIDIA 的 CUDA 飞轮（装机量 → 开发者 → 算法 → 装机量）是经典的 [[进入威慑]] 策略——通过积累不可逆的网络效应，使潜在进入者预期进入后利润为负。
