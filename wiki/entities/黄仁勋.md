# 黄仁勋

## 基本信息

- **英文名**：Jensen Huang
- **职务**：[[NVIDIA]] 创始人兼首席执行官
- **荣誉**：美国工程院院士
- **演讲场合（本 Wiki 收录）**：NVIDIA GTC 2026 主题演讲（2026-03-16）

## 演讲核心论点

- 把 NVIDIA 定位从"芯片公司"重塑为"AI 基础设施和工厂公司"。
- 提出 **[[Token工厂经济学]]**：未来数据中心是"生产 Token 的工厂"，每瓦 Token 吞吐量决定商业命脉。
- 给出 **2027 年至少 1 万亿美元 AI 算力需求**预期，并称 60% 来自前五大超大型云服务商，40% 来自主权云、企业、工业、机器人、边缘计算。
- 阐述 [[推理拐点]] 与 [[Agent与AaaS]]：AI 从感知/生成进化到推理/行动，每一家 SaaS 都将变成 AaaS。
- 介绍下一代系统 [[Vera Rubin]]、对 [[Groq]] 的整合、以及共封装光学（CPO）路线图。
- 把 [[OpenClaw]] 类比为"智能体计算机的操作系统"，并发布企业版 NeMo Claw 参考设计。
- 描绘"年薪 + Token 配额"的硅谷招聘新形态。

## 关键引用

> "在固定的功率下，谁的每瓦 Token 吞吐量最高，谁的生产成本就最低。"
> "未来公司里的每一位工程师都将拥有年度 Token 预算……入职附带多少 Token 配额，已经成为硅谷的新晋招聘话题。"

## 利益相关披露

- 黄仁勋作为 [[NVIDIA]] 创始人，其演讲中对算力需求规模、性能倍数（如 35×、350×）的论断主要出自 NVIDIA 自身或友好分析机构（Semi Analysis 等），需以独立基准（MLPerf 等）交叉验证。
- 演讲发布后 NVIDIA 股价当日涨超 4.3%。
