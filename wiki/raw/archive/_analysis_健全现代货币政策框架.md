## 二、核心概念（建议页面）

### 中国货币政策框架（Batch 主轴，新增 8）

1. [[现代货币政策框架]] — **本文中枢概念**；包含"目标 / 工具 / 传导"三组件；区别于 Mankiw 教材一般理论。
2. [[跨周期政策设计]] — 2020 后中国央行新提概念；区别于"逆周期调节"（counter-cyclical）；强调中长期匹配而非短期对冲。
3. [[M2与社会融资规模]] — 中国货币政策中介目标；"基本匹配"原则（≈ 名义经济增速）；与 Mankiw 货币数量论 / Taylor 规则的混合体。
4. [[社会融资规模]] — 2011 年人民银行创设的中国独有指标；涵盖银行表内 + 表外 + 直接融资。
5. [[央行政策利率体系-中国]] — 双轨结构：OMO 利率（短期）+ MLF 利率（中期）；与美联储联邦基金利率单一目标的差异。
6. [[利率市场化改革-中国]] — "MLF→LPR→贷款利率"市场化传导路径；2019-08 LPR 改革节点。
7. [[人民币汇率市场化]] — "破7"事件（2019-08）；汇率自动稳定器功能；离岸人民币央票稳定预期机制。
8. [[现代中央银行制度]] — 上位概念，包含"现代货币政策框架 + 金融基础设施 + 系统性风险防控 + 国际治理"四组件。

### 货币政策工具（新增 7）

9. [[LPR贷款市场报价利率]] — 2019-08 改革；MLF + 加点机制；嵌入 FTP（内部资金转移定价）；2020-03~08 存量浮动利率贷款定价基准转换。
10. [[MLF中期借贷便利]] — 中期政策利率工具；"中期"通常 1 年；2014 创设。
11. [[OMO公开市场操作-中国]] — 短期政策利率工具；7 天逆回购为主；与美联储 OMO 同名异实（中国不直接调节联邦基金利率，调节短端政策利率）。
12. [[SLF常备借贷便利]] — 利率走廊上限；银行主动申请的流动性工具。
13. [[CBS央行票据互换]] — 2019 创设；为银行永续债提供流动性支持；解决资本工具的二级市场流动性。
14. [[再贷款再贴现]] — 结构性货币政策工具；定向支持小微 / 民营 / 三农 / 抗疫等。
15. [[结构性货币政策工具]] — 总称；包含 TMLF / 抗疫保供再贷款（3000 亿）/ 复工复产再贷款（5000 亿）/ 普惠性再贷款再贴现（1 万亿）/ 普惠小微贷款延期支持工具 / 普惠小微信用贷款支持计划等。

### 监管与制度（新增 4）

16. [[宏观审慎评估MPA]] — 中国央行宏观审慎工具；对银行货币创造的前瞻性引导。
17. [[央行三大约束-流动性资本利率]] — 本文核心方法论；区别于 Mankiw 的"准备金 + OMO + 贴现率"传统三工具叙事。
18. [[永续债银行资本工具]] — 2018+ 创设；解决银行资本约束；CBS 配套。
19. [[财政赤字货币化]] — "央行和财政两个钱袋子"分立原则；防止 monetary financing；与 MMT / 现代货币理论形成对照。

### 政治经济（新增 1）

20. [[新发展格局]] — "国内大循环为主体、国内国际双循环相互促进"；货币政策的政治经济背景。

## 四、矛盾发现

### 与 Mankiw 9e 教材的核心矛盾

1. **货币创造机制（[CONTRADICTION] 重要级别：高）**
   - Mankiw 9e Ch 4：基础货币 → 货币乘数 → 广义货币（外生货币论）
   - 孙国峰文：**"在现代信用货币体系下，银行通过贷款等资产扩张方式创造存款，是货币创造的直接主体"**（内生货币论）
   - 中国央行实质上接受了 BoE 2014《Money Creation in the Modern Economy》（McLeay-Radia-Thomas）的"loans create deposits"视角，与 Mankiw 主流教材形成对立。
   - **政策含义差异**：Mankiw 框架下央行通过 $M_0$ + $\rho$ 控制 $M$；孙国峰框架下央行通过流动性 / 资本 / 利率三约束影响银行**主动**创造的货币。

2. **货币政策中介目标（[CONTRADICTION] 中等）**
   - Mankiw 主流：通胀目标制（IT）+ Taylor 规则
   - 孙国峰：M2 + 社融"基本匹配"名义经济增速；保留数量目标元素，弱化通胀目标。
   - 这是 1990s Volcker 后被主流抛弃的"中介目标—操作目标"双层结构在中国的延续。

3. **跨周期 vs 逆周期（[CONTRADICTION] 中等）**
   - Mankiw 14-15 章：稳定化政策本质是"counter-cyclical"
   - 孙国峰：**"跨周期政策设计"** —— 跨越经济周期，平滑政策力度，**避免**短期对冲带来的政策反复。
   - 这是中国 2020 后的政策语言创新，可能受 BIS Borio (2014) 金融周期理论影响。

4. **存款基准利率"压舱石"（内在张力）**
   - 文章一方面强调 LPR 市场化、"打破隐性下限"；另一方面强调存款基准利率作为"压舱石"。
   - 这是渐进式改革的产物，但理论上不一致（不可能同时存在完全市场化贷款利率和管制存款利率）。

### 文中默认假设的潜在问题

5. **"反映潜在产出的名义经济增速"作为锚**
   - 默认存在可估计的潜在产出。
   - 但 Cambridge Capital Controversy（已建 [[Cambridge Capital Controversy]]）已证伪加总生产函数；中国 2018 后潜在增速分歧巨大（社科院 5%-7% 估计差距）。
   - 此锚定方式对 estimation error 高度敏感。

6. **"基本匹配"操作弹性**
   - "略高或略低"、"按年度"、"中长期概念"——给央行留足相机抉择空间。
   - 这与 Kydland-Prescott (1977)「规则优于相机抉择」相反；属于本 Wiki 已建 [[规则与相机抉择]] / [[时间不一致性]] 中的"相机抉择"立场。

## 六、反面论点与数据空白（发散性检查初稿）

> 概念页须包含此小节，下列内容将拆分到对应概念页。

### 货币政策框架的"现代性"质疑

1. **MMT / 后凯恩斯主义视角**：
   - "防止财政赤字货币化"是反 MMT 立场，但 PSL（抵押补充贷款）、抗疫特别国债、2024-25 万亿超长期特别国债**已部分模糊**央地财政货币边界。
   - Wray 2012 / Kelton 2020：主权货币国家"两个钱袋子"分立是制度化幻觉，技术上央行总是支持财政融资（结算系统）。
   - 中国央行选择"防止"而非"承认"，是政治选择而非技术约束。

2. **货币内生论 vs 外生论的内部张力**：
   - 文章承认银行资产扩张创造存款（内生论），但同时保留"基础货币-准备金-货币乘数"工具（外生论）。
   - Borio (BIS 2017)：央行政策语言与现代银行学不一致是普遍问题，中国版本尤其矛盾。

3. **Cambridge Capital Controversy**：
   - "潜在产出的名义经济增速"依赖加总生产函数，已被 Sraffa-Robinson 证伪。
   - 中国 2018+ 潜在增速估计分歧（许宪春 vs 林毅夫 vs 蔡昉 vs 朱嘉明）说明此锚的脆弱性。

4. **规则 vs 相机抉择**：
   - Kydland-Prescott (1977) / Sargent-Wallace 时间不一致性论证支持规则；
   - 中国"灵活精准、合理适度" + "搞好跨周期政策设计" + "创造性应对"是典型相机抉择立场；
   - 新古典反驳：政策时滞 + 预测困难（[[政策时滞与预测困难]] 已建）。

### 工具有效性质疑

5. **LPR 改革的实证争议**：
   - 殷剑峰 (2020) / 张明 (2021)：LPR 改革后银行间贷款利率分化加大，传导效率有限。
   - 银行 FTP 改革滞后于 LPR；存款基准"压舱石"挤压银行净息差。
   - "打破隐性下限"是否真实达到？需要银行业实际定价数据。

6. **结构性货币政策工具的精准性**：
   - 黄益平等：再贷款 / 再贴现的"精准滴灌"易被银行"包装"使用。
   - 普惠小微贷款增速 "高完成度" 可能是统计调整 + 政策性贷款挤出市场化贷款。

7. **永续债 + CBS 的金融稳定后果**：
   - 1.2 万亿永续债集中在大型银行 vs 中小银行资本约束依然紧张。
   - CBS 工具的资产负债表后果（央行拿到银行永续债，承担信用风险）未充分讨论。

8. **不可能三角的中国变体**：
   - 周小川 (2020)：资本项目部分管制 + 浮动汇率 + 货币政策独立性"实质上是 Mundell-Fleming 不可能三角的中国特色变体"，长期张力存在。
   - 2020-2022 中美利差倒挂 + 资本外流压力是约束的体现。

9. **Taylor 规则估计**：
   - 丁志杰 (2019) / Sun-Mehrotra (BIS 2017)：1995-2017 年中国 PBoC 反应函数对通胀反应系数 < 1，违反 Taylor 原则。
   - 可能存在"金融稳定动机"或"汇率稳定动机"覆盖了通胀反应。

### 政治经济背景

10. **央行独立性问题**：
    - 文章引用习近平表述、强调党的领导。
    - 西方央行独立性范式（Rogoff 1985 / Alesina-Summers 1993）vs 中国央行作为国务院组成部门的体制差异。
    - 这不是简单"好坏"问题，而是体制选择的实质差异。

11. **预测后视：2021-2025 政策实践**：
    - 文章预见"防止信用收缩"风险，但未预见 **2021-2022 房地产去杠杆危机** 与 **2023-2024 通缩压力**。
    - "基本匹配"在 2022-2024 出现"M2 增速持续高于名义 GDP"现象（剪刀差），但通胀低迷——简单数量论失效证据，需 [BIAS] 标注。
    - 2024 货币政策框架"二次改革"（潘功胜 2024 陆家嘴论坛）已明显修订本文部分立场（如淡化 M2 目标）。

### 数据空白

12. **永续债微观结构**：发行结构（按银行规模 / 区域）、二级市场流动性（CBS 实际使用率）、永续债持有人结构。
13. **直达工具的微观证据**：普惠小微贷款延期工具的违约率、信用贷款支持计划的精准度评估。
14. **离岸央票实证**：发行规模、对离岸 CNH 汇率的影响估计。
15. **企业"财务中性"实证**：套保比例、汇率风险管理工具使用率、外汇衍生品市场深度。
16. **中美 Taylor 规则系数对照**（Sun-Mehrotra 2017 起）的**当代更新**（2018-2024）。
17. **2022-2024 M2 / 社融 vs 名义 GDP 剪刀差现象**（"基本匹配"原则的实证违反）。

**方案 A（推荐）**：在 `wiki/foundations/macroeconomics/` 现有四子目录下新增中国相关页面，与 Mankiw 教材页面并列。理由：
- 保持 foundations 单一根目录，避免多线索分裂。
- 中国实践本质上是宏观经济学 foundations 的本土实例，逻辑上属于同一层。
- 通过页面命名（如 `LPR贷款市场报价利率.md`、`OMO公开市场操作-中国.md`）和 tags（`china-monetary-policy`）区分。
- 主题页 [[中国货币政策框架]] 作为入口，类似 [[宏观经济学共识与分歧]] 的中枢导览。

**方案 B**：新建 `wiki/foundations/china-monetary-policy/` 子目录。
- 优点：明确分离教材理论与本土实践。
- 缺点：与现有 `microeconomics`/`macroeconomics` 二分法不一致；未来若有"中国微观经济学"需要再分裂。
