## 5. 知识缺口（合并）

- 中等规模陷阱与 Token 工厂经济学**均缺独立量化证据**。
- 两文均缺**劳动伦理与监管**的系统讨论：算法用工合规、Token 计价的合同形态、Agent 自主决策的责任归属。
- "AI 释放个体"主张与"算法压榨"现实之间的弥合机制（如平台议价权、算法解释权）尚无答案。
- 在中国 / 欧盟 / 美国的差异化监管环境下，这套愿景的**适配条件**未被讨论。
- 能耗、碳排、水耗与 AI 工厂经济学的兼容性需要更多实证。

## 7.5 Batch 4 市场失灵视角（Ch 18-22）

Batch 4 的 [[市场失灵：外部性]] 和 [[市场失灵：信息不对称]] 为两条叙事提供了第一福利定理失效模式的系统分析：

| 叙事议题 | 市场失灵类型 | 微观经济学对应 |
|---|---|---|
| 算法压榨（美团骑手） | 信息不对称 + 外部性 | [[逆向选择]]（骑手质量不可观测）+ [[信息筛选]]（算法作为筛选工具）+ [[生产外部性]]（交通事故社会成本） |
| Token 工厂能耗 | 负外部性 | [[生产外部性]]（碳排放/水耗）+ [[Pigou税]]（算力碳税提案）+ [[市场缺失]]（污染权未定价） |
| 平台数据垄断 | 信息不对称 + 市场势力 | [[信号传递]]（用户通过行为发送信号）+ [[信息筛选]]（平台通过算法筛选用户）+ 垄断买方（Ch 23-25） |
| 开源 AI 模型 | 正外部性 + 公共品 | [[消费外部性]]（网络效应）+ 公共品供给不足（Ch 27） |
| 数据隐私 | 负外部性 + 信息不对称 | [[消费外部性]]（个人信息泄露）+ [[市场缺失]]（数据产权未界定） |

关键洞见：两位作者的叙事在 Batch 4 框架下可被诊断为"第一福利定理的多重失效"——但这不意味着"市场完全失效"或"政府必须全面干预"。[[Coase定理]] 提示：若产权可界定且交易成本低，市场可自行解决部分外部性；[[信号传递]] 和 [[信息筛选]] 提示：信息不对称可通过机制设计缓解。政策的艺术在于识别哪些失灵需要干预、哪些可通过制度创新自愈。

## 7.6 Batch 5 不完全竞争视角（Ch 23-28）

Batch 5 的 [[不完全竞争与博弈论]] 和 [[公共品与政治经济]] 为两条叙事提供了"市场势力"和"集体决策"的分析工具：

| 叙事议题 | 不完全竞争类型 | 微观经济学对应 |
|---|---|---|
| 平台垄断买方（美团骑手） | 垄断买方 + 双边市场 | [[进入壁垒]]（算法锁定）+ [[Stackelberg竞争]]（平台先动优势）+ 双边市场定价 |
| 云服务商寡头竞争（Token工厂） | 寡头竞争 | [[Cournot竞争]]（产能投资）+ [[Bertrand竞争]]（价格匹配）+ [[合谋与卡特尔]]（默契合谋） |
| NVIDIA 垄断 / 进入威慑 | 垄断 + 网络效应 | [[垄断定价]]（$MR = MC < P$）+ [[进入壁垒]]（CUDA 飞轮）+ [[自然垄断]]（IRS） |
| 开源 AI 模型 | 公共品 + 正外部性 | [[公共品]]（非竞争性、非排他性）+ [[搭便车问题]]（谁为训练付费？） |
| 算法治理的政治经济 | 寻租 + 社会选择 | [[寻租]]（平台俘获监管）+ [[Arrow不可能定理]]（算法规则的民主制定不可能） |

关键洞见：Batch 5 揭示"算法压榨"不仅是信息不对称（Batch 4 的诊断），更是**市场势力**（垄断买方、寡头竞争、进入壁垒）的结果。美团骑手的低工资不仅因为平台知道骑手更多信息，更因为平台作为垄断买方可压低工资；NVIDIA 的高定价不仅因为产品优秀，更因为 CUDA 生态系统的网络效应构成进入壁垒。政策干预需同时针对信息不对称（透明度、可携带性）和市场势力（反垄断、最低工资、进入促进）。

## 7.7 Batch 6 行为经济学视角（Ch 29-30）

Batch 6 的 [[行为经济学与规范经济学]] 和 [[市场、市民社会与政府的平衡]] 为两条叙事提供了"心理偏差"和"制度失灵对称性"的分析工具：

| 叙事议题 | 行为经济学机制 | 微观经济学对应 |
|---|---|---|
| 骑手自动接单默认选项 | [[现时偏向偏好]] + [[参照依赖偏好与损失厌恶\|现状偏好]] | 自动接单 = [[自由主义家长主义]] 的 nudge；骑手保留退出权 |
| 高峰奖励的框架设计 | [[框架效应]] | 平台以"奖励"而非"正常工资削减"呈现价差，利用收益域vs损失域的不对称 |
| 超时罚款的损失厌恶放大 | [[参照依赖偏好与损失厌恶]] | 超时罚款 = 损失（心理权重 2.25×），骑手为避免损失而接受更多订单 |
| Token 工厂的分层定价默认 | [[框架效应]] + [[参照依赖偏好与损失厌恶]] | 默认高配额套餐利用现状偏好锁定用户 |
| 算法治理的三制度平衡 | [[三条腿凳子]] | 市场（平台定价）+ 市民社会（骑手工会/社区）+ 政府（最低工资/监管）的三重失灵 |

关键洞见：Batch 6 揭示"算法压榨"不仅是信息不对称（Batch 4）和市场势力（Batch 5），更是**心理偏差**的系统利用——平台通过默认选项设计、框架选择和损失厌恶放大，使骑手在"自愿"的表象下做出违背自身长期利益的决策。这与 [[自由主义家长主义]] 的"助推"逻辑同源但方向相反：自由主义家长主义假设政策设计者是 benevolent，而平台算法的设计目标是利润最大化。政策回应需从"禁止"转向"选择架构监管"——如强制平台展示多方案对比（打破框架垄断）、允许骑手自定义默认设置（恢复退出权）、设置罚款上限（限制损失厌恶的过度利用）。

### 制度失灵的对称性

Batch 6 的 [[三条腿凳子]] 框架提示：算法治理问题不能仅靠政府监管解决——
- **市场失灵**：平台利用心理偏差 + 垄断势力压榨骑手；
- **市民社会失灵**：骑手缺乏有效的集体行动机制（工会弱化、流动性高）；
- **政府失灵**：监管者面临信息不对称（算法黑箱）和寻租风险（平台俘获）。

三制度均需改进：市场侧需要选择架构透明化；市民社会侧需要骑手组织化；政府侧需要算法审计和可解释性标准。
